# 海水资源的综合利用

> [!abstract] 概览
> 海水中含有大量的氯化钠及溴、镁、碘等元素，是重要的液体矿产资源。本笔记讲解**海水提溴**（氧化—吹出—富集）、**海水提镁**（沉淀—转化—电解）的流程与原理，以及**海水淡化**与**粗盐提纯**的方法。核心是运用氧化还原反应和元素化合物知识设计物质分离、富集的流程。

## 核心概念

### 1. 海水资源概况

- 海水中溶解有大量 $\ce{NaCl}$、$\ce{MgCl2}$、$\ce{NaBr}$、$\ce{NaI}$ 等盐类，溴和镁主要以**化合态**存在于海水中。
- 海水中溴元素含量很低，直接蒸馏无法得到溴单质，必须**富集**。

### 2. 海水提溴（海水中溴离子 $\ce{Br^-}$ → 溴单质 $\ce{Br2}$）

**原理**：溴离子被氧化剂氧化为溴单质。
$$\ce{Cl2 + 2Br^- -> 2Cl^- + Br2}$$

**流程（"氧化—吹出—富集"）**：
1. **酸化**：用硫酸酸化海水（抑制 $\ce{Cl2}$ 与水的反应）。
2. **氧化**：通入 $\ce{Cl2}$ 把 $\ce{Br^-}$ 氧化为 $\ce{Br2}$：$\ce{Cl2 + 2NaBr -> 2NaCl + Br2}$。
3. **吹出**：用热空气（或水蒸气）把 $\ce{Br2}$ 从溶液中吹出（溴易挥发）。
4. **吸收（富集）**：用还原剂（如 $\ce{SO2}$）吸收溴蒸气，使溴重新变为溴离子，浓度大大提高：$\ce{Br2 + SO2 + 2H2O -> 2HBr + H2SO4}$。
5. **再氧化**：再次通入 $\ce{Cl2}$ 氧化得到高浓度的溴：$\ce{Cl2 + 2HBr -> 2HCl + Br2}$。
6. **蒸馏**：蒸馏得到液溴。

> [!note] 为什么"两步氧化"
> 海水中溴离子浓度太低，一次氧化后溴量少。通过"氧化→吹出→还原吸收→再氧化"，实现了溴的**富集**，这是工业流程设计的核心思想。

### 3. 海水提镁

**原料**：海水（含 $\ce{Mg^{2+}}$）、石灰乳、盐酸。

**流程**：
1. **沉淀**：向海水（或卤水）中加入**石灰乳**（$\ce{Ca(OH)2}$）使 $\ce{Mg^{2+}}$ 沉淀：
$$\ce{MgCl2 + Ca(OH)2 -> Mg(OH)2 v + CaCl2}$$
（不选 $\ce{NaOH}$ 是考虑成本，石灰乳便宜易得。）
2. **溶解**：过滤得到 $\ce{Mg(OH)2}$，加入盐酸转化为 $\ce{MgCl2}$：
$$\ce{Mg(OH)2 + 2HCl -> MgCl2 + 2H2O}$$
3. **浓缩、结晶**：得到 $\ce{MgCl2·6H2O}$，在 $\ce{HCl}$ 气流中加热脱水得无水 $\ce{MgCl2}$（防止水解）。
4. **电解**：电解熔融 $\ce{MgCl2}$：
$$\ce{MgCl2 ->[电解] Mg + Cl2 ^}$$

### 4. 海水淡化

- 方法：**蒸馏法**（加热使水汽化再冷凝）、**电渗析法**、**离子交换法**、**反渗透法（膜法）**等。
- 原理：除去海水中的可溶性盐类，获得淡水。

### 5. 粗盐的提纯（海水晒盐）

- 粗盐中含 $\ce{Ca^{2+}}$、$\ce{Mg^{2+}}$、$\ce{SO4^{2-}}$ 等杂质离子。
- 依次加入**过量 $\ce{BaCl2}$**（除 $\ce{SO4^{2-}}$）、**过量 $\ce{NaOH}$**（除 $\ce{Mg^{2+}}$）、**过量 $\ce{Na2CO3}$**（除 $\ce{Ca^{2+}}$ 及过量的 $\ce{Ba^{2+}}$），过滤后再加**适量盐酸**调节 pH 除多余 $\ce{CO3^{2-}}$、$\ce{OH^-}$。
- 加试剂顺序口诀："$\ce{BaCl2}$ → $\ce{NaOH}$ → $\ce{Na2CO3}$ → 过滤 → 盐酸"（$\ce{BaCl2}$ 必须在 $\ce{Na2CO3}$ 之前，$\ce{Na2CO3}$ 在过滤前）。

> [!warning] 加药顺序
> $\ce{BaCl2}$ 必须在 $\ce{Na2CO3}$ 之前加入，因为过量 $\ce{Ba^{2+}}$ 要靠 $\ce{CO3^{2-}}$ 除去；$\ce{Na2CO3}$ 必须在过滤前加，因为生成的 $\ce{BaCO3}$、$\ce{CaCO3}$ 沉淀要过滤除去；盐酸最后加。

## 典型例题

### 例题 1：海水提溴流程分析

**题目**：海水提溴时，为什么要先用 $\ce{Cl2}$ 氧化、再用热空气吹出、又用 $\ce{SO2}$ 吸收，最后再通 $\ce{Cl2}$？写出相关方程式。

**分析**：海水中溴离子浓度低，直接蒸馏无法得到溴。流程通过"氧化→吹出→还原吸收（富集）→再氧化"提高溴的浓度。

**解答**：
- 第一步氧化：$\ce{Cl2 + 2NaBr -> 2NaCl + Br2}$；
- 用热空气吹出 $\ce{Br2}$（溴易挥发）；
- 吸收富集：$\ce{Br2 + SO2 + 2H2O -> 2HBr + H2SO4}$（溴又变回 $\ce{Br^-}$，浓度增大）；
- 再氧化：$\ce{Cl2 + 2HBr -> 2HCl + Br2}$，得到高浓度溴，再蒸馏。

**点评**：提溴流程的核心是"**富集**"——利用溴易挥发（吹出）和 $\ce{SO2}$ 还原（吸收）实现溴的浓缩。理解每一步的目的比死记方程式更重要。

### 例题 2：海水提镁流程

**题目**：由海水制备金属镁，写出"石灰乳沉淀→盐酸溶解→电解"三步反应方程式，并说明为什么不直接用 $\ce{NaOH}$ 沉淀。

**分析**：按流程逐一书写，沉淀用石灰乳（成本低）。

**解答**：
- 沉淀：$\ce{MgCl2 + Ca(OH)2 -> Mg(OH)2 v + CaCl2}$；
- 溶解：$\ce{Mg(OH)2 + 2HCl -> MgCl2 + 2H2O}$；
- 电解：$\ce{MgCl2 ->[电解] Mg + Cl2 ^}$。

不用 $\ce{NaOH}$ 的原因：$\ce{NaOH}$ 成本较高，工业上从经济角度选用来源广、价格低的石灰乳。

**点评**：海水提镁体现了"资源综合利用 + 经济性"思想。注意工业制镁电解的是熔融 $\ce{MgCl2}$（而非 $\ce{MgO}$，因 $\ce{MgO}$ 熔点太高）。

## 海水资源的其他利用与流程题方法

### 海水中的其他资源

- 食盐（$\ce{NaCl}$）：晒盐、制烧碱、纯碱、氯气（氯碱工业原料）。
- 碘：海带富含碘元素，用灼烧—浸取—氧化法提取碘。
- 镁、溴、钾盐、锂等：海水中含量丰富。

### 海带提碘（拓展）

1. 海带灼烧成灰 → 水浸取（$\ce{I^-}$ 进入溶液）。
2. 加入氧化剂（$\ce{H2O2}$ 或 $\ce{Cl2}$）把 $\ce{I^-}$ 氧化为 $\ce{I2}$。
3. 用有机溶剂（如 $\ce{CCl4}$）萃取碘，分液得碘的有机溶液。
4. 蒸馏回收有机溶剂、蒸发结晶得碘。

### 工艺流程题解题"四步法"

1. 明确原料与目标产物（原料中哪些成分，目标是什么）。
2. 拆解流程步骤，标注每步目的（除杂、转化、富集、分离）。
3. 写出关键方程式（氧化还原、复分解、电解）。
4. 检查"循环利用"与"环境保护"（母液循环、尾气处理）。

### 海水淡化的方法比较

| 方法 | 原理 | 特点 |
| --- | --- | --- |
| 蒸馏法 | 加热蒸发再冷凝 | 能耗高、产水纯 |
| 反渗透法 | 加压使水透过半透膜 | 能耗较低、广泛应用 |
| 电渗析法 | 离子在电场中迁移 | 同时可制盐 |

## 易错提醒

> [!warning] 常见错误
> - "直接蒸馏海水就能得到溴"❌ —— 海水中溴浓度太低，必须先氧化、吹出、富集。
> - "提溴第一步用 $\ce{Br2}$ 氧化 $\ce{Cl^-}$"❌ —— 顺序反了，是 $\ce{Cl2}$ 氧化 $\ce{Br^-}$（氯比溴活泼）。
> - "海水提镁用 $\ce{NaOH}$ 沉淀 $\ce{Mg^{2+}}$"❌ —— 工业上用**石灰乳**（$\ce{Ca(OH)2}$），成本低。
> - "电解 $\ce{MgO}$ 制镁"❌ —— 电解熔融 $\ce{MgCl2}$（$\ce{MgO}$ 熔点太高）。
> - "粗盐提纯中先加 $\ce{Na2CO3}$ 再加 $\ce{BaCl2}$"❌ —— $\ce{BaCl2}$ 必须在 $\ce{Na2CO3}$ **之前**加，过量 $\ce{Ba^{2+}}$ 由 $\ce{CO3^{2-}}$ 除去。
> - "海水淡化是化学变化"❌ —— 蒸馏、反渗透等主要是**物理变化**。
