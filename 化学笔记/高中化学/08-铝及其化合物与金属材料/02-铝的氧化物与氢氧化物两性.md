# 铝的氧化物与氢氧化物两性

> [!abstract] 概览
> $\ce{Al2O3}$ 与 $\ce{Al(OH)3}$ 是"两性"的典型代表——既溶于酸又溶于强碱。本笔记重点：两性氧化物/氢氧化物的概念与方程式、$\ce{Al(OH)3}$ 的制备（必须用氨水）、$\ce{Al^{3+}}$ 与 $\ce{AlO2^-}$ 的相互转化，以及**明矾净水**的原理。这是高考离子方程式、图像题、流程题的必考内容。

## 核心概念

### 什么是两性

- **两性氧化物**：既能与酸反应生成盐和水，又能与碱反应生成盐和水的氧化物，如 $\ce{Al2O3}$、$\ce{ZnO}$。
- **两性氢氧化物**：既能与酸反应，又能与强碱反应生成盐和水的氢氧化物，如 $\ce{Al(OH)3}$、$\ce{Zn(OH)2}$。
- 注意：$\ce{Al(OH)3}$ 只溶于**强碱**，不溶于弱碱（如氨水）。

### $\ce{Al(OH)3}$ 的两种电离方式

$\ce{Al(OH)3}$ 既能酸式电离，又能碱式电离：

- 碱式电离：$\ce{Al(OH)3 \rightleftharpoons Al^{3+} + 3OH^-}$（与酸反应促进此方向）
- 酸式电离：$\ce{Al(OH)3 \rightleftharpoons H+ + AlO2^- + H2O}$（与碱反应促进此方向）

这就是 $\ce{Al(OH)3}$ 两性的本质。

## 重点知识：$\ce{Al2O3}$

### 物理性质

- 白色难溶固体，**熔点很高**（约 $2054\ \degree\ce{C}$）。
- 天然的 $\ce{Al2O3}$ 晶体称为**刚玉**，硬度很大，可作磨料；含微量杂质时呈红宝石（含 $\ce{Cr^{3+}}$）、蓝宝石（含 $\ce{Fe^{2+}/Ti^{4+}}$）等颜色。

### 化学性质（两性氧化物）

- 与酸：$\ce{Al2O3 + 6H+ -> 2Al^{3+} + 3H2O}$
- 与强碱：$\ce{Al2O3 + 2OH^- -> 2AlO2^- + H2O}$
- 与酸、碱均反应，故为两性氧化物。

### 用途

- 冶炼铝的原料：$2\ce{Al2O3} \xrightarrow[冰晶石]{电解} 4\ce{Al} + 3\ce{O2 ^}$（冰晶石作助熔剂降低熔点）。
- 耐火材料（熔点高）。

> [!warning] 电解冶炼铝不用 $\ce{AlCl3}$
> 铝的冶炼采用**电解熔融 $\ce{Al2O3}$**（加冰晶石助熔），不电解 $\ce{AlCl3}$，因为 $\ce{AlCl3}$ 是共价化合物，熔融态不导电。

## 重点知识：$\ce{Al(OH)3}$

### 物理性质与用途

- 白色胶状沉淀，不溶于水。
- 可中和胃酸（抗酸药成分），净水，制铝盐。

### 化学性质（两性氢氧化物）

- 与酸：$\ce{Al(OH)3 + 3H+ -> Al^{3+} + 3H2O}$
- 与强碱：$\ce{Al(OH)3 + OH^- -> AlO2^- + 2H2O}$
- 受热分解：$2\ce{Al(OH)3} \xrightarrow{\Delta} \ce{Al2O3} + 3\ce{H2O}$

> [!warning] $\ce{Al(OH)3}$ 只溶于强碱
> $\ce{Al(OH)3}$ 能溶于 $\ce{NaOH}$、$\ce{KOH}$ 等强碱，但**不溶于氨水**（弱碱）。因此实验室制备 $\ce{Al(OH)3}$ 用氨水而不用 $\ce{NaOH}$，避免生成的 $\ce{Al(OH)3}$ 继续溶解。

### $\ce{Al(OH)3}$ 的制备

1. **铝盐 + 氨水**（实验室常用）：
   $$\ce{Al^{3+} + 3NH3.H2O -> Al(OH)3 v + 3NH4+}$$
2. **偏铝酸盐 + 通入 $\ce{CO2}$**：
   - 少量 $\ce{CO2}$：$2\ce{AlO2^-} + \ce{CO2} + 3\ce{H2O} -> 2\ce{Al(OH)3 v} + \ce{CO3^{2-}}$
   - 过量 $\ce{CO2}$：$\ce{AlO2^-} + \ce{CO2} + 2\ce{H2O} -> \ce{Al(OH)3 v} + \ce{HCO3^-}$

> [!tip] 为什么用氨水不用 $\ce{NaOH}$
> $\ce{Al(OH)3}$ 溶于强碱不溶于弱碱。若用 $\ce{NaOH}$，会继续反应：$\ce{Al(OH)3 + OH^- -> AlO2^- + 2H2O}$，得不到沉淀或沉淀部分溶解。故**制备 $\ce{Al(OH)3}$ 必须用氨水**。

### $\ce{Al^{3+}}$ 与 $\ce{AlO2^-}$ 的相互转化

- $\ce{Al^{3+} + 3OH^- -> Al(OH)3 v}$（碱少量）
- $\ce{Al^{3+} + 4OH^- -> AlO2^- + 2H2O}$（碱过量）
- $\ce{AlO2^- + H+ + H2O -> Al(OH)3 v}$（酸少量）
- $\ce{AlO2^- + 4H+ -> Al^{3+} + 2H2O}$（酸过量）
- 双水解：$\ce{3AlO2^- + Al^{3+} + 6H2O -> 4Al(OH)3 v}$（$\ce{Al3+}$ 与 $\ce{AlO2^-}$ 不共存）

> [!note] 铝的"量变"图像思维
> 向 $\ce{AlCl3}$ 溶液中滴加 $\ce{NaOH}$：先产生沉淀（$\ce{Al(OH)3}$），后沉淀溶解（生成 $\ce{AlO2^-}$）。沉淀量随 $\ce{NaOH}$ 量变化呈现"**先增后减**"的图像，沉淀最多时 $\ce{n(Al^{3+}) : n(OH^-) = 1 : 3}$，恰好溶解完时 $\ce{n(Al^{3+}) : n(OH^-) = 1 : 4}$。

## 重点知识：明矾净水

- 明矾化学式：$\ce{KAl(SO4)2 . 12H2O}$（十二水合硫酸铝钾），是**复盐**。
- 电离：$\ce{KAl(SO4)2 -> K+ + Al^{3+} + 2SO4^{2-}}$
- 净水原理：$\ce{Al^{3+}}$ 水解生成氢氧化铝**胶体**：
  $$\ce{Al^{3+} + 3H2O \rightleftharpoons Al(OH)3(胶体) + 3H+}$$
  $\ce{Al(OH)3}$ 胶体具有吸附性，能吸附水中悬浮的杂质并沉降，从而净水。

> [!warning] 明矾净水不是杀菌消毒
> 明矾净水靠 $\ce{Al(OH)3}$ 胶体的**吸附**作用除去悬浮杂质，属于物理/胶体化学范畴，**不能杀菌消毒**，也不能除去可溶性杂质（如重金属离子）。"净水"≠"杀菌"。

## 典型例题

### 例题 1：$\ce{Al(OH)3}$ 的制备

**题目**：下列试剂中，能用于制备 $\ce{Al(OH)3}$ 且沉淀不会溶解的是（ ）
A. $\ce{AlCl3}$ 溶液与 $\ce{NaOH}$ 溶液
B. $\ce{AlCl3}$ 溶液与氨水
C. $\ce{NaAlO2}$ 溶液与 $\ce{NaOH}$ 溶液
D. $\ce{AlCl3}$ 溶液与 $\ce{KOH}$ 溶液

**分析**：$\ce{Al(OH)3}$ 溶于强碱（$\ce{NaOH}$、$\ce{KOH}$）但不溶于弱碱（氨水）。A、D 用强碱会继续溶解沉淀；C 中 $\ce{NaAlO2}$ 与 $\ce{NaOH}$ 不反应，无法生成沉淀；B 中氨水是弱碱，$\ce{Al^{3+} + 3NH3.H2O -> Al(OH)3 v + 3NH4+}$，沉淀不溶解。

**解答**：答案：**B**。

**点评**：制备 $\ce{Al(OH)3}$ 首选"铝盐 + 氨水"，这是高考实验题的标准答案。强碱会让 $\ce{Al(OH)3}$ 溶解，弱碱（氨水）不能溶解。

### 例题 2：$\ce{Al3+}$ 与碱的量关系

**题目**：向 $100\ \ce{mL}$ 含 $0.1\ \ce{mol}$ $\ce{AlCl3}$ 的溶液中逐滴加入 $\ce{NaOH}$ 溶液，当生成沉淀的质量最大时，消耗 $\ce{NaOH}$ 的物质的量为（ ）
A. $0.1\ \ce{mol}$　　B. $0.3\ \ce{mol}$　　C. $0.4\ \ce{mol}$　　D. $0.5\ \ce{mol}$

**分析**：沉淀最多时，$\ce{Al^{3+}}$ 恰好全部转化为 $\ce{Al(OH)3}$：$\ce{Al^{3+} + 3OH^- -> Al(OH)3 v}$。$0.1\ \ce{mol}$ $\ce{Al^{3+}}$ 需要 $0.3\ \ce{mol}$ $\ce{NaOH}$。若继续加 $\ce{NaOH}$，沉淀溶解：$\ce{Al(OH)3 + OH^- -> AlO2^- + 2H2O}$。

**解答**：生成沉淀最多时 $\ce{n(NaOH) = 3n(Al^{3+}) = 0.3\ \ce{mol}}$，答案：**B**。

**点评**：沉淀最多时"铝离子 : 氢氧根 = 1 : 3"；沉淀恰好全部溶解时"铝离子 : 氢氧根 = 1 : 4"。这两个计量关系是图像题的核心。

## 易错提醒

> [!warning] 易错点清单
> 1. $\ce{Al(OH)3}$ 只溶于强碱，不溶于弱碱（氨水）——制备必须用氨水。
> 2. $\ce{Al2O3}$ 熔点极高，冶炼铝用电解熔融 $\ce{Al2O3}$，不电解 $\ce{AlCl3}$。
> 3. 明矾净水是 $\ce{Al^{3+}}$ 水解生成胶体的吸附作用，不能杀菌消毒。
> 4. $\ce{Al3+}$ 与 $\ce{AlO2^-}$ 因双水解不能大量共存：$\ce{3AlO2^- + Al^{3+} + 6H2O -> 4Al(OH)3 v}$。
> 5. $\ce{Al(OH)3}$ 受热分解生成 $\ce{Al2O3}$ 和 $\ce{H2O}$，条件"加热"。
> 6. 偏铝酸根化学式是 $\ce{AlO2^-}$，不要写成 $\ce{Al(OH)4^-}$（高中习惯写 $\ce{AlO2^-}$）。
