# 离子反应与离子方程式

> [!abstract] 概览
> 有离子参加的反应叫**离子反应**，大多在水溶液中进行。用实际参加反应的离子符号表示反应的式子叫**离子方程式**。
> 离子方程式既能表达一个具体反应，也能表达一类反应的共同本质（如 $\ce{H+ + OH- -> H2O}$ 表示强酸与强碱的中和）。
> 本章核心是掌握离子方程式的"**写、拆、删、查**"四步法，并攻克高考难点——**与量有关**的离子方程式。

## 核心概念

### 1. 离子反应的实质

离子反应的实质是溶液中某些离子的浓度发生**减小**。只要反应能使自由离子的种类或数目减少，反应即可发生：

1. 生成难溶物（沉淀）；
2. 生成难电离物质（弱电解质、水）；
3. 生成挥发性物质（气体）；
4. （后续）发生氧化还原反应、络合反应。

### 2. 离子方程式与化学方程式的关系

| | 化学方程式 | 离子方程式 |
| --- | --- | --- |
| 表示对象 | 具体的一个反应 | 一类反应的共性 |
| 书写特点 | 用化学式 | 强电解质拆成离子 |
| 示例 | $\ce{NaOH + HCl -> NaCl + H2O}$ | $\ce{H+ + OH- -> H2O}$ |

> [!tip] 离子方程式的意义
> $\ce{H+ + OH- -> H2O}$ 表示所有强酸与强碱生成可溶性盐的中和反应；而 $\ce{CH3COOH + OH- -> CH3COO- + H2O}$ 表示弱酸参与的中和，弱酸不拆。

## 重点知识

### 1. 离子方程式的书写四步法

以 $\ce{CuSO4}$ 溶液与 $\ce{Ba(OH)2}$ 溶液反应为例：

**（1）写**：写出化学方程式
$$\ce{CuSO4 + Ba(OH)2 -> Cu(OH)2 v + BaSO4 v}$$

**（2）拆**：把易溶且完全电离的物质拆成离子
$$\ce{Cu^2+ + SO4^2- + Ba^2+ + 2OH- -> Cu(OH)2 v + BaSO4 v}$$

**（3）删**：删去两边不参加反应的相同离子（本例无）

**（4）查**：检查原子个数守恒、电荷守恒、是否符合实际反应
$$\ce{Cu^2+ + SO4^2- + Ba^2+ + 2OH- -> Cu(OH)2 v + BaSO4 v}$$

### 2. 拆写规则（核心！）

**拆成离子的**（强电解质、且溶液状态）：
- 强酸：$\ce{HCl}$、$\ce{H2SO4}$、$\ce{HNO3}$；
- 强碱：$\ce{NaOH}$、$\ce{KOH}$、$\ce{Ba(OH)2}$；
- 可溶性盐：钾盐、钠盐、铵盐、硝酸盐等绝大多数盐。

**不能拆的**（写化学式）：
- 难溶物：$\ce{BaSO4}$、$\ce{AgCl}$、$\ce{CaCO3}$、$\ce{Fe(OH)3}$、$\ce{Cu(OH)2}$ 等；
- 弱电解质：$\ce{CH3COOH}$、$\ce{H2CO3}$、$\ce{NH3.H2O}$、$\ce{H2O}$、$\ce{HClO}$ 等；
- 气体：$\ce{CO2}$、$\ce{SO2}$、$\ce{NH3}$、$\ce{H2}$ 等；
- 单质、氧化物：$\ce{Fe}$、$\ce{Cl2}$、$\ce{Na2O}$、$\ce{Al2O3}$ 等。

> [!warning] 微溶物的处理
> 微溶物（$\ce{Ca(OH)2}$、$\ce{CaSO4}$、$\ce{Ag2SO4}$、$\ce{MgCO3}$）作**反应物且处于澄清溶液**时拆成离子；作**生成物析出沉淀**时不拆。如石灰乳（$\ce{Ca(OH)2}$ 悬浊液）与 $\ce{Cl2}$ 反应：$\ce{Cl2 + Ca(OH)2 -> Ca2+ + Cl- + ClO- + H2O}$（石灰乳不拆）。澄清石灰水中 $\ce{Ca(OH)2}$ 拆写为 $\ce{Ca^2+ + 2OH-}$。

### 3. 离子方程式正误判断的"四查"

1. **查拆分**：该拆的拆、不该拆的不拆（最常见错误：$\ce{NaHCO3}$ 写成 $\ce{Na+ + H+ + CO3^2-}$，错，应写 $\ce{Na+ + HCO3-}$）；
2. **查守恒**：原子守恒（配平）+ **电荷守恒**（两边电荷代数和相等）；
3. **查配比**：是否符合反应物的物质的量之比（尤其与量有关）；
4. **查产物**：是否符合客观事实（如 $\ce{Fe}$ 与盐酸生成 $\ce{Fe^2+}$ 而非 $\ce{Fe^3+}$）。

### 4. 与量有关的离子方程式（高考重点难点）

原则：**"少定多变"**——不足量的物质按化学式比例反应（系数定为 1），过量物质的数量随之调整。

**典型情境 1：$\ce{CO2}$ 少量 / 过量通入 $\ce{NaOH}$ 溶液**
- 少量：$\ce{CO2 + 2OH- -> CO3^2- + H2O}$；
- 过量：$\ce{CO2 + OH- -> HCO3-}$。

**典型情境 2：$\ce{Ca(OH)2}$ 与 $\ce{NaHCO3}$（或 $\ce{Na2CO3}$）**
- $\ce{Ca(OH)2}$ 少量：$\ce{Ca^2+ + 2OH- + 2HCO3- -> CaCO3 v + CO3^2- + 2H2O}$；
- $\ce{NaHCO3}$ 少量：$\ce{Ca^2+ + OH- + HCO3- -> CaCO3 v + H2O}$。

**典型情境 3：$\ce{NaHSO4}$ 与 $\ce{Ba(OH)2}$**
- $\ce{Ba(OH)2}$ 过量（$\ce{NaHSO4}$ 少量，$\ce{SO4^2-}$ 全部沉淀且溶液呈中性）：$\ce{Ba^2+ + 2OH- + 2H+ + SO4^2- -> BaSO4 v + 2H2O}$；
- $\ce{Ba(OH)2}$ 少量（$\ce{Ba^2+}$ 与 $\ce{OH-}$ 按 $1:2$ 消耗）：$\ce{Ba^2+ + OH- + H+ + SO4^2- -> BaSO4 v + H2O}$。

**典型情境 4：$\ce{AlCl3}$ 与 $\ce{NaOH}$**
- $\ce{NaOH}$ 少量：$\ce{Al^3+ + 3OH- -> Al(OH)3 v}$；
- $\ce{NaOH}$ 过量：$\ce{Al^3+ + 4OH- -> [Al(OH)4]-}$（或写 $\ce{AlO2- + 2H2O}$）。

> [!tip] 与量有关题目的判断技巧
> 先明确"**谁不足、谁过量**"。把不足量的物质按组成比例定为"标准量"（通常系数为 1），再由它决定所需另一种反应物的离子数。写完后务必用"原子守恒 + 电荷守恒"验证。

## 典型例题

### 例题 1（离子方程式正误判断）

**题目**：下列离子方程式书写正确的是（　）
A. $\ce{Fe + 2H+ -> Fe^3+ + H2 ^}$
B. $\ce{Na + H2O -> Na+ + OH- + H2 ^}$
C. 向 $\ce{NaHCO3}$ 溶液中滴加稀盐酸：$\ce{HCO3- + H+ -> CO2 ^ + H2O}$
D. $\ce{Cu + 2H+ -> Cu^2+ + H2 ^}$

**分析**：A 错——$\ce{Fe}$ 与非氧化性酸反应生成 $\ce{Fe^2+}$，不是 $\ce{Fe^3+}$；B 错——不满足电荷守恒，应配平为 $\ce{2Na + 2H2O -> 2Na+ + 2OH- + H2 ^}$；C 对——$\ce{HCO3-}$ 是弱酸的酸式酸根不拆，与 $\ce{H+}$ 反应生成 $\ce{CO2}$ 和 $\ce{H2O}$；D 错——$\ce{Cu}$ 不与稀盐酸、稀硫酸反应。

**解答**：选 **C**。

**点评**：本题四个选项覆盖离子方程式正误判断的高频陷阱：产物是否符合事实（A、D）、配平与守恒（B）、拆分是否正确（C）。判断顺序建议：先查"事实"，再查"拆分"，最后查"守恒与配比"。

### 例题 2（与量有关 + 定量计算）

**题目**：向含 $0.02\ \text{mol}$ $\ce{Ca(OH)2}$ 的澄清石灰水中缓慢通入 $\ce{CO2}$，当恰好生成 $0.02\ \text{mol}$ 碳酸钙沉淀时，写出对应反应的离子方程式，并计算此时通入 $\ce{CO2}$ 的体积（标准状况，$V_m=22.4\ \text{L/mol}$）。

**分析**：$\ce{Ca(OH)2}$ 与 $\ce{CO2}$ 反应先生成 $\ce{CaCO3}$：$\ce{Ca^2+ + 2OH- + CO2 -> CaCO3 v + H2O}$。$0.02\ \text{mol}$ $\ce{Ca(OH)2}$ 提供 $0.02\ \text{mol}$ $\ce{Ca^2+}$，恰好生成 $0.02\ \text{mol}$ $\ce{CaCO3}$，说明通入 $\ce{CO2}$ 为 $0.02\ \text{mol}$。

**解答**：
离子方程式：$\ce{Ca^2+ + 2OH- + CO2 -> CaCO3 v + H2O}$
由化学计量关系：$n(\ce{CO2})=n(\ce{CaCO3})=0.02\ \text{mol}$，
$$V(\ce{CO2})=n\cdot V_m=0.02\times 22.4=0.448\ \text{L}$$

答：通入 $\ce{CO2}$ 的体积为 **0.448 L**。

**点评**：本题将离子方程式与物质的量计算结合。注意若 $\ce{CO2}$ 过量，沉淀会继续溶解（$\ce{CaCO3 + CO2 + H2O -> Ca(HCO3)2}$），属于"与量有关"的典型递进。

## 易错提醒

> [!warning] 易错提醒
> - **$\ce{NaHCO3}$ 的拆分**：在水溶液中写 $\ce{Na+ + HCO3-}$，不能写成 $\ce{Na+ + H+ + CO3^2-}$。
> - **$\ce{NH3.H2O}$、$\ce{H2O}$ 是弱电解质，不拆**；写 $\ce{NH3.H2O}$ 而不能写 $\ce{NH3 + H2O}$。
> - **$\ce{Fe}$ 与酸（非氧化性酸）生成 $\ce{Fe^2+}$**；与 $\ce{Cl2}$、$\ce{HNO3}$（氧化性）才生成 $\ce{Fe^3+}$。
> - **电荷守恒常被忽略**：如 $\ce{2Na + 2H2O -> 2Na+ + 2OH- + H2 ^}$，左边电荷为 0，右边电荷也为 0 才正确。
> - **与量有关时系数不可随意**：$\ce{Ca(OH)2}$ 与 $\ce{NaHCO3}$ 反应，少量/过量产物不同，注意沉淀中 $\ce{Ca^2+}$、$\ce{OH-}$、$\ce{HCO3-}$ 的配比。
> - **微溶物**：作澄清溶液反应物时拆，作沉淀生成物时不拆。
