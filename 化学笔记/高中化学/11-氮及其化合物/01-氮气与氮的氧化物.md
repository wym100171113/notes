# 氮气与氮的氧化物

> [!abstract] 概览
> $\ce{N2}$ 因分子中含有**键能极大的 $\ce{N≡N}$ 三键**而化学性质稳定。氮的氧化物中高考重点是 $\ce{NO}$ 与 $\ce{NO2}$：$\ce{NO}$ 无色、难溶、极易被氧化；$\ce{NO2}$ 红棕色、易溶于水并发生自身氧化还原（$\ce{3NO2 + H2O -> 2HNO3 + NO}$）。本章还涉及氮的氧化物溶于水的相关计算。

## 核心概念

### 1. 氮气的结构与稳定性

- 电子式：$\ce{:N:::N:}$，分子中存在 $\ce{N≡N}$ 三键，键能**极大**（$946\ \mathrm{kJ/mol}$），破坏它需要很高的能量。
- 因此 $\ce{N2}$ **化学性质很稳定**，常温下很难与其他物质反应。
- 但高温、放电、催化条件下仍能反应（如雷雨时 $\ce{N2 + O2 ->[放电] 2NO}$）。

### 2. 氮的常见氧化物

| 氧化物 | 氮的价态 | 颜色/状态 | 水溶性 | 备注 |
| --- | --- | --- | --- | --- |
| $\ce{N2O}$ | +1 | 无色气体 | 可溶 | 笑气 |
| $\ce{NO}$ | +2 | **无色**气体 | **难溶** | 有毒，易被氧化 |
| $\ce{NO2}$ | +4 | **红棕色**气体 | **易溶** | 有毒，有刺激性气味 |
| $\ce{N2O4}$ | +4 | 无色 | 与 $\ce{NO2}$ 共存 | $\ce{NO2}$ 二聚 |
| $\ce{N2O5}$ | +5 | 无色 | 易溶 | 硝酸酐 |

> [!note] 无色 NO 与红棕色 NO2
> $\ce{NO}$ 是无色气体，$\ce{NO2}$ 是红棕色气体。$\ce{NO}$ 在空气中立即被氧化：$\ce{2NO + O2 -> 2NO2}$（现象：无色变红棕色）。

## 化学性质

### 1. 氮气的化学性质（放电/高温下）

- 与氧气（放电或高温）：$\ce{N2 + O2 ->[放电或高温] 2NO}$（雷雨肥田的原理之一）
- 与氢气（工业合成氨）：$\ce{N2 + 3H2 <=>[高温高压][催化剂] 2NH3}$（可逆）
- 与活泼金属（如 $\ce{Mg}$）：$\ce{N2 + 3Mg ->[点燃] Mg3N2}$（氮化镁，遇水水解：$\ce{Mg3N2 + 6H2O -> 3Mg(OH)2 + 2NH3 ^}$）

### 2. 一氧化氮（$\ce{NO}$）

- **物理性质**：无色、有毒气体，**难溶于水**，密度略大于空气。
- **化学性质**：
  - **易被氧化**（$\ce{NO}$ 的还原性）：$\ce{2NO + O2 -> 2NO2}$
  - **不能与水反应**（所以 $\ce{NO}$ 是"不成盐氧化物"之一）。
  - 具有还原性，能使酸性 $\ce{KMnO4}$ 褪色。
- 收集方法：**排水集气法**（不能用排空气法，因与 $\ce{O2}$ 反应且密度接近空气）。

### 3. 二氧化氮（$\ce{NO2}$）

- **物理性质**：红棕色、有刺激性气味的**有毒气体**，密度比空气大，**易溶于水**，易液化。
- **化学性质**：
  - **与水反应**（自身氧化还原/歧化）：
$$\ce{3NO2 + H2O -> 2HNO3 + NO}$$
  - 与氧气同时通入水中（$\ce{NO2 + O2 + 2H2O -> 4HNO3}$ 的配平：$4\ce{NO2} + \ce{O2} + 2\ce{H2O} -> 4\ce{HNO3}$）。
  - 氧化性：能使湿润的淀粉碘化钾试纸**变蓝**（$\ce{NO2}$ 将 $\ce{I^-}$ 氧化为 $\ce{I2}$）。
- 收集方法：**向上排空气法**（不能排水，因易溶于水且与水反应）。

> [!important] 氮的氧化物对环境的危害
> - **光化学烟雾**：$\ce{NOx}$（$\ce{NO}$、$\ce{NO2}$）在阳光作用下与碳氢化合物反应形成。
> - **硝酸型酸雨**：$\ce{NO2 + H2O -> HNO3 + NO}$，最终生成硝酸。
> - 汽车尾气治理：$\ce{2NO + 2CO ->[催化剂] N2 + 2CO2}$（归中，$\ce{NO}$ 中 $\ce{N}$ 降价、$\ce{CO}$ 中 $\ce{C}$ 升价）。

## 氮的氧化物溶于水的计算

- **$\ce{NO2}$ 溶于水**：$\ce{3NO2 + H2O -> 2HNO3 + NO}$，$3$ 体积 $\ce{NO2}$ 生成 $1$ 体积 $\ce{NO}$，气体减少 $2/3$。
- **$\ce{NO2}$ 与 $\ce{O2}$ 混合通入水中**：
  $$\ce{4NO2 + O2 + 2H2O -> 4HNO3}$$
  当 $V(\ce{NO2}):V(\ce{O2}) = 4:1$ 时，气体**恰好完全溶解**，无剩余。
- **$\ce{NO}$ 与 $\ce{O2}$ 混合通入水中**：
  $$\ce{4NO + 3O2 + 2H2O -> 4HNO3}$$
  当 $V(\ce{NO}):V(\ce{O2}) = 4:3$ 时，气体恰好完全溶解。
- 若气体有剩余，剩余气体是 $\ce{NO}$（过量）或 $\ce{O2}$（过量），**不可能剩余 $\ce{NO2}$**（$\ce{NO2}$ 遇水生成 $\ce{NO}$）。

## 氮的固定与自然界氮循环

- **氮的固定**：将游离态氮（$\ce{N2}$）转化为氮的化合物的过程。
  - **自然固氮**：雷雨天放电固氮（$\ce{N2 + O2 ->[放电] 2NO}$）；豆科植物根瘤菌固氮。
  - **人工固氮**：工业合成氨 $\ce{N2 + 3H2 <=>[高温高压][催化剂] 2NH3}$。
- 氮循环：$\ce{N2 ->[固氮] 含氮化合物 ->[硝化] NO3^- ->[反硝化] N2}$，维持自然界氮的平衡。
- **大气污染与防治**：
  - 汽车尾气中 $\ce{NOx}$ 的治理：$\ce{2NO + 2CO ->[催化剂] N2 + 2CO2}$。
  - 光化学烟雾、硝酸型酸雨都与 $\ce{NOx}$ 排放有关。
  - $\ce{NO2}$ 用 $\ce{NaOH}$ 溶液吸收：$\ce{2NO2 + 2NaOH -> NaNO3 + NaNO2 + H2O}$（$\ce{NO}$、$\ce{NO2}$ 混合气可被碱液吸收：$\ce{NO + NO2 + 2NaOH -> 2NaNO2 + H2O}$）。

## 典型例题

### 例题 1

**题目**：将盛有 $\ce{NO2}$ 和 $\ce{O2}$ 混合气体的试管倒立于水中，最终试管内剩余气体为 $\ce{O2}$，且剩余气体体积为原混合气体的 $1/10$。求原混合气体中 $\ce{NO2}$ 与 $\ce{O2}$ 的体积比。

**分析**：设原混合气体总体积为 $V$，则剩余 $\ce{O2}$ 体积为 $V/10$，参加反应的混合气体体积为 $9V/10$。按 $\ce{4NO2 + O2 + 2H2O -> 4HNO3}$，参加反应的 $\ce{NO2}$ 占 $4/5$，$\ce{O2}$ 占 $1/5$：
$V(\ce{NO2}) = \dfrac{9V}{10} \times \dfrac{4}{5} = \dfrac{36V}{50} = \dfrac{18V}{25}$；$V(\ce{O2}) = \dfrac{9V}{10} \times \dfrac{1}{5} + \dfrac{V}{10} = \dfrac{9V}{50} + \dfrac{5V}{50} = \dfrac{14V}{50} = \dfrac{7V}{25}$。
故 $V(\ce{NO2}):V(\ce{O2}) = \dfrac{18}{25} : \dfrac{7}{25} = 18:7$。

**解答**：$V(\ce{NO2}):V(\ce{O2}) = 18:7$。

**点评**：本题考查 $\ce{NO2}$、$\ce{O2}$ 混合气倒立于水的计算。关键是先判断剩余气体，再按"恰好反应"比例分配参加反应的气体。

### 例题 2

**题目**：下列说法正确的是（　）
A. $\ce{NO}$ 和 $\ce{NO2}$ 均可用排空气法收集
B. $\ce{NO2}$ 溶于水生成硝酸，所以 $\ce{NO2}$ 是硝酸的酸酐
C. 常温下 $\ce{N2}$ 的化学性质很稳定，是因为 $\ce{N≡N}$ 键能大
D. $\ce{NO}$ 与 $\ce{O2}$ 混合后颜色不变

**分析**：A 错误：$\ce{NO}$ 易与 $\ce{O2}$ 反应，不能用排空气法收集（用排水法）；$\ce{NO2}$ 可用向上排空气法。B 错误：$\ce{NO2}$ 溶于水生成硝酸和 $\ce{NO}$，不是酸酐；硝酸的酸酐是 $\ce{N2O5}$。C 正确：$\ce{N≡N}$ 键能大，$\ce{N2}$ 稳定。D 错误：$\ce{2NO + O2 -> 2NO2}$，无色变为红棕色。

**解答**：选 **C**。

**点评**：注意"酸酐"定义——酸酐是酸**脱水**后的氧化物，$\ce{HNO3}$ 的酸酐是 $\ce{N2O5}$，而不是 $\ce{NO2}$。$\ce{NO2}$ 与水的歧化反应是高频考点。

### 例题 3

**题目**：将充满 $\ce{NO}$ 和 $\ce{NO2}$ 的混合气体（体积比为 $1:1$）的试管倒置于水槽中，一段时间后试管内液面上升。求最终剩余气体的体积占原混合气体体积的几分之几（假设气体都在标准状况下）。

**分析**：$\ce{NO2}$ 溶于水发生 $\ce{3NO2 + H2O -> 2HNO3 + NO}$，$\ce{NO}$ 不溶于水也不与水反应。设 $\ce{NO}$、$\ce{NO2}$ 各为 $1$ 体积（共 $2$ 体积）。$1$ 体积 $\ce{NO2}$ 反应生成 $\dfrac{1}{3}$ 体积 $\ce{NO}$，则剩余 $\ce{NO}$ 体积为 $1 + \dfrac{1}{3} = \dfrac{4}{3}$ 体积。

**解答**：剩余气体体积为原混合气体体积的 $\dfrac{\dfrac{4}{3}}{2} = \dfrac{2}{3}$。

**点评**：这是"氮氧化物溶于水"的基础计算。核心是把握 $\ce{3NO2 + H2O -> 2HNO3 + NO}$ 中"$\ce{NO2}$ 有 $\dfrac{1}{3}$ 转化为 $\ce{NO}$"，并结合 $\ce{NO}$ 不溶于水的性质。此类题还可扩展为"$\ce{NO2}$、$\ce{NO}$、$\ce{O2}$ 混合气溶于水最终无剩余"的组合计算。

## 易错提醒

> [!warning]
> - $\ce{NO}$ 是**不成盐氧化物**（不与水、碱反应），$\ce{NO2}$ 与碱反应生成硝酸盐与亚硝酸盐（不是简单的酸性氧化物）。
> - $\ce{HNO3}$ 的酸酐是 $\ce{N2O5}$，**不是 $\ce{NO2}$**。
> - $\ce{NO2}$ 溶于水：$\ce{3NO2 + H2O -> 2HNO3 + NO}$，**氮的化合价既有升高（$\ce{+4 -> +5}$）又有降低（$\ce{+4 -> +2}$）**，是歧化反应。
> - $\ce{NO}$ 不能用排空气法收集；$\ce{NO2}$ 不能用排水法收集。
> - "雷雨发庄稼"依靠的是 $\ce{N2 + O2 ->[放电] 2NO}$，再经系列反应生成硝酸盐。
> - 混合气溶于水的计算中，剩余气体只可能是 $\ce{NO}$ 或 $\ce{O2}$，不可能剩余 $\ce{NO2}$。
