# 铁单质

> [!abstract] 概览
> 铁（$\ce{Fe}$）位于第四周期第Ⅷ族，是典型的**变价金属**。本笔记围绕铁单质的化学性质展开，核心是"**不同氧化剂把铁氧化到不同价态**"：强氧化剂（$\ce{Cl2}$、$\ce{O2}$、稀硝酸）把铁氧化为 $\ce{Fe^{3+}}$，弱氧化剂（$\ce{S}$、$\ce{I2}$、$\ce{Cu^{2+}}$、$\ce{H+}$）只能把铁氧化为 $\ce{Fe^{2+}}$。同时注意钝化现象与水蒸气反应这两个特殊考点。

## 核心概念

### 铁的原子结构与位置

- 原子序数 26，位于**第四周期第Ⅷ族**，是过渡元素的代表。
- 原子结构示意图：核外电子排布为 $1s^2 2s^2 2p^6 3s^2 3p^6 3d^6 4s^2$。
- 最外层 2 个电子（4s），次外层 3d 亚层未充满，故铁具有**可变价态**（+2、+3），这也是过渡金属区别于主族金属的特征。

### 物理性质

- 银白色金属，有金属光泽，导电、导热性良好，有延展性。
- 能被磁铁吸引（**铁磁性**），密度约 $7.86\ \ce{g/cm^3}$。
- 纯铁抗腐蚀能力较强；日常生活中见到的"铁"多为含碳的生铁或钢，容易锈蚀。

## 重点知识：化学性质

铁是较活泼的金属，但还原性弱于 $\ce{Na}$、$\ce{Mg}$、$\ce{Al}$。产物中铁的价态由**氧化剂强弱**决定。

### 1. 与非金属单质反应

| 反应 | 化学方程式 | 铁的价态 | 说明 |
| --- | --- | --- | --- |
| 与氯气 | $\ce{2Fe + 3Cl2 \xrightarrow{\Delta} 2FeCl3}$ | $+3$ | $\ce{Cl2}$ 氧化性强，生成 $\ce{FeCl3}$（棕黄色固体） |
| 与溴 | $\ce{2Fe + 3Br2 \xrightarrow{\Delta} 2FeBr3}$ | $+3$ | 与 $\ce{Cl2}$ 类似 |
| 与氧气 | $\ce{3Fe + 2O2 \xrightarrow{点燃} Fe3O4}$ | $+\frac{8}{3}$ | 剧烈燃烧，火星四射，产物为**黑色**四氧化三铁 |
| 与硫 | $\ce{Fe + S \xrightarrow{\Delta} FeS}$ | $+2$ | $\ce{S}$ 氧化性弱，生成黑色 $\ce{FeS}$ |
| 与碘 | $\ce{Fe + I2 \xrightarrow{\Delta} FeI2}$ | $+2$ | $\ce{I2}$ 氧化性弱，生成 $\ce{FeI2}$ |

> [!warning] 铁与氯气、硫产物价态不同
> 铁与 $\ce{Cl2}$、$\ce{Br2}$ 反应生成 $\ce{Fe^{3+}}$，而与 $\ce{S}$、$\ce{I2}$ 反应生成 $\ce{Fe^{2+}}$。原因：$\ce{Cl2}$、$\ce{Br2}$ 氧化性强于 $\ce{Fe^{3+}}$，能把铁氧化到最高价；而 $\ce{S}$、$\ce{I2}$ 氧化性弱于 $\ce{Fe^{3+}}$，只能把铁氧化到 $\ce{Fe^{2+}}$。**这是高考选择题的经典陷阱**。

### 2. 与酸反应

| 酸 | 方程式 | 说明 |
| --- | --- | --- |
| 盐酸、稀硫酸（非氧化性酸） | $\ce{Fe + 2H+ -> Fe^{2+} + H2 ^}$ | 生成 $\ce{Fe^{2+}}$（浅绿色） |
| 稀硝酸（氧化性酸，不足） | $\ce{3Fe + 8HNO3(稀) -> 3Fe(NO3)2 + 2NO ^ + 4H2O}$ | 铁过量时生成 $\ce{Fe^{2+}}$ |
| 稀硝酸（氧化性酸，过量） | $\ce{Fe + 4HNO3(稀) -> Fe(NO3)3 + NO ^ + 2H2O}$ | 硝酸过量时生成 $\ce{Fe^{3+}}$ |
| 浓硫酸、浓硝酸 | 常温下**钝化**，不反应 | 生成致密氧化膜，可用铝罐、铁罐储运浓硝酸 |

> [!tip] 铁与稀硝酸的"量"思维
> 铁与稀硝酸反应，产物是 $\ce{Fe^{2+}}$ 还是 $\ce{Fe^{3+}}$，取决于**谁过量**。硝酸过量（$\ce{n(HNO3) : n(Fe) \ge 4}$）生成 $\ce{Fe^{3+}}$；铁过量则先生成 $\ce{Fe^{3+}}$，多余的铁再与 $\ce{Fe^{3+}}$ 归中为 $\ce{Fe^{2+}}$，最终生成 $\ce{Fe^{2+}}$。

### 3. 与盐溶液反应（置换/归中）

- 与硫酸铜溶液：$\ce{Fe + Cu^{2+} -> Fe^{2+} + Cu}$（湿法炼铜原理）
- 与氯化铁溶液：$\ce{Fe + 2Fe^{3+} -> 3Fe^{2+}}$（归中反应，工业上用铁粉除去 $\ce{FeCl3}$ 中杂质）
- 与硝酸银溶液：$\ce{Fe + 2Ag+ -> Fe^{2+} + 2Ag}$

> [!note] 归中反应特征
> $\ce{Fe + 2Fe^{3+} -> 3Fe^{2+}}$ 是同种元素不同价态间的"归中反应"，中间价态 $\ce{Fe^{2+}}$ 既是氧化产物又是还原产物。

### 4. 与水蒸气反应

$$
\ce{3Fe + 4H2O(g) \xrightarrow{高温} Fe3O4 + 4H2}
$$

> [!warning] 铁与水蒸气的特殊之处
> 铁在**高温下**与水蒸气反应生成 $\ce{Fe3O4}$ 和 $\ce{H2}$，**不生成 $\ce{Fe(OH)3}$ 或 $\ce{Fe(OH)2}$**。常温下铁与水不反应。该反应条件是"水蒸气 + 高温"，产物中铁显 $+\frac{8}{3}$ 价。

### 5. 钝化现象

- 常温下，铁遇**浓硫酸、浓硝酸**表面生成一层致密的氧化物薄膜，阻止反应继续进行，称为**钝化**。
- 应用：可用铁制容器储运浓硫酸、浓硝酸。
- 注意：加热条件下钝化膜被破坏，铁会与浓硫酸、浓硝酸剧烈反应。

## 典型例题

### 例题 1：铁与不同氧化剂反应的产物判断

**题目**：等质量的铁分别与足量氯气、足量盐酸反应，下列叙述正确的是（ ）
A. 二者转移的电子数相同
B. 生成的气体在标准状况下体积相同
C. 生成物的中铁元素价态相同
D. 转移的电子数之比为 $3 : 2$

**分析**：铁与 $\ce{Cl2}$ 反应生成 $\ce{FeCl3}$（铁显 $+3$ 价），与盐酸反应生成 $\ce{FeCl2}$（铁显 $+2$ 价）。等质量铁物质的量相同，设为 $n$。与氯气反应转移 $3n$ mol 电子，与盐酸反应转移 $2n$ mol 电子。

**解答**：
- 转移电子数之比 $= 3n : 2n = 3 : 2$，D 正确，A 错误。
- 与盐酸反应生成 $\ce{H2}$（$n$ mol），与氯气反应不生成气体，B 错误。
- 产物中铁价态分别为 $+3$、$+2$，C 错误。
- 答案：**D**。

**点评**：核心是"同一物质与不同氧化剂反应，产物价态由氧化剂强弱决定"。氯气氧化性强，把铁氧化到 $+3$ 价；盐酸中的 $\ce{H+}$ 氧化性弱，只能把铁氧化到 $+2$ 价。

### 例题 2：铁与稀硝酸的反应

**题目**：将足量铁粉投入稀硝酸中，充分反应后，溶液中大量存在的离子是（ ）
A. $\ce{Fe^{3+}}$、$\ce{NO3^-}$、$\ce{H+}$
B. $\ce{Fe^{2+}}$、$\ce{NO3^-}$
C. $\ce{Fe^{3+}}$、$\ce{NO3^-}$
D. $\ce{Fe^{2+}}$、$\ce{Fe^{3+}}$、$\ce{NO3^-}$

**分析**：铁粉**足量**，硝酸相对不足。硝酸先把铁氧化为 $\ce{Fe^{3+}}$，多余的铁再与 $\ce{Fe^{3+}}$ 发生归中反应：$\ce{Fe + 2Fe^{3+} -> 3Fe^{2+}}$，最终铁的价态为 $+2$。硝酸被还原后 $\ce{H+}$ 消耗殆尽。

**解答**：溶液中大量存在的离子是 $\ce{Fe^{2+}}$ 和 $\ce{NO3^-}$，答案：**B**。

**点评**：铁与稀硝酸反应，金属过量则产物为亚铁盐。这是"量"影响产物的典型题型，务必抓住"先氧化到高价，再归中到低价"的先后顺序。

## 易错提醒

> [!warning] 易错点清单
> 1. 铁与 $\ce{Cl2}$ 反应生成 $\ce{FeCl3}$，与 $\ce{S}$ 反应生成 $\ce{FeS}$——不要混淆，由氧化剂强弱决定。
> 2. 铁与非氧化性酸（盐酸、稀硫酸）反应只生成 $\ce{Fe^{2+}}$，**不能写 $\ce{Fe^{3+}}$**。
> 3. 常温下铁遇浓硫酸、浓硝酸"钝化"是化学变化（生成氧化膜），不是不反应。
> 4. 铁与水蒸气反应生成 $\ce{Fe3O4}$ 和 $\ce{H2}$，不要误写为 $\ce{Fe(OH)3}$。
> 5. $\ce{Fe3O4}$ 中 $\ce{Fe}$ 的化合价是 $+\frac{8}{3}$，可看作 $\ce{FeO.Fe2O3}$（含 $1$ 个 $\ce{Fe^{2+}}$ 和 $2$ 个 $\ce{Fe^{3+}}$）。
