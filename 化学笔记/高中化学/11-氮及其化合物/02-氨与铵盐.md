# 氨与铵盐

> [!abstract] 概览
> 氨气（$\ce{NH3}$）是氮的 $-3$ 价氢化物，**极易溶于水**（喷泉实验）、显**碱性**、具有**还原性**，是高中最重要的气体之一。本章重点：喷泉实验原理、$\ce{NH3}$ 与水/酸的反应、氨的催化氧化、**实验室制氨**，以及铵盐的不稳定性与 $\ce{NH4+}$ 的检验。

## 核心概念

### 1. 氨气的物理性质

- **无色**、有**刺激性气味**的**气体**，密度比空气**小**。
- **极易溶于水**（常温下 $1$ 体积水约溶解 $700$ 体积 $\ce{NH3}$）。
- 极易**液化**（液氨气化时吸收大量热，用作制冷剂）。
- 有毒（对人体有刺激作用）。

### 2. 喷泉实验

- **原理**：$\ce{NH3}$ 极易溶于水，使烧瓶内气体急剧减少、压强**急剧减小**，外界大气压将烧杯中的水压入烧瓶，形成**喷泉**。
- **现象**：烧杯中的水迅速进入烧瓶，形成红色喷泉（水中预先滴入酚酞）。
- 应用：能形成喷泉的气体需满足"**极易溶于水**"（如 $\ce{NH3}$、$\ce{HCl}$、$\ce{SO2}$、$\ce{NO2}$ 等）或与溶液中物质**快速反应**（如 $\ce{CO2}$ + $\ce{NaOH}$ 溶液）。

> [!note] 喷泉实验的定量
> 若烧瓶充满 $\ce{NH3}$ 且全溶于水，最终溶液充满烧瓶，$c(\ce{NH3·H2O}) \approx \dfrac{V/22.4\ \mathrm{L\cdot mol^{-1}}}{V\ \mathrm{L}} = \dfrac{1}{22.4}\ \mathrm{mol/L}$（忽略体积变化）。

## 化学性质

### 1. 与水反应（氨水）

$$\ce{NH3 + H2O <=> NH3·H2O <=> NH4+ + OH-}$$

- 氨水显**碱性**（一水合氨 $\ce{NH3·H2O}$ 是弱碱，部分电离）。
- $\ce{NH3·H2O}$ 不稳定，受热分解：$\ce{NH3·H2O ->[Δ] NH3 ^ + H2O}$。
- 氨水中含有的粒子：$\ce{NH3·H2O}$、$\ce{NH3}$、$\ce{H2O}$、$\ce{NH4+}$、$\ce{OH-}$、$\ce{H+}$（极少）。

### 2. 与酸反应

- 与盐酸：$\ce{NH3 + HCl -> NH4Cl}$（产生**白烟**）
- 与硝酸：$\ce{NH3 + HNO3 -> NH4NO3}$（白烟）
- 与硫酸：$\ce{2NH3 + H2SO4 -> (NH4)2SO4}$

> 现象"白烟"用于检验 $\ce{NH3}$（用蘸有浓盐酸的玻璃棒靠近，产生白烟 $\ce{NH4Cl}$）。

### 3. 还原性（$\ce{-3 -> 0}$ 或更高）

- **催化氧化**（工业制硝酸第一步）：
$$\ce{4NH3 + 5O2 ->[Pt][Δ] 4NO + 6H2O}$$
- 与氯气：$\ce{8NH3 + 3Cl2 -> N2 + 6NH4Cl}$（$\ce{NH3}$ 既被氧化又生成盐）
- 与氧化铜：$\ce{2NH3 + 3CuO ->[Δ] N2 + 3Cu + 3H2O}$

### 4. 与盐溶液反应（生成配合物）

$$\ce{CuSO4 + 4NH3·H2O -> [Cu(NH3)4]SO4 + 4H2O}$$

（深蓝色溶液，$\ce{Cu^{2+}}$ 的特征检验之一，见 [[常见离子的检验方法]]。）

## 氨的实验室制法

$$\ce{2NH4Cl + Ca(OH)2 ->[Δ] CaCl2 + 2NH3 ^ + 2H2O}$$

| 要点 | 说明 |
| --- | --- |
| 药品 | 氯化铵 + 消石灰（熟石灰 $\ce{Ca(OH)2}$） |
| 装置 | 固固加热（试管口略向下倾斜） |
| 收集 | **向下排空气法**（$\ce{NH3}$ 密度小于空气、极易溶于水不能用排水法） |
| 干燥 | **碱石灰**（不能用浓硫酸——会反应；不能用无水 $\ce{CaCl2}$——生成 $\ce{CaCl2·8NH3}$ 加合物） |
| 验满 | 湿润的**红色石蕊试纸**置于瓶口，变蓝 |
| 尾气处理 | 用水（防倒吸，可用倒扣漏斗） |

> [!warning] 不能用 $\ce{NH4NO3}$、$\ce{(NH4)2SO4}$ 代替？
> 受热易分解或产物不理想；实验室常用 $\ce{NH4Cl}$ 与 $\ce{Ca(OH)2}$。另外不可用 $\ce{NaOH}$ 代替 $\ce{Ca(OH)2}$（吸水结块、产率低）。

## 铵盐

- **定义**：由 $\ce{NH4+}$（铵根）与酸根组成的盐。
- **物理性质**：易溶于水，都是白色晶体。
- **化学性质**：
  1. **受热分解**（不稳定性）：
     - $\ce{NH4Cl ->[Δ] NH3 ^ + HCl ^}$（试管口遇冷又化合生成白烟 $\ce{NH4Cl}$）
     - $\ce{NH4HCO3 ->[Δ] NH3 ^ + H2O + CO2 ^}$
  2. **与碱反应**（放出 $\ce{NH3}$，是 $\ce{NH4+}$ 检验的原理）：
$$\ce{NH4+ + OH- ->[Δ] NH3 ^ + H2O}$$
- **$\ce{NH4+}$ 检验**：加浓 $\ce{NaOH}$ 溶液并加热，产生使湿润**红色石蕊试纸变蓝**的气体（$\ce{NH3}$）。

## 典型例题

### 例题 1

**题目**：实验室用氯化铵和消石灰制取氨气。（1）写出化学方程式；（2）如何检验氨气已收集满？

**分析**：（1）固固加热反应制氨。（2）$\ce{NH3}$ 是碱性气体，用湿润的红色石蕊试纸验满，变蓝即满。

**解答**：
（1）$\ce{2NH4Cl + Ca(OH)2 ->[Δ] CaCl2 + 2NH3 ^ + 2H2O}$。
（2）将湿润的**红色石蕊试纸**置于集气瓶口，若试纸**变蓝**，说明已收集满。

**点评**：制氨实验是高频考点，注意收集方法（向下排空气法）、干燥剂（碱石灰）、验满方法（湿润红色石蕊试纸变蓝）。不要用排水法，因为 $\ce{NH3}$ 极易溶于水。

### 例题 2

**题目**：将 $\ce{NH3}$ 通入滴有酚酞的水中，溶液变红；加热后又变回无色。用平衡原理解释。

**分析**：$\ce{NH3}$ 溶于水生成一水合氨：$\ce{NH3 + H2O <=> NH3·H2O}$，$\ce{NH3·H2O}$ 部分电离出 $\ce{OH-}$：$\ce{NH3·H2O <=> NH4+ + OH-}$，溶液显碱性，酚酞变红。加热时 $\ce{NH3·H2O}$ 分解并放出 $\ce{NH3}$（$\ce{NH3·H2O ->[Δ] NH3 ^ + H2O}$），$\ce{OH-}$ 浓度下降，碱性减弱，红色褪去。

**解答**：因为氨水存在电离平衡 $\ce{NH3·H2O <=> NH4+ + OH-}$，溶液呈碱性使酚酞变红；加热促使 $\ce{NH3·H2O}$ 分解并逸出 $\ce{NH3}$，平衡逆向移动，$\ce{OH-}$ 减少，故红色褪去。

**点评**：该题结合电离平衡解释氨水的性质，体现了"弱碱电离平衡"与"气体逸出"的综合，是必修一与选必一水溶液平衡衔接的常见考题。

## 易错提醒

> [!warning]
> - **$\ce{NH3}$ 极易溶于水（$1:700$）**，收集只能用向下排空气法，不能用排水法。
> - 氨水显碱性，但 $\ce{NH3}$ 本身**不是碱**（是不含 $\ce{OH-}$ 的化合物），是"碱性气体"。
> - 干燥 $\ce{NH3}$ 用**碱石灰**，不用浓硫酸、无水 $\ce{CaCl2}$、$\ce{P2O5}$。
> - $\ce{NH4Cl}$ 受热"升华"是**化学变化**（分解后又化合），不是物理升华。
> - 检验 $\ce{NH4+}$ 必须"**加强碱 + 加热**"并用湿润红色石蕊试纸检验气体。
> - 氨的催化氧化生成 $\ce{NO}$（不是 $\ce{NO2}$，更不是 $\ce{N2}$），$\ce{NO}$ 再被氧化为 $\ce{NO2}$。
