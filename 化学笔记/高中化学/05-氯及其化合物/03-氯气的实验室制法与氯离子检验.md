# 氯气的实验室制法与氯离子检验

> [!abstract] 概览
> 氯气的实验室制法是高考**化学实验**题的高频考点，涉及装置连接、除杂、干燥、收集、尾气处理与定量计算；氯离子检验则是离子鉴别的经典内容。本笔记整理制氯的反应原理（$\ce{MnO2}$ 与浓盐酸加热）、完整的实验装置与操作要点，以及 $\ce{Cl^-}$ 的检验方法与干扰排除，并强调"浓盐酸、加热、还原性 + 氧化性"等关键条件。

## 核心概念

- **反应原理**：二氧化锰与**浓**盐酸在**加热**条件下反应
  $$\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$$
- **$\ce{MnO2}$ 只与浓盐酸反应**：盐酸变稀后反应停止（$\ce{MnO2}$ 氧化性不足以氧化稀盐酸）。
- **氯离子检验**：$\ce{AgNO3}$ 溶液 + 稀硝酸，产生**白色不溶于稀硝酸**的沉淀 $\ce{AgCl}$。
- **装置要点**：发生 → 除杂（饱和食盐水除 $\ce{HCl}$）→ 干燥（浓硫酸）→ 收集（向上排空气或排饱和食盐水）→ 尾气处理（$\ce{NaOH}$ 溶液）。

## 重点知识

### 1. 反应原理与条件分析

$$\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$$

- 该反应中 $\ce{MnO2}$ 作氧化剂（$\ce{Mn^{4+} -> Mn^{2+}}$），浓盐酸作还原剂（$\ce{Cl^- -> Cl2}$），同时表现出酸性。
- 实际被氧化的 $\ce{HCl}$ 只有一半：$4\ \mathrm{mol}$ 浓盐酸中只有 $2\ \mathrm{mol}$ 被氧化生成 $\ce{Cl2}$，另 $2\ \mathrm{mol}$ 生成 $\ce{MnCl2}$。
- **必须用浓盐酸且需加热**：稀盐酸与 $\ce{MnO2}$ 不反应；加热促进反应进行。反应中盐酸浓度不断降低，变稀后反应停止，因此**浓盐酸不能完全反应**（$\ce{MnO2}$ 可能过量）。

> [!warning] 物质的量陷阱
> 用 $n\ \mathrm{mol}$ 浓盐酸与足量 $\ce{MnO2}$ 反应，生成 $\ce{Cl2}$ 的物质的量**小于 $\dfrac{n}{4}\ \mathrm{mol}$**，因为随反应进行盐酸变稀，反应停止，实际被氧化的 $\ce{HCl}$ 少于一半。这类"过量/不足"判断是高考陷阱。

### 2. 实验装置与流程

```
  浓盐酸 滴加漏斗
     │
 圆底烧瓶(加 MnO2) ──加热──> 除杂(饱和食盐水) ──> 干燥(浓硫酸) ──> 收集(向上排空气/排饱和食盐水) ──> 尾气处理(NaOH)
```

| 环节 | 试剂/方法 | 作用 |
| --- | --- | --- |
| 发生装置 | 圆底烧瓶 + 分液漏斗，$\ce{MnO2}$ + 浓盐酸加热 | 产生 $\ce{Cl2}$ |
| 除杂 | **饱和食盐水** | 除去 $\ce{Cl2}$ 中混有的 $\ce{HCl}$（$\ce{Cl2}$ 在饱和食盐水中溶解度小） |
| 干燥 | **浓硫酸**（或无水 $\ce{CaCl2}$） | 除去水蒸气 |
| 收集 | **向上排空气法**（密度大于空气）或**排饱和食盐水法** | 收集氯气 |
| 尾气处理 | **$\ce{NaOH}$ 溶液** | 吸收多余 $\ce{Cl2}$，防止污染 |

> [!tip] 为什么用"排饱和食盐水"
> $\ce{Cl2}$ 能溶于水，但**在饱和食盐水中的溶解度很小**（饱和食盐水中 $\ce{Cl^-}$ 浓度大，抑制氯气溶解），所以可用排饱和食盐水收集，同时还能进一步除去 $\ce{HCl}$。

### 3. 操作要点与验满

- **验满**：用湿润的**淀粉碘化钾试纸**靠近瓶口，试纸变**蓝**说明已集满（$\ce{Cl2 + 2KI -> 2KCl + I2}$，淀粉遇碘变蓝）。
- **尾气处理**：用 $\ce{NaOH}$ 溶液吸收：$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$。
- **不能用水封/排空气收集的注意**：氯气有毒，实验要在通风橱中进行；多余氯气务必用碱液吸收。
- **制备过程中**：先检查气密性，再装药品；加热时用酒精灯外焰；结束实验先撤离导管再熄灭酒精灯（防倒吸）。

### 4. 氯离子的检验

**原理**：
$$\ce{Ag+ + Cl^- -> AgCl v}\qquad(\text{白色沉淀，不溶于稀硝酸})$$

**操作步骤**：
1. 取少量待测液于试管中；
2. 先加**稀硝酸**酸化（排除 $\ce{CO3^{2-}}$、$\ce{SO3^{2-}}$ 等干扰）；
3. 再滴加**$\ce{AgNO3}$ 溶液**；
4. 若产生**白色沉淀且不溶于稀硝酸**，则证明含 $\ce{Cl^-}$。

> [!warning] 干扰排除
> 必须加稀硝酸酸化，因为 $\ce{CO3^{2-}}$、$\ce{PO4^{3-}}$ 等也能与 $\ce{Ag+}$ 生成白色沉淀（$\ce{Ag2CO3}$ 等），但这些沉淀**溶于稀硝酸**，只有 $\ce{AgCl}$ 不溶。不可用盐酸酸化（会引入 $\ce{Cl^-}$）。

### 5. 氯气制法的其他方法（拓展）

$$\ce{2KMnO4 + 16HCl(浓) -> 2KCl + 2MnCl2 + 5Cl2 ^ + 8H2O}$$
（$\ce{KMnO4}$ 氧化性更强，无需加热。）

$$\ce{KClO3 + 6HCl(浓) -> KCl + 3Cl2 ^ + 3H2O}$$
（归中反应制氯气。）

> [!note] 归中反应
> 次氯酸盐/氯酸盐与浓盐酸反应都是"$\ce{ClO^-}$（或 $\ce{ClO3^-}$）中的正价氯 + $\ce{Cl^-}$ 中的负价氯 → 0 价氯气"的**归中反应**，也是制氯气的常见方法。

### 6. 高考实验题高频设问

1. **试剂选择**：除 $\ce{HCl}$ 用饱和食盐水，干燥用浓硫酸，尾气用 $\ce{NaOH}$ 溶液——为什么不用水除 $\ce{HCl}$？（氯气也溶于水）
2. **装置顺序**：除杂必须在干燥之前，收集在前、尾气处理在后，顺序不能颠倒。
3. **验满方法**：湿润淀粉碘化钾试纸变蓝，或湿润的蓝色石蕊试纸先变红后褪色（氯水酸性+漂白）。
4. **尾气吸收装置**：用 $\ce{NaOH}$ 溶液且要防倒吸（可用倒扣漏斗等）。
5. **安全操作**：实验在通风橱中进行；先检漏/检气密性，再装药；先撤导管后灭灯。
6. **氯离子检验的规范表述**："取少量溶液，先加稀硝酸酸化，再滴加 $\ce{AgNO3}$ 溶液，若产生白色沉淀且不溶于稀硝酸，则含 $\ce{Cl^-}$"。

> [!tip] 常见连接题
> 制取干燥纯净的氯气，装置连接顺序一般为：**发生装置 → 饱和食盐水（除 $\ce{HCl}$）→ 浓硫酸（干燥）→ 收集装置（向上排空气或排饱和食盐水）→ 尾气吸收（$\ce{NaOH}$）**。

## 典型例题

### 例题 1（浓盐酸不足的陷阱计算）

**题目**：将含 $0.4\ \mathrm{mol}$ $\ce{HCl}$ 的浓盐酸与足量 $\ce{MnO2}$ 混合加热，能否制得 $0.1\ \mathrm{mol}$ 的 $\ce{Cl2}$？

**分析**：由方程式 $\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$ 看，$4\ \mathrm{mol}$ 浓盐酸生成 $1\ \mathrm{mol}$ 氯气，似乎 $0.4\ \mathrm{mol}$ 盐酸应生成 $0.1\ \mathrm{mol}$ 氯气。但随反应进行，盐酸变稀，与 $\ce{MnO2}$ 不再反应，实际生成氯气**小于** $0.1\ \mathrm{mol}$。

**解答**：不能。反应过程中盐酸浓度逐渐减小，当变为稀盐酸后反应停止，被氧化的 $\ce{HCl}$ 少于总量的一半（少于 $0.2\ \mathrm{mol}$），故生成 $\ce{Cl2}$ 的物质的量小于 $0.1\ \mathrm{mol}$。

**点评**：这是高考经典的"浓盐酸不能完全反应"陷阱。答题要强调"盐酸变稀后不再反应"这一条件限制，而不能机械按方程式比例计算。

### 例题 2（氯离子检验的应用）

**题目**：某无色溶液中可能含有 $\ce{Cl^-}$ 或 $\ce{CO3^{2-}}$。请设计实验检验是否含有 $\ce{Cl^-}$。

**分析**：$\ce{Ag+}$ 与 $\ce{CO3^{2-}}$ 也生成白色沉淀（$\ce{Ag2CO3}$），但 $\ce{Ag2CO3}$ 溶于稀硝酸，$\ce{AgCl}$ 不溶。需先加稀硝酸排除干扰。

**解答**：取少量待测液，先滴加足量**稀硝酸**至无明显气泡（排除 $\ce{CO3^{2-}}$），再滴加 $\ce{AgNO3}$ 溶液。若产生**白色沉淀且不溶于稀硝酸**，则证明含有 $\ce{Cl^-}$；若沉淀溶解，则说明原沉淀为 $\ce{Ag2CO3}$，不含（或需另行判断）$\ce{Cl^-}$。

**点评**：离子检验的核心是**排除干扰**。检验 $\ce{Cl^-}$ 用"稀硝酸 + $\ce{AgNO3}$"，关键是 $\ce{AgCl}$ 不溶于稀硝酸而 $\ce{Ag2CO3}$ 溶于稀硝酸。注意不能用盐酸酸化。

## 易错提醒

> [!warning] 易错点
> 1. **$\ce{MnO2}$ 只与浓盐酸反应**：稀盐酸不与 $\ce{MnO2}$ 反应；加热条件下浓盐酸才能反应，且盐酸变稀后反应停止。
> 2. **被氧化的 $\ce{HCl}$ 只有一半**：$4\ \mathrm{mol}$ 盐酸中 $2\ \mathrm{mol}$ 被氧化、$2\ \mathrm{mol}$ 体现酸性，做计算时勿把全部盐酸都当作还原剂。
> 3. **收集与除杂**：除 $\ce{HCl}$ 用**饱和食盐水**（不是水，水会溶解氯气）；干燥用**浓硫酸**；收集用**向上排空气**或**排饱和食盐水**。
> 4. **尾气处理必须用 $\ce{NaOH}$**：$\ce{Cl2}$ 有毒，不能直接排放；不能用石灰水（浓度太低吸收不充分）。
> 5. **验满用湿润淀粉碘化钾试纸**变蓝，不是用点燃的木条。
> 6. **氯离子检验必须先加稀硝酸**：排除 $\ce{CO3^{2-}}$ 等干扰，且不能用盐酸酸化。
> 7. **实验结束**先撤导管再灭灯，防止倒吸。
