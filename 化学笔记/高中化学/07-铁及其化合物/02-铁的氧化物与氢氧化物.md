# 铁的氧化物与氢氧化物

> [!abstract] 概览
> 本笔记系统整理铁的三种氧化物（$\ce{FeO}$、$\ce{Fe2O3}$、$\ce{Fe3O4}$）与两种氢氧化物（$\ce{Fe(OH)2}$、$\ce{Fe(OH)3}$）。重点是** $\ce{Fe(OH)2}$ 的制备必须隔绝氧气**（白色→灰绿色→红褐色），以及 $\ce{Fe3O4}$ 的化合价组成。这些是高考实验题与选择题的必考点。

## 核心概念

- 铁的氧化物都是**碱性氧化物**，能与酸反应生成盐和水，但不能与碱反应（区别于铝的氧化物）。
- 铁的氢氧化物都是**不溶性碱**，受热易分解。
- $\ce{Fe(OH)2}$ 极易被氧化，是本章实验设计的核心难点。

## 重点知识：铁的氧化物

| 氧化物 | $\ce{FeO}$ | $\ce{Fe2O3}$ | $\ce{Fe3O4}$ |
| --- | --- | --- | --- |
| 颜色 | 黑色粉末 | 红棕色粉末 | 黑色晶体 |
| 铁元素价态 | $+2$ | $+3$ | $+\frac{8}{3}$（$1$ 个 $\ce{Fe^{2+}}$、$2$ 个 $\ce{Fe^{3+}}$） |
| 俗称 | 无 | 铁红 | 磁性氧化铁 |
| 主要用途 | — | 红色颜料、炼铁原料 | 磁性材料（磁盘） |
| 与盐酸 | $\ce{FeO + 2H+ -> Fe^{2+} + H2O}$ | $\ce{Fe2O3 + 6H+ -> 2Fe^{3+} + 3H2O}$ | $\ce{Fe3O4 + 8H+ -> 2Fe^{3+} + Fe^{2+} + 4H2O}$ |

### 重要说明

1. **$\ce{Fe3O4}$ 的化合价**：可看作 $\ce{FeO.Fe2O3}$，即含 $1$ 个 $\ce{Fe^{2+}}$ 和 $2$ 个 $\ce{Fe^{3+}}$。1 mol $\ce{Fe3O4}$ 与盐酸反应生成 $2$ mol $\ce{Fe^{3+}}$ 和 $1$ mol $\ce{Fe^{2+}}$。
2. **$\ce{FeO}$ 不稳定**：在空气中加热容易被氧化，$6\ce{FeO} + \ce{O2} \xrightarrow{\Delta} 2\ce{Fe3O4}$。
3. **$\ce{Fe2O3}$ 是铝热反应的重要原料**：$\ce{Fe2O3 + 2Al \xrightarrow{高温} 2Fe + Al2O3}$。
4. **$\ce{Fe2O3}$ 的还原**：工业炼铁的主反应 $\ce{Fe2O3 + 3CO \xrightarrow{高温} 2Fe + 3CO2}$。
5. 三种氧化物都**不溶于水**，都不能直接与水反应生成氢氧化物。

> [!warning] $\ce{Fe3O4}$ 与盐酸的产物
> $\ce{Fe3O4}$ 与盐酸反应生成的是 $\ce{Fe^{3+}}$ 和 $\ce{Fe^{2+}}$ 的混合盐：$\ce{Fe3O4 + 8H+ -> 2Fe^{3+} + Fe^{2+} + 4H2O}$。不要误写成只生成 $\ce{Fe^{3+}}$。

## 重点知识：铁的氢氧化物

### 1. $\ce{Fe(OH)2}$ 的制备（重点实验）

**原理**：$\ce{FeSO4 + 2NaOH -> Fe(OH)2 v + Na2SO4}$

$\ce{Fe(OH)2}$ 为**白色**沉淀，但极易被空气中氧气氧化，故制备时**必须隔绝氧气**。

**操作要点（防氧化四件套）**：
1. 使用**新配制的 $\ce{FeSO4}$ 溶液**（或向溶液中加少量铁粉，防止 $\ce{Fe^{2+}}$ 被氧化）。
2. **$\ce{NaOH}$ 溶液加热煮沸**，除去溶解的氧气。
3. 用**长胶头滴管**将 $\ce{NaOH}$ 溶液**伸入 $\ce{FeSO4}$ 液面以下**再滴加。
4. 在液面上**加一层植物油（或苯）**，隔绝空气。

**现象**：白色沉淀 → 迅速变为**灰绿色** → 最终变为**红褐色**。

**氧化过程**：$4\ce{Fe(OH)2} + \ce{O2} + 2\ce{H2O} -> 4\ce{Fe(OH)3}$

> [!warning] 灰绿色沉淀怎么来的
> 白色 $\ce{Fe(OH)2}$ 在空气中被氧化时，部分被氧化成 $\ce{Fe(OH)3}$，两者混合呈灰绿色，最终完全氧化为红褐色 $\ce{Fe(OH)3}$。看到"灰绿色"要立即联想到 $\ce{Fe(OH)2}$ 被氧化。

### 2. $\ce{Fe(OH)3}$ 的制备与性质

- **制备**：$\ce{FeCl3 + 3NaOH -> Fe(OH)3 v + 3NaCl}$（红褐色沉淀）
- **与酸反应**：$\ce{Fe(OH)3 + 3H+ -> Fe^{3+} + 3H2O}$
- **受热分解**：$2\ce{Fe(OH)3} \xrightarrow{\Delta} \ce{Fe2O3} + 3\ce{H2O}$（红褐色粉末变红棕色）

### 3. 氢氧化铁胶体

- 制备（选必/拓展）：向沸水中滴加饱和 $\ce{FeCl3}$ 溶液：
  $$\ce{FeCl3 + 3H2O \xrightarrow{煮沸} Fe(OH)3(胶体) + 3HCl}$$
- 用途：$\ce{Fe(OH)3}$ 胶体可净水，与明矾净水原理类似（都是胶体的吸附性）。

### 4. $\ce{Fe(OH)2}$ 与 $\ce{Fe(OH)3}$ 对比总结

| 对比项 | $\ce{Fe(OH)2}$ | $\ce{Fe(OH)3}$ |
| --- | --- | --- |
| 颜色 | 白色（被氧化后灰绿色、红褐色） | 红褐色 |
| 制备原理 | $\ce{Fe^{2+} + 2OH^- -> Fe(OH)2 v}$ | $\ce{Fe^{3+} + 3OH^- -> Fe(OH)3 v}$ |
| 稳定性 | 极易被氧化 | 较稳定 |
| 与酸反应 | $\ce{Fe(OH)2 + 2H+ -> Fe^{2+} + 2H2O}$ | $\ce{Fe(OH)3 + 3H+ -> Fe^{3+} + 3H2O}$ |
| 受热分解 | 隔绝空气加热：$\ce{Fe(OH)2 -> FeO + H2O}$ | $2\ce{Fe(OH)3} \xrightarrow{\Delta} \ce{Fe2O3} + 3\ce{H2O}$ |
| 转化关系 | $4\ce{Fe(OH)2} + \ce{O2} + 2\ce{H2O} -> 4\ce{Fe(OH)3}$ | — |

> [!note] $\ce{Fe(OH)2}$ 隔绝空气分解
> $\ce{Fe(OH)2}$ 在隔绝空气条件下加热分解生成 $\ce{FeO}$：$\ce{Fe(OH)2 \xrightarrow{\Delta} FeO + H2O}$；但若在空气中加热，$\ce{FeO}$ 会被氧化为 $\ce{Fe3O4}$。两者条件不同，产物不同。

## 典型例题

### 例题 1：$\ce{Fe(OH)2}$ 制备实验

**题目**：实验室制备 $\ce{Fe(OH)2}$，下列操作不能达到预期目的的是（ ）
A. 用新配制的 $\ce{FeSO4}$ 溶液
B. 将 $\ce{NaOH}$ 溶液煮沸后冷却使用
C. 将滴管插入 $\ce{FeSO4}$ 液面以下滴加 $\ce{NaOH}$ 溶液
D. 在敞口容器中迅速混合两种溶液

**分析**：$\ce{Fe(OH)2}$ 极易被氧化，D 中敞口混合会让空气中的氧气迅速氧化 $\ce{Fe(OH)2}$，无法观察到白色沉淀。A、B、C 都是防氧化的正确操作。

**解答**：答案：**D**。

**点评**：制备 $\ce{Fe(OH)2}$ 的一切操作都围绕"**隔绝氧气**"展开——新制亚铁盐、煮沸除氧、伸入液面下、油封。这四个要点缺一不可。

### 例题 2：$\ce{Fe3O4}$ 与酸反应的计算

**题目**：将 $\ce{Fe3O4}$ 完全溶于足量盐酸中，所得溶液中 $\ce{n(Fe^{3+}) : n(Fe^{2+})}$ 为（ ）
A. $1 : 1$　　B. $2 : 1$　　C. $1 : 2$　　D. $3 : 1$

**分析**：$\ce{Fe3O4}$ 可看作 $\ce{FeO.Fe2O3}$，含 $1$ 个 $\ce{Fe^{2+}}$ 和 $2$ 个 $\ce{Fe^{3+}}$。与盐酸反应时，$\ce{FeO}$ 部分提供 $\ce{Fe^{2+}}$，$\ce{Fe2O3}$ 部分提供 $\ce{Fe^{3+}}$，无氧化还原。

**解答**：$\ce{Fe3O4 + 8H+ -> 2Fe^{3+} + Fe^{2+} + 4H2O}$，故 $\ce{n(Fe^{3+}) : n(Fe^{2+}) = 2 : 1}$，答案：**B**。

**点评**：记牢 $\ce{Fe3O4}$ 中"两价三价铁"的数量比（$\ce{Fe^{2+}}$:$1$，$\ce{Fe^{3+}}$:$2$），这是解计算题的关键。

## 易错提醒

> [!warning] 易错点清单
> 1. $\ce{FeO}$、$\ce{Fe2O3}$、$\ce{Fe3O4}$ 都是**黑色或红棕色**固体，都不溶于水、不与水反应。
> 2. $\ce{Fe(OH)2}$ 是**白色**沉淀（不是红褐色），红褐色是 $\ce{Fe(OH)3}$。
> 3. $\ce{Fe(OH)2}$ 制备必须隔绝氧气，四个防氧化要点要能默写。
> 4. $\ce{Fe(OH)3}$ 受热分解生成 $\ce{Fe2O3}$ 和 $\ce{H2O}$，条件是"加热"。
> 5. $\ce{Fe3O4}$ 与盐酸反应生成两种铁盐，方程式要会写。
> 6. 铝热反应用的是 $\ce{Fe2O3}$，不是 $\ce{FeO}$ 或 $\ce{Fe3O4}$（高考常考）。
