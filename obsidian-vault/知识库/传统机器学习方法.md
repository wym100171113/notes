# 传统机器学习方法

> [!abstract] 用途
> 在第四阶段作为对比基线，与 CNN 的识别性能进行比较，体现深度学习的优势。

## 1. SVM（支持向量机）

**核心思想**：寻找一个超平面，最大化不同类别之间的间隔（Margin）。

**与 CNN 对比**：
- SVM 需要手工提取特征（如 HOG、LBP、颜色直方图）
- CNN 自动学习特征，无需手工设计

**Scikit-learn 实现**：
```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler

# 特征提取（HOG）
from skimage.feature import hog

# 训练
svm = SVC(kernel='rbf', C=1.0, gamma='scale')
svm.fit(X_train, y_train)
```

## 2. KNN（K近邻）

**核心思想**：对于一个新样本，找出训练集中距离最近的 K 个样本，用多数投票决定分类。

**关键参数**：K 值（通常取 3、5、7）

**与 CNN 对比**：
- KNN 无训练过程，但推理时需要遍历所有训练样本（慢）
- CNN 训练耗时，但推理极快

**Scikit-learn 实现**：
```python
from sklearn.neighbors import KNeighborsClassifier

knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train)
```

## 3. 决策树（Decision Tree）

**核心思想**：通过一系列"如果-那么"规则进行决策，树的每个节点是一个特征判断。

**Scikit-learn 实现**：
```python
from sklearn.tree import DecisionTreeClassifier

dt = DecisionTreeClassifier(max_depth=10)
dt.fit(X_train, y_train)
```

## 4. 手工特征提取方法

### HOG（方向梯度直方图）
- 统计图像局部区域的梯度方向分布
- 适合描述物体轮廓和形状
- 常用于行人检测

### LBP（局部二值模式）
- 描述图像局部纹理特征
- 对光照变化不敏感

### 颜色直方图
- 统计图像的颜色分布
- 适合区分颜色差异大的类别

## 对比实验设计

| 方法 | 特征 | 优点 | 缺点 |
|------|------|------|------|
| CNN | 自动学习 | 准确率高，端到端 | 需要大量数据和计算 |
| SVM + HOG | 手工提取 | 小样本有效 | 特征设计依赖经验 |
| KNN | 原始像素 | 简单直观 | 推理慢，内存大 |
| 决策树 | 手工特征 | 可解释性强 | 容易过拟合 |
