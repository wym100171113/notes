# 硅单质与二氧化硅

> [!abstract] 概览
> 硅是地壳中含量**第二**的元素，自然界中只以**化合态**存在。本章重点：**晶体硅**（原子晶体、半导体材料、工业制硅与提纯）、**二氧化硅**（$\ce{SiO2}$ 的原子晶体结构与性质——酸性氧化物通性、与 $\ce{HF}$ 的特殊反应、弱氧化性）及其用途（光导纤维、石英玻璃）。

## 核心概念

### 1. 硅的存在与位置

- 位于第 3 周期第 IVA 族，原子序数 14，最外层 4 个电子，既能失电子又能得电子，但**主要以 +4 价**存在。
- 地壳中含量居**第二**（约 26.3%），自然界**没有游离态硅**，均以**硅酸盐**和 **$\ce{SiO2}$**（石英、水晶、沙子）等化合态存在。

### 2. 晶体硅的结构与性质

- **结构**：**原子晶体**，每个 $\ce{Si}$ 原子与 4 个 $\ce{Si}$ 原子以共价键相连，形成正四面体网状结构（与金刚石类似，键长更长、键能更小）。
- **物理性质**：灰黑色、有金属光泽的固体，硬度大，熔点高，是良好的**半导体材料**。
- **化学性质**：常温下化学性质稳定，不与 $\ce{O2}$、$\ce{H2O}$、盐酸、稀硫酸反应；但在加热或特定条件下反应。

## 工业制硅（三步法）

1. **粗硅的制取**（用焦炭在高温下还原 $\ce{SiO2}$）：
$$\ce{SiO2 + 2C ->[高温] Si + 2CO ^}$$
2. **提纯（生成气态氯化物）**：
$$\ce{Si + 2Cl2 ->[高温] SiCl4}$$
3. **用 $\ce{H2}$ 还原 $\ce{SiCl4}$（或高温分解 $\ce{SiHCl3}$）**：
$$\ce{SiCl4 + 2H2 ->[高温] Si + 4HCl}$$

> 通过"粗硅 → 气态 $\ce{SiCl4}$ → 高纯硅"的多步转化，利用 $\ce{SiCl4}$ 易挥发、易提纯的特点，得到高纯度硅（用于芯片制造）。

## 晶体硅的化学性质

- 与氟气（常温）：$\ce{Si + 2F2 -> SiF4}$
- 与氢氟酸：$\ce{Si + 4HF -> SiF4 ^ + 2H2 ^}$
- 与强碱溶液：$\ce{Si + 2NaOH + H2O -> Na2SiO3 + 2H2 ^}$
- 高温与 $\ce{O2}$：$\ce{Si + O2 ->[高温] SiO2}$

> [!note] 硅的"两性"误区
> 硅能与 $\ce{NaOH}$ 反应放出 $\ce{H2}$，但**不是典型的两性元素**（不与盐酸等非氧化性酸反应），只是"能与强碱反应的非金属单质"。

## 二氧化硅（$\ce{SiO2}$）

### 结构

- **原子晶体**：每个 $\ce{Si}$ 与 4 个 $\ce{O}$ 形成共价键，每个 $\ce{O}$ 与 2 个 $\ce{Si}$ 相连，形成立体网状结构。
- 由此导致 $\ce{SiO2}$ 熔点高、硬度大、不导电、化学性质稳定。

### 物理性质

- 硬度大、熔点高（$>1600\ \mathrm{℃}$），难溶于水。
- 天然存在：**石英**（结晶）、**水晶**（较纯石英）、**玛瑙**、沙子的主要成分。

### 化学性质

#### 1. 酸性氧化物的通性（但不溶于水）

- 与碱反应（生成可溶性硅酸盐）：
$$\ce{SiO2 + 2NaOH -> Na2SiO3 + H2O}$$
  （因此**碱液不能盛放在磨口玻璃塞的试剂瓶中**，应使用橡胶塞。）
- 与碱性氧化物反应（高温）：
$$\ce{SiO2 + CaO ->[高温] CaSiO3}$$
- 与 $\ce{Na2CO3}$ 反应（高温，玻璃工业原理）：
$$\ce{SiO2 + Na2CO3 ->[高温] Na2SiO3 + CO2 ^}$$
- **不能与水反应**（$\ce{SiO2}$ 不与水反应生成硅酸）。

#### 2. 特性：与氢氟酸反应

$$\ce{SiO2 + 4HF -> SiF4 ^ + 2H2O}$$

- 这是 $\ce{SiO2}$ 的**特征反应**，用于**刻蚀玻璃**（如在玻璃上雕刻花纹、标刻度）。
- 因此 **$\ce{HF}$ 不能盛放在玻璃容器中**（应盛于塑料或铅制容器中）。

#### 3. 弱氧化性

$$\ce{SiO2 + 2C ->[高温] Si + 2CO ^}$$

（工业制粗硅的原理，$\ce{Si}$ 被还原为单质。）

#### 4. 与一般酸不反应

- $\ce{SiO2}$ 不与盐酸、稀硝酸、浓硫酸反应（只有 $\ce{HF}$ 例外）。

## 用途

| 物质 | 用途 |
| --- | --- |
| 晶体硅 | 半导体材料：芯片、集成电路、太阳能电池板、晶体管 |
| $\ce{SiO2}$ | **光导纤维**（通信）、石英玻璃（耐高温仪器）、光学镜片、水晶饰品 |
| 硅胶（$\ce{H2SiO3}$ 脱水产物） | 干燥剂、催化剂载体 |

## 典型例题

### 例题 1

**题目**：下列关于 $\ce{SiO2}$ 的叙述正确的是（　）
A. $\ce{SiO2}$ 与 $\ce{CO2}$ 均为酸性氧化物，均能与水反应生成相应酸
B. $\ce{SiO2}$ 能与 $\ce{HF}$ 反应，说明它是碱性氧化物
C. $\ce{SiO2}$ 能与 $\ce{NaOH}$ 溶液反应，故可用 $\ce{SiO2}$ 制成的玻璃瓶长期盛放 $\ce{NaOH}$ 溶液
D. $\ce{SiO2}$ 是原子晶体，熔点很高

**分析**：A 错误：$\ce{SiO2}$ 虽为酸性氧化物，但**不与水反应**。B 错误：与 $\ce{HF}$ 反应是特性，不改变"酸性氧化物"分类。C 错误：$\ce{SiO2}$ 与 $\ce{NaOH}$ 反应生成 $\ce{Na2SiO3}$，会腐蚀玻璃，故碱液不能用玻璃塞瓶长期盛放。D 正确：$\ce{SiO2}$ 为原子晶体，熔点高。

**解答**：选 **D**。

**点评**：考查 $\ce{SiO2}$ 的两个"反常"：① 酸性氧化物但不溶于水；② 与 $\ce{HF}$ 反应。同时考查"碱液腐蚀玻璃"的常见应用问题。

### 例题 2

**题目**：工业上以石英砂（主要成分 $\ce{SiO2}$）和焦炭为原料制取粗硅，写出化学方程式；若要得到高纯硅，还需进一步提纯，写出提纯过程中的两步关键反应。

**分析**：粗硅由 $\ce{SiO2}$ 被 $\ce{C}$ 还原得到；提纯先将 $\ce{Si}$ 转化为易挥发的 $\ce{SiCl4}$，再用 $\ce{H2}$ 还原。

**解答**：
① $\ce{SiO2 + 2C ->[高温] Si + 2CO ^}$；
② $\ce{Si + 2Cl2 ->[高温] SiCl4}$；
③ $\ce{SiCl4 + 2H2 ->[高温] Si + 4HCl}$。

**点评**：工业制硅是"氧化还原 + 物质提纯"的经典流程。关键理解：粗硅纯度不够，需转化为气态 $\ce{SiCl4}$ 经蒸馏提纯后再还原为高纯硅。

## 易错提醒

> [!warning]
> - **$\ce{SiO2}$ 是酸性氧化物，但不与水反应**（不能直接制硅酸）。
> - **$\ce{SiO2}$ 只与 $\ce{HF}$ 反应**（$\ce{SiO2 + 4HF -> SiF4 + 2H2O}$），不与其他酸反应；$\ce{HF}$ 不能盛放在玻璃容器中。
> - **碱液不能长期盛放于玻璃塞试剂瓶**：$\ce{SiO2 + 2NaOH -> Na2SiO3 + H2O}$，$\ce{Na2SiO3}$ 有黏性，会黏住瓶塞。
> - 硅是半导体，$\ce{SiO2}$ 是光导纤维的主要原料——"硅与二氧化硅用途"勿混淆（硅：芯片/半导体；$\ce{SiO2}$：光纤/石英）。
> - 工业制硅中 $\ce{SiO2 + 2C ->[高温] Si + 2CO}$，产物是 $\ce{CO}$（不是 $\ce{CO2}$），因为碳过量且高温。
> - 硅能与 $\ce{NaOH}$ 反应放出 $\ce{H2}$，但不能据此说硅是"两性元素"。
