# 硫单质

> [!abstract] 概览
> 硫单质（俗称**硫黄**）是硫元素的游离态存在形式。学习重点是：硫的**物理性质**（黄色、难溶、易溶 $\ce{CS2}$）、**化学性质**（与变价金属生成低价硫化物、与氧气只生成 $\ce{SO2}$、与碱的歧化反应）以及**价态三角**。硫是氧化还原反应的"典型双面手"，既有氧化性又有还原性。

## 核心概念

- **位置与结构**：硫位于第 3 周期第 VIA 族，原子序数 16，最外层 6 个电子，易得 2 个电子形成 $\ce{S^{2-}}$（-2 价），也易与氧形成 +4、+6 价化合物。
- **存在形态**：
  - **游离态**：火山口附近的硫黄、含硫矿泉。
  - **化合态**：硫化物（如 $\ce{FeS2}$、$\ce{H2S}$）、硫酸盐（如 $\ce{CaSO4·2H2O}$、$\ce{Na2SO4·10H2O}$）。
- **常见化合价**：$\ce{-2}$、$\ce{0}$、$\ce{+4}$、$\ce{+6}$，构成"价态三角"。

## 物理性质

| 性质 | 描述 |
| --- | --- |
| 颜色状态 | 淡黄色固体，质脆 |
| 溶解性 | 难溶于水，微溶于酒精，**易溶于二硫化碳 $\ce{CS2}$** |
| 熔沸点 | 较低，加热可直接升华（易熔化） |
| 俗名 | 硫黄、硫磺 |

> [!note] 记忆技巧
> "硫黄难溶于水，但怕二硫化碳"——利用 $\ce{CS2}$ 溶解单质硫，可清洗试管内残留的硫。

## 化学性质

### 1. 与金属反应（生成低价硫化物）

| 反应 | 方程式 | 说明 |
| --- | --- | --- |
| 与铁 | $\ce{Fe + S ->[Δ] FeS}$ | 生成 $\ce{FeS}$（硫的氧化性弱，铁被氧化为 +2 价） |
| 与铜 | $\ce{2Cu + S ->[Δ] Cu2S}$ | 生成 $\ce{Cu2S}$（铜被氧化为 +1 价，**不是 $\ce{CuS}$**） |
| 与汞 | $\ce{Hg + S -> HgS}$ | **常温**即可反应，用于消除散落的汞（水银） |
| 与银 | $\ce{2Ag + S -> Ag2S}$ | 银器在空气中变黑的原因（表面生成 $\ce{Ag2S}$） |

> [!warning] 氧化性弱
> 硫与变价金属反应，**只能将金属氧化到低价态**（$\ce{Fe -> Fe^{2+}}$，$\ce{Cu -> Cu^{+}}$），这与氯气（可将 $\ce{Fe}$ 氧化到 $\ce{Fe^{3+}}$、$\ce{Cu}$ 氧化到 $\ce{Cu^{2+}}$）不同。记忆：**"氯氧铁三铜二，硫只铁二铜一。"**

### 2. 与非金属反应

| 反应 | 方程式 | 说明 |
| --- | --- | --- |
| 与氧气 | $\ce{S + O2 ->[点燃] SO2}$ | 只生成 $\ce{SO2}$，**不生成 $\ce{SO3}$** |
| 与氢气 | $\ce{H2 + S ->[Δ] H2S}$ | 生成硫化氢（无色有臭鸡蛋气味、有毒） |

### 3. 与强氧化性酸反应

- 与浓硫酸：$\ce{S + 2H2SO4(浓) ->[Δ] 3SO2 ^ + 2H2O}$
- 与浓硝酸：$\ce{S + 6HNO3(浓) ->[Δ] H2SO4 + 6NO2 ^ + 2H2O}$

> 此时硫表现出**还原性**（$\ce{0 -> +4}$ 或 $\ce{0 -> +6}$）。

### 4. 与碱反应（歧化反应）

$$\ce{3S + 6NaOH ->[Δ] 2Na2S + Na2SO3 + 3H2O}$$

- 单质硫在碱性条件下发生**自身氧化还原（歧化）**，$\ce{0}$ 价硫一部分降为 $\ce{-2}$ 价（$\ce{Na2S}$），一部分升为 $\ce{+4}$ 价（$\ce{Na2SO3}$）。
- 该反应可用来**除去试管中残留的硫**。

### 5. 价态三角（氧化还原主线）

```text
      S(+4)  SO2 / H2SO3 / SO3^2-
     ^   \
    /     \
   S(0) --→ 氧化剂氧化
   ↓还原性 ↑氧化性
  S(-2)  H2S / 硫化物 / S^2-
```

- **氧化性**：$\ce{S + Fe -> FeS}$、$\ce{S + 2Ag -> Ag2S}$。
- **还原性**：$\ce{S + O2 -> SO2}$、$\ce{S + 2H2SO4(浓) -> 3SO2 + 2H2O}$。
- 判断某价态硫显氧化性还是还原性，要看**价态变化方向**。

## 硫的氢化物：硫化氢（H2S）

- 物理性质：无色、有**臭鸡蛋气味**的**有毒气体**，密度比空气大，**能溶于水**。
- 化学性质：
  - **弱酸性**（氢硫酸是二元弱酸）：$\ce{H2S <=> H+ + HS-}$，$\ce{HS- <=> H+ + S^{2-}}$。
  - **强还原性**（$\ce{-2}$ 价硫）：在空气中不完全燃烧 $\ce{2H2S + O2 -> 2S + 2H2O}$；完全燃烧 $\ce{2H2S + 3O2 ->[点燃] 2SO2 + 2H2O}$。
  - 与 $\ce{SO2}$ 反应（归中）：$\ce{2H2S + SO2 -> 3S + 2H2O}$（实验室用于处理多余 $\ce{SO2}$）。
  - 与 $\ce{Cl2}$、酸性 $\ce{KMnO4}$、浓硫酸等氧化剂反应。
- 检验：能使湿润的**醋酸铅试纸**变黑（生成黑色 $\ce{PbS}$）。

> [!note] 硫化氢的实验室制备
> 用强酸与硫化物反应：$\ce{FeS + 2HCl -> FeCl2 + H2S ^}$（用稀盐酸或稀硫酸，不能用浓硫酸——浓硫酸会氧化 $\ce{H2S}$）。

## 用途

- 制硫酸（先制 $\ce{SO2}$，再催化氧化为 $\ce{SO3}$）。
- 制造**黑火药**（一硫二硝三木炭：$\ce{S}$、$\ce{KNO3}$、$\ce{C}$）。
- 橡胶**硫化**，增强弹性与强度。
- 制农药（石硫合剂）、医药（硫磺软膏）。

## 典型例题

### 例题 1

**题目**：下列说法正确的是（　）
A. 硫在过量氧气中燃烧生成 $\ce{SO3}$
B. 硫与铁、铜反应分别生成 $\ce{Fe2S3}$、$\ce{CuS}$
C. 硫既能表现氧化性，又能表现还原性
D. 硫难溶于水，但易溶于酒精

**分析**：逐项判断。A：硫在空气中或纯氧中燃烧都只生成 $\ce{SO2}$，与氧气过量与否无关，错误。B：硫氧化性弱，与铁、铜反应生成 $\ce{FeS}$、$\ce{Cu2S}$，错误。C：硫与金属反应作氧化剂、与氧气/强氧化性酸反应作还原剂，正确。D：硫微溶于酒精（不是易溶），易溶于 $\ce{CS2}$，错误。

**解答**：选 **C**。

**点评**：本题考查硫的"氧气过量仍只生成 $\ce{SO2}$"这一易错点，以及硫与变价金属生成**低价**硫化物。做题要抓住"硫的氧化性弱"这一本质。

### 例题 2

**题目**：汞洒落在地面后，可用硫粉处理，写出相关反应的化学方程式，并说明利用了什么性质。

**分析**：汞是液体，蒸气压大，有毒，需及时除去。硫粉能与汞在常温下反应生成固态的硫化汞，防止汞蒸气扩散。

**解答**：$\ce{Hg + S -> HgS}$，利用了硫的**氧化性**（将 $\ce{Hg}$ 氧化为 $\ce{Hg^{2+}}$，同时生成不挥发的 $\ce{HgS}$ 固体）。

**点评**：此反应在常温即可发生，是"硫粉处理水银"的经典实际应用，也体现了硫与变价金属反应生成低价态硫化物的一般规律。

### 例题 3

**题目**：将 $3.2\ \mathrm{g}$ 硫粉与足量铁粉混合加热，充分反应后生成 $\ce{FeS}$。求生成的 $\ce{FeS}$ 的质量。

**分析**：$\ce{Fe + S ->[Δ] FeS}$，硫粉与铁粉按 $1:1$ 反应。$n(\ce{S}) = \dfrac{3.2\ \mathrm{g}}{32\ \mathrm{g\cdot mol^{-1}}} = 0.1\ \mathrm{mol}$，则 $n(\ce{FeS}) = 0.1\ \mathrm{mol}$，$m(\ce{FeS}) = 0.1\ \mathrm{mol} \times 88\ \mathrm{g\cdot mol^{-1}} = 8.8\ \mathrm{g}$。

**解答**：$m(\ce{FeS}) = 8.8\ \mathrm{g}$。

**点评**：本题考查"物质的量"与化学方程式的简单计算。关键是先判断哪个反应物过量（铁粉足量，以硫为基准计算），再按计量关系求产物质量。

## 易错提醒

> [!warning]
> - **$\ce{S}$ 与 $\ce{O2}$ 反应只生成 $\ce{SO2}$**，无论氧气是否过量，都不会生成 $\ce{SO3}$（$\ce{SO3}$ 只能由 $\ce{SO2}$ 催化氧化制得）。
> - **硫与变价金属生成低价硫化物**：$\ce{FeS}$、$\ce{Cu2S}$，不是 $\ce{Fe2S3}$、$\ce{CuS}$。
> - **硫易溶于 $\ce{CS2}$，微溶于酒精**，不要与"难溶于水"混淆。
> - 硫与碱的歧化反应中，$\ce{S}$ 既是氧化剂又是还原剂，**氧化产物是 $\ce{Na2SO3}$，还原产物是 $\ce{Na2S}$**，氧化产物与还原产物物质的量之比为 $1:2$。
