# 二氧化硫

> [!abstract] 概览
> $\ce{SO2}$ 是硫的最重要氧化物，兼具**酸性氧化物通性**、**强还原性**、**弱氧化性**和独特的**漂白性**，是高考的"高频考点"。本章重点是：$\ce{SO2}$ 与水、碱的反应，与 $\ce{Br2}$、酸性 $\ce{KMnO4}$、$\ce{O2}$、氯水的氧化还原反应，以及**漂白原理与氯水的本质区别**和 $\ce{SO2}$ 的检验。

## 核心概念

- **分子组成**：$\ce{SO2}$，硫为 +4 价，处于中间价态，因此**既有还原性又有氧化性**（以还原性为主）。
- **物理性质**：
  - 无色、有**刺激性气味**的**有毒气体**；
  - 密度比空气**大**；
  - 极易液化；
  - **易溶于水**（常温下 1 体积水约溶解 40 体积 $\ce{SO2}$）。
- 制备（实验室）：$\ce{Na2SO3 + H2SO4(浓) -> Na2SO4 + SO2 ^ + H2O}$。
- 工业来源：燃烧含硫燃料、冶炼含硫矿石（$\ce{4FeS2 + 11O2 ->[高温] 2Fe2O3 + 8SO2}$）。

## 化学性质

### 1. 酸性氧化物的通性

- 与水反应（生成中强酸亚硫酸，**可逆**）：
$$\ce{SO2 + H2O <=> H2SO3}$$
- 与碱反应：
$$\ce{SO2 + 2NaOH -> Na2SO3 + H2O}$$
$$\ce{SO2 + Ca(OH)2 -> CaSO3 v + H2O}$$
- 与碱性氧化物反应：
$$\ce{SO2 + Na2O -> Na2SO3}$$
- 使紫色石蕊溶液**变红**（酸性能使指示剂变色，但**不褪色**）。

> [!note] 与 CO2 的"通性"比较
> $\ce{SO2}$ 与 $\ce{CO2}$ 都是酸性氧化物，都能使澄清石灰水变浑浊，都能被 $\ce{NaOH}$ 吸收。区分它们不能只看石灰水，而应利用 $\ce{SO2}$ 的**还原性**或**漂白性**（见典型例题）。

### 2. 还原性（$\ce{+4 -> +6}$，主要性质）

| 反应 | 方程式 | 现象 |
| --- | --- | --- |
| 与溴水 | $\ce{SO2 + Br2 + 2H2O -> 2HBr + H2SO4}$ | 溴水**褪色** |
| 与酸性 $\ce{KMnO4}$ | $\ce{5SO2 + 2KMnO4 + 2H2O -> K2SO4 + 2MnSO4 + 2H2SO4}$ | 紫红色**褪去** |
| 与氯水 | $\ce{SO2 + Cl2 + 2H2O -> 2HCl + H2SO4}$ | 氯水黄绿色**褪去** |
| 与氧气（催化氧化） | $\ce{2SO2 + O2 <=>[催化剂][Δ] 2SO3}$ | 工业制硫酸的关键一步 |
| 与 $\ce{FeCl3}$ | $\ce{SO2 + 2FeCl3 + 2H2O -> H2SO4 + 2FeCl2 + 2HCl}$ | 黄色变浅绿 |

> [!warning] SO2 使溴水、酸性 KMnO4 褪色是"氧化还原褪色"，不是漂白性！

### 3. 氧化性（$\ce{+4 -> 0}$，很弱）

$$\ce{SO2 + 2H2S -> 3S v + 2H2O}$$

- 黄色固体（硫）生成，说明 $\ce{SO2}$ 将 $\ce{H2S}$ 氧化，本身被还原为 $\ce{S}$。

### 4. 漂白性（重要考点）

- 原理：$\ce{SO2}$ 与某些有色物质（如品红）结合生成**不稳定的无色化合物**，加热或久置后颜色**恢复**。
- 特点：**可逆性**、选择性（对品红等特定有色物质有效，不能漂白石蕊等指示剂）。

| 物质 | 漂白原理 | 是否可逆 |
| --- | --- | --- |
| $\ce{SO2}$ | 与有色物质**化合**生成不稳定无色物质 | **可逆**（加热恢复原色） |
| 氯水 / $\ce{NaClO}$ / $\ce{H2O2}$ | **氧化**有色物质（破坏有色基团） | **不可逆** |
| 活性炭 | **物理吸附**色素 | 可逆（吸附） |

> [!important] 易混淆点
> - $\ce{SO2}$ 使**品红褪色**后，**加热又变红**（漂白性、可逆）。
> - 氯水使**品红褪色**后，**加热不变红**（氧化、不可逆）。
> - $\ce{SO2}$ 使溴水、酸性 $\ce{KMnO4}$ 褪色，是因为**还原性**（褪色后加热不恢复）。
> - 石蕊试液：$\ce{SO2}$ 使之**变红不褪色**；氯水使之**先变红后褪色**。

### 5. 酸雨的形成

$$\ce{SO2 ->[H2O] H2SO3 ->[O2] H2SO4}$$

硫酸型酸雨：$\ce{pH < 5.6}$，防治措施：减少含硫燃料燃烧、脱硫处理、开发新能源。

## 工业制硫酸（接触法）

| 步骤 | 反应 | 说明 |
| --- | --- | --- |
| 造气 | $\ce{4FeS2 + 11O2 ->[高温] 2Fe2O3 + 8SO2}$ | 沸腾炉 |
| 接触氧化 | $\ce{2SO2 + O2 <=>[V2O5][Δ] 2SO3}$ | 接触室，可逆、放热 |
| 吸收 | $\ce{SO3 + H2O -> H2SO4}$ | 用 $98.3\%$ 浓硫酸吸收（直接用水吸收会产生酸雾） |

> [!note] SO2 与 SO3、CO2 的对比
> | 气体 | 与水 | 与碱 | 漂白性 | 还原性 |
> | --- | --- | --- | --- | --- |
> | $\ce{SO2}$ | 生成 $\ce{H2SO3}$（可逆） | 生成亚硫酸盐 | 有（可逆） | 强 |
> | $\ce{SO3}$ | 生成 $\ce{H2SO4}$（放热） | 生成硫酸盐 | 无 | 无 |
> | $\ce{CO2}$ | 生成 $\ce{H2CO3}$（可逆） | 生成碳酸盐 | 无 | 无 |

## SO2 的检验

- **操作**：将气体通入**品红溶液**，若品红**褪色**，加热后**又恢复红色**，则证明是 $\ce{SO2}$。
- 注意：仅"使品红褪色"不足以证明是 $\ce{SO2}$（氯水也能使品红褪色），必须结合"加热恢复红色"来确认。

## 典型例题

### 例题 1

**题目**：能用来鉴别 $\ce{SO2}$ 和 $\ce{CO2}$ 的试剂是（　）
A. 澄清石灰水　B. 紫色石蕊试液　C. 品红溶液　D. $\ce{BaCl2}$ 溶液

**分析**：$\ce{SO2}$ 与 $\ce{CO2}$ 均为酸性氧化物，都能使澄清石灰水变浑浊、使石蕊变红，都含 $\ce{SO3^{2-}/CO3^{2-}}$ 弱酸根，故 A、B 不能鉴别；$\ce{BaCl2}$ 与两者均不反应（亚硫酸、碳酸均为弱酸，不能与 $\ce{BaCl2}$ 生成沉淀），D 不能鉴别；只有 $\ce{SO2}$ 能使品红褪色，$\ce{CO2}$ 不能，故 C 正确。

**解答**：选 **C**。

**点评**：鉴别题的关键是找**性质差异**。$\ce{SO2}$ 的"漂白性、还原性"是与 $\ce{CO2}$ 最显著的区别。

### 例题 2

**题目**：将 $\ce{SO2}$ 和 $\ce{Cl2}$ 按 $1:1$（同温同压下体积比）通入品红溶液，观察到的现象是（　）
A. 立即褪色　B. 不褪色　C. 先褪色后恢复　D. 颜色加深

**分析**：$\ce{SO2}$ 与 $\ce{Cl2}$ 按 $1:1$ 恰好完全反应：
$\ce{SO2 + Cl2 + 2H2O -> 2HCl + H2SO4}$。生成物 $\ce{HCl}$、$\ce{H2SO4}$ 均无漂白性，两者漂白能力相互"抵消"，故品红**不褪色**。

**解答**：选 **B**。

**点评**：这是高考经典陷阱——"两瓶混合气体都有漂白性，混合后漂白性反而消失"。做题时务必想到 $\ce{SO2}$ 的**还原性**与 $\ce{Cl2}$ 的**氧化性**会发生氧化还原反应。

### 例题 3

**题目**：某混合气体中可能含有 $\ce{SO2}$ 和 $\ce{CO2}$。为验证是否含 $\ce{SO2}$，可将混合气体依次通过：①品红溶液 ②酸性 $\ce{KMnO4}$ 溶液 ③品红溶液 ④澄清石灰水。请说明每一步的作用，并分析"②的作用是除去 $\ce{SO2}$ 且证明 $\ce{SO2}$ 已被除尽"的依据。

**分析**：①品红褪色 → 证明含 $\ce{SO2}$（$\ce{CO2}$ 不能使品红褪色）。②酸性 $\ce{KMnO4}$ 褪色 → 吸收（氧化）$\ce{SO2}$，同时说明 $\ce{SO2}$ 具有还原性。③品红不褪色 → 证明 $\ce{SO2}$ 已被除尽，防止其对检验 $\ce{CO2}$ 产生干扰（$\ce{SO2}$ 也能使石灰水变浑浊）。④石灰水变浑浊 → 证明含 $\ce{CO2}$。

**解答**：①检验 $\ce{SO2}$；②除去 $\ce{SO2}$（酸性 $\ce{KMnO4}$ 氧化 $\ce{SO2}$ 生成 $\ce{SO4^{2-}}$）；③确认 $\ce{SO2}$ 已除尽；④检验 $\ce{CO2}$。若③中品红不褪色，则证明 $\ce{SO2}$ 已被完全吸收，④中石灰水变浑浊一定是 $\ce{CO2}$ 所致。

**点评**：这是经典的"气体检验流程设计"——"检验 → 除杂 → 再检验是否除尽 → 检验目标气体"。凡是要检验 $\ce{CO2}$ 而气体中又可能含 $\ce{SO2}$，都必须先用酸性 $\ce{KMnO4}$ 或溴水除去 $\ce{SO2}$，并确认除尽后再通入石灰水。

## 易错提醒

> [!warning]
> - $\ce{SO2}$ 使**品红褪色**是漂白性（可逆）；使**溴水、酸性 $\ce{KMnO4}$ 褪色**是还原性（不可逆）。两者原理不同，勿混淆。
> - $\ce{SO2}$ 是**酸性氧化物**，与水生成的是**亚硫酸 $\ce{H2SO3}$**（中强酸），不是硫酸。
> - $\ce{SO2}$ 不能使石蕊褪色，只能使其**变红**；氯水能使石蕊**先变红后褪色**。
> - $\ce{SO2 + Cl2 + 2H2O -> 2HCl + H2SO4}$：当两者恰好完全反应时（$1:1$）漂白性消失。
> - 鉴别 $\ce{SO2}$ 时，要先看是否使品红褪色，再**加热看是否恢复红色**，两步缺一不可。
