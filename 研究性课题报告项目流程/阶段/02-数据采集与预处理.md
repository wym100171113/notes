# 第二阶段：数据采集与预处理

> [!info] 阶段概览
> **时间**：2026.09.01 ~ 2026.10.31（2 个月）
> **方法**：实地拍摄、公开数据集下载、数据标注
> **产出**：TrashNet 数据 + 校园自建数据集 + 数据增强后的训练集

## 任务清单

### 任务 1：下载并使用 TrashNet

- [ ] 下载 TrashNet 数据集（6 类约 2500 张）
- [ ] 熟悉数据集目录结构
- [ ] 统计各类别样本数量
- [ ] 可视化各类别样本图片
- [ ] 参考：[[数据集清单#TrashNet]]

### 任务 2：构建校园自建数据集

- [ ] 制定拍摄计划（场景、光照、角度、设备）
- [ ] 拍摄可回收物图像（目标 300+ 张）
- [ ] 拍摄厨余垃圾图像（目标 300+ 张）
- [ ] 拍摄有害垃圾图像（目标 200+ 张）
- [ ] 拍摄其他垃圾图像（目标 400+ 张）
- [ ] 总计目标：1000 ~ 2000 张

### 任务 3：数据清洗

- [ ] 去重（重复或高度相似的图像）
- [ ] 去模糊（删除模糊/低质量图像）
- [ ] 统一尺寸（resize 到 128×128）
- [ ] 统一格式（全部转为 JPG 或 PNG）
- [ ] 检查标签正确性

### 任务 4：数据增强

- [ ] 随机旋转（±15°）
- [ ] 水平翻转
- [ ] 随机裁剪 + 缩放
- [ ] 亮度/对比度调整
- [ ] 色彩扰动（参考知乎文章 `channel_shift_range`）
- [ ] 目标：扩充训练集至 3000+ 张

### 任务 5：数据集划分

- [ ] 训练集：70%
- [ ] 验证集：15%
- [ ] 测试集：15%
- [ ] 使用分层抽样（Stratified Split）保证类别均衡

> [!warning] 注意事项
> 验证集和测试集**不做数据增强**，仅做归一化（`rescale=1./255`）。
> 数据增强仅在训练集上进行。

## 知乎参考

参考文章 [[深度学习实战-基于CNN卷积神经网络的垃圾图像分类识别模型]] 的第 4.3 和 4.4 节：

- 使用 `train_test_split` 做分层抽样
- 使用 `ImageDataGenerator` 做数据增强
- 训练集增强参数：rotation_range=15, width_shift_range=0.1, height_shift_range=0.1, shear_range=0.1, zoom_range=0.1, horizontal_flip=True, brightness_range=(0.8,1.2)
