# 环境保护与绿色化学

> [!abstract] 概览
> 化学在推动发展的同时也带来环境问题。本笔记讲解主要的环境问题（酸雨、温室效应、光化学烟雾、臭氧层破坏）及其化学原理，并重点介绍**绿色化学**的理念——以**原子经济性**为核心，从**源头**减少污染，实现"零排放"。原子利用率计算是考查重点。

## 核心概念

### 1. 主要环境问题及化学原理

| 环境问题 | 主要污染物/来源 | 化学原理 |
| --- | --- | --- |
| 酸雨 | $\ce{SO2}$、氮氧化物（$\ce{NO_x}$） | 煤、石油燃烧排放 $\ce{SO2}$、$\ce{NO_x}$，溶于水生成 $\ce{H2SO3}$、$\ce{H2SO4}$、$\ce{HNO3}$，pH < 5.6 |
| 温室效应 | $\ce{CO2}$、$\ce{CH4}$ 等 | 化石燃料大量燃烧，温室气体使地球升温 |
| 光化学烟雾 | 氮氧化物、碳氢化合物 | 汽车尾气在日光下发生光化学反应，生成臭氧、醛类等刺激物 |
| 臭氧层破坏 | 氟氯烃（氟利昂）、$\ce{NO_x}$ | 氟氯烃释放 $\ce{Cl}$ 原子，催化分解臭氧 $\ce{O3}$ |

> [!note] 酸雨的界定
> 正常雨水的 pH 约为 5.6（溶解了空气中的 $\ce{CO2}$ 生成碳酸）。pH **小于 5.6** 的雨水才称为酸雨。

### 2. 绿色化学

- **核心思想**：从源头消除污染，而不是先污染后治理。
- **理想目标**：反应物中的原子**全部**转化为期望产物，实现"原子经济性"，零排放、零污染。

### 3. 原子经济性

**原子利用率** = $\dfrac{\text{期望产物的总质量}}{\text{反应物（生成物）总质量}} \times 100\%$。

- 原子利用率**越高**，说明原料转化为期望产物的程度越高，副产物越少，越"绿色"。
- **理想**的原子利用率为 **100%**：常见于**加成反应、化合反应、加聚反应**（无副产物）。
- **较低**的原子利用率：常见于**取代反应、消去反应、复分解反应**（生成小分子副产物，如 $\ce{HCl}$、$\ce{H2O}$、$\ce{CO2}$）。

> [!tip] 判断"绿色"的常见反应类型
> 原子利用率 100% 的典型：$\ce{CH2=CH2 + H2O -> CH3CH2OH}$、$\ce{CH2=CH2 + Br2 -> CH2BrCH2Br}$、加聚反应、化合反应。
> 有副产物"浪费原子"的典型：$\ce{CH4 + Cl2 -> CH3Cl + HCl}$（$\ce{HCl}$ 中的氢、氯原子未进入目标产物）。

## 重点知识

### 1. 绿色化学的五大原则（要点）

1. **防止污染优于治理污染**（从源头避免废物产生）。
2. **原子经济性**：最大限度利用原料中的原子。
3. **无害化学合成**：尽量不用有毒、有害的原料与溶剂。
4. **设计安全的化学品**：产物对人体和环境无害。
5. **使用可再生原料**：减少对不可再生资源（石油等）的依赖。

### 2. 原子利用率的计算

**公式**：$\text{原子利用率} = \dfrac{m(\text{期望产物})}{m(\text{全部产物})} \times 100\% = \dfrac{m(\text{期望产物})}{m(\text{反应物})} \times 100\%$。

> [!warning] 注意
> 原子利用率关注"质量"，与产率（产率 = 实际产量/理论产量）不同。原子利用率是从"原料利用是否彻底"角度评价反应，产率是从"实际得到多少"角度评价反应。

### 3. 典型绿色化学示例

- **理想反应**：$\ce{CH2=CH2 + H2O ->[催化剂] CH3CH2OH}$（原子利用率 100%）。
- **非理想反应**：$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$（$\ce{HCl}$ 为副产物，氢原子未全部进入目标产物）。
- **新型合成路线**：以 $\ce{CO2}$ 为原料合成碳酸酯等高分子，既固定温室气体又实现高原子经济性。

### 4. 生活中的环保行动（化学视角）

- 垃圾分类与资源回收（如废旧金属回收）。
- 推广清洁能源（氢能、太阳能），减少化石燃料燃烧。
- 汽车尾气净化：在催化剂作用下把 $\ce{CO}$、$\ce{NO_x}$ 转化为 $\ce{CO2}$、$\ce{N2}$。

## 典型例题

### 例题 1：原子利用率计算

**题目**：工业上用乙烯与水加成制乙醇：$\ce{CH2=CH2 + H2O -> CH3CH2OH}$。计算该反应的原子利用率。

**分析**：该反应是加成反应，产物只有乙醇一种，所有反应物的原子都进入期望产物，原子利用率应为 100%。

**解答**：
$$M(\ce{CH2=CH2}) = 28,\quad M(\ce{H2O}) = 18,\quad M(\ce{CH3CH2OH}) = 46$$
$$\text{原子利用率} = \frac{46}{28 + 18} \times 100\% = \frac{46}{46} \times 100\% = 100\%$$

**点评**：加成反应、化合反应、加聚反应原子利用率为 100%，是最"绿色"的反应类型。计算时用期望产物质量除以反应物总质量即可。

### 例题 2：绿色化学的判断

**题目**：下列做法符合绿色化学理念的是（　）
A. 用大量水稀释工业废水再排放
B. 用 $\ce{CH2=CH2}$ 与 $\ce{H2O}$ 直接加成制乙醇
C. 先排放尾气，再建处理装置治理
D. 大量使用氟氯烃作制冷剂

**分析**：稀释排放只是"转移污染"，不是从源头消除（A 错）；乙烯水化制乙醇原子利用率 100%、无副产物，符合原子经济性（B 对）；"先污染后治理"违背绿色化学"源头预防"理念（C 错）；氟氯烃破坏臭氧层（D 错）。

**解答**：选 **B**。

**点评**：绿色化学的核心是"源头预防 + 原子经济性"。凡强调"末端治理""稀释排放"的做法都不符合绿色化学理念。

## 环境问题的化学治理与新理念

### 常见污染的化学治理

| 污染 | 治理思路 |
| --- | --- |
| 酸雨 | 燃煤脱硫（用石灰石吸收 $\ce{SO2}$）、开发清洁能源 |
| 温室效应 | 节能减排、$\ce{CO2}$ 捕集利用（如合成碳酸酯） |
| 光化学烟雾 | 汽车尾气催化净化（$\ce{CO + NO ->[催化剂] CO2 + \tfrac12 N2}$） |
| 水污染 | 污水处理达标排放、减少含磷洗涤剂 |
| 白色污染 | 可降解塑料、回收再利用 |

### 绿色化学与"碳中和"

- 碳中和：通过植树造林、节能减排、$\ce{CO2}$ 捕集等方式抵消自身产生的 $\ce{CO2}$。
- 绿色化学是达成碳中和的重要化学手段（如以 $\ce{CO2}$ 为原料合成高附加值产品）。

### 原子经济性与产率的对比

| 比较项 | 原子经济性 | 产率 |
| --- | --- | --- |
| 评价角度 | 原料原子是否全部进入目标产物 | 实际产量与理论产量之比 |
| 关注点 | 过程是否"浪费"原子 | 结果是否"得到"足够多产物 |
| 理想值 | 100% | 接近 100% |

### 绿色化学经典考题点

- 判断反应是否"绿色"：加成、化合、加聚反应通常原子利用率高。
- 原料选择：尽量用无毒、可再生的原料。
- 催化剂：开发高效选择性催化剂，减少副产物。

## 易错提醒

> [!warning] 常见错误
> - "pH < 7 的雨水就是酸雨"❌ —— 正常雨水因溶有 $\ce{CO2}$ 显酸性（pH 约 5.6），pH < 5.6 才是酸雨。
> - "原子利用率与产率是一回事"❌ —— 原子利用率看"原子是否全部进入目标产物"（质量角度），产率看"实际产量与理论产量之比"。
> - "绿色化学 = 治理污染"❌ —— 绿色化学强调**源头预防**，先污染后治理不符合理念。
> - "所有有机反应都符合原子经济性"❌ —— 取代反应（如甲烷氯代）有副产物 $\ce{HCl}$，原子利用率较低。
> - "温室效应完全由 $\ce{CO2}$ 造成"❌ —— $\ce{CH4}$、$\ce{N2O}$ 等也是温室气体，但 $\ce{CO2}$ 是主要贡献者。
> - "汽车尾气净化是物理变化"❌ —— 尾气中 $\ce{CO}$、$\ce{NO_x}$ 在催化剂作用下转化为 $\ce{CO2}$、$\ce{N2}$，是化学变化。
