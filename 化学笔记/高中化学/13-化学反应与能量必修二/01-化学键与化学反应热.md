# 化学键与化学反应热

> [!abstract] 概览
> 化学反应的本质是**旧化学键断裂、新化学键形成**的过程。化学键的断裂要**吸收能量**，化学键的形成会**放出能量**，二者之差决定了反应是**放热**还是**吸热**。本笔记围绕"键能—能量变化"这条主线，讲解放热/吸热反应的判断、常见放热/吸热反应类型，以及利用键能计算反应热的方法。

## 核心概念

### 1. 化学键与能量

- 化学键是原子间强烈的相互作用，其强弱可用**键能**（断开 1 mol 化学键所吸收的能量）衡量，单位常用 $\ce{kJ·mol^{-1}}$。
- 化学反应过程中：
  - **断裂反应物中的化学键** → **吸收能量**（克服原子间的吸引力）；
  - **形成生成物中的化学键** → **放出能量**（原子间结合释放）。
- 反应热（能量变化）$\Delta H$ = 反应物总键能 − 生成物总键能 = 断键吸收的总能量 − 成键放出的总能量。

### 2. 放热反应与吸热反应

| 类型 | 能量关系 | 反应热 | 体系温度 | 能量图像 |
| --- | --- | --- | --- | --- |
| 放热反应 | 反应物总能量 > 生成物总能量 | $\Delta H < 0$ | 环境温度升高 | 反应物能量高，生成物能量低 |
| 吸热反应 | 反应物总能量 < 生成物总能量 | $\Delta H > 0$ | 环境温度降低 | 反应物能量低，生成物能量高 |

> [!note] 从微观键能角度理解
> 若断键吸收能量 **小于** 成键放出能量 → 放热（如 $\ce{H2 + Cl2 -> 2HCl}$）；
> 若断键吸收能量 **大于** 成键放出能量 → 吸热（如 $\ce{H2 + I2 -> 2HI}$ 在较低温度下吸热）。

### 3. 反应热计算的两种途径

1. **键能法**：$\Delta H$ = 反应物的键能总和 − 生成物的键能总和。
2. **能量法**：$\Delta H$ = 生成物的总能量 − 反应物的总能量（常用于图像题）。

## 重点知识

### 1. 常见的放热反应

- **燃烧反应**：一切燃料的燃烧，如 $\ce{CH4 + 2O2 -> CO2 + 2H2O}$。
- **中和反应**：酸与碱反应，如 $\ce{HCl + NaOH -> NaCl + H2O}$，均放热。
- **金属与酸反应**：如 $\ce{Zn + H2SO4 -> ZnSO4 + H2 ^}$。
- **大多数化合反应**：如 $\ce{CaO + H2O -> Ca(OH)2}$。
- **铝热反应**：$\ce{2Al + Fe2O3 ->[高温] Al2O3 + 2Fe}$。

### 2. 常见的吸热反应

- **大多数分解反应**：如 $\ce{CaCO3 ->[高温] CaO + CO2 ^}$、$\ce{2H2O ->[通电] 2H2 ^ + O2 ^}$。
- $\ce{C + CO2 ->[高温] 2CO}$。
- $\ce{Ba(OH)2·8H2O + 2NH4Cl -> BaCl2 + 2NH3 ^ + 10H2O}$（固体混合，温度明显下降）。
- 碳与水蒸气（水煤气）反应：$\ce{C + H2O(g) ->[高温] CO + H2}$。

> [!tip] 判断技巧
> 吸热反应常见的"扛把子"是 $\ce{C}$ 参与的还原反应、大多数分解反应和 $\ce{Ba(OH)2·8H2O + NH4Cl}$ 实验。判断时先看是否属于这些"模板"，再看能量图像（反应物总能量低则吸热）。

### 3. 利用键能计算反应热

**步骤**：
1. 写出化学方程式并配平。
2. 数出反应物与生成物中各化学键的数目（注意结构式）。
3. 代入公式：$\Delta H$ = 反应物键能总和 − 生成物键能总和。

**示例**：$\ce{H2(g) + Cl2(g) -> 2HCl(g)}$，已知 $\ce{H-H}$ 键能 $436\ \mathrm{kJ·mol^{-1}}$，$\ce{Cl-Cl}$ 键能 $243\ \mathrm{kJ·mol^{-1}}$，$\ce{H-Cl}$ 键能 $431\ \mathrm{kJ·mol^{-1}}$。

$$\Delta H = (436 + 243) - 2 \times 431 = 679 - 862 = -183\ \mathrm{kJ·mol^{-1}}$$

反应放热 $183\ \mathrm{kJ·mol^{-1}}$。

### 4. 放热与吸热的图像判断

在"反应过程—能量"图像中：
- 若反应物的总能量线**高于**生成物 → 放热反应，$\Delta H < 0$。
- 若反应物的总能量线**低于**生成物 → 吸热反应，$\Delta H > 0$。
- 图中最高点表示**活化能**（过渡态能量），与反应热是两回事。

> [!warning] 活化能与反应热
> 反应热只取决于反应物与生成物的总能量之差，与是否需要活化能无关。放热反应也可能需要先加热引发（如铝热反应需要高温点燃）。

## 典型例题

### 例题 1：键能计算反应热

**题目**：已知断裂 1 mol 下列化学键所需能量：$\ce{H-H}$ 为 $436\ \mathrm{kJ}$，$\ce{N-H}$ 为 $391\ \mathrm{kJ}$，$\ce{N#N}$ 为 $946\ \mathrm{kJ}$。试计算反应 $\ce{N2(g) + 3H2(g) -> 2NH3(g)}$ 的反应热。

**分析**：先数化学键。反应物含 1 个 $\ce{N#N}$ 三键和 3 个 $\ce{H-H}$ 键；生成物 2 mol $\ce{NH3}$ 含 6 个 $\ce{N-H}$ 键。反应热 = 反应物键能总和 − 生成物键能总和。

**解答**：
$$\Delta H = (946 + 3 \times 436) - 6 \times 391 = (946 + 1308) - 2346 = 2254 - 2346 = -92\ \mathrm{kJ·mol^{-1}}$$

答：该反应为放热反应，$\Delta H = -92\ \mathrm{kJ·mol^{-1}}$。

**点评**：本题是键能计算的典型题，关键在于**准确数出分子中化学键的数目**（如 1 mol $\ce{NH3}$ 有 3 个 $\ce{N-H}$ 键），并注意键能单位是 $\ce{kJ·mol^{-1}}$，切勿漏乘物质的量。

### 例题 2：放热/吸热反应的判断

**题目**：下列反应属于吸热反应的是（　）
A. $\ce{CH4 + 2O2 ->[点燃] CO2 + 2H2O}$　B. $\ce{CaO + H2O -> Ca(OH)2}$
C. $\ce{Ba(OH)2·8H2O + 2NH4Cl -> BaCl2 + 2NH3 ^ + 10H2O}$　D. $\ce{Fe + H2SO4 -> FeSO4 + H2 ^}$

**分析**：A 是燃烧（放热）；B 是化合反应中的金属氧化物与水化合（放热）；D 是金属与酸反应（放热）；C 是经典的吸热反应，固体混合后温度显著降低。

**解答**：选 **C**。

**点评**：判断吸热/放热不能死记硬背"化合都放热、分解都吸热"，因为个别特例存在；但本题的 C 选项是教材经典实验，属于必记模板。考试中先认模板，再结合能量图像复核。

## 图像题与比较技巧

### 能量—反应过程图像

- 横轴表示反应过程，纵轴表示能量。
- 反应物总能量线高于生成物 → 放热；低于 → 吸热。
- 图像中的"峰"对应活化能（过渡态），峰的"高度"与反应热无关。

### 常见比较方法

| 问题 | 判断依据 |
| --- | --- |
| 哪个反应放热更多 | 比较反应物总能量与生成物总能量之差 |
| 键能大说明什么 | 键能越大，键越牢固，该化学键越难断裂 |
| 放热反应一定自发吗 | 一般自发，但需要活化能引发（如燃烧需点燃） |

### 反应热大小比较易错点

- 比较 $\Delta H$ 大小时注意正负号：放热越多，$\Delta H$ 数值越小（负得越多）。
- 如 $\ce{H2(g) + O2(g)}$ 完全燃烧生成液态水放热多于生成气态水，故 $\Delta H$ 更小。

### 记忆口诀

"断键吸、成键放；反应热 = 断键吸收 − 成键放出；放热为负、吸热为正。"

## 易错提醒

> [!warning] 常见错误
> - "断键放出能量，成键吸收能量"❌ —— 断键**吸收**能量，成键**放出**能量。
> - "放热反应不需要加热"❌ —— 放热反应也可能需要点燃/加热引发（如 $\ce{CH4}$ 燃烧需点燃）。
> - "吸热反应必须加热才能进行"❌ —— $\ce{Ba(OH)2·8H2O}$ 与 $\ce{NH4Cl}$ 常温即可进行且明显降温。
> - 键能计算时忘记乘以化学计量数对应的键数目❌ —— 如 1 mol $\ce{NH3}$ 含 3 个 $\ce{N-H}$ 键，2 mol $\ce{NH3}$ 是 6 个。
> - 把"反应热"与"活化能"混淆❌ —— 活化能对应能量图像中的"峰高"，反应热对应"反应物—生成物能量差"。
