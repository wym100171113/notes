# 烃（烷、烯、炔与芳香烃）

> [!abstract] 概览
> 烃是只含碳、氢的有机物，是有机化学的"骨架"。本笔记依次掌握**烷烃**（取代）、**烯烃**（加成、加聚、氧化）、**炔烃**（乙炔的制备与性质）与**芳香烃**（苯及苯的同系物）的结构与性质。核心是抓住**碳碳单键/双键/三键与苯环"特殊结构"**决定的不同反应类型。

## 核心概念

### 1. 烷烃
- 通式：$\ce{C_nH_{2n+2}}$（$n\ge1$），碳原子均为 $sp^3$ 杂化，只含 σ 键。
- 物理性质：随碳原子数增多，熔沸点升高；$n\le4$ 为气态；不溶于水。
- 化学性质：性质稳定，不与强酸、强碱、强氧化剂反应。
  - **取代反应（卤代）**：光照下与 $\ce{Cl2}$ 等发生自由基取代。
    $$\ce{CH4 + Cl2 ->[光照] CH3Cl + HCl}$$
  - **氧化反应**：燃烧。$\ce{C_nH_{2n+2} + \dfrac{3n+1}{2}O2 ->[点燃] nCO2 + (n+1)H2O}$
  - **裂化/裂解**：$\ce{C16H34 -> C8H18 + C8H16}$ 等，用于制取小分子烯烃与汽油。

### 2. 烯烃
- 通式：$\ce{C_nH_{2n}}$（含一个 $\ce{C=C}$），双键碳为 $sp^2$ 杂化，含 1σ+1π，π 键易断裂。
- **加成反应**（特征反应）：
  - 加卤素：$\ce{CH2=CH2 + Br2 -> CH2BrCH2Br}$（溴水褪色，用于检验烯烃）。
  - 加 $\ce{H2}$：$\ce{CH2=CH2 + H2 ->[催化剂] CH3CH3}$。
  - 加 $\ce{HX}$：$\ce{CH2=CH2 + HCl -> CH3CH2Cl}$（不对称烯烃按马氏规则）。
  - 加水：$\ce{CH2=CH2 + H2O ->[催化剂、加压] CH3CH2OH}$（工业制乙醇）。
- **加聚反应**：$\ce{nCH2=CH2 ->[催化剂] [-CH2-CH2-]_n}$（聚乙烯）。
- **氧化反应**：燃烧；使酸性 $\ce{KMnO4}$ 溶液褪色（被氧化）。
- 二烯烃可发生 1,4-加成（共轭二烯）。

### 3. 炔烃
- 通式：$\ce{C_nH_{2n-2}}$（含一个 $\ce{C≡C}$），三键碳为 $sp$ 杂化，含 1σ+2π。
- **乙炔的实验室制备**：
  $$\ce{CaC2 + 2H2O -> Ca(OH)2 + CH≡CH \uparrow}$$
  （电石 + 水，用饱和食盐水可减缓反应速率）
- 乙炔性质：
  - 燃烧：明亮火焰，含碳量高；
  - 与 $\ce{Br2}$ 加成：$\ce{CH≡CH + 2Br2 -> CHBr2CHBr2}$；
  - 与 $\ce{H2}$ 分步加成可制乙烯、乙烷；
  - 与 $\ce{HCl}$ 加成制氯乙烯，再聚合成聚氯乙烯（PVC）。

### 4. 芳香烃——苯
- 苯分子式 $\ce{C6H6}$，平面正六边形，六个碳均为 $sp^2$ 杂化，6 个碳间形成大 π 键（介于单双键之间）。
- **结构特征**：苯环中碳碳键完全相同，键长相等，既不是单键也不是双键。
- 化学性质："**易取代、难加成、可氧化（苯本身难氧化）**"。
  - **取代反应**：
    - 硝化：$\ce{C6H6 + HNO3 ->[浓H2SO4、加热] C6H5NO2 + H2O}$（硝基苯）。
    - 卤代：$\ce{C6H6 + Br2 ->[FeBr3] C6H5Br + HBr}$（溴苯）。
    - 磺化：$\ce{C6H6 + H2SO4(浓) ->[加热] C6H5SO3H + H2O}$（苯磺酸）。
  - **加成反应**：与 $\ce{H2}$ 在催化下生成环己烷：$\ce{C6H6 + 3H2 ->[催化剂] C6H12}$。
  - 苯不能使溴水、酸性 $\ce{KMnO4}$ 溶液褪色（区别于烯、炔）。

### 5. 苯的同系物
- 通式：$\ce{C_nH_{2n-6}}$（$n\ge6$），如甲苯 $\ce{C6H5CH3}$。
- 性质：苯环上取代（邻、间、对）；**侧链受苯环影响易被氧化**，能使酸性 $\ce{KMnO4}$ 溶液褪色（苯不能）：
  $$\ce{C6H5CH3 ->[KMnO4/H+] C6H5COOH}$$
- 甲苯硝化：$\ce{C6H5CH3 + 3HNO3 ->[浓H2SO4] C6H2CH3(NO2)3 + 3H2O}$（TNT，2,4,6-三硝基甲苯）。

## 重点知识

### 烃类性质对比速查表

| 烃 | 通式 | 结构特点 | 特征反应 | 使溴水褪色 | 使 KMnO4 褪色 |
| --- | --- | --- | --- | --- | --- |
| 烷烃 | $\ce{C_nH_{2n+2}}$ | 只含 σ 键 | 取代（光照） | 否 | 否 |
| 烯烃 | $\ce{C_nH_{2n}}$ | 含 $\ce{C=C}$ | 加成、加聚 | 是 | 是 |
| 炔烃 | $\ce{C_nH_{2n-2}}$ | 含 $\ce{C≡C}$ | 加成 | 是 | 是 |
| 苯 | $\ce{C6H6}$ | 大 π 键 | 取代（催化） | 否（萃取分层） | 否 |
| 苯的同系物 | $\ce{C_nH_{2n-6}}$ | 苯环+侧链 | 取代、侧链氧化 | 否 | 是 |

> [!warning] 溴水褪色辨析
> 烯、炔使溴水褪色是**加成反应**（化学变化）；苯使溴水**萃取分层**（上层橙红色、下层无色）是物理变化，不算褪色。

## 典型例题

### 例题 1：乙炔的制备与性质
**题目**：实验室用碳化钙与水反应制取乙炔，写出反应方程式并说明为何用饱和食盐水代替水。

**分析**：电石与水反应剧烈，放热，用饱和食盐水可减小 $\ce{CaC2}$ 与水的接触、减缓反应速率，便于控制。

**解答**：$\ce{CaC2 + 2H2O -> Ca(OH)2 + CH≡CH\uparrow}$。用饱和食盐水代替水能减缓反应速率、控制气流平稳。

**点评**：电石法制乙炔是常考实验，注意产物 $\ce{Ca(OH)2}$ 是微溶物；生成的乙炔常混有 $\ce{H2S}$、$\ce{PH3}$ 等杂质，可用 $\ce{CuSO4}$ 溶液除去。

### 例题 2：苯的性质辨析
**题目**：下列事实能证明苯分子中碳碳键不是单双键交替的是（　）① 苯不能使溴水褪色；② 苯不能使酸性 $\ce{KMnO4}$ 溶液褪色；③ 苯的邻二甲苯只有一种；④ 苯环上碳碳键长均相等。

**分析**：若碳碳键单双交替，则邻位二取代物应有两种（相邻单键、双键两种位置），且碳碳键长应有两种。

**解答**：③ 邻二甲苯只有一种、④ 碳碳键长相等都能直接证明；① ② 也支持但不如 ③④ 直接。选 ③④。

**点评**：邻位二取代物只有一种，是证明苯环不存在交替单双键的经典依据。

### 例题 3：烃的燃烧计算
**题目**：某气态烃 10 mL 完全燃烧生成 30 mL $\ce{CO2}$ 和 20 mL 水蒸气（同温同压），求该烃的分子式并判断可能属于哪类烃。

**分析**：同温同压下气体体积比 = 物质的量比。设烃为 $\ce{C_xH_y}$：
$$x=\frac{V(\ce{CO2})}{V(\ce{烃})}=\frac{30}{10}=3,\qquad y=\frac{2\times V(\ce{H2O})}{V(\ce{烃})}=\frac{2\times20}{10}=4$$
分子式为 $\ce{C3H4}$。$\ce{C3H4}$ 满足通式 $\ce{C_nH_{2n-2}}$（$n=3$），属于炔烃或二烯烃。

**解答**：分子式为 $\ce{C3H4}$，可能为丙炔 $\ce{CH≡CCH3}$ 或丙二烯 $\ce{CH2=C=CH2}$，属于炔烃（或二烯烃）。

**点评**：燃烧计算抓住"碳守恒、氢守恒"：$x=V(\ce{CO2})/V(\ce{烃})$，$y=2V(\ce{H2O})/V(\ce{烃})$。算出的 H 数 $y$ 必须满足 $y\le2x+2$ 且为偶数，否则数据有误。

## 易错提醒

> [!warning] 易错点
> 1. **烷烃不能使溴水/酸性 KMnO4 褪色**，烯、炔可以（加成/氧化）。
> 2. **苯使溴水"萃取分层"不是褪色**，不能据此说苯与溴发生了反应。
> 3. **苯的同系物（甲苯）能使酸性 KMnO4 褪色，而苯不能**，关键在侧链。
> 4. **乙炔中碳为 sp 杂化**，直线形，四个原子共线；烯烃双键碳 $sp^2$ 共面。
> 5. **加成反应"原子利用率 100%"**，取代反应不是；写方程式别漏无机小分子（如 $\ce{HCl}$、$\ce{H2O}$）。
> 6. **烃分子中 H 数必为偶数**（CnH2n+2、2n、2n-2、2n-6），计算结果若为奇数要复查。
