## 一、(共8题，每题8分)

1. 不能表示为两个素数之和的大于2的最小偶数是$\_\_\_\_\_\_$.

2. 能表示成$n^2 + 1 \ (n \in \mathbb{Z})$形式的最大素数为 $\_\_\_\_\_\_$.

3. 在平面上任给$n \ (n \geq 2)$个点$A_1, A_2, \dots, A_n$，其中任意两点间的距离不超过1，则
$\max_{1 \leq i < j \leq n} \min A_i A_j = \_\_\_\_\_\_.$

4. 若关于$x, y, z$的方程$\frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} \ (n \geq 2)$无正整数解，则$n$的最小值为 $\_\_\_\_\_\_$.

5. 记$\sigma(n) = \sum_{d|n} d \ (d \in \mathbb{Z}^*)$，则满足$\sigma(n) = 2n$最小的奇数为 $\_\_\_\_\_\_$.

6. 已知$f(x) \in \mathbb{Z}[x]$，且$f(e + \pi) = 0$，则$\deg f(x) = \_\_\_\_\_\_$.

7. 记$p_n$为从小到大第$n$个素数，则所有满足$p_{n+1} - p_n = 2$的正整数$n$的和为 $\_\_\_\_\_\_$.

8. 给定整数$m$，若平面上任意$n$个点中必有$m$个点构成一个凸$m$边形的$m$个顶点，则$n$的最小值为 $\_\_\_\_\_\_$.

## 二、解答题

9. (本题16分) 证明：
$$
\int_0^1 \left( \sum_{p \leq 2N} e^{2\pi i p \alpha} \right)^2 e^{-4\pi i N \alpha} d\alpha > 0
$$

10. (本题20分) 对任意正整数$n$，定义
$$
f(n) = \begin{cases} 
3n + 1, & \text{当 } n \text{ 为奇数}, \\
\frac{n}{2}, & \text{当 } n \text{ 为偶数}
\end{cases}
$$
给定的正整数$n$，试求最小的正整数$k$，使得$f^{(k)}(n) = 1$.

11. (本题20分) 记$\zeta(s) = \sum_{1}^{+\infty} \frac{1}{n^s} \ (s \in \mathbb{C})$，证明：$\zeta(s)$的零点除非负整数外，实部都是$\frac{1}{2}$.
