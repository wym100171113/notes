# 第四阶段：模型优化与对比分析

> [!info] 阶段概览
> **时间**：2027.02.01 ~ 2027.04.30（3 个月）
> **方法**：模型调优、迁移学习、对比实验
> **产出**：优化后的 CNN 模型 + 传统方法对比 + 完整评估报告

## 任务清单

### 任务 1：CNN 模型结构优化

- [ ] 尝试不同网络深度（2层 / 3层 / 4层卷积模块）
- [ ] 尝试不同卷积核大小（3×3 / 5×5）
- [ ] 尝试不同 Dropout 比例（0.25 / 0.3 / 0.5）
- [ ] 尝试不同优化器（Adam / SGD + Momentum）
- [ ] 记录每次实验的配置与结果

### 任务 2：迁移学习

- [ ] 加载预训练 ResNet18 / ResNet34 模型
- [ ] 冻结卷积层，替换全连接层
- [ ] 微调（Fine-tuning）：解冻最后几层卷积
- [ ] 对比从头训练 vs 迁移学习的效果
- [ ] 记录：训练时间、收敛速度、最终准确率

### 任务 3：传统机器学习方法对比

- [ ] 使用 HOG / LBP 手工特征提取
- [ ] 训练 SVM 分类器
- [ ] 训练 KNN 分类器
- [ ] 训练决策树分类器
- [ ] 将 CNN 特征与传统特征对比
- [ ] 参考：[[传统机器学习方法]]

### 任务 4：综合评估

- [ ] 评估指标：准确率（Accuracy）
- [ ] 评估指标：精确率（Precision）
- [ ] 评估指标：召回率（Recall）
- [ ] 评估指标：F1-score
- [ ] 绘制混淆矩阵（Confusion Matrix）
- [ ] 对比表：CNN 各变体 + 迁移学习 + SVM + KNN
- [ ] 目标：最终 CNN 在校园自建数据集准确率 ≥ 90%

> [!tip] 实验管理建议
> 每次实验使用 [[实验记录模板]] 记录，便于后续论文撰写时回溯。
> 关键实验参数用表格汇总，一目了然。
