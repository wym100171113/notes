- 浓硝酸与铜（分子方程式）  
  $Cu(s) + 4HNO_3(\text{conc}) \rightarrow Cu(NO_3)_2(aq) + 2NO_2(g) + 2H_2O(l)$

- 浓硝酸与铜（离子方程式，去掉观测离子）  
  $Cu(s) + 4H^+(aq) + 2NO_3^-(aq) \rightarrow Cu^{2+}(aq) + 2NO_2(g) + 2H_2O(l)$

- 浓硝酸的氧化还原半反应（配电子）  
  - 氧化： $Cu \rightarrow Cu^{2+} + 2e^-$  
  - 还原： $NO_3^- + 2H^+ + e^- \rightarrow NO_2 + H_2O$  
  （将还原式乘以 $2$，与氧化式相加即可得到总反应）

- 稀硝酸与铜（分子方程式）  
  $3Cu(s) + 8HNO_3(\text{dil}) \rightarrow 3Cu(NO_3)_2(aq) + 2NO(g) + 4H_2O(l)$

- 稀硝酸与铜（离子方程式，去掉观测离子）  
  $3Cu(s) + 8H^+(aq) + 2NO_3^-(aq) \rightarrow 3Cu^{2+}(aq) + 2NO(g) + 4H_2O(l)$

- 稀硝酸的氧化还原半反应（配电子）  
  - 氧化： $Cu \rightarrow Cu^{2+} + 2e^-$  
  - 还原： $NO_3^- + 4H^+ + 3e^- \rightarrow NO + 2H_2O$  
  （将还原式乘以 $2$、氧化式乘以 $3$ 后相加得到总反应）

- 说明  
  - 浓硝酸中，硝酸根多被还原为 $NO_2$（棕色气体）；稀硝酸中多被还原为 $NO$（无色气体，遇空气可被氧化为 $NO_2$）。  
  - 铜被氧化为 $Cu^{2+}$，生成硝酸铜溶液。

什么是吉布斯自由能（直观比喻）
- 吉布斯自由能可以看作“可用来做非体积外功（如化学转化、电化学做功等）的能量”。  
- 如果一个过程能把能量转成我们想要的有用功（或向着平衡自发进行），通常对应自由能下降；反之，若自由能升高则不自发（需要外界供能）。

核心公式（要记住的几个）
- 反应自由能变： $ΔG = ΔH - TΔS$  
  - $ΔH$：反应的焓变（吸放热）  
  - $ΔS$：反应的熵变（无序度改变）  
  - $T$：温度（单位 K）
- 标准与任意条件： $ΔG = ΔG^\circ + RT\ln Q$  
  - $ΔG^\circ$：标准自由能变（所有物质在标准状态）  
  - $Q$：反应商（当前浓度/分压关系）
- 平衡常数关系： $ΔG^\circ = -RT\ln K$  
  - 当 $ΔG^\circ$ 很负时，$K$ 很大，平衡偏向生成物

判定自发性的简单规则
- $ΔG < 0$：反应在给定条件下自发进行（向生成物方向）  
- $ΔG = 0$：反应达到平衡（没有净变化）  
- $ΔG > 0$：反应在该条件下不自发（需要外界做功或改变条件）

注意：自发性是热力学概念，只说明方向和能否进行；反应速率（动力学）要看活化能和反应机理，二者不同概念。

例子 1：氢气与氧气生成水（放热、强正向自发）
- 反应： $2H_2 + O_2 \rightarrow 2H_2O$（液态水）  
- 在 298 K，标准自由能变约 $ΔG^\circ \approx -237\ \mathrm{kJ\ mol^{-1}}$（每摩尔水）。  
- 结论：$ΔG^\circ$ 很负，反应热力学上强烈自发（解释为什么燃烧/爆燃会放能）。但需点火（动力学上的活化能）才能快速发生。

例子 2：合成氨（哈柏法，平衡受温度/压力影响）
- 反应： $N_2 + 3H_2 \rightleftharpoons 2NH_3$  
- 该反应在低温下放热，$ΔG^\circ$ 更负（有利生成 NH3），但低温反应速率非常慢；高温速率快但平衡被推向反应物端。  
- 工业上通过提高压力和使用催化剂，在折衷温度下达到较高产率。这说明：热力学告诉我们是否可能（ΔG），动力学与条件决定实际产率和速率。

例子 3：硝酸铵溶于水（吸热但仍自发，熵起主要作用）
- 硝酸铵溶解是吸热过程（$ΔH>0$），但溶解后溶液的无序度增加（$ΔS>0$）；若 $TΔS$ 大于 $ΔH$，则 $ΔG<0$，过程自发。  
- 这就是一次性冷敷包冷却的原理：吸热但自发，溶液温度下降。

例子 4：电池反应（自由能与电动势的关系）
- 电化学反应： $ΔG = -nFE$  
  - $n$：转移的电子数，$F$：法拉第常数，$E$：电池电动势（伏）  
- 若 $E>0$，则 $ΔG<0$，电池能自发放电输出电能。

简单定量示例（把概念数字化）
- 假设某反应的 $ΔG^\circ = -30\ \mathrm{kJ\ mol^{-1}}$，求平衡常数 $K$ 在 298 K 下的大致值：  
  - 用 $ΔG^\circ = -RT\ln K$，取 $R = 8.314\ \mathrm{J\,mol^{-1}K^{-1}}$，$T=298\ \mathrm{K}$，注意单位要一致（J）：  
  - $-30000 = -8.314\times298\times\ln K$ → $\ln K \approx 12.1$ → $K \approx e^{12.1}\approx 1.8\times10^5$。  
  - 结论：$K$ 很大，平衡强烈偏向生成物。

总结（把握重点）
- 吉布斯自由能告诉你“反应在给定条件下能否自发发生以及距离平衡远近”。  
- 公式 $ΔG = ΔH - TΔS$ 把能量与无序两个因素结合起来，$ΔG^\circ = -RT\ln K$ 将热力学与化学平衡联系起来。  
- 热力学（ΔG）说能否发生，动力学（活化能、催化剂）说快不快。  
- 在实际化学和工业过程中，常通过改变温度、压力、浓度或耦合反应来控制 $ΔG$ 方向或有效实现转化。

- 概述  
  - 杂化轨道（hybrid orbitals）是价键理论（valence bond, VB）为解释分子中定向共价键而引入的一种线性组合模型。直观上把原子轨道（$s,p$ 等）按一定权重线性叠加，形成能指向特定空间方向、适合形成 $\sigma$ 键的“杂化轨道”。  
  - 这是一个有效的近似：用来解释键角、键形状、以及为什么某些原子形成特定几何构型（如四面体、平面三角、直线等）。

- 数学表述（行内公式示例）  
  - $sp^3$ 杂化： $|sp^3\rangle = \frac{1}{2}\big(|s\rangle + |p_x\rangle + |p_y\rangle + |p_z\rangle\big)$（等权简写，归一化系数见下）。  
  - $sp^2$ 杂化： $|sp^2\rangle = \frac{1}{\sqrt{3}}\big(|s\rangle + |p_x\rangle + |p_y\rangle\big)$。  
  - $sp$ 杂化： $|sp\rangle = \frac{1}{\sqrt{2}}\big(|s\rangle + |p_x\rangle\big)$。  
  - 一般 $sp^n$ 的线性组合中，$s$ 与 $p$ 分量的相对权重可写成： $|sp^n\rangle = \frac{1}{\sqrt{1+n}}\big(|s\rangle + \sqrt{n}\,|p\rangle\big)$，因此 $s$ 成分的系数为 $1/\sqrt{1+n}$，$p$ 成分的总系数为 $\sqrt{n/(1+n)}$。  
  - 这些表达式仅表示轨道混合的方向与成分比，并隐含归一化。

- 常见杂化类型与几何（和典型键角）  
  - $sp^3$：四面体，键角约 $109.5^\circ$（例：甲烷 $CH_4$）。  
  - $sp^2$：平面三角，键角约 $120^\circ$（例：乙烯 $C_2H_4$，苯中的碳）。  
  - $sp$：线性，键角 $180^\circ$（例：乙炔 $C_2H_2$）。  
  - 含孤对电子的例外：氨 $NH_3$（近似 $sp^3$，但孤对使键角降到 $\sim107^\circ$）；水 $H_2O$（近似 $sp^3$，键角 $\sim104.5^\circ$）。

- 典型例子与示意（行内公式）  
  - 甲烷 $CH_4$：碳基态 $2s^2 2p^2$，概念上“激发”到 $2s^1 2p^3$ 然后形成四个 $sp^3$，每个 $sp^3$ 与一个 H 的 $1s$ 形成 $\sigma$ 键，从而解释等价的四个 C–H 键和四面体构型。反应式式样（示意）： $|sp^3_C\rangle + |1s_H\rangle \rightarrow \sigma(C-H)$。  
  - 乙烯 $C_2H_4$：每个碳采用 $sp^2$ 杂化，三个 $sp^2$ 形成平面内的 $\sigma$ 键（两个与 H，一个与另一 C），剩下的未杂化 $p_z$ 轨道侧向重叠生成 $\pi$ 键，从而得到 C=C 双键（一个 $\sigma$ + 一个 $\pi$）。  
  - 乙炔 $C_2H_2$：碳采用 $sp$ 杂化，两个 $sp$ 形成线性的 $\sigma$ 键（与 H 与对方 C），每个碳剩两个垂直的未杂化 $p$ 形成两个垂直的 $\pi$ 键，构成三键（$\sigma$ + 两个 $\pi$）。

- 如何判定原子杂化（常用经验法）  
  - 电子域/价电子对数法：观测原子周围的电子域数（键与孤对计作一个域）。域数为 4 → $sp^3$；3 → $sp^2$；2 → $sp$。注意：共振、二次键或扩展周期会引起偏差。  
  - 结合实验数据：键角、键长、光谱与计算结果常用来验证或修正简单判定。

- 理论发展与历史要点（简单时间线）  
  - 1920 年代以前：价键与共价键概念成形（Heitler–London、Lewis 电子对等）。  
  - 1931 年：Linus Pauling 正式提出“杂化轨道”的概念，以解释有方向性的键与等价键的出现。  
  - 随后几十年：价键理论（含杂化）与分子轨道（MO）理论并行发展（Hund、Mulliken 等对 MO 做出贡献）。  
  - 20 世纪中后期：随着量子化学计算发展，杂化被看作一种有用的近似或解释框架；严格的电子结构由分子轨道计算给出。现代视角通常用计算化学（HF、DFT 等）判断轨道组成、键序与电子密度分布。  
  - 当代：杂化理论仍广泛用于教学和快速定性判断，但复杂/受离域影响的体系（芳香族、过渡金属配合物、超价分子等）更多依赖 MO/计算来精确描述。

- 局限与细化（重要）  
  - 局限：杂化是局部、近似的概念，不能总是精确描述离域化体系（如苯的 π 离域）、过渡金属化学、或强电负性/电荷转移明显的键。  
  - 非整数杂化：实测与计算常给出非整数 $sp^{n}$（如 $sp^{2.3}$），表示 $s$/$p$ 成分的连续变化，符合 Bent 定律（Bent's rule）：“电负性大的取代基与杂化轨道中更多 $p$ 成分相连，电正性取代基倾向于与更多 $s$ 成分相连”。  
  - 替代理论：对许多体系，分子轨道（MO）理论能更自然地描述电子离域与能级分布；杂化可视为局域化 MO 的一种变换（线性组合）。

- 与实验的对应证据  
  - 键角/键长（X 射线衍射、电子衍射、红外/拉曼光谱）与杂化预测一致时，支持该杂化模型。  
  - 光电子能谱与计算轨道成分分析可以定量给出 $s$/$p$ 比例，验证或修正简单杂化模型。  
  - 量子化学计算（如自然轨道、自然键轨道 NBO 分析）常直接给出“原子的杂化成分百分比”。

- 实用提示（教学与笔记中的写法）  
  - 在 Obsidian 中写行内公式示例：写 $sp^3$、$|sp^2\rangle = \frac{1}{\sqrt{3}}(|s\rangle+|p_x\rangle+|p_y\rangle)$ 等，均会被渲染。  
  - 想要表达非整数杂化，可直接写 $sp^{2.3}$ 或 $|sp^{2.3}\rangle = \frac{1}{\sqrt{1+2.3}}(|s\rangle+\sqrt{2.3}\,|p\rangle)$。  
  - 加入实际分子例子（如 $CH_4$, $C_2H_4$, $C_2H_2$, $NH_3$, $H_2O$, 苯 C6H6）并配上键角数字，有助理解。

- 总结（要点回顾）  
  - 杂化轨道是价键理论中的一种线性组合近似，用于解释键的方向性和等价性。  
  - 常见类型 $sp^3$、$sp^2$、$sp$ 分别对应四面体、平面三角、线性几何；孤对和共振会引起偏差。  
  - 历史上由 Pauling 系统化，引入教学与定性解释；现代则更多结合 MO 与量子化学计算来精确描述电子结构。  
  - 杂化仍是化学入门与有机化学理解结构与反应性的核心工具，但要注意其局限并在必要时使用更精确的计算与实验证据。

- 基本概念  
  - 电离（ionization）：弱电解质或气体在溶液中分解成离子的过程，常用平衡表示（弱酸举例）： $HA \rightleftharpoons H^+ + A^-$，对应的酸离解常数 $K_a = \dfrac{[H^+][A^-]}{[HA]}$。  
  - 水解（hydrolysis）：水分子与可电离离子反应，生成酸或碱的过程，常见于盐溶液或可质子化/去质子化的离子。例如阴离子水解： $A^- + H_2O \rightleftharpoons HA + OH^-$；阳离子水解： $B^+ + H_2O \rightleftharpoons BOH + H^+$（具体产物视体系而定）。

- 水的自离（自电离）  
  - 自离方程： $2H_2O \rightleftharpoons H_3O^+ + OH^-$（简写为 $H_2O \rightleftharpoons H^+ + OH^-$）。  
  - 离子积： $K_w = [H^+][OH^-]$，在 $25^\circ\mathrm{C}$ 时 $K_w = 1.0\times10^{-14}$，因此纯水中 $[H^+]=[OH^-]=1.0\times10^{-7}$，$pH = 7$。  
  - 温度依赖：$K_w$ 随温度变化（升温时通常增大），因此“中性 pH”随温度改变。

- 酸碱平衡与 pH 关系  
  - $pH = -\log_{10}[H^+]$，$pOH = -\log_{10}[OH^-]$，且 $pH + pOH = pK_w$（在 $25^\circ\mathrm{C}$ 下为 $14$）。  
  - Henderson–Hasselbalch 方程（缓冲溶液）： $pH = pK_a + \log\frac{[A^-]}{[HA]}$，用于弱酸-其共轭碱缓冲体系。

- 弱电解质的电离度与近似计算  
  - 对初始浓度为 $C$ 的弱酸 $HA$，若电离度为 $α$，则 $[H^+] = αC$，$[A^-] = αC$，$[HA] = (1-α)C$，代入得： $K_a = \dfrac{α^2 C}{1-α}$。当 $α \ll 1$（即 $K_a \ll C$）时，近似 $α \approx \sqrt{\dfrac{K_a}{C}}$，从而 $[H^+] \approx \sqrt{K_a C}$。  
  - 例子：$0.10\ \mathrm{M}$ 乙酸（$K_a=1.8\times10^{-5}$），估算 $[H^+] \approx \sqrt{1.8\times10^{-5}\times0.10} = 1.34\times10^{-3}$，$pH \approx 2.87$。

- 共轭酸碱间的关系  
  - 对共轭酸碱对 $HA/A^-$ 有 $K_a K_b = K_w$，其中 $K_b$ 为 $A^-$ 的碱常数。即 $K_b = \dfrac{K_w}{K_a}$。这在判断盐水解方向时很有用。

- 盐的水解（常见类型与方程）  
  - 强酸 + 强碱生成的盐（如 $NaCl$）：不水解，溶液近中性（忽略离子相互作用与高浓度效应）。  
  - 强酸的阴离子或强碱的阳离子（如 $Na^+$、$Cl^-$）：通常不水解。  
  - 弱酸的阴离子（如 $CH_3COO^-$）会水解生成碱性溶液： $A^- + H_2O \rightleftharpoons HA + OH^-$，其碱度常数 $K_b = \dfrac{[HA][OH^-]}{[A^-]} = \dfrac{K_w}{K_a}$。  
  - 弱碱的阳离子（如 $NH_4^+$）会水解生成酸性溶液： $BH^+ + H_2O \rightleftharpoons B + H_3O^+$，其酸度常数 $K_a = \dfrac{[B][H_3O^+]}{[BH^+]} = \dfrac{K_w}{K_b}$。  
  - 例子：醋酸钠 $CH_3COONa$ 在水中： $CH_3COO^- + H_2O \rightleftharpoons CH_3COOH + OH^-$，$K_b(CH_3COO^-)=K_w/K_a(CH_3COOH)$，因此溶液呈碱性。氯化铵 $NH_4Cl$： $NH_4^+ + H_2O \rightleftharpoons NH_3 + H_3O^+$，溶液呈酸性。

- 多步水解与高电荷金属离子  
  - 高电荷或小半径的金属阳离子（如 $Al^{3+}, Fe^{3+}$）可发生逐步水解并放出多个质子：  
    - $M^{3+} + H_2O \rightleftharpoons M(OH)^{2+} + H^+$  
    - $M(OH)^{2+} + H_2O \rightleftharpoons M(OH)_2^+ + H^+$，……  
  - 这些平衡常数通常很小，但总体使溶液酸化，并常导致水解沉淀（形成氢氧化物沉淀）或生成配合物。

- 两性/两亲物种与缓冲、两侧反应  
  - 两性离子（amphiprotic），如 $HCO_3^-$：既能作为酸也能作为碱，水解表现与其 $K_a$ 和 $K_b$（或两步电离常数）共同决定。  
  - 若 $X$ 是两性离子，其等效水解常数可由 $K_a$ 与 $K_b$ 的关系导出，用于求解其溶液 pH。

- 活度与离子强度的影响  
  - 实际溶液中应使用活度 $a_i = \gamma_i [i]$（$\gamma_i$ 为活度系数）而非浓度来精确写平衡常数。离子强度增大时 $\gamma_i$ 偏离 1，会影响平衡位置和观测的 pH（特别是高浓度或多价离子体系）。  
  - 常见近似：稀溶液中可用浓度近似活度；对定量精算或高离子强度体系建议使用 Debye–Hückel 或扩展模型计算 $\gamma_i$。

- 常见效应与应用  
  - 共同离子效应（common-ion effect）：加入含弱酸/弱碱的共轭离子会抑制电离或水解（Le Châtelier 原理），用于抑制溶解或改变 pH。  
  - 缓冲溶液：通过弱酸/其共轭碱或弱碱/其共轭酸的配比，利用 Henderson–Hasselbalch 方程稳定 pH。  
  - 水解在环境与材料中重要：土壤化学、金属离子水化与沉淀、药物溶解度与离子化态、工业废水处理等。

- 计算示例（数值演示）  
  - 醋酸根 $0.10\ \mathrm{M}$：已示例估算 $[OH^-]$（同 $[H^+]$ 的处理），也可由 $K_b = K_w/K_a = 1.0\times10^{-14}/1.8\times10^{-5} = 5.56\times10^{-10}$，设 $x$ 为 $[OH^-]$，则 $K_b = x^2/(0.10-x)\approx x^2/0.10$，得 $x\approx\sqrt{5.56\times10^{-11}} = 7.46\times10^{-6}$，$pOH \approx 5.13$，$pH \approx 8.87$。  
  - 铵盐 $0.10\ \mathrm{M}$：$K_a(NH_4^+) = K_w/K_b(NH_3)$（若 $K_b(NH_3)=1.8\times10^{-5}$），则 $K_a \approx 5.56\times10^{-10}$，类似求解可得酸性 pH。

- 实验与测量注意事项  
  - 精确 pH 测量需注意离子强度、温度、缓冲能力与电极校准；高离子强度或有机溶剂混合体系下要修正活度。  
  - 在计算水解与电离时注意单位一致性、简化近似的适用条件（如 $x\ll C$）以及多平衡耦合问题（需解联立方程或数值求解）。

- 小结（要点）  
  - 电离描述物质在溶液中生成离子的平衡，水解描述离子与水反应生成酸/碱的平衡；两者常用 $K_a$, $K_b$, $K_w$ 来表征并通过 $pH$ 描述溶液酸碱性。  
  - 判断溶液酸碱性时要看盐的来源（强/弱酸、强/弱碱）及离子本身的酸碱性质；复杂体系需考虑活度、离子强度与多步平衡。

- 基本概念（直观）  
  - 同离子效应（common-ion effect）：当溶液中已存在某个与弱电解质解离产生相同离子的“同离子”时，根据勒夏特列原理（Le Châtelier），该弱电解质的电离/溶解会被抑制。换言之，外加同离子使平衡向生成未电离物或固体一侧移动，从而降低其溶解度或电离度。  
  - 缓冲溶液（buffer）：由弱酸与其共轭碱或弱碱与其共轭酸组成的体系，能抵抗少量强酸或强碱加入时的 pH 变化。缓冲的核心在于存在足够的可与加来的 H+ 或 OH- 发生中和反应的共轭对。

- 同离子效应的数学描述（以弱酸 $HA$ 为例）  
  - 弱酸电离： $HA \rightleftharpoons H^+ + A^-$，酸度常数 $K_a = \dfrac{[H^+][A^-]}{[HA]}$。  
  - 若外加相同的 $A^-$（例如加入 $A^-X$ 或其盐），初始 $[A^-]$ 增大，则为维持 $K_a$，平衡需减小 $[H^+]$ 或增大 $[HA]$，即电离被抑制。  
  - 近似处理：初始 $[HA]=C$，外加 $[A^-]=C_s$，电离量 $x$ 很小时，$K_a \approx \dfrac{x(C_s)}{C}$，因此 $x \approx \dfrac{K_a C}{C_s}$，显示 $x$ 随同离子浓度 $C_s$ 增大而减小。

- 同离子效应的两类常见实例  
  - 抑制电离（弱酸/弱碱）：如在醋酸溶液中加入醋酸钠会显著降低醋酸的电离度并使 pH 接近 $pK_a$（等摩尔时 pH≈$pK_a$）。  
  - 抑制溶解（难溶盐）：如 $AgCl(s) \rightleftharpoons Ag^+ + Cl^-$，若溶液中已存在 $Cl^-$（例如加入 $NaCl$），则 $AgCl$ 的溶解度被大幅压低。利用平衡常数 $K_{sp}=[Ag^+][Cl^-]$ 可定量计算。

- Henderson–Hasselbalch 方程与缓冲原理（推导）  
  - 从 $K_a = \dfrac{[H^+][A^-]}{[HA]}$ 可得 $[H^+] = K_a \dfrac{[HA]}{[A^-]}$。两边取负对数，得到 Henderson–Hasselbalch 方程： $pH = pK_a + \log\frac{[A^-]}{[HA]}$。  
  - 该式在用浓度近似活度、并假定溶液中 $[A^-]$ 与 $[HA]$ 变化由酸碱中和主导时非常适用。  
  - 缓冲最有效的 pH 范围通常为 $pK_a \pm 1$，此时两组分浓度相当且缓冲容量最大。

- 缓冲容量与影响因素（要点）  
  - 缓冲容量（buffer capacity）大致与缓冲组分的绝对浓度成正比：浓度越大，能中和的酸/碱摩尔数越多，pH 变化越小。  
  - 当添加的强酸/强碱的量小于缓冲组分摩尔数的少许百分比时，用 Henderson–Hasselbalch 的逐步中和法计算非常准确。  
  - 活度效应：在高离子强度下应用活度修正（$a_i=\gamma_i[i]$），否则用浓度计算会有偏差。

- 数值例题 1：同离子效应（醋酸系统）  
  - 题目：已知 $K_a(CH_3COOH)=1.8\times10^{-5}$。  
    - 情况 A：$0.10\ \mathrm{M}$ 醋酸溶液，求 $[H^+]$ 与 $pH$（不加任何醋酸根）。  
    - 情况 B：在上述 $0.10\ \mathrm{M}$ 醋酸中加入 $0.10\ \mathrm{M}$ 醋酸钠（$CH_3COONa$），求新的 $[H^+]$ 与 $pH$。  
  - 解答：  
    - 情况 A（弱酸单独电离近似）： 令电离度产生 $x=[H^+]$，近似 $x \ll 0.10$，则 $K_a \approx \dfrac{x^2}{0.10}$，于是 $x \approx \sqrt{K_a\times0.10} = \sqrt{1.8\times10^{-5}\times0.10} = 1.34\times10^{-3}$，$pH \approx -\log(1.34\times10^{-3}) \approx 2.87$。  
    - 情况 B（有同离子 $[A^-]_0=0.10$）：设因 HA 电离产生 $x$，则 $[H^+]=x$，$[A^-]=0.10+x\approx0.10$，$[HA]=0.10-x\approx0.10$（因 $x\ll0.10$）。代入 $K_a$ 得 $K_a \approx \dfrac{x\cdot0.10}{0.10} = x$，所以 $[H^+] \approx K_a = 1.8\times10^{-5}$，$pH \approx 4.74$（等于 $pK_a$，因为近似下 $[A^-]\approx[HA]$）。  
  - 结论：加入同离子后 $[H^+]$ 从 $1.34\times10^{-3}$ 降到 $1.8\times10^{-5}$，电离被强烈抑制，pH 显著升高。

- 数值例题 2：缓冲溶液计算与加入强酸/强碱后的 pH 变化  
  - 题目：配制 1.00 L 溶液，含 $0.100\ \mathrm{mol}$ 醋酸（$CH_3COOH$）和 $0.050\ \mathrm{mol}$ 醋酸根（来自 $CH_3COONa$）。已知 $pK_a=4.744$（$K_a=1.8\times10^{-5}$）。  
    - (a) 求初始 pH。  
    - (b) 向该溶液中加入 $0.00100\ \mathrm{mol}$ HCl（强酸），求新 pH。  
    - (c) 向原始溶液加入 $0.00200\ \mathrm{mol}$ NaOH（强碱），求新 pH。  
  - 解答：  
    - (a) 用 Henderson–Hasselbalch： $pH = pK_a + \log\frac{[A^-]}{[HA]}$，此处用摩尔数比（体积相同，浓度比等于摩尔数比）。所以 $pH = 4.744 + \log\frac{0.050}{0.100} = 4.744 + \log(0.5) = 4.744 - 0.301 = 4.443$。  
    - (b) 加 HCl：HCl 会与 $A^-$ 中和： $A^- + H^+ \rightarrow HA$。新摩尔数： $n_{A^-}=0.050-0.00100=0.0490$，$n_{HA}=0.100+0.00100=0.101$（总体体积近似不变为 1.00 L）。用 Henderson–Hasselbalch： $pH = 4.744 + \log\frac{0.0490}{0.101} = 4.744 + \log(0.485) = 4.744 - 0.314 = 4.430$。pH 只下降约 $0.013$，说明缓冲作用显著。  
    - (c) 加 NaOH：NaOH 会与 $HA$ 中和： $HA + OH^- \rightarrow A^- + H_2O$。新摩尔数： $n_{HA}=0.100-0.00200=0.0980$，$n_{A^-}=0.050+0.00200=0.0520$。$pH = 4.744 + \log\frac{0.0520}{0.0980} = 4.744 + \log(0.531) = 4.744 - 0.275 = 4.469$。pH 上升约 $0.026$。  
  - 结论：在小量强酸/碱加入时，缓冲溶液的 pH 变化很小；变化方向与所加物质（酸使 pH 降，碱使 pH 升）一致。

- 同离子效应在溶解度问题中的应用（数值示例）  
  - 例：$AgCl(s) \rightleftharpoons Ag^+ + Cl^-$，$K_{sp}=1.8\times10^{-10}$（假设值）。  
    - 在纯水中，可溶解度 $s$ 满足 $K_{sp}=s^2$，所以 $s=\sqrt{1.8\times10^{-10}}=1.34\times10^{-5}\ \mathrm{M}$。  
    - 若在 $0.010\ \mathrm{M}$ NaCl 中溶解 $AgCl$，则 $[Cl^-]\approx0.010$（来自 NaCl），$[Ag^+]=s'$，满足 $K_{sp}=s'\times0.010$，因此 $s'=\dfrac{1.8\times10^{-10}}{0.010}=1.8\times10^{-8}\ \mathrm{M}$。  
    - 溶解度被约 $1.34\times10^{-5}/1.8\times10^{-8}\approx745$ 倍地抑制 —— 明显的同离子效应。

- 注意事项与现实修正  
  - 活度而非浓度：严格平衡应使用活度（$a_i=\gamma_i[i]$），在高离子强度或高浓度体系中不得不修正。Henderson–Hasselbalch 用浓度通常在稀溶液里足够好。  
  - 缓冲范围与选择：选择 pK_a 接近目标 pH 的酸/碱对，且组分浓度要足够大以获得所需的缓冲容量。  
  - 非等体积加入：若加入强酸/强碱的体积不可忽略，应用摩尔数并除以新总体积来得到新浓度再代入 Henderson–Hasselbalch 或完整平衡方程。

- 小结（要点回顾）  
  - 同离子效应：外加同离子会抑制弱电解质的电离或难溶盐的溶解，通常可以通过修改平衡初始浓度并用平衡常数定量计算。  
  - 缓冲溶液：由弱酸/共轭碱（或弱碱/共轭酸）组成，pH 可由 $pH = pK_a + \log\frac{[A^-]}{[HA]}$ 快速估算；缓冲容量与组分绝对浓度有关，最佳在 $[A^-]\approx[HA]$（即 pH≈pK_a）。  
  - 在精确计算时注意活度、离子强度与总体积的变化。

基本定义与物理意义
- 焓（$H$）：在恒压过程下系统与外界交换的热量（含内部能与体积功项的综合），常用于化学反应的放/吸热描述。反应的焓变记作 $ΔH$。
- 熵（$S$）：表示体系无序程度或能量分散程度的量，熵增意味着能量更“分散”、可用来做有用功的能力减少。反应的熵变记作 $ΔS$。
- 吉布斯自由能（$G$）：在恒温恒压条件下可用于做非体积外功（化学做功、电化学做功等）的能量，定义为 $G=H-TS$。反应的自由能变记作 $ΔG$，是判断自发性的关键量。

三者的核心关系
- 反应自由能变的基本公式： $ΔG = ΔH - TΔS$。  
  - 这里 $T$ 是绝对温度（K）。  
  - 直观理解：$ΔH$ 给出反应释放或吸收的热量（有利或不利），$TΔS$ 给出因熵变“抵消/消耗”的能量部分，二者差决定剩下可以做有用功的能量。
- 标准与任意条件下的关系： $ΔG = ΔG^\circ + RT\ln Q$，其中 $ΔG^\circ$ 是标准自由能变，$Q$ 是反应商（当前浓度或分压构成），$R$ 是气体常数。  
  - 在平衡时 $ΔG=0$，得到 $ΔG^\circ = -RT\ln K$，$K$ 为平衡常数。

判定自发性的准则（恒温恒压）
- $ΔG < 0$：过程在给定条件下自发（向生成物方向进行）。  
- $ΔG = 0$：体系处于平衡（无净驱动力）。  
- $ΔG > 0$：过程不自发（需外界做功或改变条件才能进行）。

热力学 vs 动力学
- 自发性仅由热力学（$ΔG$ 的符号）决定；反应速率受动力学（活化能、催化剂等）控制。即 $ΔG<0$ 不保证快速发生。

例子（带直观说明）
- 例 1：氢气与氧气生成水（放热且自发）  
  - 反应： $2H_2 + O_2 \rightarrow 2H_2O$（液态水）  
  - 在 298 K，标准自由能变约 $ΔG^\circ \approx -237\ \mathrm{kJ\ mol^{-1}}$（每摩尔水）。  
  - 物理解释：生成水时 $ΔH$ 很负（放热，有利），$ΔS$ 为负（气态变为液态，熵减，不利），但 $|ΔH|$ 大于 $T|ΔS|$，所以 $ΔG$ 仍为负，反应热力学上强烈自发（实际需要点火克服动力学活化能才能迅速发生）。
- 例 2：硝酸铵溶于水（吸热但自发）  
  - 过程： 硝酸铵固体溶解为离子溶液。实验上该过程吸热（$ΔH>0$），但熵增（$ΔS>0$）。  
  - 因为溶解后体系无序度大增，若 $TΔS > ΔH$，则 $ΔG = ΔH - TΔS < 0$，过程自发。  
  - 这就是一次性冷敷包中硝酸铵溶解导致降温的热力学原因：吸热但熵增使得总体自由能下降。
- 例 3：合成氨（哈伯法）说明温度与平衡的折衷  
  - 反应： $N_2 + 3H_2 \rightleftharpoons 2NH_3$。该反应放热（$ΔH<0$），且熵减（$ΔS<0$）。  
  - 低温有利于热力学平衡向产物（$ΔG$ 更负），但低温反应速率非常慢。工业上通过中等温度与高压并用催化剂折衷以获得可接受的产率与速率。  
  - 可用公式 $ΔG = ΔG^\circ + RT\ln Q$ 来评估不同浓度/压力下的反应趋向。

如何用公式判断某一条件下的自发性（步骤）
- 计算或查表得到 $ΔH$ 与 $ΔS$（尽量在同一温度附近或对 $T$ 进行修正）；计算 $ΔG = ΔH - TΔS$ 判断符号。  
- 若存在非标准浓度/分压，用 $ΔG = ΔG^\circ + RT\ln Q$ 评估瞬时趋势；当 $ΔG=0$ 时找到平衡常数 $K$： $ΔG^\circ = -RT\ln K$。

- 熵（热力学定义，微分形式）  
  - 对可逆过程，系统的熵变由可逆传热定义： $dS = \frac{\delta Q_\text{rev}}{T}$，对有限过程累加为 $ΔS = \int_{i}^{f}\frac{\delta Q_\text{rev}}{T}$。  
  - 说明：此处 $T$ 是绝对温度（K），$\delta Q_\text{rev}$ 表示可逆过程中的微小热量通量。该定义适用于封闭且成分不变的系统（如无质量流入/出）。  
- 熵（统计力学定义）  
  - 微观态数表述（玻尔兹曼）： $S = k_B \ln \Omega$，其中 $k_B$ 是玻尔兹曼常数，$\Omega$ 是宏观态对应的微观态数。  
  - 概率分布（吉布斯熵）： $S = -k_B \sum_i p_i \ln p_i$，$p_i$ 为第 $i$ 个微观态的概率。  
  - 说明：这两式给出熵的微观起源，与热力学定义一一对应，在平衡和统计势态分析中常用。

- 焓（定义）  
  - 焓的定义为： $H \equiv U + pV$，其中 $U$ 是系统内能，$p$ 是压强，$V$ 是体积。  
  - 单位：焦耳（J）。常用摩尔焓 $\bar H$ 或比焓 $h$（单位质量）表示。

- 焓的微分形式与热力学关系（一般可压缩、可变组分情况）  
  - 从基本关系 $dU = T\,dS - p\,dV + \sum_i \mu_i\,dN_i$ 推出（$\mu_i$ 为化学势，$N_i$ 为粒子数）：  
    $dH = d(U+pV) = T\,dS + V\,dp + \sum_i \mu_i\,dN_i$。  
  - 对于封闭且组成不变的系统（$\sum_i \mu_i\,dN_i=0$），有： $dH = T\,dS + V\,dp$。  
  - 若仅有常压过程且无非体积功，微小热输入等于焓的改变： $\delta Q_{p,\text{rev}} = dH$，因此在恒压可逆加热中 $ΔH = Q_p$（常压下的吸放热）。

- 理想气体的常用简化式  
  - 理想气体的焓仅依赖温度： $H = H(T)$，因此对封闭体系的变动： $ΔH = \int_{T_1}^{T_2} C_p(T)\,dT$。若近似 $C_p$ 为常数，则 $ΔH = C_p\,(T_2-T_1)$（摩尔或全体系视具体单位）。  
  - 理想气体的熵变（可逆过程）：  
    $ΔS = \int_{T_1}^{T_2}\frac{C_p(T)}{T}\,dT - R\ln\frac{p_2}{p_1}$，等温过程简化为 $ΔS = nR\ln\frac{V_2}{V_1}$（或每摩尔 $Δ\bar S = R\ln\frac{V_2}{V_1}$）。

- 常见例子（快速记忆）  
  - 等温可逆膨胀理想气体： $ΔS = nR\ln\frac{V_2}{V_1}$。  
  - 加热理想气体（恒压，摩尔数不变）： $ΔH = n\bar C_p (T_2-T_1)$，并且 $ΔS = n\int_{T_1}^{T_2}\frac{\bar C_p}{T}\,dT$（若 $\bar C_p$ 常数，则 $ΔS = n\bar C_p\ln\frac{T_2}{T_1}$）。
