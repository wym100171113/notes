# 钠单质

> [!abstract] 概览
> 钠是第三周期第 IA 族元素，原子序数 11，最外层只有 1 个电子，**极易失去**，是典型的活泼金属。本笔记系统整理钠的物理性质、化学性质（与氧气、氯气、硫、水、酸、盐溶液的反应）、保存方法以及焰色试验，重点理解"钠与水反应"的现象与实质，并学会用"物质的量"进行定量计算。

## 核心概念

- **原子结构**：$\ce{Na}$，电子层结构 2、8、1，最外层 1 个电子，易失去形成 $\ce{Na+}$（$1s^2 2s^2 2p^6$）。
- **强还原性**：金属活动性顺序中钠排在很前面，还原性很强；氧化产物为 $\ce{Na+}$。
- **保存**：钠保存在**煤油**中，以隔绝空气与水。
- **焰色试验**：钠的焰色为**黄色**，是钠元素的特征性质，可用于检验 $\ce{Na+}$（物理变化）。

## 重点知识

### 1. 物理性质

| 性质 | 描述 |
| --- | --- |
| 状态颜色 | 银白色、有金属光泽的固体 |
| 硬度 | 质软，可用小刀切割 |
| 密度 | $0.97\ \mathrm{g/cm^3}$，比水小 |
| 熔点 | 约 $97.8\ \mathrm{^\circ C}$，较低 |
| 导电导热 | 良好（金属通性） |

> [!tip] 记忆口诀
> 钠是"**软、轻、熔、亮**"的金属：软到能切、轻到浮在水面、熔点低到加热即熔、切开后银白光亮。

### 2. 化学性质（核心）

钠化学性质非常活泼，常温下即与 $\ce{O2}$ 等反应，加热或点燃时反应更剧烈。

#### (1) 与非金属单质反应

- **与氧气（常温）**：表面迅速变暗，生成白色氧化钠
  $$\ce{4Na + O2 -> 2Na2O}$$
- **与氧气（点燃/加热）**：黄色火焰，生成淡黄色过氧化钠
  $$\ce{2Na + O2 \xrightarrow{\Delta} Na2O2}$$
- **与氯气**：剧烈燃烧，产生白烟（$\ce{NaCl}$ 固体小颗粒）
  $$\ce{2Na + Cl2 \xrightarrow{\Delta} 2NaCl}$$
- **与硫**：研磨或加热即化合（甚至爆炸）
  $$\ce{2Na + S \xrightarrow{\Delta} Na2S}$$

#### (2) 与水反应

$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$

**现象记忆口诀："浮、熔、游、响、红"**
- **浮**：钠的密度小于水，浮在水面上；
- **熔**：反应放热，钠熔点低，熔成闪亮的小球；
- **游**：产生的氢气推动小球四处游动；
- **响**：反应剧烈，发出嘶嘶的响声；
- **红**：滴入酚酞后溶液变红，说明生成了碱 $\ce{NaOH}$。

离子方程式：
$$\ce{2Na + 2H2O -> 2Na+ + 2OH- + H2 ^}$$

> [!note] 实质
> 钠与水反应的实质是钠与水（弱电解质）电离出的 $\ce{H+}$ 反应。由于水中 $\ce{H+}$ 浓度很小，反应靠钠的强还原性推动；与酸反应时 $\ce{H+}$ 浓度大，反应更剧烈。

#### (3) 与酸反应

$$\ce{2Na + 2HCl -> 2NaCl + H2 ^}$$

酸中 $\ce{H+}$ 浓度大，反应比与水更剧烈。

#### (4) 与盐溶液反应（重点难点）

钠**先与水反应**生成 $\ce{NaOH}$ 和 $\ce{H2}$，$\ce{NaOH}$ 再与盐发生复分解反应。**钠不能从盐溶液中置换出金属单质**。

例：钠投入 $\ce{CuSO4}$ 溶液中
$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$
$$\ce{2NaOH + CuSO4 -> Cu(OH)2 v + Na2SO4}$$

总反应式：
$$\ce{2Na + 2H2O + CuSO4 -> Cu(OH)2 v + Na2SO4 + H2 ^}$$

现象：钠浮于液面熔成小球游动并产生气体，同时生成**蓝色絮状沉淀** $\ce{Cu(OH)2}$。

#### (5) 钠在空气中放置的变化过程

切开钠 → 表面变暗（生成 $\ce{Na2O}$）→ 吸水生成 $\ce{NaOH}$ → 与 $\ce{CO2}$ 反应生成 $\ce{Na2CO3\cdot 10H2O}$ → 风化失去结晶水变为 $\ce{Na2CO3}$（纯碱）。

### 3. 焰色试验

- **操作**：用洁净的铂丝（或铁丝）蘸取待测物，放在无色火焰上灼烧，观察火焰颜色。
- **钠**：黄色火焰；**钾**：紫色（透过蓝色钴玻璃观察，滤去钠的黄光）。
- **本质**：电子跃迁发射特征光，属**物理变化**。
- **铂丝洗净**：每次使用后先用**盐酸**蘸洗，再在火焰上灼烧至无色。

> [!tip] 区分元素与单质
> 焰色试验检验的是**元素**（可以是单质、离子或化合物），如 $\ce{NaCl}$、$\ce{NaOH}$、$\ce{Na}$ 均呈黄色。

## 典型例题

### 例题 1（钠与水反应的计算）

**题目**：将 $4.6\ \mathrm{g}$ 金属钠投入足量水中，求生成 $\ce{H2}$ 在标准状况下的体积和所得溶液中 $\ce{NaOH}$ 的物质的量。

**分析**：反应为 $\ce{2Na + 2H2O -> 2NaOH + H2 ^}$，$\ce{Na}$ 的摩尔质量为 $23\ \mathrm{g/mol}$。先由质量求钠的物质的量，再按化学计量数比求产物物质的量，最后用气体摩尔体积换算体积。

**解答**：
$$n(\ce{Na}) = \dfrac{m}{M} = \dfrac{4.6\ \mathrm{g}}{23\ \mathrm{g/mol}} = 0.2\ \mathrm{mol}$$

由方程式知 $n(\ce{H2}) : n(\ce{Na}) = 1 : 2$，$n(\ce{NaOH}) : n(\ce{Na}) = 1 : 1$，故：
$$n(\ce{H2}) = 0.1\ \mathrm{mol},\qquad n(\ce{NaOH}) = 0.2\ \mathrm{mol}$$

标准状况下氢气的体积：
$$V(\ce{H2}) = n(\ce{H2}) \cdot V_m = 0.1\ \mathrm{mol} \times 22.4\ \mathrm{L/mol} = 2.24\ \mathrm{L}$$

**点评**：本题是"物质的量 → 化学方程式 → 气体摩尔体积"的经典综合题。关键是由质量先求物质的量，再严格按系数比换算，注意 $\ce{H2}$ 的系数是 1/2，勿直接照搬钠的物质的量。

### 例题 2（钠与盐溶液反应）

**题目**：把一小块钠投入到 $\ce{FeCl3}$ 溶液中，写出发生反应的化学方程式，并描述观察到的现象。

**分析**：钠先与水反应生成 $\ce{NaOH}$ 与 $\ce{H2}$，$\ce{NaOH}$ 再与 $\ce{FeCl3}$ 复分解生成 $\ce{Fe(OH)3}$ 红褐色沉淀。总反应按得失电子配平。

**解答**：
$$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$$
$$\ce{FeCl3 + 3NaOH -> Fe(OH)3 v + 3NaCl}$$

总反应式：
$$\ce{6Na + 6H2O + 2FeCl3 -> 2Fe(OH)3 v + 6NaCl + 3H2 ^}$$

现象：钠浮于液面、熔成闪亮小球、四处游动、发出嘶响，同时产生**红褐色沉淀**。

**点评**：钠与盐溶液反应时"**先水后盐**"，不能置换金属。现象描述要完整，包含"浮、熔、游、响"与沉淀颜色两部分。

## 易错提醒

> [!warning] 易错点
> 1. **钠不能置换盐溶液中的金属**：如钠投入 $\ce{CuSO4}$ 溶液得到 $\ce{Cu(OH)2}$ 蓝色沉淀而非铜单质（只有熔融态盐在高温下才可能置换）。
> 2. **钠的保存**：保存在**煤油**中；不能保存在水中（会反应），也不能裸露在空气中（被氧化）。
> 3. **$\ce{Na2O}$ 与 $\ce{Na2O2}$ 勿混淆**：常温生成 $\ce{Na2O}$（白色），点燃/加热生成 $\ce{Na2O2}$（淡黄色）。
> 4. **焰色试验是物理变化**：不是化学变化；观察钾需透过蓝色钴玻璃。
> 5. **钠着火不能用**水或 $\ce{CO2}$ 灭火（钠与水反应、钠在 $\ce{CO2}$ 中也能燃烧），应用**沙土**盖灭。
> 6. **过量钠与盐溶液**：钠过量时，多余钠继续与水反应放出 $\ce{H2}$，分析气体量时不能只按"置换"考虑。

## 与其他知识关联
