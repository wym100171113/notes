# 电磁学

- 电场与磁场的物理定义  
- 电场：由电荷产生的场，描述单位正电荷在该点受到的静电力，单位 $\,\mathrm{V/m}$ 或 $\,\mathrm{N/C}$。对点电荷 $q$，在位置 $\mathbf{r}$ 的电场为 $\mathbf{E}(\mathbf{r}) = \dfrac{1}{4\pi\epsilon_0}\dfrac{q}{r^2}\hat r\,$。  
- 磁场：由电流或变化的电场产生，作用于运动电荷，改变其速度方向，单位 $\,\mathrm{T}$。长直导线电流 $I$ 在距离 $r$ 处的磁场（环向）为 $B(r) = \dfrac{\mu_0 I}{2\pi r}\,$。

- 单个带电粒子的受力（洛伦兹力）  
- 带电粒子在电磁场中的力： $\mathbf{F} = q\big(\mathbf{E} + \mathbf{v}\times\mathbf{B}\big)\,$。  
- 注：电场项可做功改变粒子动能，磁场项垂直速度只改变方向不改变瞬时动能。

- 麦克斯韦方程组（真空的微分形式）  
- 高斯电场定律： $\nabla\cdot\mathbf{E} = \dfrac{\rho}{\epsilon_0}\,$。  
- 高斯磁场定律： $\nabla\cdot\mathbf{B} = 0\,$（无磁单极）。  
- 法拉第感应定律： $\nabla\times\mathbf{E} = -\dfrac{\partial\mathbf{B}}{\partial t}\,$。  
- 安培–麦克斯韦定律： $\nabla\times\mathbf{B} = \mu_0\mathbf{J} + \mu_0\epsilon_0 \dfrac{\partial\mathbf{E}}{\partial t}\,$。

- 麦克斯韦方程的常用积分形式  
- $\displaystyle \oint_{\partial V}\mathbf{E}\cdot d\mathbf{A} = \dfrac{1}{\epsilon_0}\int_V \rho\,dV\,$。  
- $\displaystyle \oint_{\partial V}\mathbf{B}\cdot d\mathbf{A} = 0\,$。  
- $\displaystyle \oint_{\partial S}\mathbf{E}\cdot d\mathbf{\ell} = -\dfrac{d}{dt}\int_S \mathbf{B}\cdot d\mathbf{A}\,$。  
- $\displaystyle \oint_{\partial S}\mathbf{B}\cdot d\mathbf{\ell} = \mu_0\int_S \mathbf{J}\cdot d\mathbf{A} + \mu_0\epsilon_0 \dfrac{d}{dt}\int_S \mathbf{E}\cdot d\mathbf{A}\,$。

- 介质中的场与边界量（线性各向同性近似）  
- 电位移： $\mathbf{D} = \epsilon \mathbf{E}\,$；磁场强度： $\mathbf{H} = \dfrac{1}{\mu}\mathbf{B}\,$。  
- 边界条件（界面法向单位矢 $\mathbf{n}$ 指向介质 2）：  
- $\mathbf{n}\cdot(\mathbf{D}_2-\mathbf{D}_1) = \sigma_f\,$； $\mathbf{n}\cdot(\mathbf{B}_2-\mathbf{B}_1) = 0\,$。  
- $\mathbf{n}\times(\mathbf{E}_2-\mathbf{E}_1) = \mathbf{0}\,$； $\mathbf{n}\times(\mathbf{H}_2-\mathbf{H}_1) = \mathbf{K}_f\,$。

- 电磁能量与能量流  
- 场的能量密度（真空）： $u = \dfrac{1}{2}\big(\epsilon_0 E^2 + \dfrac{1}{\mu_0}B^2\big)\,$。  
- 波印廷矢（能量流密度）： $\mathbf{S} = \dfrac{1}{\mu_0}\mathbf{E}\times\mathbf{B}\,$。  
- 波印廷定理： $\dfrac{\partial u}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}\,$（场能率的变化等于流出率加耗散功）。

- 电磁波（真空）  
- 波动方程： $\nabla^2\mathbf{E} - \mu_0\epsilon_0 \dfrac{\partial^2\mathbf{E}}{\partial t^2} = \mathbf{0}\,$（对 $\mathbf{B}$ 相同）。  
- 光速： $c = \dfrac{1}{\sqrt{\mu_0\epsilon_0}}\approx 3.00\times10^8\ \mathrm{m/s}\,$。  
- 平面波： $\mathbf{E}\perp\mathbf{B}\perp\hat{k}\,$，且 $B = E/c\,$，能量流方向为 $\mathbf{E}\times\mathbf{B}$。

- 势函数与规范  
- 向量势与标势： $\mathbf{B} = \nabla\times\mathbf{A}\,$， $\mathbf{E} = -\nabla\phi - \dfrac{\partial\mathbf{A}}{\partial t}\,$。  
- 洛伦兹规范： $\nabla\cdot\mathbf{A} + \mu_0\epsilon_0 \dfrac{\partial\phi}{\partial t} = 0\,$，在此下势满足波动方程便于求解辐射问题。

- 常见速记公式与例子  
- 无限平面均匀面电荷（面密度 $\sigma$）的电场： $E = \dfrac{\sigma}{2\epsilon_0}\,$（两侧大小相同方向相反）。  
- 点电荷电场： $\mathbf{E}(\mathbf{r}) = \dfrac{1}{4\pi\epsilon_0}\dfrac{q}{r^2}\hat r\,$。  
- 无限长直导线磁场： $B(r) = \dfrac{\mu_0 I}{2\pi r}\,$。  
- 单位：电场 $[\mathrm{V/m}]$，磁感应强度 $[\mathrm{T}]$，电位 $[\mathrm{V}]$。

## 概览（直观）
- 洛伦兹力描述单个带电粒子在电场与磁场中的受力，公式为 $\mathbf{F} = q\big(\mathbf{E} + \mathbf{v}\times\mathbf{B}\big)\,$。  
- 安培力是电流（大量移动电荷）在磁场中受到的力，微元形式为 $d\mathbf{F} = I\,d\mathbf{l}\times\mathbf{B}\,$，整体线段为 $\mathbf{F} = I\mathbf{L}\times\mathbf{B}\,$（当磁场近似均匀且电流沿直线且方向与 $\mathbf{L}$ 一致时）。  
- 两者本质相关：电流由移动电荷构成，安培力可由洛伦兹力对移动电荷求和得到（见推导部分）。

## 洛伦兹力（粒子受力）
- 含义：带电粒子（电荷 $q$）若同时处在电场 $\mathbf{E}$ 和磁场 $\mathbf{B}$ 中，受到的合力是电场力 $q\mathbf{E}$ 加上磁场力 $q\mathbf{v}\times\mathbf{B}$。  
- 方向判定（右手规则，正电荷）：用右手，食指指向速度 $\mathbf{v}$，中指指向磁场 $\mathbf{B}$，大拇指就指向磁场力方向（即 $\mathbf{v}\times\mathbf{B}$ 的方向）。对于负电荷（如电子），实际力方向与此相反。  
- 重要性质：磁力始终垂直于速度（$\mathbf{v}\cdot(\mathbf{v}\times\mathbf{B})=0$），所以磁力本身不做功，不改变粒子速率（动能），只改变运动方向（常见圆周或螺旋运动）。  
- 例：带电粒子在匀强磁场中做圆周运动（仅有磁场，无电场）。半径与频率：  
  - 轨道半径 $r = \dfrac{m v}{|q| B}\,$（$m$ 为质量，$v$ 是速度大小）。  
  - 回转角频率（回转频率） $\omega = \dfrac{|q|B}{m}\,$（又称回旋频率，和速度大小无关）。  
  - 说明：这是质谱仪、回旋加速器中常用的基本公式。

## 安培力（电流段受力）
- 微元形式： $d\mathbf{F} = I\,d\mathbf{l}\times\mathbf{B}\,$，其中 $d\mathbf{l}$ 指向电流方向且长度为段长。  
- 对整段直导线（长度 $\mathbf{L}$）在匀场 $\mathbf{B}$ 下： $\mathbf{F} = I\mathbf{L}\times\mathbf{B}\,$。大小为 $F = I L B\sin\theta\,$，$\theta$ 是 $\mathbf{L}$ 与 $\mathbf{B}$ 之间的夹角。  
- 方向同样由右手规则判定（食指：电流方向， 中指：磁场方向， 大拇指：力方向，注意这与带电粒子 $\mathbf{v}\times\mathbf{B}$ 的右手规则一致，因为电流方向为正电荷流动方向）。  
- 实际应用：电动机中转矩来自安培力，麦克斯韦力矩推导中也常出现该量。

## 从洛伦兹力到安培力（简单推导）
- 把电流看作是大量带电粒子以漂移速度 $\mathbf{v}_d$ 在金属截面积 $A$ 中移动，单位体积中自由载流子数为 $n$，单个载流子电荷为 $q$。长度为 $d\mathbf{l}$ 的线段内带电量 $dq = n q A\,d\ell$。  
- 该段上所有粒子受的磁力为 $d\mathbf{F} = dq\,\mathbf{v}_d\times\mathbf{B} = n q A\,d\ell\,\mathbf{v}_d\times\mathbf{B}$。  
- 电流 $I = n q A v_d$，代入得 $d\mathbf{F} = I\,d\mathbf{l}\times\mathbf{B}$，即安培力表达式。

## 两条平行直导线间的相互作用（经典例子）
- 两条平行长度远大于间距、间距为 $d$ 的直导线，电流分别为 $I_1$ 与 $I_2$。第二导线在第一导线产生的磁场 $B_1$ 中受到安培力。结果为每单位长度的力：  
  $\dfrac{F}{L} = \dfrac{\mu_0 I_1 I_2}{2\pi d}\,$，其中 $\mu_0 = 4\pi\times10^{-7}\ \mathrm{H/m}$。  
- 方向：若电流同向，力相互吸引；若反向，互相排斥。  
- 数值例子：取 $I_1=I_2=5\ \mathrm{A}$，$d=0.1\ \mathrm{m}$，则每米受力为 $\dfrac{F}{L} = \dfrac{4\pi\times10^{-7}\cdot25}{2\pi\cdot0.1} = 5.0\times10^{-5}\ \mathrm{N/m}\,$（很小，但可在精密实验中测得）。  
- 说明：这个力的定义被用来定义电流单位安培（历史上）。

## 常见公式速记
- 洛伦兹力： $\mathbf{F} = q\big(\mathbf{E} + \mathbf{v}\times\mathbf{B}\big)\,$。  
- 安培力微元： $d\mathbf{F} = I\,d\mathbf{l}\times\mathbf{B}\,$。  
- 直线段总力（匀场）： $\mathbf{F} = I\mathbf{L}\times\mathbf{B}\,$，大小 $F=ILB\sin\theta\,$。  
- 平行直导线互力/每长度： $\dfrac{F}{L} = \dfrac{\mu_0 I_1 I_2}{2\pi d}\,$。  
- 圆周运动半径（单带电粒子在纯磁场中）： $r = \dfrac{m v}{|q| B}\,$；角频率 $\omega = \dfrac{|q|B}{m}\,$。

## 练习题（可做课堂/自测）
- 练习 1：一段长为 $0.2\ \mathrm{m}$ 的直导线通以 $3\ \mathrm{A}$ 电流，处在垂直于导线的均匀磁场 $B=0.5\ \mathrm{T}$ 中，求受到的力大小。  
  - 解答要点：使用 $F=ILB\sin\theta$，这里 $\theta=90^\circ$，所以 $F=3\times0.2\times0.5=0.3\ \mathrm{N}$。  
- 练习 2：带电粒子 $q=1.6\times10^{-19}\ \mathrm{C}$，质量 $m=9.11\times10^{-31}\ \mathrm{kg}$（电子），以速度 $v=10^6\ \mathrm{m/s}$ 垂直进入磁场 $B=0.01\ \mathrm{T}$，求其轨道半径。提示：代入 $r=mv/(|q|B)$。  
- 练习 3（扩展）：证明安培力微元公式 $d\mathbf{F}=I\,d\mathbf{l}\times\mathbf{B}$ 可由洛伦兹力对段内所有载流子求和得到（按推导段落步骤做）。

## 注意事项与物理直觉
- 磁力不做功：磁力只改变速度方向，不直接改变粒子动能，因此磁场不能使静止荷电粒子加速（需要电场或非静态磁场诱导的电场）。  
- 电子与传统电流方向：电流方向通常按照正电荷移动方向定义；在金属中实际是电子（负电荷）流动，所以用右手规则时对电子要反向判断。  
- 在电动机中，安培力产生转矩；在质量分离（质谱）中，洛伦兹力使带电粒子弯曲轨道从而基于质荷比进行分离。

## 基本概念（直观）
- 感应电动势（简称感应 emf）指由于磁通量随时间变化在电路中“产生”的电压驱动力。常用符号 $ε$ 表示。  
- 感应电流是由感应电动势驱动的电流。方向由楞次定律决定：感应电流的磁场总是阻碍原来磁通量变化（即“阻止变化”）。

## 磁通量（关键量）
- 磁通量定义为穿过回路的磁场总量： $\Phi = \int_S \mathbf{B}\cdot d\mathbf{A}\,$，对于平面、均匀 $B$ 和面积 $A$，简化为 $\Phi = B A \cos\theta\,$，$\theta$ 为 $\mathbf{B}$ 与法向之间的夹角。

## 法拉第电磁感应定律（定量）
- 积分形式（闭合回路的感应电动势）：
  $ε = -\dfrac{d\Phi}{dt}\,$。  
  负号即楞次定律的数学体现（方向规则）。
- 微分形式（麦克斯韦-法拉第方程）：
  $\nabla\times\mathbf{E} = -\dfrac{\partial\mathbf{B}}{\partial t}\,$，表示变化的磁场会产生旋转的电场（感应电场），即非保守电场。

## 楞次定律（方向判定）
- 直观说法：若外界使通过回路的磁通量增加，感应电流方向产生的磁场会试图减小这个增加；若磁通量减小，感应磁场会试图增大它。  
- 判定实用法：用“磁场方向试图抵抗原来磁通变化”的原则或用右手法则配合负号判断方向。

## 两类常见产生感应 emf 的情况
- 变化的磁场穿过固定回路（例如线圈中磁场随时间变化）：$ε = -\dfrac{d}{dt}\int_S \mathbf{B}\cdot d\mathbf{A}$，此时产生的是感应电场，和静电场不同，可以沿闭合路径有非零线积分。  
- 导体在磁场中运动（导体切割磁力线，称“运动电动势”或“切割电动势”）：  
  - 微元导线段上产生的电动势可写为 $dε = (\mathbf{v}\times\mathbf{B})\cdot d\mathbf{\ell}\,$，整体为 $ε = \int (\mathbf{v}\times\mathbf{B})\cdot d\mathbf{\ell}\,$。  
  - 简化例子：长为 $\ell$ 的导棒以速度 $v$ 垂直切割匀强磁场 $B$，两端电动势为 $ ε = B\ell v\,$（方向按 $\mathbf{v}\times\mathbf{B}$ 定）。

## 示例：在磁场中的导轨与导棒（常见实验装置）
- 设两平行导轨间距 $\ell$，导棒以速度 $v$ 沿导轨移动且与均匀 $B$ 垂直。导棒两端电势差 $ ε = B\ell v\,$。若导轨与外电阻接成回路，则产生感应电流，方向由楞次定律决定，运动受到磁阻力（匀强 $B$ 下做功转为热，机械做功被磁力吸收）。

## 自感与互感（大学扩展）
- 自感（线圈自身磁通随自身电流变化产生的 emf）：$ε_L = -L\dfrac{dI}{dt}\,$，$L$ 为自感系数（电感），单位 H（亨利）。  
- 能量储存：电感中储存的磁能为 $U = \dfrac{1}{2} L I^2\,$。  
- 互感（两个线圈）：若线圈 1 的电流变化在 2 中产生感应 emf，则 $ε_2 = -M\dfrac{dI_1}{dt}\,$，$M$ 为互感系数。变压器就是基于互感工作的装置（理想变压器 $V_1/V_2 = N_1/N_2$）。

## RL 电路瞬态（简单解析）
- 纯感与电阻串联、外加恒定电压源 $V$ 时，基尔霍夫电压定律为 $V - R I - L\dfrac{dI}{dt} = 0\,$。解得施加电压瞬时起始（假设 $I(0)=0$）：  
  $I(t) = \dfrac{V}{R}\Big(1 - e^{-tR/L}\Big)\,$，时间常数 $\tau = \dfrac{L}{R}\,$。  
- 断开电源时，电流按 $ I(t) = I_0 e^{-tR/L} $ 衰减，但电感会产生阻止电流骤变的高电压（需注意泄放路径或火花）。

## 能量与功（物理直觉）
- 改变磁通需要做功；例如推导棒以恒速切割磁场，外力做功等于电路中耗散的热功（楞次定律保证磁力做功方向与外力相反）。  
- 感应电场做功给电荷运动形成电流，电阻将电能转换为热，电感则把能量暂时储存在磁场中。

## 常见应用与现象
- 变压器、电动机与发电机（磁通变化或相对运动产生电压）。  
- 炎热铁片或金属板中出现涡流（涡流制动、金属探伤、感应加热）。  
- 磁阻（运动导体在磁场中受阻力，例如磁阻制动器）。  
- 无线充电与感应加热基于互感与交变磁场。

## 练习题（含解题要点）
- 练习 1：一根长 $\ell=0.5\ \mathrm{m}$ 的导棒以速度 $v=2\ \mathrm{m/s}$ 垂直穿过匀强磁场 $B=0.3\ \mathrm{T}$，求两端电动势。  
  - 要点：$ε=B\ell v=0.3\times0.5\times2=0.3\ \mathrm{V}$。  
- 练习 2：线圈的磁通以 $\Phi(t)=0.1\sin(100t)\ \mathrm{Wb}$ 变化，求瞬时感应电动势 $ε(t)$。  
  - 要点：$ε=-d\Phi/dt = -0.1\times100\cos(100t) = -10\cos(100t)\ \mathrm{V}$。  
- 练习 3（扩展）：在 RL 串联电路中，$L=0.2\ \mathrm{H}$，$R=10\ \Omega$，外加 $V=5\ \mathrm{V}$。求 $I(t)$。  
  - 要点：$\tau=L/R=0.02\ \mathrm{s}$，$I(t)=\dfrac{5}{10}(1-e^{-t/0.02})=0.5(1-e^{-50t})\ \mathrm{A}$。

## 小结（便于记忆）
- 感应定律的核心公式：$ε = -\dfrac{d\Phi}{dt}$（法拉第）与 $\nabla\times\mathbf{E} = -\dfrac{\partial\mathbf{B}}{\partial t}$（微分形式）。  
- 运动导体的 emf：$ε = \int (\mathbf{v}\times\mathbf{B})\cdot d\mathbf{\ell}$，简化情形 $ε=B\ell v$。  
- 自感：$ ε_L = -L\dfrac{dI}{dt} $，能量 $U=\dfrac{1}{2}LI^2$。  
- 方向判定靠楞次定律：感应总是“反抗”磁通的变化。

## 楞次定理的表述（直观）
- 楞次定理：感应电流的方向总是使得它自身产生的磁场阻碍原来磁通量的变化。  
- 直观记忆法：感应电流“反对变化”。若外界使穿过回路的磁通量增加，感应电流产生的磁场会试图减小该增加；若外界使磁通量减少，感应电流会试图增大它。

## 数学形式（与法拉第电磁感应定律结合）
- 法拉第定律给出感应电动势（面向标量形式）： $ε = -\dfrac{d\Phi}{dt}$，其中 $\Phi = \int_S \mathbf{B}\cdot d\mathbf{A}$ 为穿过回路的磁通量。负号即楞次定律的数学表征（指明方向）。  
- 微分形式（场的角度）： $\nabla\times\mathbf{E} = -\dfrac{\partial\mathbf{B}}{\partial t}$，表示变化的磁场在空间产生旋转电场（非静电场），使得沿闭合路径的电场线积分非零。

## 方向判定的简单方法（中学层面）
- 用负号或“反抗变化”的原则判断方向；在具体题目中常用右手规则配合磁场方向与回路方向来判定感应电流方向。  
- 示例：若一恒定向右的磁场逐渐增强穿过纸面朝向读者的圆形线圈，感应电流将产生一个向左的磁场（即反向磁场），其方向可由右手定则判断为与原来磁场方向相反。

## 能量守恒的体现（关键论证与例子）
- 本质观点：楞次定律保证感应电流的作用是“阻碍”磁通的变化，因此外界在改变磁通时必须做功；这部分外界做的功要么以热的形式在电路中耗散（焦耳热），要么暂时存储在磁场中（电感器储能）。楞次定律正是能量守恒在电磁感应中的表现形式之一。

### 例 1：运动导体（导棒切割磁力线）
- 设长为 $\ell$ 的导棒以速度 $\mathbf{v}$ 垂直滑动在两平行导轨上，且在导轨与导棒形成的回路内存在垂直纸面的匀强磁场 $\mathbf{B}$（方向指入纸面）。导棒两端感应电动势（简化）为 $ε = B\ell v\,$。若回路总电阻为 $R$，则感应电流为 $I = \dfrac{ε}{R} = \dfrac{B\ell v}{R}$。  
- 磁力（安培力）作用在导棒上，大小为 $F = I\ell B = \dfrac{B^2\ell^2 v}{R}$，方向与导棒运动相反（抵抗运动）。  
- 外力做功率为 $P_\text{ext} = F v = \dfrac{B^2\ell^2 v^2}{R}$。同时电路中电功率耗散为 $P_R = I^2 R = \dfrac{B^2\ell^2 v^2}{R}$。  
- 结论： $P_\text{ext} = P_R$，外界做功完全转为电阻的热，能量守恒成立；楞次定律保证磁力方向使外界必须做正功来维持运动。

### 例 2：带电感的 RL 回路（能量分配）
- 对串联电感 $L$ 与电阻 $R$ 的回路，若由外加电源 $ε_\text{ext}(t)$ 驱动，基尔霍夫电压定律给出： $ε_\text{ext} + ε_\text{ind} - IR = 0$，而自感形成的感应电动势为 $ε_\text{ind} = -L\dfrac{dI}{dt}$。  
- 整理得： $ε_\text{ext} = IR + L\dfrac{dI}{dt}$。两边同时乘以 $I$ 得功率形式：  
  $P_\text{ext} \equiv ε_\text{ext}I = I^2 R + L I \dfrac{dI}{dt}\,$。  
- 注意： $I^2 R$ 是瞬时的焦耳热功率，另外一项可改写为磁场能的变化率：  
  $L I \dfrac{dI}{dt} = \dfrac{d}{dt}\Big(\dfrac{1}{2}LI^2\Big)\,$。  
- 因此得到清晰的功率分配关系：  
  $P_\text{ext} = I^2 R + \dfrac{d}{dt}\Big(\dfrac{1}{2}LI^2\Big)\,$。  
- 物理含义：外界提供的功分两部分——一部分瞬时转化为热耗散，另一部分被储存在线圈的磁场中（若 $I$ 增加）；当电流衰减时，储存在磁场的能量又释放并经电阻耗散或回馈电源。

### 能量守恒的通用表述
- 在所有感应现象中，外界改变磁通所做的机械功等于电路中增加的能量（磁场储能）加上不可逆耗散（焦耳热）加可能的辐射损失（在高频或非理想情况下）。楞次定律保证了方向性，使得外界做功正是为了克服感应电流产生的反作用力/力矩，从而实现能量平衡。

## 涡流（涡流制动）与宏观演示
- 在一个导体中局部存在感应电流回路（闭合的“涡流”），会在导体内部产生焦耳热并对运动产生制动（磁阻）。例如金属板进入磁场时会迅速减速，这是动能被感应电流转化为热能的直接例子。  
- 在无电阻的理想超导体中，感应电流可以永久流动（无热耗散），因此外界做功会被储存在磁场中（或使超导体产生相应力矩），这也是楞次定律在无耗散极端下的另一种体现。

## 小练习（巩固理解）
- 练习 1：长 $\ell=0.4\ \mathrm{m}$ 的导棒以速度 $v=1\ \mathrm{m/s}$ 在 $B=0.2\ \mathrm{T}$ 区域中滑动，回路总电阻 $R=2\ \Omega$。求感应电动势、感应电流、磁阻力及外界做功率。  
  - 提示： $ε=B\ell v$，$I=ε/R$，$F=I\ell B$，$P_\text{ext}=Fv$。  
- 练习 2（RL）：已知 $L=0.1\ \mathrm{H}$，$R=5\ \Omega$，由电源 $ε_\text{ext}=10\ \mathrm{V}$ 驱动，求稳态（长时间后）电流与初始瞬间（开关刚闭合时）能量分配的瞬时形式（写出 $P_\text{ext}=I^2R + d/dt(1/2LI^2)$ 的应用）。

## 小结（便于记忆）
- 楞次定理 = 法拉第定律中的负号，表明感应电流方向总是阻碍磁通变化。  
- 能量观：外界改变磁通必须做功；这功要么以热耗散（电阻）形式释放，要么被磁场暂时储存（电感）。数学上在 RL 回路中表现为 $ε_\text{ext}I = I^2R + d(1/2LI^2)/dt$。  
- 实验印象：导棒切割磁力线、磁阻制动、变压器初级侧对次级侧做功的能量流动，都是楞次定律与能量守恒的直接体现。

## 概览
- 基尔霍夫定律包括：电流定律（KCL）和电压定律（KVL）。  
- 物理意义：KCL 来源于电荷守恒，KVL 来源于能量守恒（单值电势或环路中总电位降为零，含感应场时需小心）。  
- 在电路分析中常用的方法有：节点电压法（Node-Voltage）、网目电流法（Mesh/Loop）、叠加原理、戴维南/诺顿等价、以及在含电容/电感和交流电路中的复阻抗与拉普拉斯/相量法。

## 基尔霍夫定律的陈述
- 基尔霍夫电流定律（KCL）：对任一节点，流入电流代数和为零（或流入等于流出）。用式子写为 $\sum_i I_i = 0\,$（在该节点取正向为流入或流出需统一约定）。  
- 基尔霍夫电压定律（KVL）：对任一闭合回路，沿环路电压代数和为零： $\sum_k V_k = 0\,$。注意：当存在时间变化的磁通（非静态情形）时，需用法拉第的感应电动势项修正。

## 签号约定（实用建议）
- 电压降 $V=IR$：当沿着电流方向跨过电阻时电势降低为 $IR$。  
- 对电源（理想电压源）：沿从负极到正极为电压升 $+V_s$，相反方向为 $-V_s$。  
- 对受控符号（方向/极性）在列方程前统一标注，避免符号错误。

## 常用分析方法（步骤与要点）

- 简化电路：串并联合并电阻、电压源/电流源的源变换（电压源串联电阻 ⇄ 电流源并联电阻）。  
- 节点电压法（适用于节点较少、电源相对复杂的电路）：  
  - 选一个参考节点（地）。其余每个节点记作未知电压 $V_i$（相对于地）。  
  - 对每个非参考节点应用 KCL，将通过欧姆定律 $I=(V_\text{node}-V_\text{other})/R$ 代入。  
  - 形成线性方程组，解出 $V_i$。  
- 网目电流法（适用于有多个回路且平面可画成网目的电路）：  
  - 给每个独立网目假设一个网目电流 $I_k$（方向通常取顺时针）。  
  - 对每个网目用 KVL 列式，电阻上的压降写成与网目电流相关的差（共享电阻上为 $R(I_i-I_j)$）。  
  - 解线性方程组得到网目电流。  
- 叠加原理（线性电路中）：对电路中每个独立源单独作用，其他独立源置零（电压源短路，电流源开路），求响应后叠加。只适用于线性电路（无乘积项、非线性元件时不能用）。  
- 戴维南/诺顿等价：在电路某两端替换为等效电压源 $V_\text{th}$ 串联电阻 $R_\text{th}$（或等效电流源 $I_N$ 并联 $R_N$），便于计算负载响应。$R_\text{th}$ 可通过独立源关闭后从两端看进去的等效阻抗得到，或用短路电流/开路电压方法： $R_\text{th}=V_\text{oc}/I_\text{sc}$。

## 示例 1：串联分压（KVL 的直接应用）
- 电路：理想电压源 $V_s=12\ \mathrm{V}$ 串联两个电阻 $R_1=2\ \Omega$、$R_2=4\ \Omega$，求中点电压 $V_{mid}$（相对于电源负极/地）。  
- 分析：串联电流 $I=V_s/(R_1+R_2)=12/6=2\ \mathrm{A}$。中点到地的电压为 $V_{mid}=V_s - I R_1 = 12 - 2\times2 = 8\ \mathrm{V}$。（或用分压公式 $V_{mid}=V_s\dfrac{R_2}{R_1+R_2}$ 得同样结果。）

## 示例 2：节点电压法（一步列方程）
- 电路：电压源 $V_s=10\ \mathrm{V}$ 通过 $R_1=2\ \Omega$ 接到节点 $V_1$；节点 $V_1$ 接两个电阻 $R_2=4\ \Omega$、$R_3=6\ \Omega$ 分别接地。求 $V_1$。  
- 列式：对节点 $V_1$ 应用 KCL，流出节点到地的电流为 $V_1/R_2 + V_1/R_3$，流入节点来自电源为 $(V_s - V_1)/R_1$，故 $(V_s - V_1)/R_1 - V_1/R_2 - V_1/R_3 = 0$。代入数值得 $(10-V_1)/2 - V_1/4 - V_1/6 = 0$。解得 $V_1 = 10 / (1/2 + 1/4 + 1/6)^{-1}$ 计算后 $V_1 = 10 \times ( \frac{1}{2} ) / ( … )$（实际计算可整理为线性方程解出 $V_1 \approx 5.45\ \mathrm{V}$）。

  - （注：你可以把上式化成统一分母后求解，展示步骤用于课堂演示。）

## 示例 3：网目电流法（两回路共享电阻）
- 电路：两个回路，左回路电源 $V_1$、右回路电源 $V_2$，中间共享电阻 $R_s$。设左网目电流 $I_1$、右网目电流 $I_2$。  
- 对左回路用 KVL： $-V_1 + R_L I_1 + R_s(I_1 - I_2) = 0$。  
- 对右回路用 KVL： $-V_2 + R_R I_2 + R_s(I_2 - I_1) = 0$。  
- 解联立方程得 $I_1,I_2$，再由 $I_1-I_2$ 得共享电阻电流方向和大小。

## 含电容、电感的瞬态（大学扩展，常见 RC、RL、RLC）
- 自然响应与强迫响应：含储能元件的电路在开合或源改变时出现瞬态，需考虑元件初始条件（$V_C(0)$、$I_L(0)$）。  
- RC 充电（直流阶跃电压 $V$ 加在 $R$ 与 $C$ 串联）：  
  - 电容电压随时间： $V_C(t) = V\big(1 - e^{-t/(RC)}\big)\,$。  
  - 电流： $I(t) = \dfrac{V}{R} e^{-t/(RC)}\,$。  
  - 时间常数 $\tau = RC\,$ 控制充放电快慢。  
- RL 回路（电感与电阻串联，对阶跃电压）：  
  - 电流随时间： $I(t) = \dfrac{V}{R}\big(1 - e^{-tR/L}\big)\,$，时间常数 $\tau = L/R\,$。  
  - 电感在电流突变时产生很大电压（$V_L = L\,dI/dt$），需要注意击穿或采取续流路径。  
- 对更复杂电路或复合初始条件，常用拉普拉斯变换将常微分方程转化为代数方程，或用状态变量法（矩阵形式）。

## 交流稳态与相量法（复阻抗）
- 在稳恒正弦交流下，把 $v(t)=V_m\cos(\omega t+\varphi)$ 表示为相量 $\hat V = V_m e^{j\varphi}$，元件阻抗为：  
  - 电阻 $Z_R = R\,$；电感 $Z_L = j\omega L\,$；电容 $Z_C = 1/(j\omega C)\,$（$j$ 为虚数单位）。  
- KCL、KVL 在相量形式仍然成立，代数求解相量电压/电流，最后取实部或幅值相位恢复时域。  
- 有功功率（平均功率）： $P = VI\cos\phi\,$，其中 $\phi$ 是电压与电流相位差。复功率 $S = P + jQ = \hat V \hat I^*$（星号为复共轭）。

## 能量与功率（在基尔霍夫分析中的体现）
- 在任一电路节点或闭合回路上，基于 KCL/KVL 可写出功率守恒关系：供给功率 = 元件耗散（电阻 $I^2R$） + 存储/释放（电感 $d(1/2LI^2)/dt$ 与电容 $d(1/2C V^2)/dt$） + 可能的辐射损失。  
- 在稳态交流下，电感/电容不消耗平均有功功率，但会有无功功率交换与相位差。

## 常用解题技巧与注意事项
- 先观察电路对称性，尽量化简（串并联合并、电源变换）。  
- 明确未知量（节点电压或网目电流）数量与独立方程数是否匹配。  
- 对含电压源直接连接两个非参考节点时，节点法可用“超节点”处理（把电压源两端和连接的节点作为超节点写 KCL，并写电压源约束方程）。  
- 对含有受控源（电压/电流依赖于电路变量）仍可用相同方法，方程中包含受控源相关项。  
- 若遇到时间变化的磁通（例如感应电动势明显），KVL 需加上感应 emf 项： $\sum V_k = -\dfrac{d\Phi}{dt}$（此类题目常在电磁感应章节出现）。
