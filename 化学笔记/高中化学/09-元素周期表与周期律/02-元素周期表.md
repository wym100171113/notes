# 元素周期表

> [!abstract] 概览
> 元素周期表是化学的"地图"。本笔记系统梳理周期表的结构：**7 个周期、16 个族**（7 个主族、7 个副族、Ⅷ族、0 族），以及"**位置—结构—性质**"三者之间的推理关系。重点是"周期序数 = 电子层数，主族序数 = 最外层电子数"，这是元素推断题的基本工具。

## 核心概念

### 周期表的结构总览

周期表由**横行（周期）**和**纵行（族）**组成：

- **周期**：7 个横行（7 个周期）。
- **族**：18 个纵行，合并为 16 个族。

| 项目 | 数量 | 说明 |
| --- | --- | --- |
| 短周期 | 3 个 | 第 1、2、3 周期（元素种类：$2$、$8$、$8$） |
| 长周期 | 3 个 | 第 4、5、6 周期（元素种类：$18$、$18$、$32$） |
| 不完全周期 | 1 个 | 第 7 周期（目前未填满，元素种类最多 $32$） |
| 主族 | 7 个 | ⅠA~ⅦA（含短周期元素，由短周期+长周期共同构成） |
| 副族 | 7 个 | ⅠB~ⅦB（只由长周期元素构成） |
| Ⅷ族 | 1 个 | 第 8、9、10 三个纵行 |
| 0 族 | 1 个 | 第 18 纵行（稀有气体） |

### 周期数与族序数的决定因素

- **周期序数 = 电子层数**（原子有几个电子层就在第几周期）。
- **主族序数 = 最外层电子数**。
- 副族序数与最外层、次外层电子数有关（过渡金属，选必二深化）。

> [!tip] 记忆口诀
> "周期看层数，主族看价电；一主一族对号入座，短长周期看行数。"

## 重点知识：周期表分区与对角线规则

### 元素分区

- **金属元素**：位于周期表左下方（大部分元素是金属）。
- **非金属元素**：位于周期表右上方（含稀有气体）。
- **分界线**：沿 $\ce{B}$—$\ce{Si}$—$\ce{As}$—$\ce{Te}$—$\ce{At}$ 的"阶梯线"，分界线两侧元素既有金属性又有非金属性。
- 金属性最强：$\ce{Fr}$（第 7 周期ⅠA）；非金属性最强：$\ce{F}$（第 2 周期ⅦA）。

### 对角线规则（重要规律）

周期表中，左上角与右下角相邻的**对角线元素**性质相似：
$$
\ce{Li} \rightsquigarrow \ce{Mg},\qquad \ce{Be} \rightsquigarrow \ce{Al},\qquad \ce{B} \rightsquigarrow \ce{Si}
$$
如 $\ce{Be}$ 与 $\ce{Al}$ 相似：$\ce{Be(OH)2}$ 有两性、$\ce{BeCl2}$ 是共价化合物；$\ce{B}$ 与 $\ce{Si}$ 相似：$\ce{H3BO3}$ 与 $\ce{H2SiO3}$ 都是弱酸。

> [!note] 对角线规则的原理
> 对角线元素"电子层数 +1、最外层电子数 +1"，两者竞争效应抵消，使金属性/非金属性、化合价等性质相近。这是元素推断题常考的知识点。

### 镧系与锕系

- 第 6 周期ⅢB 族：镧系（$\ce{La}$~$\ce{Lu}$，15 种元素）。
- 第 7 周期ⅢB 族：锕系（$\ce{Ac}$~$\ce{Lr}$，15 种元素）。
- 这两系元素都排在周期表ⅢB 族，共占一个格子，是周期表中特殊位置。

### 周期表记忆口诀

- **前 20 号元素顺口溜**：氢氦锂铍硼，碳氮氧氟氖；钠镁铝硅磷，硫氯氩钾钙。
- **前三个短周期元素种类**：第 1 周期 2 种、第 2 周期 8 种、第 3 周期 8 种。
- **主族序数与最外层电子数对应**：ⅠA 一个电子、ⅡA 两个电子……ⅦA 七个电子、0 族八个电子（$\ce{He}$ 为两个）。
- **稀有气体定位**：$\ce{He}$（第 1 周期 0 族）、$\ce{Ne}$（第 2 周期 0 族）、$\ce{Ar}$（第 3 周期 0 族）、$\ce{Kr}$、$\ce{Xe}$、$\ce{Rn}$，最外层均达稳定结构（$\ce{He}$ 为 $2$，其余为 $8$）。

> [!tip] 推断题的突破口
> 见到"短周期元素"先想到第 1、2、3 周期共 18 种元素；见到"原子半径最大"通常是 $\ce{Na}$；"气态氢化物最稳定"是非金属性最强的 $\ce{F}$；"最高价氧化物水化物碱性最强"是 $\ce{Na}$（短周期）或 $\ce{Fr}$（全周期）。

## 重点知识：位置—结构—性质的关系

### 相互推导

| 由已知推未知 | 方法 |
| --- | --- |
| 原子结构 → 位置 | 电子层数 → 周期序数；最外层电子数 → 主族序数 |
| 位置 → 结构 | 周期序数 → 电子层数；主族序数 → 最外层电子数；核电荷数 = 原子序数 |
| 位置/结构 → 性质 | 金属性/非金属性、化合价（最高正价 = 主族序数） |

### 化合价规律

- 主族元素**最高正价 = 主族序数**（氟无正价，氧无最高正价）。
- 非金属元素最低负价 = 主族序数 $-$ 8（绝对值 $= 8 -$ 主族序数）。
- 如 $\ce{Cl}$（ⅦA）：最高正价 $+7$，最低负价 $-1$；$\ce{S}$（ⅥA）：最高正价 $+6$，最低负价 $-2$。

> [!warning] 特殊元素化合价
> 氟（$\ce{F}$）没有正价；氧（$\ce{O}$）一般无最高正价（通常显 $-2$ 价）；稀有气体化学性质稳定，化合价一般为 $0$。

## 典型例题

### 例题 1：由结构推断位置

**题目**：某元素原子的最外层电子数是次外层电子数的 $3$ 倍，则该元素在周期表中的位置是（ ）
A. 第 2 周期ⅥA 族　　B. 第 3 周期ⅥA 族　　C. 第 2 周期ⅣA 族　　D. 第 3 周期ⅣA 族

**分析**：最外层电子数不超过 $8$。若次外层为 $\ce{K}$ 层（2 个电子），最外层最多 2 个（$\ce{K}$ 层为最外层时不超过 2），$3$ 倍不可能。故次外层为 $\ce{L}$ 层（8 个电子）不成立——次外层若为 2 则最外层 6，此时电子层结构为 2、6，即第 2 周期（电子层数 2），最外层 6 个电子为 ⅥA 族，是氧元素。

**解答**：电子排布为 $2$、$6$，第 2 周期ⅥA 族（$\ce{O}$）。答案：**A**。

**点评**：由"最外层 = 次外层 × 3"先锁定电子层结构，再由"周期序数 = 电子层数、主族序数 = 最外层电子数"定位。

### 例题 2：位置推断元素

**题目**：某元素位于第 3 周期ⅥA 族，下列说法正确的是（ ）
A. 该元素是非金属元素
B. 该元素的最高正价为 $+6$ 价
C. 该元素的最低负价为 $-1$ 价
D. 该元素是 $\ce{Cl}$

**分析**：第 3 周期ⅥA 族元素是**硫（$\ce{S}$）**。硫是非金属元素（A 对）；最高正价 = 主族序数 = $+6$（B 对）；最低负价 = 主族序数 $- 8 = -2$（C 错）；ⅥA 族不是 $\ce{Cl}$（氯是ⅦA，D 错）。

**解答**：答案：**A、B**。

**点评**：主族元素"最高正价 = 主族序数，最低负价 = 主族序数 $- 8$"。记住硫（ⅥA）的最高正价 $+6$、最低负价 $-2$，这是高频考点。

## 易错提醒

> [!warning] 易错点清单
> 1. 周期序数 = 电子层数，主族序数 = 最外层电子数，两者对应关系不能混淆。
> 2. 副族元素（过渡金属）不满足"主族序数 = 最外层电子数"。
> 3. Ⅷ族包含第 8、9、10 **三个纵行**，不是一族一个纵行。
> 4. 0 族（第 18 纵行）是稀有气体，化学性质稳定。
> 5. 氟无正价、氧无最高正价；最高正价 = 主族序数只对主族元素成立。
> 6. 对角线规则（$\ce{Li-Mg}$、$\ce{Be-Al}$、$\ce{B-Si}$）是推断题常见陷阱。
