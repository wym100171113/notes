# 氯气

> [!abstract] 概览
> 氯气 $\ce{Cl2}$ 是黄绿色、有毒、有刺激性气味的气体，是卤素单质的代表。氯原子最外层 7 个电子，易得 1 个电子形成 $\ce{Cl^-}$，因此 $\ce{Cl2}$ 具有**强氧化性**。本笔记系统整理氯气的物理性质、化学性质（与金属、非金属、水、碱的反应）、氯水的成分与漂白性，重点掌握"氯水成分为三分子三离子""漂白的是次氯酸"等易错点，并会用物质的量进行定量计算。

## 核心概念

- **物理性质**：黄绿色、有刺激性气味、有毒；密度比空气大；能溶于水（1 体积水约溶解 2 体积氯气）；**易液化**（加压或降温，液氯为纯净物）。
- **强氧化性**：氯原子易得电子，氯气是典型的强氧化剂，可氧化金属、非金属及低价离子。
- **氯水成分**：氯气溶于水部分与水反应生成 $\ce{HCl}$ 和 $\ce{HClO}$，氯水是**混合物**。
- **漂白原理**：真正起漂白作用的是**次氯酸 $\ce{HClO}$**（强氧化性漂白），干燥的氯气无漂白性。

## 重点知识

### 1. 物理性质

| 性质 | 描述 |
| --- | --- |
| 颜色状态 | 黄绿色气体 |
| 气味 | 有刺激性气味，有毒 |
| 密度 | 比空气大（相对分子质量 71） |
| 溶解性 | 能溶于水（1:2），但溶解度不大 |
| 液化 | 易液化（常温加压），液氯黄绿色，是纯净物 |

> [!warning] 液氯 vs 氯水
> **液氯**是液态 $\ce{Cl2}$，是纯净物，无漂白性；**氯水**是氯气的水溶液，是混合物，有漂白性。

### 2. 化学性质（核心）

#### (1) 与金属反应（氯气是强氧化剂，把金属氧化到高价）

- **与钠**：剧烈燃烧，产生白烟
  $$\ce{2Na + Cl2 \xrightarrow{\Delta} 2NaCl}$$
- **与铁**：剧烈燃烧，生成棕褐色烟（**氯化铁，铁被氧化到 +3 价**）
  $$\ce{2Fe + 3Cl2 \xrightarrow{\Delta} 2FeCl3}$$
- **与铜**：剧烈燃烧，生成棕黄色烟（氯化铜，溶于水呈蓝色或绿色）
  $$\ce{Cu + Cl2 \xrightarrow{\Delta} CuCl2}$$

> [!note] 变价金属的特殊性
> 氯气与变价金属反应时，把金属氧化到**高价**：$\ce{Fe -> Fe^{3+}}$、$\ce{Cu -> Cu^{2+}}$。这与盐酸/稀硫酸（氧化到低价）不同，说明氯气氧化性强于非氧化性酸。

#### (2) 与非金属反应（氢气）

- **安静燃烧**（氢气在氯气中燃烧）：苍白色火焰，瓶口有白雾
  $$\ce{H2 + Cl2 \xrightarrow{点燃} 2HCl}$$
- **混合爆炸**（氢气与氯气混合光照）：爆炸
  $$\ce{H2 + Cl2 \xrightarrow{光照} 2HCl}$$

> [!tip] 现象辨析
> $\ce{H2}$ 在 $\ce{Cl2}$ 中安静燃烧，火焰**苍白色**，瓶口白雾（$\ce{HCl}$ 遇水蒸气形成酸雾）；$\ce{Cl2}$ 在 $\ce{H2}$ 中燃烧则火焰呈**苍白色或白雾状**，两者本质相同，都是化合为 $\ce{HCl}$。

#### (3) 与水反应（氯水）

$$\ce{Cl2 + H2O <=> HCl + HClO}$$

- 生成的 $\ce{HClO}$（次氯酸）是弱酸，有强氧化性和漂白性，见光易分解。
- **氯水成分**（常考）：

| 类型 | 成分 |
| --- | --- |
| 三分子 | $\ce{Cl2}$、$\ce{H2O}$、$\ce{HClO}$ |
| 三离子 | $\ce{H+}$、$\ce{Cl^-}$、$\ce{ClO^-}$ |

> [!warning] 漂白的是 $\ce{HClO}$ 不是 $\ce{Cl2}$
> 干燥氯气本身无漂白性；氯气使湿润的有色布条褪色，是因为 $\ce{Cl2}$ 与 $\ce{H2O}$ 反应生成了 $\ce{HClO}$。**检验"氯气无漂白性而氯水有漂白性"**是经典实验题。

#### (4) 与碱反应（制消毒剂）

- **与氢氧化钠溶液**（制漂白液/吸收尾气）：
  $$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$$
- **与石灰乳（氢氧化钙）**（制漂白粉）：
  $$\ce{2Cl2 + 2Ca(OH)2 -> Ca(ClO)2 + CaCl2 + 2H2O}$$

> [!note] 歧化反应
> 氯气与碱反应中，$\ce{Cl2}$ 中氯元素从 0 价分别变为 $-1$ 价（$\ce{Cl^-}$）和 $+1$ 价（$\ce{ClO^-}$），**氯气既作氧化剂又作还原剂**，是歧化反应。

#### (5) 与还原性物质反应

$$\ce{Cl2 + 2FeCl2 -> 2FeCl3}$$
$$\ce{Cl2 + 2KI -> 2KCl + I2}\quad(\text{生成碘，使淀粉变蓝})$$
$$\ce{Cl2 + SO2 + 2H2O -> H2SO4 + 2HCl}$$

### 3. 氯气与"新制/久置氯水"的区别

| 比较 | 新制氯水 | 久置氯水 |
| --- | --- | --- |
| 颜色 | 浅黄绿色 | 无色 |
| 主要成分 | $\ce{Cl2}$、$\ce{HClO}$、$\ce{HCl}$ 等 | $\ce{HCl}$（$\ce{HClO}$ 已分解） |
| 性质 | 有漂白性、有酸性 | 只有酸性，无漂白性 |
| 原因 | $\ce{HClO}$ 见光分解 | $\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$ |

### 4. 用途

- 制盐酸（$\ce{H2 + Cl2}$ 燃烧）；
- 制漂白液、漂白粉、$\ce{ClO2}$ 等消毒剂；
- 自来水消毒（用少量氯气，杀菌并兼有漂白作用，残留 $\ce{HClO}$ 有消毒效果）。

## 典型例题

### 例题 1（氯气与碱反应的计算）

**题目**：将 $7.1\ \mathrm{g}$ 氯气通入足量 $\ce{NaOH}$ 溶液中，求生成的 $\ce{NaCl}$ 和 $\ce{NaClO}$ 的物质的量。

**分析**：反应为 $\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$，$\ce{Cl2}$ 摩尔质量为 $71\ \mathrm{g/mol}$。先求氯气物质的量，再按系数比求产物。

**解答**：
$$n(\ce{Cl2}) = \dfrac{7.1\ \mathrm{g}}{71\ \mathrm{g/mol}} = 0.1\ \mathrm{mol}$$

由方程式，$n(\ce{NaCl}) : n(\ce{NaClO}) : n(\ce{Cl2}) = 1 : 1 : 1$，故：
$$n(\ce{NaCl}) = 0.1\ \mathrm{mol},\qquad n(\ce{NaClO}) = 0.1\ \mathrm{mol}$$

**点评**：抓住氯气与碱反应"1 mol $\ce{Cl2}$ 生成 1 mol $\ce{NaCl}$ 和 1 mol $\ce{NaClO}$"，即 $\ce{Cl2}$ 中的氯原子"一半到 $\ce{Cl^-}$、一半到 $\ce{ClO^-}$"。这是歧化反应的计量基础。

### 例题 2（氯气与铁反应 + 氧化产物判断）

**题目**：将 $2.8\ \mathrm{g}$ 铁粉与足量氯气充分反应，求生成 $\ce{FeCl3}$ 的质量。

**分析**：$\ce{2Fe + 3Cl2 -> 2FeCl3}$，$\ce{Fe}$ 的摩尔质量为 $56\ \mathrm{g/mol}$，$\ce{FeCl3}$ 摩尔质量为 $162.5\ \mathrm{g/mol}$。氯气过量，铁完全反应且被氧化到 $+3$ 价。

**解答**：
$$n(\ce{Fe}) = \dfrac{2.8\ \mathrm{g}}{56\ \mathrm{g/mol}} = 0.05\ \mathrm{mol}$$
$$n(\ce{FeCl3}) = n(\ce{Fe}) = 0.05\ \mathrm{mol}$$
$$m(\ce{FeCl3}) = 0.05 \times 162.5 = 8.125\ \mathrm{g}$$

**点评**：氯气与变价金属反应生成**高价氯化物**（$\ce{FeCl3}$ 而非 $\ce{FeCl2}$）。若换成盐酸则生成 $\ce{FeCl2}$，需注意氧化剂不同、产物不同。

## 易错提醒

> [!warning] 易错点
> 1. **漂白的是 $\ce{HClO}$ 不是 $\ce{Cl2}$**：干燥氯气无漂白性；检验时需用湿润的有色布条。
> 2. **液氯是纯净物**（液态 $\ce{Cl2}$），氯水是混合物；液氯无漂白性。
> 3. **氯气与变价金属生成高价氯化物**：$\ce{Fe}$ 与 $\ce{Cl2}$ 生成 $\ce{FeCl3}$，$\ce{Cu}$ 生成 $\ce{CuCl2}$。
> 4. **氯气有毒**：实验室闻氯气要用"扇闻法"，尾气用 $\ce{NaOH}$ 溶液吸收。
> 5. **新制氯水与久置氯水**：久置氯水只剩 $\ce{HCl}$，无漂白性，酸性也不变（$\ce{HClO}$ 分解产生的 $\ce{HCl}$ 补偿）。
> 6. **"三分子三离子"**：氯水中的分子是 $\ce{Cl2}$、$\ce{H2O}$、$\ce{HClO}$，离子是 $\ce{H+}$、$\ce{Cl^-}$、$\ce{ClO^-}$，不要漏掉 $\ce{HClO}$ 分子。
> 7. **$\ce{Cl2}$ 与 $\ce{SO2}$ 混合通入品红**：两者恰好完全反应（$\ce{Cl2 + SO2 + 2H2O -> H2SO4 + 2HCl}$）时漂白能力反而**消失**（生成物无漂白性）。
