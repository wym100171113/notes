# 传感器技术

> [!abstract] 概览
> 传感器技术是利用物理、化学或生物效应将待测非电学量（温度、压力、光强、磁场等）转换为可测电学量的器件与方法总称，是现代测量、自动化与物联网系统的信息入口。

## 核心内容

传感器按工作原理可分为物理型、化学型与生物型三大类。**物理传感器**基于力、热、光、磁等物理效应，应用最广，如电阻应变片、热电偶、光电二极管、霍尔元件；**化学传感器**基于化学反应或吸附引起电学性质变化，如气敏、离子选择性电极；**生物传感器**将生物活性单元（酶、抗体、DNA）与换能器结合，用于血糖、免疫检测。

常见物理传感器的工作原理：

| 类型 | 被测量 | 工作原理 |
| --- | --- | --- |
| 热敏电阻 / 热电偶 | 温度 | 电阻率随温度变化 / 塞贝克效应 |
| 电阻应变片 | 压力 / 形变 | 形变引起电阻变化 |
| 光敏电阻 / 光电二极管 | 光强 | 半导体光电导 / 光生电动势 |
| 霍尔元件 | 磁场 | 霍尔效应输出横向电压 |

传感器的核心性能指标包括灵敏度（输出变化与输入变化之比）、线性度、响应时间、迟滞与稳定性。实际应用中常通过电桥电路、放大电路与模数转换将微弱传感信号调理为可处理的标准信号，并配合微处理器实现数字测量与智能补偿。

传感器技术已深度融入现代生活与工业：汽车中的加速度计触发安全气囊，手机中的陀螺仪与磁力计实现姿态识别，工业流程中的压力与流量传感器保障生产安全，医疗中的血氧与心电传感器支撑生命监护。与半导体物理、微机电系统 (MEMS) 的结合推动传感器向微型化、智能化、低功耗方向持续发展。
