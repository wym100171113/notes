# 碳酸钠与碳酸氢钠

> [!abstract] 概览
> $\ce{Na2CO3}$（碳酸钠，俗称**纯碱、苏打**）与 $\ce{NaHCO3}$（碳酸氢钠，俗称**小苏打**）是钠的两种重要盐。二者都由 $\ce{Na+}$ 与含碳酸根构成，但酸根不同（$\ce{CO3^{2-}}$ 与 $\ce{HCO3^{-}}$），导致热稳定性、溶解性、碱性与反应速率差异明显。本笔记重点对比二者的性质，掌握与酸/碱/盐的反应、相互转化规律、鉴别方法，并了解[[侯氏制碱法1|侯氏制碱法]]。

## 核心概念

- **俗称**：$\ce{Na2CO3}$ — 纯碱、苏打、面碱；$\ce{NaHCO3}$ — 小苏打。
- **热稳定性**：$\ce{Na2CO3}$ 受热不分解；$\ce{NaHCO3}$ 受热易分解：$\ce{2NaHCO3 \xrightarrow{\Delta} Na2CO3 + CO2 ^ + H2O}$。
- **溶解性**：$\ce{Na2CO3}$ 溶解度比 $\ce{NaHCO3}$ **大**；同温度下碳酸钠易形成结晶水合物 $\ce{Na2CO3\cdot 10H2O}$（风化）。
- **碱性**：相同浓度下，$\ce{Na2CO3}$ 溶液的碱性**强于** $\ce{NaHCO3}$。
- **相互转化**：$\ce{Na2CO3}$ 与 $\ce{CO2}$/水/酸作用生成 $\ce{NaHCO3}$；$\ce{NaHCO3}$ 加热或加碱可转化为 $\ce{Na2CO3}$。

## 重点知识

### 1. 碳酸钠与碳酸氢钠的性质对比

| 对比项 | $\ce{Na2CO3}$ | $\ce{NaHCO3}$ |
| --- | --- | --- |
| 俗称 | 纯碱、苏打 | 小苏打 |
| 状态 | 白色粉末 | 白色细小晶体 |
| 溶解性 | 易溶（较大） | 可溶（较小） |
| 水溶液酸碱性 | 较强碱性 | 较弱碱性（也呈碱性） |
| 热稳定性 | 受热不易分解 | 受热易分解（约 150℃ 开始） |
| 与盐酸反应 | $\ce{Na2CO3 + 2HCl -> 2NaCl + CO2 ^ + H2O}$ | $\ce{NaHCO3 + HCl -> NaCl + CO2 ^ + H2O}$ |
| 与盐酸反应快慢 | 慢（分两步，先生成 $\ce{HCO3^{-}}$） | 快（一步完成） |
| 与 $\ce{NaOH}$ | 不反应 | $\ce{NaHCO3 + NaOH -> Na2CO3 + H2O}$ |
| 与 $\ce{Ca(OH)2}$ | 生成 $\ce{CaCO3}$ 沉淀 | 生成 $\ce{CaCO3}$ 沉淀（量不同产物不同） |
| 与 $\ce{CO2}$ | $\ce{Na2CO3 + CO2 + H2O -> 2NaHCO3}$ | 不反应 |
| 与 $\ce{CaCl2}$ | 生成 $\ce{CaCO3}$ 沉淀 | 一般不反应（生成不沉淀） |

> [!warning] 与盐酸反应的本质
> $\ce{Na2CO3}$ 与盐酸反应是**分两步**进行的：先 $\ce{CO3^{2-} + H+ -> HCO3^{-}}$，再 $\ce{HCO3^{-} + H+ -> CO2 ^ + H2O}$。因此滴加顺序不同，现象不同（正滴 vs 反滴）。

### 2. 热稳定性实验

- 装置：分别加热 $\ce{Na2CO3}$ 与 $\ce{NaHCO3}$，用澄清石灰水检验放出的气体。
- 现象：$\ce{Na2CO3}$ 不分解，石灰水不变浑浊；$\ce{NaHCO3}$ 受热分解，石灰水变浑浊。
- 方程式：$\ce{2NaHCO3 \xrightarrow{\Delta} Na2CO3 + CO2 ^ + H2O}$
- 结论：热稳定性 $\ce{Na2CO3}$ > $\ce{NaHCO3}$（碳酸氢盐一般都不稳定）。

> [!tip] 钠盐热稳定性规律
> 碳酸盐的热稳定性：$\ce{Na2CO3}$ > $\ce{NaHCO3}$；一般"正盐 > 酸式盐"，且"碳酸盐 > 对应碳酸氢盐"。

### 3. 相互转化

$$\ce{Na2CO3 <=>[+CO2+H2O][+NaOH 或 \Delta] NaHCO3}$$

- **$\ce{Na2CO3 -> NaHCO3}$**：通入 $\ce{CO2}$ 或加适量酸（盐酸）：
  $$\ce{Na2CO3 + CO2 + H2O -> 2NaHCO3}$$
- **$\ce{NaHCO3 -> Na2CO3}$**：加热，或加适量 $\ce{NaOH}$：
  $$\ce{2NaHCO3 \xrightarrow{\Delta} Na2CO3 + CO2 ^ + H2O}$$
  $$\ce{NaHCO3 + NaOH -> Na2CO3 + H2O}$$

> [!warning] 与 $\ce{CO2}$ 的量关系
> 向 $\ce{NaOH}$ 溶液通入 $\ce{CO2}$ 时，$\ce{CO2}$ 少量生成 $\ce{Na2CO3}$，过量生成 $\ce{NaHCO3}$：
> - $\ce{2NaOH + CO2(少量) -> Na2CO3 + H2O}$
> - $\ce{NaOH + CO2(过量) -> NaHCO3}$

### 4. 鉴别方法

| 方法 | 原理 |
| --- | --- |
| 加热法 | $\ce{NaHCO3}$ 分解产生 $\ce{CO2}$（使石灰水变浑浊），$\ce{Na2CO3}$ 不分解 |
| 加盐酸速率 | 等量固体与等浓度盐酸反应，$\ce{NaHCO3}$ 产生气泡更快 |
| 加 $\ce{CaCl2}$/$\ce{BaCl2}$ 溶液 | $\ce{Na2CO3}$ 生成白色沉淀，$\ce{NaHCO3}$ 不沉淀 |
| 测 pH | 同浓度下 $\ce{Na2CO3}$ 溶液 pH 更大 |

> [!tip] 口诀
> "**钠二碳三不分解，钠二氢碳热分解；苏打先慢后快冒，小苏打一口气跑完**"——碳酸钠与盐酸分两步慢反应，碳酸氢钠一步快反应。

### 5. 侯氏制碱法

- 核心反应：$\ce{NaCl + NH3 + CO2 + H2O -> NaHCO3 v + NH4Cl}$，利用 $\ce{NaHCO3}$ 溶解度较小而析出。
- 顺序：先通 $\ce{NH3}$（增大 $\ce{CO2}$ 溶解度），再通 $\ce{CO2}$。
- 产物：$\ce{NaHCO3}$ 煅烧得 $\ce{Na2CO3}$，副产 $\ce{NH4Cl}$（氮肥）。
- 详见 [[侯氏制碱法1]]、[[侯氏制碱法2]]。

### 6. 用途

- $\ce{Na2CO3}$：制玻璃、造纸、洗涤剂、纺织等；也用于工业制碱。
- $\ce{NaHCO3}$：焙制糕点（发酵粉）、治疗胃酸过多（中和胃酸）、泡沫灭火器（与酸反应生成 $\ce{CO2}$）。

## 典型例题

### 例题 1（热分解 + 差量计算）

**题目**：将 $16.8\ \mathrm{g}$ 的 $\ce{NaHCO3}$ 固体充分加热至质量不再变化，求所得 $\ce{Na2CO3}$ 的质量和放出的 $\ce{CO2}$ 在标准状况下的体积。

**分析**：$\ce{NaHCO3}$ 摩尔质量为 $84\ \mathrm{g/mol}$，$\ce{Na2CO3}$ 为 $106\ \mathrm{g/mol}$。由方程式 $\ce{2NaHCO3 \xrightarrow{\Delta} Na2CO3 + CO2 ^ + H2O}$ 可知 $2\ \mathrm{mol}\ \ce{NaHCO3}$ 生成 $1\ \mathrm{mol}\ \ce{Na2CO3}$ 和 $1\ \mathrm{mol}\ \ce{CO2}$。

**解答**：
$$n(\ce{NaHCO3}) = \dfrac{16.8\ \mathrm{g}}{84\ \mathrm{g/mol}} = 0.2\ \mathrm{mol}$$
$$n(\ce{Na2CO3}) = 0.1\ \mathrm{mol},\qquad m(\ce{Na2CO3}) = 0.1 \times 106 = 10.6\ \mathrm{g}$$
$$n(\ce{CO2}) = 0.1\ \mathrm{mol},\qquad V(\ce{CO2}) = 0.1 \times 22.4 = 2.24\ \mathrm{L}$$

**点评**：热分解差量问题，按方程式系数比换算即可。也可用"固体质量差"检验：$16.8 - 10.6 = 6.2\ \mathrm{g}$，恰等于 $0.1\ \mathrm{mol}\ \ce{CO2}(4.4\ \mathrm{g}) + 0.1\ \mathrm{mol}\ \ce{H2O}(1.8\ \mathrm{g})$。

### 例题 2（碳酸钠与盐酸反应的滴加顺序）

**题目**：向 $100\ \mathrm{mL}$ 浓度为 $1\ \mathrm{mol/L}$ 的 $\ce{Na2CO3}$ 溶液中逐滴加入 $0.5\ \mathrm{mol}$ 的 $\ce{HCl}$，求生成 $\ce{CO2}$ 的体积（标准状况）。

**分析**：$n(\ce{Na2CO3}) = 0.1\ \mathrm{mol}$。滴加顺序为"向碳酸钠中滴盐酸"，先发生 $\ce{CO3^{2-} + H+ -> HCO3^{-}}$（消耗 $0.1\ \mathrm{mol}\ \ce{H+}$，剩余 $0.4\ \mathrm{mol}\ \ce{H+}$），再发生 $\ce{HCO3^{-} + H+ -> CO2 ^ + H2O}$，但 $\ce{HCO3^{-}}$ 只有 $0.1\ \mathrm{mol}$，故生成 $0.1\ \mathrm{mol}\ \ce{CO2}$。

**解答**：
第一阶段：$\ce{CO3^{2-} + H+ -> HCO3^{-}}$，$0.1\ \mathrm{mol}\ \ce{CO3^{2-}}$ 消耗 $0.1\ \mathrm{mol}\ \ce{H+}$，生成 $0.1\ \mathrm{mol}\ \ce{HCO3^{-}}$；
剩余 $\ce{H+}$：$0.5 - 0.1 = 0.4\ \mathrm{mol}$。

第二阶段：$\ce{HCO3^{-} + H+ -> CO2 ^ + H2O}$，$\ce{HCO3^{-}}$ 只有 $0.1\ \mathrm{mol}$，$\ce{H+}$ 过量，故生成 $\ce{CO2}$ 物质的量受 $\ce{HCO3^{-}}$ 限制：
$$n(\ce{CO2}) = 0.1\ \mathrm{mol},\qquad V(\ce{CO2}) = 0.1 \times 22.4 = 2.24\ \mathrm{L}$$

**点评**：碳酸钠中滴盐酸与盐酸中滴碳酸钠结果完全不同——前者分两步、先无气泡后有气泡；后者立即产生气泡。这类"顺序决定现象"的题目是高考必考点，务必分析清楚哪一步是限量试剂。

## 易错提醒

> [!warning] 易错点
> 1. **热稳定性**：$\ce{Na2CO3}$ 受热不分解，$\ce{NaHCO3}$ 受热分解，勿混淆。
> 2. **$\ce{Na2CO3}$ 俗名"纯碱"但属于盐**：显碱性（水解），但不是碱。
> 3. **与盐酸反应的顺序问题**：向 $\ce{Na2CO3}$ 中滴盐酸，先无气泡后产生气泡；向盐酸中滴 $\ce{Na2CO3}$，立即产生气泡。两种滴加方式现象不同。
> 4. **$\ce{NaHCO3}$ 与 $\ce{CaCl2}$/$\ce{BaCl2}$ 不反应**（一般不生成沉淀），但 $\ce{Na2CO3}$ 会生成沉淀，这是鉴别二者的简便方法。
> 5. **除杂**：$\ce{Na2CO3}$ 中混有 $\ce{NaHCO3}$，用加热法；$\ce{NaHCO3}$ 中混有 $\ce{Na2CO3}$，可通 $\ce{CO2}$（配成溶液）。
> 6. **溶解度**：$\ce{Na2CO3}$ 溶解度大于 $\ce{NaHCO3}$（同温），侯氏制碱正是利用这一点使 $\ce{NaHCO3}$ 析出。
> 7. **结晶水合物**：$\ce{Na2CO3\cdot 10H2O}$ 在空气中易**风化**失水变为粉末状 $\ce{Na2CO3}$。
