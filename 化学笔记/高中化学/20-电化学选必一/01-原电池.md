# 原电池

> [!abstract] 概览
> 本笔记研究**原电池**——将化学能转化为电能的装置。核心是掌握原电池的构成条件、电极判断（"负极氧化、正极还原"）、电极反应式的书写（含介质配平）、盐桥的作用，以及常见化学电源（锌锰干电池、铅蓄电池、锂电池、燃料电池）的原理。高考中"给电池写电极反应 + 判断离子移动方向"是必考题型。

## 核心概念

### 1. 原电池的定义与构成条件

**定义**：把化学能转化为电能的装置。本质是**自发的氧化还原反应**被拆成两个半反应，分别在两极进行，电子沿外电路定向移动形成电流。

**构成条件**（四要素）：
1. **两个活泼性不同的电极**（或一个电极 + 惰性电极）；
2. **电解质溶液**（或熔融电解质）；
3. **形成闭合回路**（导线连接 + 溶液离子导电或盐桥）；
4. **能自发发生氧化还原反应**。

> [!warning] 关键判据
> 能否形成原电池，本质看"**该氧化还原反应能否自发进行**"。若设计错误（如两个电极都不参与反应、溶液与电极不反应），则不能产生持续电流。

### 2. 电极判断：负极氧化、正极还原

以 $\ce{Zn-Cu}$ 原电池（稀硫酸）为例：
$$\text{负极（Zn）：}\quad \ce{Zn - 2e- = Zn^2+} \quad \text{（氧化反应）}$$
$$\text{正极（Cu）：}\quad \ce{2H+ + 2e- = H2 ^} \quad \text{（还原反应）}$$
$$\text{总反应：}\quad \ce{Zn + 2H+ = Zn^2+ + H2 ^}$$

| 电极 | 电子流向 | 电极反应类型 | 电极质量变化 |
| --- | --- | --- | --- |
| 负极 | 电子流出 | 氧化反应（失电子） | 活性电极溶解，质量减小 |
| 正极 | 电子流入 | 还原反应（得电子） | 通常质量不变或增大（析出金属/气体） |

> [!tip] 记忆
> "**负氧化、正还原；失电子、被氧化、作负极。**"

### 3. 电极反应式的书写方法

**步骤**：
1. 写出总反应，标出化合价变化，确定氧化、还原半反应；
2. 负极（阳极）：失电子的物质 − $n e^-$ → 氧化产物；
3. 正极（阴极）：得电子的物质 + $n e^-$ → 还原产物；
4. **介质配平**：在碱性介质中不能出现 $H^+$，酸性介质中不能出现 $OH^-$；氧、氢原子用 $H_2O$ 与 $H^+/OH^-$ 配平；
5. 检查电荷守恒与原子守恒。

**示例**：氢氧燃料电池（碱性介质，$KOH$ 溶液）。
$$\text{负极：}\quad \ce{H2 - 2e- + 2OH- = 2H2O}$$
$$\text{正极：}\quad \ce{O2 + 4e- + 2H2O = 4OH-}$$
$$\text{总反应：}\quad \ce{2H2 + O2 = 2H2O}$$

> [!warning] 介质配平要点
> 燃料电池中电极反应式**必须写介质参与**：酸性介质正极 $\ce{O2 + 4e- + 4H+ = 2H2O}$，碱性介质正极 $\ce{O2 + 4e- + 2H2O = 4OH-}$。同一电池在不同介质中电极反应不同，但总反应相同。

### 4. 盐桥的作用

盐桥通常为含 $\ce{KCl}$（或 $\ce{KNO3}$、$\ce{NH4NO3}$）琼脂的 U 形管。

- **作用**：① 构成闭合回路（离子导电）；② 平衡两池电荷，维持溶液电中性，使电流持续；
- **离子移动方向**：盐桥中阳离子移向**正极区**，阴离子移向**负极区**（为抵消电极反应造成的电荷积累）。

> [!note] 单液电池 vs 双液电池
> 单液电池（$\ce{Zn}$ 和 $\ce{Cu}$ 插在同一杯 $\ce{H2SO4}$ 中）效率低：$\ce{Zn}$ 直接与 $\ce{CuSO4}$ 或酸反应，化学能转化为热能浪费。双液电池用盐桥隔开，让氧化、还原分别在两池进行，电子只能走外电路，效率高、电流稳定。

## 重点知识

### 1. 常见化学电源

#### （1）锌锰干电池（一次电池）
- 负极（$\ce{Zn}$ 筒）：$\ce{Zn - 2e- = Zn^2+}$
- 正极（石墨棒，$\ce{MnO2}$ 为活性物质）：$\ce{2MnO2 + 2NH4+ + 2e- = Mn2O3 + 2NH3 + H2O}$（碱性锌锰电池正极：$\ce{2MnO2 + 2e- + H2O = Mn2O3 + 2OH-}$）
- 特点：不可充电，放电后不能恢复。

#### （2）铅蓄电池（二次电池，可充电）
$$\text{负极：}\quad \ce{Pb + SO4^2- - 2e- = PbSO4 v}$$
$$\text{正极：}\quad \ce{PbO2 + 4H+ + SO4^2- + 2e- = PbSO4 + 2H2O}$$
$$\text{放电总反应：}\quad \ce{Pb + PbO2 + 2H2SO4 = 2PbSO4 + 2H2O}$$
充电时反向进行，是原电池与电解池的互逆过程。

> [!warning] 二次电池充电方程式
> 充电反应 = 放电反应的**逆反应**。写充电电极反应时，把放电电极反应反过来、电子移向调转（阳极失电子、阴极得电子）。铅蓄电池放电时 $H_2SO_4$ 浓度**减小**，充电时浓度增大。

#### （3）锂电池
- 负极（$\ce{Li}$）：$\ce{Li - e- = Li+}$，锂是密度小、活泼性极强的金属；
- 特点：能量密度高、电压高、寿命长，但锂易与水反应，需用非水电解质（有机溶剂），且需防过充爆炸。

#### （4）燃料电池
燃料（$\ce{H2}$、$\ce{CH4}$、$\ce{CH3OH}$、$\ce{NH3}$ 等）在负极氧化，$\ce{O2}$ 在正极还原。
- 优点：能量转化率高、产物洁净（氢氧燃料电池产物只有水）。
- 氢氧燃料电池（酸性介质）：
$$\text{负极：}\quad \ce{2H2 - 4e- = 4H+}$$
$$\text{正极：}\quad \ce{O2 + 4e- + 4H+ = 2H2O}$$

> [!tip] 燃料电池总反应与燃烧反应一致
> 燃料电池的总反应就是该燃料的燃烧反应（如甲烷 $\ce{CH4 + 2O2 = CO2 + 2H2O}$）。先写总反应，再写较简单的一极，另一极由总反应减出。

### 2. 原电池中的离子移动方向

- **阳离子**（$H^+$、$Cu^{2+}$、$Zn^{2+}$）移向**正极**；
- **阴离子**（$Cl^-$、$SO_4^{2-}$、$OH^-$）移向**负极**；
- **电子**只能沿导线从负极到正极，不能进入溶液。

> [!warning] 常见误区
> "电子经溶液从负极流向正极"是**错误**的。溶液中是靠离子定向移动导电，电子不下水；外电路电子从负极到正极，内电路阳离子向正极移动。

### 3. 电极产物的定量计算（电子守恒）

$$n(e^-) = n(\text{失电子物质的量}) \times \text{化合价升高数} = n(\text{得电子物质的量}) \times \text{化合价降低数}$$

例：$\ce{Zn-Cu}$ 原电池中转移 0.2 mol 电子，则溶解 $\ce{Zn}$：$n(\ce{Zn}) = \dfrac{0.2}{2} = 0.1\ mol$（$m = 6.5\ g$）；正极析出 $\ce{H2}$：$n(\ce{H2}) = \dfrac{0.2}{2} = 0.1\ mol$（$V = 2.24\ L$，标况）。

## 典型例题

### 例题 1（电极判断与离子移动）

**题目**：某原电池总反应为 $\ce{Zn + Cu^2+ = Zn^2+ + Cu}$。回答：（1）哪极是负极？（2）电子流向？（3）盐桥中 $K^+$ 移向哪极区？

**分析**：$\ce{Zn}$ 失电子被氧化，作负极；$\ce{Cu^2+}$ 得电子被还原，在正极析出 $\ce{Cu}$。

**解答**：
（1）$\ce{Zn}$ 为**负极**，$\ce{Cu}$（或石墨）为**正极**；
（2）电子由负极（Zn）沿导线流向正极（Cu）；
（3）盐桥中阳离子（$K^+$）移向**正极区**，以平衡正极消耗 $Cu^{2+}$ 后过剩的阴离子；阴离子（$Cl^-$）移向**负极区**。

**点评**：判断离子移动方向看"哪极需要电荷补偿"——正极不断消耗阳离子（$Cu^{2+}$），需盐桥阳离子补入；负极不断生成阳离子（$Zn^{2+}$），需盐桥阴离子来中和。

### 例题 2（电极反应书写与电子守恒计算）

**题目**：氢氧燃料电池以 $\ce{KOH}$ 溶液为电解质。（1）写两电极反应；（2）若电路中通过 0.4 mol 电子，消耗 $\ce{H2}$ 多少克（标况下体积多少）？

**分析**：碱性介质，正极氧气得电子与水结合生成 $OH^-$；负极氢气失电子与 $OH^-$ 结合生成水。

**解答**：
$$\text{负极：}\quad \ce{2H2 - 4e- + 4OH- = 4H2O} \quad \text{即 } \ce{H2 - 2e- + 2OH- = 2H2O}$$
$$\text{正极：}\quad \ce{O2 + 4e- + 2H2O = 4OH-}$$
转移 0.4 mol 电子，由 $\ce{H2 - 2e-}$ 知：$n(\ce{H2}) = \dfrac{0.4}{2} = 0.2\ mol$，$m(\ce{H2}) = 0.2 \times 2 = 0.4\ g$，标况体积 $V = 0.2 \times 22.4 = 4.48\ L$。

**点评**：写燃料电池电极反应先定介质再配平。计算用"电子守恒"：1 mol $\ce{H2}$ 失 2 mol 电子，1 mol $\ce{O2}$ 得 4 mol 电子，据此建立比例。

### 例题 3（化学电源判断）

**题目**：铅蓄电池放电时的负极反应为 $\ce{Pb + SO4^2- - 2e- = PbSO4}$。判断：放电时溶液中 $H_2SO_4$ 浓度如何变化？充电时该反应是阴极反应还是阳极反应？

**分析**：放电总反应消耗 $H_2SO_4$；充电是放电的逆过程，失电子的反应对应阳极。

**解答**：
放电时总反应 $\ce{Pb + PbO2 + 2H2SO4 = 2PbSO4 + 2H2O}$ 消耗硫酸，故 $H_2SO_4$ 浓度**减小**。充电时该反应反向进行（$\ce{PbSO4 + 2e- = Pb + SO4^2-}$）为**得电子**反应，在**阴极**发生；放电时的负极反应在充电时对应**阳极**（$\ce{PbSO4 - 2e- + 2H2O = PbO2 + SO4^2- + 4H+}$）。

**点评**：二次电池充电时，"原电池的负极"变成"电解池的阳极"，"正极"变成"阴极"——抓住"失电子=阳极、得电子=阴极"就不会错。

## 易错提醒

> [!warning] 本节高频失分点
> 1. **电极名称与反应类型脱钩**：负极、阳极都发生氧化（失电子）；正极、阴极都发生还原（得电子）。
> 2. **电极反应漏写介质**：燃料电池、碱性电池的电极反应必须写 $H^+/OH^-/H_2O$ 配平，酸性介质不能出现 $OH^-$。
> 3. **电子从溶液迁移**：电子只走外电路，溶液中靠离子导电。
> 4. **盐桥作用理解片面**：盐桥既接通回路又平衡电荷，缺一不可；离子移动方向别写反。
> 5. **二次电池充电方向写反**：充电 = 放电逆反应，放电负极 ↔ 充电阳极。
> 6. **忽视"能否自发"**：设计原电池必须先判断氧化还原反应能否自发（$\Delta G < 0$，即 $\Delta G = -nFE < 0$）。

## 与其他知识关联

- 与氧化还原反应：原电池的本质是自发的氧化还原反应，电极反应即氧化/还原半反应。
- 与化学平衡：原电池能否持续工作与反应的平衡常数、$\Delta G = -nFE$ 有关，可联系 [[化学反应平衡移动的影响因素]]。
- 与电解质电离：电解质溶液导电依靠离子，电解质分类见 [[一、物质的分类及转化1.电解质与电离方程式]]。
- 与电解池：原电池是电解池的逆过程（二次电池充电即电解），见 [[02-电解池]]。
- 与金属腐蚀：钢铁吸氧腐蚀、析氢腐蚀本质是微电池（原电池），见 [[03-金属腐蚀与防护]]。
