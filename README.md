# 📚 Obsidian Notes Vault

一个基于 **Obsidian + GitHub** 的个人知识库，包含学习笔记、想法整理、项目记录与长期积累的内容。  
本仓库通过 **Obsidian Git 插件** 实现自动化备份与版本管理，确保所有笔记安全、可追踪、可回溯。

---

## ✨ 特性 Features

- 📝 **Markdown 优雅书写**：所有内容均采用纯 Markdown，结构清晰、可移植性强  
- 🔄 **自动化同步**：使用 Obsidian Git 自动 commit & push  
- 🕒 **版本可追踪**：每一次修改都被记录，可随时回滚  
- 📦 **跨设备同步**：可在多台设备上克隆仓库并使用 Obsidian 打开  
- 🔐 **私有仓库保护**：内容仅自己可见，安全可靠
