# 不定积分表

## 基本积分公式

| 积分 | 结果 |
|------|------|
| $\int k \, dx$ | $kx + C$ |
| $\int x^n \, dx$ | $\dfrac{x^{n+1}}{n+1} + C \quad (n \neq -1)$ |
| $\int \dfrac{1}{x} \, dx$ | $\ln \vert x \vert + C$ |
| $\int e^x \, dx$ | $e^x + C$ |
| $\int a^x \, dx$ | $\dfrac{a^x}{\ln a} + C \quad (a>0, a\neq 1)$ |

## 有理函数积分

| 积分 | 结果 |
|------|------|
| $\int \dfrac{1}{a^2 + x^2} \, dx$ | $\dfrac{1}{a} \arctan \dfrac{x}{a} + C$ |
| $\int \dfrac{1}{a^2 - x^2} \, dx$ | $\dfrac{1}{2a} \ln \left\vert \dfrac{a+x}{a-x} \right\vert + C$ |
| $\int \dfrac{1}{x^2 - a^2} \, dx$ | $\dfrac{1}{2a} \ln \left\vert \dfrac{x-a}{x+a} \right\vert + C$ |
| $\int \dfrac{1}{(x+a)(x+b)} \, dx$ | $\dfrac{1}{a-b} \ln \left\vert \dfrac{x+b}{x+a} \right\vert + C \quad (a \neq b)$ |
| $\int \dfrac{x}{x^2 \pm a^2} \, dx$ | $\dfrac{1}{2} \ln \vert x^2 \pm a^2 \vert + C$ |

## 无理函数积分（含平方根）

| 积分 | 结果 |
|------|------|
| $\int \dfrac{1}{\sqrt{a^2 - x^2}} \, dx$ | $\arcsin \dfrac{x}{a} + C$ |
| $\int \dfrac{1}{\sqrt{x^2 \pm a^2}} \, dx$ | $\ln \left\vert x + \sqrt{x^2 \pm a^2} \right\vert + C$ |
| $\int \dfrac{1}{x\sqrt{x^2 - a^2}} \, dx$ | $\dfrac{1}{a} \operatorname{arcsec} \left\vert \dfrac{x}{a} \right\vert + C$ |
| $\int \sqrt{a^2 - x^2} \, dx$ | $\dfrac{x}{2} \sqrt{a^2 - x^2} + \dfrac{a^2}{2} \arcsin \dfrac{x}{a} + C$ |
| $\int \sqrt{x^2 \pm a^2} \, dx$ | $\dfrac{x}{2} \sqrt{x^2 \pm a^2} \pm \dfrac{a^2}{2} \ln \left\vert x + \sqrt{x^2 \pm a^2} \right\vert + C$ |
| $\int \dfrac{x}{\sqrt{a^2 \pm x^2}} \, dx$ | $\pm \sqrt{a^2 \pm x^2} + C$ |

## 三角函数积分

| 积分 | 结果 |
|------|------|
| $\int \sin x \, dx$ | $-\cos x + C$ |
| $\int \cos x \, dx$ | $\sin x + C$ |
| $\int \tan x \, dx$ | $-\ln \vert \cos x \vert + C = \ln \vert \sec x \vert + C$ |
| $\int \cot x \, dx$ | $\ln \vert \sin x \vert + C$ |
| $\int \sec x \, dx$ | $\ln \vert \sec x + \tan x \vert + C$ |
| $\int \csc x \, dx$ | $\ln \vert \csc x - \cot x \vert + C$ |
| $\int \sec^2 x \, dx$ | $\tan x + C$ |
| $\int \csc^2 x \, dx$ | $-\cot x + C$ |
| $\int \sec x \tan x \, dx$ | $\sec x + C$ |
| $\int \csc x \cot x \, dx$ | $-\csc x + C$ |
| $\int \sin^2 x \, dx$ | $\dfrac{x}{2} - \dfrac{\sin 2x}{4} + C$ |
| $\int \cos^2 x \, dx$ | $\dfrac{x}{2} + \dfrac{\sin 2x}{4} + C$ |
| $\int \tan^2 x \, dx$ | $\tan x - x + C$ |
| $\int \cot^2 x \, dx$ | $-\cot x - x + C$ |
| $\int \sin^3 x \, dx$ | $\dfrac{\cos^3 x}{3} - \cos x + C$ |
| $\int \cos^3 x \, dx$ | $\sin x - \dfrac{\sin^3 x}{3} + C$ |

## 反三角函数积分

| 积分 | 结果 |
|------|------|
| $\int \arcsin x \, dx$ | $x \arcsin x + \sqrt{1-x^2} + C$ |
| $\int \arccos x \, dx$ | $x \arccos x - \sqrt{1-x^2} + C$ |
| $\int \arctan x \, dx$ | $x \arctan x - \dfrac{1}{2} \ln(1+x^2) + C$ |
| $\int \operatorname{arccot} x \, dx$ | $x \operatorname{arccot} x + \dfrac{1}{2} \ln(1+x^2) + C$ |
| $\int \operatorname{arcsec} x \, dx$ | $x \operatorname{arcsec} x - \ln \left\vert x + \sqrt{x^2-1} \right\vert + C$ |
| $\int \operatorname{arccsc} x \, dx$ | $x \operatorname{arccsc} x + \ln \left\vert x + \sqrt{x^2-1} \right\vert + C$ |

## 指数与对数函数积分

| 积分 | 结果 |
|------|------|
| $\int \ln x \, dx$ | $x \ln x - x + C$ |
| $\int x e^{ax} \, dx$ | $\dfrac{e^{ax}}{a^2}(ax - 1) + C$ |
| $\int x^n \ln x \, dx$ | $\dfrac{x^{n+1}}{n+1} \left( \ln x - \dfrac{1}{n+1} \right) + C \quad (n \neq -1)$ |
| $\int \dfrac{\ln x}{x} \, dx$ | $\dfrac{1}{2} (\ln x)^2 + C$ |
| $\int e^{ax} \sin bx \, dx$ | $\dfrac{e^{ax}}{a^2+b^2} (a \sin bx - b \cos bx) + C$ |
| $\int e^{ax} \cos bx \, dx$ | $\dfrac{e^{ax}}{a^2+b^2} (a \cos bx + b \sin bx) + C$ |

## 双曲函数积分

| 积分 | 结果 |
|------|------|
| $\int \sinh x \, dx$ | $\cosh x + C$ |
| $\int \cosh x \, dx$ | $\sinh x + C$ |
| $\int \tanh x \, dx$ | $\ln(\cosh x) + C$ |
| $\int \coth x \, dx$ | $\ln \vert \sinh x \vert + C$ |
| $\int \operatorname{sech} x \, dx$ | $\arctan(\sinh x) + C$ |
| $\int \operatorname{csch} x \, dx$ | $\ln \left\vert \tanh \dfrac{x}{2} \right\vert + C$ |
| $\int \operatorname{sech}^2 x \, dx$ | $\tanh x + C$ |
| $\int \operatorname{csch}^2 x \, dx$ | $-\coth x + C$ |
| $\int \operatorname{sech} x \tanh x \, dx$ | $-\operatorname{sech} x + C$ |
| $\int \operatorname{csch} x \coth x \, dx$ | $-\operatorname{csch} x + C$ |
