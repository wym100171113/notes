# 物质的转化

> [!abstract] 概览
> 物质不是孤立的，通过化学反应可以从一种物质"变"出另一种物质。本章学习两个层次：
> 1. **反应类型**——四大基本反应类型（化合、分解、置换、复分解）的分类与判断；
> 2. **转化网络**——单质、氧化物、酸、碱、盐之间的通性转化关系（如 $\ce{Ca -> CaO -> Ca(OH)2 -> CaCO3}$）。
> 掌握"物质转化"是学好元素化学的关键，也是推断题（已知转化关系推物质）的基础。

## 核心概念

### 1. 四大基本反应类型

| 类型 | 定义 | 形式 | 实例 |
| --- | --- | --- | --- |
| 化合反应 | 两种或两种以上物质生成一种物质 | $A+B \rightarrow AB$ | $\ce{CaO + H2O -> Ca(OH)2}$ |
| 分解反应 | 一种物质生成两种或两种以上物质 | $AB \rightarrow A+B$ | $\ce{2H2O2 ->[MnO2] 2H2O + O2 ^}$ |
| 置换反应 | 一种单质与一种化合物生成另一种单质与另一种化合物 | $A+BC \rightarrow AC+B$ | $\ce{Fe + CuSO4 -> FeSO4 + Cu}$ |
| 复分解反应 | 两种化合物互相交换成分生成另两种化合物 | $AB+CD \rightarrow AD+CB$ | $\ce{NaOH + HCl -> NaCl + H2O}$ |

> [!note] 反应类型与化合价变化
> 置换反应**一定**是氧化还原反应；化合、分解反应**不一定**是氧化还原反应（有单质参加或生成时才属于）；复分解反应**一定不是**氧化还原反应（元素化合价均不变）。详见 [[03-氧化还原反应/01-氧化还原基本概念]]。

### 2. 复分解反应发生的条件

复分解反应要能发生，需满足下列**至少一个**条件：

1. **生成沉淀**：如 $\ce{AgNO3 + NaCl -> AgCl v + NaNO3}$；
2. **生成气体**：如 $\ce{CaCO3 + 2HCl -> CaCl2 + H2O + CO2 ^}$；
3. **生成水**（弱电解质）：如 $\ce{NaOH + HCl -> NaCl + H2O}$。

> [!warning] 复分解的前提
> 反应物必须**可溶或虽难溶但能溶于酸**（如 $\ce{CaCO3}$ 与盐酸可反应），两种反应物通常需在溶液中相互接触、离子发生重新组合。酸、碱、盐之间的复分解本质是**离子交换**，见 [[02-离子反应/02-离子反应与离子方程式]]。

### 3. 常见酸、碱、盐、氧化物的溶解性

记忆口诀（谐音）：**钾钠铵硝皆可溶，盐酸盐不溶银，硫酸盐不溶钡，碳酸盐只溶钾钠铵**。

- 可溶性碱：$\ce{KOH}$、$\ce{NaOH}$、$\ce{Ba(OH)2}$、$\ce{Ca(OH)2}$（微溶）；
- 不溶性碱：$\ce{Mg(OH)2}$、$\ce{Fe(OH)3}$、$\ce{Cu(OH)2}$ 等；
- 氯化物：$\ce{AgCl}$ 不溶；硫酸盐：$\ce{BaSO4}$ 不溶，$\ce{Ag2SO4}$、$\ce{CaSO4}$ 微溶；
- 碳酸盐：除钾、钠、铵盐外多数难溶。

## 重点知识

### 1. 各类物质的通性（转化反应一览）

#### （1）金属单质的通性
- 与氧气反应：$\ce{4Na + O2 -> 2Na2O}$、$\ce{2Mg + O2 ->[点燃] 2MgO}$；
- 与酸反应（活泼金属）：$\ce{Fe + 2HCl -> FeCl2 + H2 ^}$；
- 与盐溶液反应（置换）：$\ce{Zn + CuSO4 -> ZnSO4 + Cu}$。

#### （2）非金属单质的通性
- 与金属化合：$\ce{2Na + Cl2 ->[点燃] 2NaCl}$；
- 与氢气化合：$\ce{Cl2 + H2 ->[点燃/光照] 2HCl}$；
- 与氧气化合：$\ce{S + O2 ->[点燃] SO2}$。

#### （3）氧化物的通性
- **酸性氧化物**：与碱反应 $\ce{CO2 + 2NaOH -> Na2CO3 + H2O}$；与水化合（可溶时）$\ce{SO3 + H2O -> H2SO4}$。
- **碱性氧化物**：与酸反应 $\ce{CuO + H2SO4 -> CuSO4 + H2O}$；与水化合（活泼金属）$\ce{Na2O + H2O -> 2NaOH}$。
- **两性氧化物**：$\ce{Al2O3}$ 既溶于酸又溶于强碱。

#### （4）酸的通性
1. 与指示剂作用：使紫色石蕊变红；
2. 与活泼金属反应放出 $\ce{H2}$：$\ce{Zn + H2SO4(稀) -> ZnSO4 + H2 ^}$；
3. 与碱性氧化物反应：$\ce{Fe2O3 + 6HCl -> 2FeCl3 + 3H2O}$；
4. 与碱中和：$\ce{H2SO4 + 2NaOH -> Na2SO4 + 2H2O}$；
5. 与某些盐反应：$\ce{HCl + AgNO3 -> AgCl v + HNO3}$。

#### （5）碱的通性
1. 与指示剂作用：使紫色石蕊变蓝、无色酚酞变红；
2. 与酸性氧化物反应：$\ce{2NaOH + CO2 -> Na2CO3 + H2O}$；
3. 与酸中和：$\ce{Ca(OH)2 + 2HCl -> CaCl2 + 2H2O}$；
4. 与某些盐反应（生成新碱、新盐，需满足复分解条件）：$\ce{2NaOH + CuSO4 -> Cu(OH)2 v + Na2SO4}$。

#### （6）盐的通性
1. 盐 + 金属 → 新盐 + 新金属（金属活动性：前置换后）：$\ce{Fe + CuSO4 -> FeSO4 + Cu}$；
2. 盐 + 酸 → 新盐 + 新酸：$\ce{Na2CO3 + 2HCl -> 2NaCl + H2O + CO2 ^}$；
3. 盐 + 碱 → 新盐 + 新碱：$\ce{Na2CO3 + Ca(OH)2 -> CaCO3 v + 2NaOH}$；
4. 盐 + 盐 → 新盐 + 新盐（均需可溶）：$\ce{NaCl + AgNO3 -> AgCl v + NaNO3}$。

### 2. 典型转化网络（"钙三角"与"碳三角"）

**钙的转化（单质 → 氧化物 → 氢氧化物 → 盐）：**
$$\ce{Ca ->[O2] CaO ->[H2O] Ca(OH)2 ->[CO2] CaCO3}$$

**碳的转化（碳三角）：**
$$\ce{CO2 <->[Ca(OH)2][高温/CaCO3] CaCO3 ->[稀盐酸] CO2 ^}$$

> [!tip] 转化主线
> 典型金属的转化链：**单质 → 碱性氧化物 → 碱 → 盐**（如 $\ce{Na -> Na2O -> NaOH -> NaCl}$）。
> 典型非金属的转化链：**单质 → 酸性氧化物 → 酸 → 盐**（如 $\ce{C -> CO2 -> H2CO3 -> CaCO3}$）。
> 推断题中，看到"化合物 A 既能与酸反应又能与碱反应"，优先想到两性物质 $\ce{Al2O3}$、$\ce{Al(OH)3}$ 或 $\ce{NaHCO3}$ 等。

### 3. 一步转化能否实现？

判断某转化能否"一步实现"，只需检查是否有符合条件的反应：

- $\ce{CaCO3 -> Ca(OH)2}$：**不能一步实现**（$\ce{CaCO3}$ 难溶，需先高温分解成 $\ce{CaO}$，再与水反应）。
- $\ce{Fe -> FeCl3}$：**不能**用盐酸一步实现（盐酸只能把铁氧化到 $\ce{FeCl2}$），需用 $\ce{Cl2}$：$\ce{2Fe + 3Cl2 ->[点燃] 2FeCl3}$。
- $\ce{Cu -> Cu(OH)2}$：**不能**一步实现（$\ce{Cu}$ 不与水反应），需先 $\ce{CuO}$ 或 $\ce{CuSO4}$。

## 典型例题

### 例题 1（反应类型判断）

**题目**：对下列反应分类：① $\ce{2H2O2 ->[MnO2] 2H2O + O2 ^}$；② $\ce{CO2 + C ->[高温] 2CO}$；③ $\ce{NaOH + HCl -> NaCl + H2O}$；④ $\ce{Fe2O3 + 3CO ->[高温] 2Fe + 3CO2}$。其中属于氧化还原反应的是（　）
A. ①②　　B. ①②④　　C. ①③④　　D. 全部

**分析**：看有无元素化合价变化。① 中氧元素由 $\ce{H2O2}$ 中 $-1$ 价变成 $\ce{H2O}$ 中 $-2$ 价和 $\ce{O2}$ 中 $0$ 价，是氧化还原反应；② 中碳元素由 $+4$（$\ce{CO2}$）变为 $+2$（$\ce{CO}$）、由 $0$（$\ce{C}$）变为 $+2$，是氧化还原反应；③ 中所有元素化合价均不变，是复分解反应、非氧化还原；④ 中铁元素由 $+3$ 变为 $0$、碳元素由 $+2$ 变为 $+4$，是氧化还原反应。

**解答**：①②④ 均含化合价升降，选 **B**。

**点评**：判断氧化还原反应的根本依据是**化合价升降**，而不是"有没有氧气参加"。③ 中化合价不变，故非氧化还原反应。

### 例题 2（转化与定量计算）

**题目**：工业上可用 $\ce{CaCO3}$ 为原料制取 $\ce{Ca(OH)2}$。现有 100 g 碳酸钙，高温煅烧完全分解后，将产物溶于适量水生成 $\ce{Ca(OH)2}$。求可制得 $\ce{Ca(OH)2}$ 的质量（相对原子质量：$\ce{Ca}=40$，$\ce{C}=12$，$\ce{O}=16$，$\ce{H}=1$）。

**分析**：反应路线为 $\ce{CaCO3 ->[高温] CaO + CO2 ^}$、$\ce{CaO + H2O -> Ca(OH)2}$。钙元素守恒，$n(\ce{CaCO3})=n(\ce{Ca(OH)2})$。先求 $n(\ce{CaCO3})$，再求 $\ce{Ca(OH)2}$ 的质量。

**解答**：
$$n(\ce{CaCO3})=\frac{100}{100}=1\ \text{mol}$$
由钙元素守恒：$n[\ce{Ca(OH)2}]=1\ \text{mol}$，
$$m[\ce{Ca(OH)2}]=n\cdot M=1\times(40+2\times 16+2\times 1)=74\ \text{g}$$

答：可制得 $\ce{Ca(OH)2}$ **74 g**。

**点评**：转化路线中"元素守恒"是计算的核心——尽管经过两步反应，钙元素的物质的量不变。这类"多步反应 + 元素守恒"是高考计算题的常青题型。

## 易错提醒

> [!warning] 易错提醒
> - **复分解反应不是化合价变化**：复分解反应的实质是离子交换，所有元素化合价均不变，一定不是氧化还原反应。
> - **置换反应的"活泼性"前提**：$\ce{Fe + CuSO4}$ 能发生是因为铁比铜活泼；若把铜放入 $\ce{FeSO4}$ 溶液则不反应。金属活动性顺序：$\ce{K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Hg > Ag > Pt > Au}$。
> - **酸的"放氢"只限活泼金属**：$\ce{Cu}$、$\ce{Ag}$ 等不与稀盐酸、稀硫酸反应（$\ce{Cu}$ 只能与浓硫酸、硝酸反应）。
> - **一步转化陷阱**：$\ce{CaCO3 -> Ca(OH)2}$、$\ce{Fe -> FeCl3}$、$\ce{Cu -> Cu(OH)2}$ 都不能一步实现。
> - **生成气体要写箭头**：反应方程式书写时，有气体逸出标"$\uparrow$"，有沉淀生成标"$\downarrow$"，条件如"点燃""高温""催化剂"不可遗漏。
