# 铝单质与铝热反应

> [!abstract] 概览
> 铝（$\ce{Al}$）是地壳中含量最多的金属元素，也是典型的**两性金属**——既能与酸反应，又能与强碱反应。本笔记重点：铝的物理性质、与氧气/酸/强碱的反应、常温钝化，以及**铝热反应**的原理与应用。铝热反应是高考必考点，考查方程式书写与用途。

## 核心概念

### 铝的原子结构与位置

- 原子序数 13，位于**第三周期第ⅢA族**。
- 原子结构示意图：$1s^2 2s^2 2p^6 3s^2 3p^1$，最外层 3 个电子，反应中易失去形成 $\ce{Al^{3+}}$。
- 地壳中**含量最多的金属元素**（含量最多的元素是氧）。

### 物理性质

- 银白色金属，密度小（$2.7\ \ce{g/cm^3}$），熔点较低（约 $660\ \degree\ce{C}$）。
- **导电性、导热性强**，仅次于银、铜，可用于电线电缆。
- 延展性好，可制成铝箔；纯铝较软，实际多用铝合金。

## 重点知识：化学性质

铝是较活泼的金属（金属活动性顺序在 $\ce{Mg}$ 与 $\ce{Zn}$ 之间），还原性强，但因其**两性**而特殊。

### 1. 与非金属反应

- 与氧气：$4\ce{Al} + 3\ce{O2} -> 2\ce{Al2O3}$。常温下表面迅速生成**致密氧化膜**，阻止内部铝继续被氧化，故铝有良好的抗腐蚀性能。
- 铝箔在氧气中点燃：剧烈燃烧，发出耀眼白光，生成 $\ce{Al2O3}$。
- 与氯气：$2\ce{Al} + 3\ce{Cl2} \xrightarrow{\Delta} 2\ce{AlCl3}$（固体氯化铝）。
- 与硫：$2\ce{Al} + 3\ce{S} \xrightarrow{\Delta} \ce{Al2S3}$。

> [!note] 致密氧化膜的意义
> 铝表面致密的 $\ce{Al2O3}$ 薄膜使铝在空气中稳定，这是铝比铁"耐腐蚀"的根本原因（$\ce{Fe2O3}$ 膜疏松多孔，不能保护内部）。

### 2. 与酸反应

- 与盐酸：$2\ce{Al} + 6\ce{HCl} -> 2\ce{AlCl3} + 3\ce{H2 ^}$
- 离子方程式：$2\ce{Al} + 6\ce{H+} -> 2\ce{Al^{3+}} + 3\ce{H2 ^}$
- 与稀硫酸类似：$2\ce{Al} + 3\ce{H2SO4} -> \ce{Al2(SO4)3} + 3\ce{H2 ^}$
- 与稀硝酸：$\ce{Al + 4HNO3(稀) -> Al(NO3)3 + NO ^ + 2H2O}$
- **常温钝化**：与浓硫酸、浓硝酸常温下不反应（表面生成致密氧化膜）。

> [!warning] 钝化也是化学变化
> 常温下铝遇浓硫酸、浓硝酸发生"钝化"，是化学变化（生成致密 $\ce{Al2O3}$ 膜），不是不反应。因此可用**铝制容器**储运浓硝酸、浓硫酸。但加热时反应剧烈。

### 3. 与强碱反应（两性的体现）

- 与氢氧化钠溶液：$2\ce{Al} + 2\ce{NaOH} + 2\ce{H2O} -> 2\ce{NaAlO2} + 3\ce{H2 ^}$
- 离子方程式：$2\ce{Al} + 2\ce{OH^-} + 2\ce{H2O} -> 2\ce{AlO2^-} + 3\ce{H2 ^}$

> [!warning] 铝与碱反应"水"参与
> 铝与强碱溶液反应，**水是反应物**，产物是偏铝酸盐和氢气，不是"氢氧化铝"。氧化剂是水（$\ce{H+}$ 来自水），$\ce{Al}$ 把水中 $\ce{H+}$ 还原为 $\ce{H2}$，$\ce{Al}$ 变为 $\ce{AlO2^-}$。书写时不要漏掉 $\ce{H2O}$。

### 4. 与盐溶液反应

- 与硫酸铜溶液：$2\ce{Al} + 3\ce{CuSO4} -> \ce{Al2(SO4)3} + 3\ce{Cu}$（铝置换铜）
- 与氯化汞溶液（铝汞齐实验，选做）。

### 5. 铝的冶炼

铝在自然界以 $\ce{Al2O3}$（铝土矿）等形式存在，工业上采用**电解熔融 $\ce{Al2O3}$** 冶炼：

$$
2\ce{Al2O3} \xrightarrow[冰晶石]{电解} 4\ce{Al} + 3\ce{O2 ^}
$$

- 冰晶石（$\ce{Na3AlF6}$）作**助熔剂**，降低 $\ce{Al2O3}$ 的熔点（其熔点高达 $2054\ \degree\ce{C}$）。
- 不电解 $\ce{AlCl3}$：$\ce{AlCl3}$ 是共价化合物，熔融态不导电。
- 铝是活泼金属（金属活动性顺序在 $\ce{Mg}$ 与 $\ce{Zn}$ 之间），只能用**电解法**冶炼，不能热还原。

### 6. 铝热反应

**原理**：铝是强还原剂，在高温下能把金属活动性比铝弱的金属从其氧化物中置换出来：

$$
\ce{2Al + Fe2O3 \xrightarrow{高温} Al2O3 + 2Fe}
$$

该反应放出大量热，温度可达 $2000\ \degree\ce{C}$ 以上。

**其他铝热反应**：

| 反应 | 冶炼的金属 |
| --- | --- |
| $\ce{4Al + 3MnO2 \xrightarrow{高温} 2Al2O3 + 3Mn}$ | 锰 |
| $\ce{2Al + Cr2O3 \xrightarrow{高温} Al2O3 + 2Cr}$ | 铬 |
| $\ce{10Al + 3V2O5 \xrightarrow{高温} 5Al2O3 + 6V}$ | 钒 |

**实验操作**：镁条引燃 → 氯酸钾（受热分解放氧助燃）引发 → 铝粉与 $\ce{Fe2O3}$ 剧烈反应。

**现象**：火星四射、放出大量热、有熔融物（铁）落入沙中、生成白色固体（$\ce{Al2O3}$）。

**应用**：
1. 野外焊接钢轨（利用高温熔融的铁）。
2. 冶炼高熔点金属（$\ce{V}$、$\ce{Cr}$、$\ce{Mn}$、$\ce{W}$ 等）。

> [!tip] 铝热反应的本质
> 铝热反应本质是**置换反应**、**氧化还原反应**、**放热反应**。$\ce{Al}$ 作还原剂被氧化为 $\ce{Al2O3}$，金属氧化物作氧化剂被还原为金属单质。判断标准：金属活动性顺序中铝后面的金属氧化物都可用铝还原。

## 典型例题

### 例题 1：铝与酸、碱反应的气体量比较

**题目**：相同物质的量的铝分别与足量盐酸、足量 $\ce{NaOH}$ 溶液反应，产生氢气的物质的量之比为（ ）
A. $1 : 1$　　B. $1 : 2$　　C. $2 : 1$　　D. $3 : 1$

**分析**：铝与盐酸：$2\ce{Al} + 6\ce{H+} -> 2\ce{Al^{3+}} + 3\ce{H2 ^}$，$\ce{Al}$ 从 $0$ 价升到 $+3$ 价，1 mol $\ce{Al}$ 转移 3 mol 电子，生成 1.5 mol $\ce{H2}$。铝与 $\ce{NaOH}$：$2\ce{Al} + 2\ce{OH^-} + 2\ce{H2O} -> 2\ce{AlO2^-} + 3\ce{H2 ^}$，同样 1 mol $\ce{Al}$ 生成 1.5 mol $\ce{H2}$。两者转移电子数相同。

**解答**：等物质的量铝与足量酸、足量碱反应，生成氢气物质的量之比为 $1 : 1$。答案：**A**。

**点评**：铝与酸、碱反应生成氢气量相等，因为铝在两个反应中都由 $0$ 价升到 $+3$ 价，转移电子数相同。这是高考常考的结论："**等量的铝与足量酸、碱反应放氢量相等**"。

### 例题 2：铝热反应的应用

**题目**：下列金属不能用铝热反应冶炼的是（ ）
A. 锰　　B. 铬　　C. 铁　　D. 镁

**分析**：铝热反应只能冶炼金属活动性比铝**弱**的金属。$\ce{Mn}$、$\ce{Cr}$、$\ce{Fe}$ 的活动性都比铝弱，可用铝热反应冶炼；$\ce{Mg}$ 的活动性比铝强，不能用铝还原 $\ce{MgO}$ 制镁。

**解答**：答案：**D**。

**点评**：判断铝热反应能否发生，看金属活动性顺序：铝只能置换铝**后面**的金属。钠、钙、镁、铝等活泼金属用**电解熔融**法冶炼。

## 易错提醒

> [!warning] 易错点清单
> 1. 铝与强碱反应要写 $\ce{H2O}$ 参与，产物是 $\ce{AlO2^-}$ 而非 $\ce{Al(OH)3}$。
> 2. 铝热反应的条件是"高温"，不是"点燃"；需要镁条和氯酸钾引发。
> 3. 铝在常温下与浓硫酸、浓硝酸钝化，但加热条件下剧烈反应。
> 4. 铝与稀硝酸反应不产生氢气（硝酸是氧化性酸，生成 $\ce{NO}$）。
> 5. 等量铝与足量酸、足量碱反应放氢量相等（转移电子数相同）。
> 6. 铝热反应是置换反应、放热反应、氧化还原反应，但**不属于**离子反应（无离子参与）。
