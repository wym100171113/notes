# 原电池与化学电池

> [!abstract] 概览
> 原电池是把**化学能转化为电能**的装置，其本质是**自发的氧化还原反应**被拆分为两个"半反应"，分别在两个电极上进行：负极失电子发生氧化反应，正极得电子发生还原反应。电子从负极经外电路流向正极，形成电流；电解质溶液中阳离子向正极迁移、阴离子向负极迁移，构成闭合回路。本笔记讲解原电池的构成条件、电极判断、电子与离子流向，以及常见电池（锌锰干电池、铅蓄电池、锂离子电池、燃料电池）。

## 核心概念

### 1. 原电池的构成条件

1. **两种活动性不同的电极材料**（或金属与能导电的非金属，如石墨）。
2. **电解质溶液**（能导电，参与离子迁移）。
3. **闭合回路**（导线连接 + 电极插入电解质溶液）。
4. **能自发进行的氧化还原反应**（这是原电池能工作的前提）。

### 2. 电极与反应类型

- **负极**：较活泼金属，发生**氧化反应**，**失电子**（"负氧"）。电极反应：$\ce{M - ne- -> M^{n+}}$。
- **正极**：较不活泼金属或非金属导体（如石墨），发生**还原反应**，**得电子**（"正还"）。

> [!tip] 记忆口诀
> "**负氧正还**"：负极氧化失电子，正极还原得电子；"电子负极出，走外电路，进正极"。

### 3. 电子流向与离子迁移

- **电子流向**：负极 →（经外电路导线）→ 正极。
- **电流方向**：正极 →（经外电路）→ 负极（与电子方向相反）。
- **离子迁移**（在电解质溶液中）：
  - **阳离子**（如 $\ce{Cu^{2+}}$、$\ce{H+}$）移向**正极**（在正极得电子）；
  - **阴离子**（如 $\ce{Cl-}$、$\ce{SO4^{2-}}$）移向**负极**。

## 重点知识

### 1. 铜锌原电池（经典模型）

以 $\ce{Zn | H2SO4 | Cu}$ 原电池为例：

| 电极 | 材料 | 电极反应 | 反应类型 |
| --- | --- | --- | --- |
| 负极 | 锌片 | $\ce{Zn - 2e- -> Zn^{2+}}$ | 氧化反应 |
| 正极 | 铜片 | $\ce{2H+ + 2e- -> H2 ^}$ | 还原反应 |

- 总反应：$\ce{Zn + 2H+ -> Zn^{2+} + H2 ^}$（即 $\ce{Zn + H2SO4 -> ZnSO4 + H2 ^}$）。
- 现象：锌片溶解变薄，铜片上有气泡产生，电流计指针偏转。
- 若电解质换为 $\ce{CuSO4}$ 溶液，则正极反应为 $\ce{Cu^{2+} + 2e- -> Cu}$（铜离子在铜片上析出）。

> [!warning] 一个重要区分
> 电子只能在**外电路**中流动，**不能**进入电解质溶液；电解质溶液中靠**离子迁移**导电。所以"电子从负极经过溶液流到正极"的说法是**错误的**。

### 2. 电极反应式的书写

书写步骤：
1. 确定负极、正极材料及对应反应（先写总反应拆成氧化/还原两半）。
2. 负极：金属失电子 → 金属阳离子；注意守恒配平（电荷守恒用 $\ce{e-}$ 补，质量守恒用水、$\ce{H+}$/$\ce{OH-}$ 补）。
3. 正极：得电子的粒子（$\ce{H+}$、$\ce{Cu^{2+}}$、$\ce{O2}$ 等）得电子 → 产物。
4. 两式相加等于总反应。

**碱性燃料电池示例**（以 $\ce{KOH}$ 为电解质）：
- 负极：$\ce{H2 - 2e- + 2OH- -> 2H2O}$；
- 正极：$\ce{O2 + 4e- + 2H2O -> 4OH-}$；
- 总反应：$\ce{2H2 + O2 -> 2H2O}$。

> [!note] 燃料电池的"总反应"就是燃料的燃烧反应
> 只要在碱性或酸性电解质中书写电极反应式，环境不同，电极反应式中出现的粒子不同（酸性环境用 $\ce{H+}$，碱性环境用 $\ce{OH-}$），但总反应不变。

### 3. 常见化学电池

| 电池 | 特点 | 正/负极材料 | 主要应用 |
| --- | --- | --- | --- |
| 锌锰干电池 | 一次电池，不能充电 | 负极为锌筒，正极为石墨棒 | 手电筒、遥控器 |
| 铅蓄电池 | 二次电池，可充电 | 负极铅，正极 $\ce{PbO2}$，电解液 $\ce{H2SO4}$ | 汽车启动电源 |
| 锂离子电池 | 质量轻、比能量高、可充电 | 负极石墨，正极含锂化合物 | 手机、笔记本电脑 |
| 氢氧燃料电池 | 能量利用率高、清洁无污染 | 负极通 $\ce{H2}$，正极通 $\ce{O2}$ | 航天器、新能源汽车 |

### 4. 原电池的应用

- 判断金属活动性：活泼性强的金属作负极。
- 加快反应速率：将金属浸入电解质并连成原电池，反应速率加快（如制氢气时加铜片形成原电池）。
- 防护金属腐蚀：被保护金属作正极（牺牲阳极的阴极保护法）。

## 典型例题

### 例题 1：铜锌原电池的判断

**题目**：将锌片和铜片用导线相连插入稀硫酸中构成原电池。下列说法正确的是（　）
A. 锌片是正极，发生还原反应
B. 铜片上有气泡产生，发生氧化反应
C. 电子从锌片经导线流向铜片
D. 溶液中的 $\ce{SO4^{2-}}$ 移向正极

**分析**：锌比铜活泼，锌作负极失电子，发生氧化反应（A 错）；铜作正极，$\ce{H+}$ 在铜片上得电子生成 $\ce{H2}$，发生还原反应（B 错）；电子由负极（锌）经导线流向正极（铜）（C 对）；阴离子 $\ce{SO4^{2-}}$ 应移向负极（D 错）。

**解答**：选 **C**。

**点评**：本题综合考查电极判断、电子流向与离子迁移。牢牢抓住"负极氧化失电子、电子沿外电路到正极、阳离子向正极迁移、阴离子向负极迁移"即可全部判断。

### 例题 2：燃料电池电极反应式

**题目**：某氢氧燃料电池以稀 $\ce{H2SO4}$ 为电解质溶液。写出其正、负极电极反应式和总反应式。

**分析**：酸性条件下，负极 $\ce{H2}$ 失电子生成 $\ce{H+}$；正极 $\ce{O2}$ 得电子结合 $\ce{H+}$ 生成水。用电荷守恒配平。

**解答**：
- 负极：$\ce{H2 - 2e- -> 2H+}$；
- 正极：$\ce{O2 + 4e- + 4H+ -> 2H2O}$；
- 总反应：$\ce{2H2 + O2 -> 2H2O}$。

**点评**：燃料电池总反应即燃料燃烧反应；书写电极反应式时要注意电解质环境。酸性环境用 $\ce{H+}$ 参与配平，正极反应中 4 个 $\ce{H+}$ 与 4 个电子结合 1 个 $\ce{O2}$，是高频考点。

## 电极反应书写技巧与拓展

### 电极反应式书写"三步法"

1. 判断正负极：较活泼金属为负极（失电子），正极是得电子的一极。
2. 写负极反应：金属 $\ce{M - ne- -> M^{n+}}$；若溶液中有离子参与配平，用 $\ce{H+}$/$\ce{OH-}$/$\ce{H2O}$ 补。
3. 写正极反应：得电子的粒子 + 电子 → 产物；正极反应 = 总反应 − 负极反应（此法最快捷）。

### 电解质环境的影响

| 环境 | 示例 | 电极反应中的配平粒子 |
| --- | --- | --- |
| 酸性 | 氢氧燃料电池（稀 $\ce{H2SO4}$） | $\ce{H+}$ 参与配平 |
| 碱性 | 氢氧燃料电池（$\ce{KOH}$） | $\ce{OH-}$ 参与配平 |
| 中性 | 铅蓄电池（$\ce{H2SO4}$ 溶液） | 需关注 $\ce{H2SO4}$ 浓度变化 |

### 常见原电池拓展

- **镁铝原电池（$\ce{NaOH}$ 溶液）**：铝与碱反应失电子，铝作负极。
- **铝铜原电池（浓硝酸）**：常温下铝钝化，铜失电子作负极。
- 判断电极不能只看金属活动性，还要看**实际能否发生自发的氧化还原反应**。

### 原电池与反应速率

- 把金属与其盐溶液组成原电池，能**加快**金属的反应速率（如锌与稀硫酸中加入铜片，氢气产生明显加快）。

## 易错提醒

> [!warning] 常见错误
> - "电子通过电解质溶液从负极流向正极"❌ —— 电子只在外电路流动，溶液中靠离子导电。
> - "阳离子移向负极"❌ —— 阳离子移向**正极**（在正极得电子），阴离子移向负极。
> - "负极得电子、正极失电子"❌ —— 负极**失**电子（氧化），正极**得**电子（还原）。
> - "电流方向与电子方向相同"❌ —— 电流方向与电子方向相反。
> - "只要有两种金属和电解质就能构成原电池"❌ —— 还必须有**自发氧化还原反应**和**闭合回路**。
> - 写电极反应式时忽略电解质环境（酸性用 $\ce{H+}$、碱性用 $\ce{OH-}$）❌。
