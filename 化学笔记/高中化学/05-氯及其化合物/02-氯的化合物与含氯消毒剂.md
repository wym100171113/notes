# 氯的化合物与含氯消毒剂

> [!abstract] 概览
> 氯的含氧酸盐与次氯酸是氯化学的核心应用，也是"氯—生活—消毒"的结合点。本笔记整理**次氯酸 $\ce{HClO}$**（弱酸性、强氧化性、不稳定）、**次氯酸盐**（$\ce{NaClO}$ 漂白液/84 消毒液、$\ce{Ca(ClO)2}$ 漂白粉有效成分）以及**含氯消毒剂**的制备、漂白原理与失效原因，并对比常见消毒剂。重点是理解"漂白/消毒归根到底是 $\ce{HClO}$ 的强氧化性"这一主线。

## 核心概念

- **次氯酸 $\ce{HClO}$**：弱酸（酸性弱于碳酸），有强氧化性、漂白性、杀菌消毒作用；不稳定，见光分解：$\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$。
- **次氯酸盐**：$\ce{NaClO}$（漂白液/84 消毒液主要成分）、$\ce{Ca(ClO)2}$（漂白粉有效成分），都是强氧化性的盐，漂白时靠生成 $\ce{HClO}$。
- **漂白粉**：$\ce{Ca(ClO)2}$ 与 $\ce{CaCl2}$ 的混合物，有效成分是 $\ce{Ca(ClO)2}$。
- **失效原理**：漂白粉/漂白液在空气中与 $\ce{CO2}$、$\ce{H2O}$ 反应生成 $\ce{HClO}$，$\ce{HClO}$ 见光分解后漂白性丧失。

## 重点知识

### 1. 次氯酸 $\ce{HClO}$

- **弱酸性**：酸性比 $\ce{H2CO3}$ 弱，电离：$\ce{HClO <=> H+ + ClO^-}$。
- **强氧化性**：能使品红、有色布条褪色，能杀菌消毒，是氯水漂白性的来源。
- **不稳定性**：见光分解
  $$\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$$
  （所以氯水要**现配现用**、保存在棕色瓶中。）

> [!note] 氧化性漂白
> $\ce{HClO}$ 的漂白属于**氧化性漂白**，把有色物质氧化成无色物质，**不可逆**（加热不能复原）。这不同于 $\ce{SO2}$ 的化合性漂白（可逆）。

### 2. 次氯酸盐与漂白液（84 消毒液）

- **制备**：氯气与 $\ce{NaOH}$ 溶液反应
  $$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$$
  （$\ce{NaClO}$ 是漂白液的主要成分，市售"84 消毒液"主要成分即 $\ce{NaClO}$。）
- **漂白原理**：$\ce{NaClO}$ 与空气中的 $\ce{CO2}$、水反应生成 $\ce{HClO}$：
  $$\ce{2NaClO + CO2 + H2O -> Na2CO3 + 2HClO}$$
  由于碳酸酸性强于次氯酸，此反应能够发生（"强酸制弱酸"）。

> [!warning] 84 消毒液不能与洁厕灵（含盐酸）混用
> $\ce{NaClO}$ 与盐酸反应：$\ce{ClO^- + Cl^- + 2H+ -> Cl2 ^ + H2O}$，会产生有毒的氯气，造成中毒事故。

### 3. 漂白粉

- **制备**：氯气与**石灰乳**反应
  $$\ce{2Cl2 + 2Ca(OH)2 -> Ca(ClO)2 + CaCl2 + 2H2O}$$
  （注意：工业上用石灰乳而非澄清石灰水，因石灰乳浓度大、成本低。）
- **成分**：$\ce{Ca(ClO)2}$ 与 $\ce{CaCl2}$ 的**混合物**；有效成分是 $\ce{Ca(ClO)2}$。
- **漂白原理（起效）**：在空气中与 $\ce{CO2}$、水作用生成 $\ce{HClO}$：
  $$\ce{Ca(ClO)2 + CO2 + H2O -> CaCO3 v + 2HClO}$$
  （书写此反应时常强调"由于次氯酸的酸性弱于碳酸，反应向右进行"。）

> [!warning] 漂白粉的失效
> 漂白粉长期露置在空气中，$\ce{Ca(ClO)2}$ 与 $\ce{CO2}$、水反应生成 $\ce{HClO}$，$\ce{HClO}$ 见光分解为 $\ce{HCl}$ 与 $\ce{O2}$，最终漂白性完全丧失：
> $$\ce{Ca(ClO)2 + CO2 + H2O -> CaCO3 + 2HClO}$$
> $$\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$$
> 所以漂白粉要**密封保存**。

### 4. 常见含氯消毒剂对比

| 消毒剂 | 主要成分/有效成分 | 原理 | 备注 |
| --- | --- | --- | --- |
| 氯水 | $\ce{Cl2}$、$\ce{HClO}$ | $\ce{HClO}$ 氧化杀菌 | 现配现用 |
| 漂白液 / 84 消毒液 | $\ce{NaClO}$ | 生成 $\ce{HClO}$ 氧化杀菌 | 不能与酸（洁厕灵）混用 |
| 漂白粉 | $\ce{Ca(ClO)2}$（有效成分） | 生成 $\ce{HClO}$ 氧化杀菌 | 密封保存，防失效 |
| $\ce{ClO2}$ | $\ce{ClO2}$ | 强氧化性 | 高效安全，用于饮用水消毒 |
| $\ce{O3}$ | 臭氧 | 强氧化性 | 非含氯，可对比 |

> [!tip] 消毒的本质
> 含氯消毒剂的消毒/漂白，归根到底是**生成 $\ce{HClO}$ 或 $\ce{ClO2}$ 等强氧化性物质**，通过氧化破坏细菌、病毒的蛋白质结构或使有色物质褪色。

### 5. 氯元素的重要化合物价态

| 价态 | 代表物 |
| --- | --- |
| $-1$ | $\ce{HCl}$、$\ce{NaCl}$ |
| $0$ | $\ce{Cl2}$ |
| $+1$ | $\ce{HClO}$、$\ce{NaClO}$、$\ce{Ca(ClO)2}$ |
| $+3$ | $\ce{HClO2}$（亚氯酸） |
| $+5$ | $\ce{HClO3}$（氯酸）、$\ce{KClO3}$ |
| $+7$ | $\ce{HClO4}$（高氯酸）、$\ce{KClO4}$ |

## 典型例题

### 例题 1（漂白粉起效反应与失效）

**题目**：漂白粉在空气中放置会逐渐失效。写出漂白粉起漂白作用的总反应，并说明其失效的化学原理。

**分析**：漂白粉有效成分 $\ce{Ca(ClO)2}$，与空气中的 $\ce{CO2}$、$\ce{H2O}$ 反应生成 $\ce{HClO}$ 起漂白作用；$\ce{HClO}$ 不稳定，见光分解即失效。

**解答**：
起漂白作用：
$$\ce{Ca(ClO)2 + CO2 + H2O -> CaCO3 v + 2HClO}$$

失效原理：
$$\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$$

即漂白粉露置于空气中，先与 $\ce{CO2}$、水反应生成 $\ce{HClO}$，$\ce{HClO}$ 见光分解为 $\ce{HCl}$ 与 $\ce{O2}$，使漂白性丧失。

**点评**："起效"与"失效"都写 $\ce{Ca(ClO)2}$ 的反应：起效是生成 $\ce{HClO}$，失效是 $\ce{HClO}$ 分解。注意 $\ce{HClO}$ 酸性弱于碳酸，所以 $\ce{CO2}$ 能把 $\ce{HClO}$ 从次氯酸盐中"顶出"。

### 例题 2（漂白粉与盐酸反应产生氯气的计算）

**题目**：取 $14.3\ \mathrm{g}$ 漂白粉（按有效成分 $\ce{Ca(ClO)2}$ 计算），与足量浓盐酸反应生成氯气，求在标准状况下生成 $\ce{Cl2}$ 的体积。已知 $\ce{Ca(ClO)2 + 4HCl(浓) -> CaCl2 + 2Cl2 ^ + 2H2O}$。

**分析**：$\ce{Ca(ClO)2}$ 摩尔质量为 $143\ \mathrm{g/mol}$。由方程式，$n(\ce{Cl2}) : n(\ce{Ca(ClO)2}) = 2 : 1$。

**解答**：
$$n(\ce{Ca(ClO)2}) = \dfrac{14.3\ \mathrm{g}}{143\ \mathrm{g/mol}} = 0.1\ \mathrm{mol}$$
$$n(\ce{Cl2}) = 2 \times 0.1 = 0.2\ \mathrm{mol}$$
$$V(\ce{Cl2}) = 0.2\ \mathrm{mol} \times 22.4\ \mathrm{L/mol} = 4.48\ \mathrm{L}$$

**点评**：次氯酸盐与浓盐酸反应会"归中"生成氯气（$\ce{ClO^-}$ 中 $+1$ 价氯与 $\ce{Cl^-}$ 中 $-1$ 价氯归中到 0 价），是氯气实验室制法的延伸。计算时注意系数比。

## 易错提醒

> [!warning] 易错点
> 1. **漂白粉是混合物**，有效成分是 $\ce{Ca(ClO)2}$，不要答成"有效成分是 $\ce{CaCl2}$"或"是纯净物"。
> 2. **$\ce{HClO}$ 酸性弱于 $\ce{H2CO3}$**：所以 $\ce{CO2}$ 能把 $\ce{HClO}$ 从 $\ce{NaClO}$、$\ce{Ca(ClO)2}$ 中制出来（"强酸制弱酸"）。
> 3. **漂白粉失效**要写两步：先生成 $\ce{HClO}$，再 $\ce{HClO}$ 见光分解。
> 4. **84 消毒液与盐酸（洁厕灵）混用生成氯气**：$\ce{ClO^- + Cl^- + 2H+ -> Cl2 ^ + H2O}$，有中毒风险。
> 5. **氧化性漂白不可逆**：$\ce{HClO}$、$\ce{NaClO}$、$\ce{Na2O2}$、$\ce{H2O2}$ 的漂白加热不恢复；$\ce{SO2}$ 漂白加热可恢复。
> 6. **次氯酸不稳定**：氯水、漂白液都要避光保存；氯水现配现用。
