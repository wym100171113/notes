# 硅酸盐与无机非金属材料

> [!abstract] 概览
> 硅酸盐是硅元素最重要的化合物形式，广泛存在于自然界（岩石、黏土）。本章重点：**硅酸钠**（$\ce{Na2SiO3}$，水玻璃）、**硅酸**（$\ce{H2SiO3}$）的制备与性质、**硅酸盐组成的氧化物表示法**，以及**传统无机非金属材料**（水泥、玻璃、陶瓷）和**新型无机非金属材料**（光导纤维、半导体、新型陶瓷）。

## 核心概念

### 1. 硅酸钠（$\ce{Na2SiO3}$）

- **物理性质**：可溶于水的白色晶体；其**水溶液俗称"水玻璃"**，是无色黏稠液体，呈**碱性**。
- **用途**：
  - 木材等的**防火剂**（涂在木材表面，受热生成硅酸薄膜隔绝空气）；
  - 建筑工业的**黏合剂**（矿物胶）；
  - 肥皂等的填充剂。
- **保存**：水玻璃呈碱性，**不能盛放在磨口玻璃塞试剂瓶**（$\ce{Na2SiO3}$ 与玻璃中的 $\ce{SiO2}$、酸性氧化物反应会黏住瓶塞），应用橡胶塞。

> [!note] 与 $\ce{CO2}$ 反应
> $\ce{Na2SiO3 + CO2 + H2O -> Na2CO3 + H2SiO3 v}$（碳酸的酸性强于硅酸，故 $\ce{CO2}$ 能把 $\ce{SiO3^{2-}}$ 从水玻璃中"顶"出来生成硅酸沉淀）。

### 2. 硅酸（$\ce{H2SiO3}$）

- **物理性质**：白色胶状沉淀，**难溶于水**。
- **化学性质**：
  - **弱酸性**（比碳酸还弱）：$\ce{H2SiO3 <=> H+ + HSiO3-}$。
  - **不稳定，受热失水**：$\ce{H2SiO3 ->[Δ] SiO2 + H2O}$。
- **制备**（用可溶性硅酸盐与较强酸反应）：
$$\ce{Na2SiO3 + 2HCl -> H2SiO3 v + 2NaCl}$$
或 $\ce{Na2SiO3 + CO2 + H2O -> Na2CO3 + H2SiO3 v}$。
- 硅酸逐渐失水形成**硅酸凝胶**，经干燥可得到**硅胶**（吸附能力强，用作干燥剂、催化剂载体）。

### 3. 硅酸盐的氧化物表示法

- 将硅酸盐改写成**金属氧化物、$\ce{SiO2}$、$\ce{H2O}$** 的形式（活泼金属氧化物在前，$\ce{SiO2}$ 次之，水最后）。
- 示例：
  - $\ce{Na2SiO3}$ → $\ce{Na2O·SiO2}$
  - $\ce{CaSiO3}$ → $\ce{CaO·SiO2}$
  - $\ce{KAlSi3O8}$（钾长石）→ $\ce{K2O·Al2O3·6SiO2}$
  - 普通玻璃 → $\ce{Na2O·CaO·6SiO2}$

> 规则：各元素的原子数目在改写前后**守恒**，系数化为最简整数比。

## 常见的硅酸盐矿物

| 矿物 | 化学组成（氧化物表示法） | 说明 |
| --- | --- | --- |
| 石英/水晶 | $\ce{SiO2}$ | 非硅酸盐，但常与之并列讨论 |
| 长石 | $\ce{K2O·Al2O3·6SiO2}$（钾长石） | 地壳中常见造岩矿物 |
| 云母 | 铝硅酸盐 | 层状结构 |
| 高岭石（黏土） | $\ce{Al2O3·2SiO2·2H2O}$ | 制陶瓷的原料 |
| 石棉 | $\ce{CaO·3MgO·4SiO2}$ | 纤维状硅酸盐 |

> [!note] 硅酸盐结构特点
> 硅酸盐结构的基本单元是 $\ce{SiO4}$ 四面体（硅连 4 个氧）。天然硅酸盐多以复杂形式存在，书写化学式时习惯用氧化物表示法，以方便比较元素组成。

## 传统无机非金属材料

| 材料 | 主要原料 | 主要生产反应 / 说明 |
| --- | --- | --- |
| **水泥** | 石灰石（$\ce{CaCO3}$）+ 黏土 | 高温煅烧，加适量石膏调节硬化速度；水硬性 |
| **玻璃** | 纯碱（$\ce{Na2CO3}$）+ 石灰石（$\ce{CaCO3}$）+ 石英（$\ce{SiO2}$） | $\ce{SiO2 + Na2CO3 ->[高温] Na2SiO3 + CO2 ^}$；$\ce{SiO2 + CaCO3 ->[高温] CaSiO3 + CO2 ^}$；普通玻璃组成为 $\ce{Na2O·CaO·6SiO2}$ |
| **陶瓷** | 黏土（含水铝硅酸盐） | 高温烧结；主要成分是硅酸盐 |

> [!important] 玻璃工业的两个反应
> 玻璃是混合物（不是单一物质）。生产时把纯碱、石灰石、石英砂混合，在玻璃窑中高温熔融：
> - $\ce{SiO2 + Na2CO3 ->[高温] Na2SiO3 + CO2 ^}$
> - $\ce{SiO2 + CaCO3 ->[高温] CaSiO3 + CO2 ^}$
> 产物 $\ce{Na2SiO3}$、$\ce{CaSiO3}$ 与过量 $\ce{SiO2}$ 熔合即得玻璃。

## 新型无机非金属材料

| 材料 | 代表 | 特性/用途 |
| --- | --- | --- |
| 半导体材料 | 高纯硅（$\ce{Si}$） | 芯片、太阳能电池、集成电路 |
| 光导纤维 | $\ce{SiO2}$ | 传递光信号，光通信 |
| 高温结构陶瓷 | 氮化硅（$\ce{Si3N4}$）、碳化硅（$\ce{SiC}$） | 耐高温、硬度大，用于发动机部件 |
| 生物陶瓷 | 羟基磷灰石等 | 人体骨修复 |
| 超硬材料 | 金刚石、$\ce{SiC}$ | 硬度大，用作刀具 |

> [!note] 光导纤维的成分
> 光导纤维的主要成分是 **$\ce{SiO2}$**（不是硅单质），利用全反射传导光信号；而半导体、芯片用的是**晶体硅**。两者不要混淆。

## 典型例题

### 例题 1

**题目**：下列有关硅酸盐及材料的说法正确的是（　）
A. 硅酸可由 $\ce{SiO2}$ 与水直接反应制得
B. 水玻璃是纯净物，可用作防火剂
C. 普通玻璃是混合物，主要成分可表示为 $\ce{Na2O·CaO·6SiO2}$
D. 光导纤维的主要成分是晶体硅

**分析**：A 错误：$\ce{SiO2}$ 不与水反应，硅酸不能由 $\ce{SiO2}$ 直接水化制得。B 错误：水玻璃是 $\ce{Na2SiO3}$ 的**水溶液**，属于混合物。C 正确：玻璃是混合物，其组成常用 $\ce{Na2O·CaO·6SiO2}$ 表示。D 错误：光导纤维的主要成分是 $\ce{SiO2}$，不是晶体硅。

**解答**：选 **C**。

**点评**：本题集中考查"玻璃是混合物"、"水玻璃是溶液（混合物）"、"$\ce{SiO2}$ 不与水反应"、"光纤成分是 $\ce{SiO2}$"四个易错点。

### 例题 2

**题目**：写出用硅酸钠溶液与盐酸反应制备硅酸的化学方程式，并判断硅酸与碳酸的酸性强弱。

**分析**：强酸制弱酸，盐酸（强酸）与 $\ce{Na2SiO3}$ 反应生成 $\ce{H2SiO3}$。又由 $\ce{Na2SiO3 + CO2 + H2O -> Na2CO3 + H2SiO3 v}$ 可知，$\ce{CO2}$（对应碳酸）能制得硅酸，说明碳酸酸性强于硅酸。

**解答**：
$\ce{Na2SiO3 + 2HCl -> H2SiO3 v + 2NaCl}$；
由 $\ce{Na2SiO3 + CO2 + H2O -> Na2CO3 + H2SiO3 v}$ 可知**酸性：$\ce{H2CO3 > H2SiO3}$**。

**点评**："强酸制弱酸"是判断酸性强弱的重要手段。注意 $\ce{H2SiO3}$ 是难溶的弱酸，其酸性弱于碳酸。

### 例题 3

**题目**：普通玻璃的主要原料是纯碱、石灰石和石英砂。取一定量玻璃，用其组成 $\ce{Na2O·CaO·6SiO2}$ 表示。试计算其中 $\ce{SiO2}$ 的质量分数（相对原子质量：$\ce{Na}=23$，$\ce{O}=16$，$\ce{Si}=28$，$\ce{Ca}=40$）。

**分析**：$\ce{Na2O·CaO·6SiO2}$ 的相对分子质量 $M = 62 + 56 + 6 \times 60 = 478$。其中 $\ce{SiO2}$ 总质量 $= 6 \times 60 = 360$。质量分数 $w = \dfrac{360}{478} \times 100\% \approx 75.3\%$。

**解答**：$\ce{SiO2}$ 的质量分数约为 $75.3\%$。

**点评**：本题考查硅酸盐氧化物表示法的**计算应用**。关键是把化学式"拆"成氧化物形式，再按相对分子质量计算质量分数。这也是高考"材料组成计算"的常见题型。

## 易错提醒

> [!warning]
> - **$\ce{SiO2}$ 不与水反应**，硅酸不能由 $\ce{SiO2}$ 与水直接制得；应通过可溶性硅酸盐（如 $\ce{Na2SiO3}$）与较强酸反应制备。
> - **水玻璃是 $\ce{Na2SiO3}$ 的水溶液，属于混合物**，不是纯净物。
> - **玻璃是混合物**，成分常用 $\ce{Na2O·CaO·6SiO2}$ 表示；陶瓷的主要成分是硅酸盐。
> - **光导纤维的成分是 $\ce{SiO2}$，不是晶体硅**；芯片、半导体才用晶体硅。
> - 玻璃工业中 $\ce{SiO2}$ 与 $\ce{Na2CO3}$、$\ce{CaCO3}$ 的反应都在**高温**下进行（$\ce{SiO2}$ 酸性弱于碳酸，常温下 $\ce{Na2CO3}$ 不能与 $\ce{SiO2}$ 反应）。
> - 硅酸盐的氧化物表示法只改写**化学式**，不表示其真实组成（玻璃中不存在独立的 $\ce{Na2O}$、$\ce{CaO}$）。
