# 铁三角与亚铁离子铁离子的转化

> [!abstract] 概览
> 本笔记是铁这一章的灵魂——$\ce{Fe}$、$\ce{Fe^{2+}}$、$\ce{Fe^{3+}}$ 三种价态的相互转化（"铁三角"），以及 $\ce{Fe^{2+}}$/$\ce{Fe^{3+}}$ 的检验方法。核心是"**氧化性：$\ce{Fe^{3+} > Cu^{2+} > Fe^{2+}}$**"，据此选择氧化剂与还原剂。这是高考实验题、流程题、离子检验题的综合考点。

## 核心概念

### 铁三角

三种价态构成三角形转化关系：

$$
\ce{Fe <=>[$H^+$、$Cu^{2+}$、$S$、$I_2$][Zn、C、CO、H_2] Fe^{2+} <=>[$Cl_2$、$O_2$、$HNO_3$、$H_2O_2$、$KMnO_4(H^+)$][Fe、Cu、I^-、SO_2、H_2S] Fe^{3+}}
$$

- **还原性**：$\ce{Fe > Fe^{2+}}$（$\ce{Fe^{2+}}$ 可被强氧化剂氧化）。
- **氧化性**：$\ce{Fe^{3+} > Cu^{2+} > Fe^{2+}}$，这是判断反应能否发生的标尺。
- **归中反应**：高价与低价互相靠拢成中间价态，如 $\ce{Fe + 2Fe^{3+} -> 3Fe^{2+}}$。

> [!tip] 记忆方法
> "铁三角，三点一线"：升价用氧化剂（$\ce{Cl2}$、$\ce{O2}$、$\ce{H2O2}$…），降价用还原剂（$\ce{Fe}$、$\ce{Cu}$、$\ce{I^-}$…），价态归中必为中间价。

## 重点知识：铁三角的具体转化

### 1. $\ce{Fe -> Fe^{2+}}$（弱氧化剂）

| 氧化剂 | 离子方程式 |
| --- | --- |
| $\ce{H+}$（非氧化性酸） | $\ce{Fe + 2H+ -> Fe^{2+} + H2 ^}$ |
| $\ce{Cu^{2+}}$ | $\ce{Fe + Cu^{2+} -> Fe^{2+} + Cu}$ |
| $\ce{S}$（加热）、$\ce{I2}$ | $\ce{Fe + S \xrightarrow{\Delta} FeS}$、$\ce{Fe + I2 -> FeI2}$ |

### 2. $\ce{Fe -> Fe^{3+}}$（强氧化剂）

| 氧化剂 | 离子方程式 |
| --- | --- |
| $\ce{Cl2}$ | $\ce{2Fe + 3Cl2 \xrightarrow{\Delta} 2FeCl3}$ |
| 稀硝酸（过量） | $\ce{Fe + 4H+ + NO3^- -> Fe^{3+} + NO ^ + 2H2O}$ |
| $\ce{O2}$（点燃） | $\ce{3Fe + 2O2 \xrightarrow{点燃} Fe3O4}$（铁的价态 $+\frac{8}{3}$） |

### 3. $\ce{Fe^{2+} -> Fe^{3+}}$（加氧化剂）

| 氧化剂 | 离子方程式 |
| --- | --- |
| $\ce{Cl2}$ | $\ce{2Fe^{2+} + Cl2 -> 2Fe^{3+} + 2Cl^-}$ |
| $\ce{H2O2}$（酸性） | $\ce{2Fe^{2+} + H2O2 + 2H+ -> 2Fe^{3+} + 2H2O}$ |
| $\ce{O2}$（久置） | $4\ce{Fe^{2+}} + \ce{O2} + 4\ce{H+} -> 4\ce{Fe^{3+}} + 2\ce{H2O}$ |
| 酸性 $\ce{KMnO4}$ | $\ce{5Fe^{2+} + MnO4^- + 8H+ -> 5Fe^{3+} + Mn^{2+} + 4H2O}$ |

> [!warning] $\ce{FeSO4}$ 溶液为什么要加铁粉
> 保存 $\ce{FeSO4}$ 溶液时加入少量铁粉，目的是防止 $\ce{Fe^{2+}}$ 被氧化：$2\ce{Fe^{3+}} + \ce{Fe} -> 3\ce{Fe^{2+}}$。同时加稀硫酸抑制 $\ce{Fe^{2+}}$ 水解。

### 4. $\ce{Fe^{3+} -> Fe^{2+}}$（加还原剂）

| 还原剂 | 离子方程式 |
| --- | --- |
| $\ce{Fe}$ | $\ce{2Fe^{3+} + Fe -> 3Fe^{2+}}$（归中） |
| $\ce{Cu}$ | $\ce{2Fe^{3+} + Cu -> 2Fe^{2+} + Cu^{2+}}$（刻蚀电路板） |
| $\ce{I^-}$ | $\ce{2Fe^{3+} + 2I^- -> 2Fe^{2+} + I2}$ |
| $\ce{SO2}$ | $\ce{2Fe^{3+} + SO2 + 2H2O -> 2Fe^{2+} + SO4^{2-} + 4H+}$ |

> [!note] $\ce{FeCl3}$ 刻蚀铜板
> 印刷电路板的制作利用 $\ce{2FeCl3 + Cu -> 2FeCl2 + CuCl2}$，即 $\ce{Fe^{3+}}$ 把 $\ce{Cu}$ 氧化成 $\ce{Cu^{2+}}$，自身被还原为 $\ce{Fe^{2+}}$。该反应说明 $\ce{Fe^{3+}}$ 氧化性强于 $\ce{Cu^{2+}}$。

## 重点知识：$\ce{Fe^{2+}}$ 与 $\ce{Fe^{3+}}$ 的检验

### 1. $\ce{Fe^{3+}}$ 的检验

- **$\ce{KSCN}$ 溶液**：滴加后溶液变**血红色**（最灵敏、最常用）。
  $$\ce{Fe^{3+} + 3SCN^- -> Fe(SCN)3}$$
- **$\ce{NaOH}$ 溶液**：生成**红褐色** $\ce{Fe(OH)3}$ 沉淀。
- **苯酚**：显紫色（选必三拓展）。

### 2. $\ce{Fe^{2+}}$ 的检验

- **$\ce{KSCN}$ 溶液**：先加 $\ce{KSCN}$，溶液**不变红**，再滴加氯水（或 $\ce{H2O2}$），溶液**变红**——说明原溶液含 $\ce{Fe^{2+}}$。
- **$\ce{NaOH}$ 溶液**：生成白色沉淀，迅速变灰绿色，最终红褐色。

> [!warning] 检验 $\ce{Fe^{2+}}$ 的先后顺序
> 检验 $\ce{Fe^{2+}}$ 时，**必须先加 $\ce{KSCN}$ 无现象，再加氧化剂变红**。如果一开始就变红，说明含 $\ce{Fe^{3+}}$；若直接加氧化剂变红，无法区分是原有的 $\ce{Fe^{3+}}$ 还是被氧化的 $\ce{Fe^{2+}}$。先加 $\ce{KSCN}$ 是为了排除 $\ce{Fe^{3+}}$ 干扰。

### 3. 检验方法的对比表格

| 检验对象 | 试剂 | 现象 |
| --- | --- | --- |
| $\ce{Fe^{3+}}$ | $\ce{KSCN}$ 溶液 | 变血红色 |
| $\ce{Fe^{3+}}$ | $\ce{NaOH}$ 溶液 | 红褐色沉淀 |
| $\ce{Fe^{2+}}$ | $\ce{NaOH}$ 溶液 | 白色→灰绿色→红褐色沉淀 |
| $\ce{Fe^{2+}}$（含 $\ce{Fe^{3+}}$） | 先 $\ce{KSCN}$，后氯水 | 先不变红，后变红 |

## 典型例题

### 例题 1：$\ce{Fe^{2+}}$ 的检验

**题目**：为检验某溶液中是否含有 $\ce{Fe^{2+}}$，正确的操作是（ ）
A. 直接滴加 $\ce{KSCN}$ 溶液，观察是否变红
B. 滴加 $\ce{NaOH}$ 溶液，观察是否生成红褐色沉淀
C. 先滴加 $\ce{KSCN}$ 溶液无现象，再滴加氯水变红
D. 滴加氯水后再加 $\ce{KSCN}$ 溶液变红

**分析**：检验 $\ce{Fe^{2+}}$ 的关键是排除 $\ce{Fe^{3+}}$ 干扰。A 只检验 $\ce{Fe^{3+}}$；B 中红褐色沉淀是 $\ce{Fe(OH)3}$（$\ce{Fe^{3+}}$）；D 无法区分 $\ce{Fe^{3+}}$ 是原有的还是 $\ce{Fe^{2+}}$ 被氧化来的。C 先加 $\ce{KSCN}$ 无现象排除 $\ce{Fe^{3+}}$，再加氧化剂变红证明 $\ce{Fe^{2+}}$。

**解答**：答案：**C**。

**点评**：$\ce{Fe^{2+}}$ 检验的经典陷阱。记住口诀："先硫氰，后氯水；先无色，后变红"。

### 例题 2：铁三角转化综合

**题目**：下列各组离子在溶液中能大量共存的是（ ）
A. $\ce{Fe^{3+}}$、$\ce{SCN^-}$、$\ce{Cl^-}$、$\ce{Na+}$
B. $\ce{Fe^{2+}}$、$\ce{H+}$、$\ce{NO3^-}$、$\ce{K+}$
C. $\ce{Fe^{3+}}$、$\ce{Cu}$、$\ce{SO4^{2-}}$、$\ce{H+}$
D. $\ce{Fe^{2+}}$、$\ce{I^-}$、$\ce{Cl^-}$、$\ce{K+}$

**分析**：A 中 $\ce{Fe^{3+}}$ 与 $\ce{SCN^-}$ 生成红色配合物，不共存；B 中 $\ce{Fe^{2+}}$ 在酸性条件下被 $\ce{NO3^-}$ 氧化（$\ce{3Fe^{2+} + NO3^- + 4H+ -> 3Fe^{3+} + NO ^ + 2H2O}$），不共存；C 中 $\ce{Cu}$ 是单质不是离子，且 $\ce{Fe^{3+}}$ 能氧化 $\ce{Cu}$；D 中 $\ce{Fe^{2+}}$ 与 $\ce{I^-}$ 还原性均较弱，$\ce{Fe^{3+}}$ 才氧化 $\ce{I^-}$，$\ce{Fe^{2+}}$ 不氧化 $\ce{I^-}$，可以共存。

**解答**：答案：**D**。

**点评**：本题综合考查"氧化还原不能共存"思想。关键判断：
- $\ce{Fe^{3+}}$ 与 $\ce{I^-}$、$\ce{S^{2-}}$、$\ce{SO3^{2-}}$ 等还原性离子不能共存；
- $\ce{Fe^{2+}}$ 与酸性 $\ce{NO3^-}$、$\ce{MnO4^-}$、$\ce{ClO^-}$ 等强氧化性离子不能共存；
- $\ce{Fe^{3+}}$ 与 $\ce{SCN^-}$ 生成配合物不能共存。

## 易错提醒

> [!warning] 易错点清单
> 1. $\ce{Fe^{3+}}$ 氧化性**强于** $\ce{Cu^{2+}}$、$\ce{I2}$、$\ce{S}$，所以 $\ce{Fe^{3+}}$ 能把 $\ce{Cu}$、$\ce{I^-}$ 氧化，而 $\ce{Fe^{2+}}$ 不能。
> 2. 检验 $\ce{Fe^{2+}}$ 一定要"先硫氰、后氯水"，顺序颠倒则结论不成立。
> 3. $\ce{Fe^{2+}}$ 在酸性条件下可被 $\ce{NO3^-}$（硝酸根 + $\ce{H+}$）氧化，与硝酸根共存需考虑酸碱性。
> 4. $\ce{FeCl3}$ 溶液刻蚀铜板，体现 $\ce{Fe^{3+}}$ 的氧化性，常用于工业流程题。
> 5. 保存 $\ce{FeSO4}$ 溶液要加铁粉和稀硫酸，分别防止氧化和水解。
> 6. 铁三角转化中"归中反应"产物为中间价态，如 $\ce{Fe + 2Fe^{3+} -> 3Fe^{2+}}$。
