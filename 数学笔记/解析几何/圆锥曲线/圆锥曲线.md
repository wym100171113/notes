# 圆锥曲线 (Conic Sections)

> [!info] 统一定义 (第二定义)
> 平面内，到一个定点 $F$（焦点）与到一条定直线 $l$（准线）的距离之比为常数 $e$ 的点的轨迹称为圆锥曲线。
> - $0 < e < 1$：椭圆
> - $e = 1$：抛物线
> - $e > 1$：双曲线
>
> 此定义统一了离心率，也是极坐标方程的出发点。参见 [[极坐标与参数方程]]。

---

## 1. 椭圆 (Ellipse)

### 1.1 第一定义
平面内到两定点 $F_1, F_2$ 的**距离之和**等于常数 $2a$（$2a > |F_1F_2|$）的点的轨迹。

### 1.2 标准方程推导
设焦点 $F_1(-c,0), F_2(c,0)$，动点 $M(x,y)$，由定义 $|MF_1|+|MF_2| = 2a$。
$$\sqrt{(x+c)^2+y^2} + \sqrt{(x-c)^2+y^2} = 2a$$
移项平方整理得：
$$\frac{x^2}{a^2} + \frac{y^2}{a^2-c^2} = 1$$
令 $b^2 = a^2 - c^2$ ($b>0$)，即得标准方程：
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a>b>0)$$

### 1.3 几何性质
- **顶点**：$(\pm a, 0), (0, \pm b)$
- **焦点**：$F_1(-c,0), F_2(c,0)$，其中 $c^2 = a^2 - b^2$
- **离心率**：$e = \dfrac{c}{a},\; 0<e<1$
- **准线**：$x = \pm \dfrac{a^2}{c}$（对应第二定义）
- **焦半径公式**：椭圆上点 $M(x_0,y_0)$，$|MF_1| = a+ex_0,\; |MF_2| = a-ex_0$（$F_1$ 为左焦点）
- **通径**：过焦点垂直长轴的弦长 $= \dfrac{2b^2}{a}$

### 1.4 焦点三角形
椭圆上点 $P$ 与两焦点构成 $\triangle F_1PF_2$，设 $\angle F_1PF_2 = \theta$：
- 周长：$2a+2c$
- 面积：$S = b^2 \tan\dfrac{\theta}{2}$（由余弦定理与定义推导）

### 1.5 点差法（中点弦）
弦端点 $A(x_1,y_1), B(x_2,y_2)$，中点 $M(x_0,y_0)$，斜率 $k$。方程相减得：
$$\frac{x_1^2-x_2^2}{a^2} + \frac{y_1^2-y_2^2}{b^2} = 0 \;\Longrightarrow\; \frac{2x_0}{a^2} + \frac{2y_0 k}{b^2} = 0$$
$$\therefore\; k = -\frac{b^2 x_0}{a^2 y_0}$$

## 2. 双曲线 (Hyperbola)

### 2.1 第一定义
平面内到两定点 $F_1, F_2$ 的**距离之差的绝对值**为常数 $2a$（$0<2a<|F_1F_2|$）的点的轨迹。

### 2.2 标准方程推导
设 $F_1(-c,0), F_2(c,0)$，由 $||MF_1|-|MF_2|| = 2a$ 化简得：
$$\frac{x^2}{a^2} - \frac{y^2}{c^2-a^2} = 1$$
令 $b^2 = c^2 - a^2$，得：
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a>0,b>0)$$

### 2.3 几何性质
- **顶点**：$(\pm a, 0)$
- **焦点**：$(\pm c,0),\; c^2 = a^2 + b^2$
- **离心率**：$e = \dfrac{c}{a} > 1$
- **渐近线**：$y = \pm \dfrac{b}{a} x$（由 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=0$ 得到）
- **准线**：$x = \pm \dfrac{a^2}{c}$
- **焦点三角形面积**：若 $\angle F_1PF_2 = \theta$，$S = b^2 \cot\dfrac{\theta}{2}$
- **等轴双曲线**：$a=b$，$e=\sqrt{2}$，渐近线垂直。

## 3. 抛物线 (Parabola)

### 3.1 定义
平面内到定点 $F$ 与到定直线 $l$ ($F\notin l$) 距离相等的点的轨迹。

### 3.2 标准方程推导
设焦点 $F(\frac{p}{2}, 0)$，准线 $x = -\frac{p}{2}$ ($p>0$)，由 $|MF| = d(M,l)$：
$$\sqrt{\left(x-\frac{p}{2}\right)^2 + y^2} = \left|x + \frac{p}{2}\right|$$
平方化简得：
$$y^2 = 2px$$

### 3.3 几何性质
- 范围：$x \ge 0$，关于 $x$ 轴对称
- 顶点：$(0,0)$
- 焦点：$F(\frac{p}{2}, 0)$，准线：$x = -\frac{p}{2}$
- 离心率：$e = 1$
- 焦半径：$|MF| = x_0 + \frac{p}{2}$
- 通径：$2p$

### 3.4 焦点弦性质
设 $AB$ 为过焦点 $F$ 的弦，$A(x_1,y_1), B(x_2,y_2)$，则：
- $x_1 x_2 = \frac{p^2}{4},\; y_1 y_2 = -p^2$
- $\dfrac{1}{|FA|} + \dfrac{1}{|FB|} = \dfrac{2}{p}$（定值）

## 4. 通用方法与定理

### 4.1 弦长公式
直线 $y=kx+m$ 与曲线联立得二次方程 $Ax^2+Bx+C=0$：
$$|AB| = \sqrt{1+k^2}\, |x_1-x_2| = \sqrt{1+k^2}\, \frac{\sqrt{\Delta}}{|A|}$$

### 4.2 切线方程（以标准方程为例）
- 椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 在 $(x_0,y_0)$ 处：$\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$
- 双曲线 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$：$\frac{x_0 x}{a^2} - \frac{y_0 y}{b^2} = 1$
- 抛物线 $y^2=2px$：$y_0 y = p(x + x_0)$

### 4.3 切点弦方程
点 $P(x_0,y_0)$ 在曲线外，过 $P$ 的两条切线的切点连线方程可将曲线方程中 $x^2\to x_0x,\; y^2\to y_0y,\; x\to\frac{x+x_0}{2}$ 等代入得到。

### 4.4 定点定值问题思路
设参消参，韦达定理整体代入，或利用极点极线、光学性质等几何特征。

## 5. 典型例题解析

> [!example] 例1：求以 $F_1(-3,0),F_2(3,0)$ 为焦点，长轴长为10的椭圆方程。
>> [!success]- 解析
>> $2a=10\Rightarrow a=5$，$c=3$，$b^2=16$。焦点在 $x$ 轴，方程为 $\dfrac{x^2}{25}+\dfrac{y^2}{16}=1$。

> [!example] 例2：椭圆 $\dfrac{x^2}{4}+y^2=1$ 的弦被 $P(1,\frac12)$ 平分，求弦所在直线斜率。
>> [!success]- 解析
>> 点差法：$k = -\dfrac{b^2 x_0}{a^2 y_0} = -\dfrac{1\times 1}{4\times \frac12} = -\dfrac12$。

> [!example] 例3：求证抛物线 $y^2=2px$ 焦点弦端点横坐标之积为定值。
>> [!success]- 证明
>> 设焦点弦 $x=my+\frac p2$，代入得 $y^2-2pmy-p^2=0$，$y_1y_2=-p^2$，则 $x_1x_2=\frac{y_1^2}{2p}\cdot\frac{y_2^2}{2p}=\frac{p^4}{4p^2}=\frac{p^2}{4}$。

## 6. 习题精选 (12 道，难度递进至竞赛)

> [!question]- 1. 已知椭圆中心在原点，焦点在 $x$ 轴，焦距为 $4\sqrt{3}$，离心率 $e=\frac{\sqrt{3}}{2}$，求椭圆方程。
>> [!success]- 解答
>> $2c=4\sqrt{3}\Rightarrow c=2\sqrt{3}$；由 $e=c/a=\sqrt{3}/2$ 得 $a=4$。$b^2=a^2-c^2=16-12=4$。方程为 $\dfrac{x^2}{16}+\dfrac{y^2}{4}=1$。

> [!question]- 2. 双曲线 $\dfrac{x^2}{9}-\dfrac{y^2}{16}=1$ 上一点 $P$ 到一个焦点的距离为5，求 $P$ 到另一焦点的距离。
>> [!success]- 解答
>> $a=3$，$2a=6$。由定义 $||PF_1|-|PF_2||=6$。若 $|PF_1|=5$，则 $|5-d|=6\Rightarrow d=11$ (负值舍去)。

> [!question]- 3. 抛物线 $y^2=8x$ 上一点 $M$ 到焦点的距离为5，求 $M$ 的坐标。
>> [!success]- 解答
>> $2p=8\Rightarrow p=4$，准线 $x=-2$。焦半径 $x_M+2=5\Rightarrow x_M=3$。代入得 $y^2=24\Rightarrow y=\pm 2\sqrt{6}$。故 $M(3,\pm 2\sqrt{6})$。

> [!question]- 4. 过椭圆 $\dfrac{x^2}{25}+\dfrac{y^2}{16}=1$ 内一点 $P(2,1)$，求以 $P$ 为中点的弦所在直线方程。
>> [!success]- 解答
>> 点差法：$k = -\dfrac{16\times 2}{25\times 1} = -\dfrac{32}{25}$。直线：$y-1 = -\frac{32}{25}(x-2)$，即 $32x+25y-89=0$。

> [!question]- 5. 斜率为1的直线过抛物线 $y^2=4x$ 焦点，且与抛物线交于 $A,B$，求弦 $AB$ 的长。
>> [!success]- 解答
>> 焦点 $F(1,0)$，直线 $y=x-1$。代入得 $(x-1)^2=4x \Rightarrow x^2-6x+1=0$。弦长 $|AB|=\sqrt{1+1}\cdot\sqrt{36-4}=8$。

> [!question]- 6. 椭圆 $\dfrac{x^2}{4}+y^2=1$ 的左焦点为 $F$，过 $F$ 的直线交椭圆于 $A,B$，求 $\triangle AOB$ 面积的最大值（$O$ 为原点）。
>> [!success]- 解答
>> $F(-\sqrt{3},0)$。设直线 $x=my-\sqrt{3}$，代入椭圆得 $(m^2+4)y^2-2\sqrt{3}my-1=0$。$|y_1-y_2|=\frac{4\sqrt{m^2+1}}{m^2+4}$。$S=\frac{\sqrt{3}}{2}|y_1-y_2| = 2\sqrt{3}\frac{\sqrt{m^2+1}}{m^2+4}$。令 $t=\sqrt{m^2+1}\ge 1$，$S=2\sqrt{3}\frac{t}{t^2+3}\le 2\sqrt{3}\cdot\frac{1}{2\sqrt{3}}=1$，当 $t=\sqrt{3}$ 时取等。最大面积为 $1$。

> [!question]- 7. 已知抛物线 $y^2=4x$ 的焦点为 $F$，过 $F$ 的直线交抛物线于 $A,B$。求证：以 $AB$ 为直径的圆与准线相切。
>> [!success]- 证明
>> $F(1,0)$，准线 $x=-1$。设 $AB$ 中点 $M$，作 $AA_1,BB_1,MM_1$ 垂直准线于 $A_1,B_1,M_1$。由定义 $|AA_1|=|AF|,|BB_1|=|BF|$。梯形中位线 $|MM_1| = \frac{|AF|+|BF|}{2} = \frac{|AB|}{2}$，恰为圆半径，且 $MM_1\perp$ 准线，故相切。

> [!question]- 8. 已知椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$ 的通径（过焦点垂直长轴的弦）长恰好等于焦距，求椭圆的离心率。
>> [!success]- 解答
>> 通径长 $=\dfrac{2b^2}{a}$，焦距 $=2c$。由条件 $\dfrac{2b^2}{a}=2c \Rightarrow b^2=ac$。又 $b^2=a^2-c^2$，故 $a^2-c^2=ac$，除以 $a^2$ 得 $1-e^2=e$，$e^2+e-1=0$，解得 $e=\dfrac{-1+\sqrt{5}}{2}$ (负舍)。

> [!question]- 9. 点 $A(2,0)$，$B$ 为椭圆 $\dfrac{x^2}{4}+y^2=1$ 上的动点，求线段 $AB$ 中点 $M$ 的轨迹方程。
>> [!success]- 解答
>> 设 $B(x_0,y_0), M(x,y)$，则 $x=\frac{x_0+2}{2}, y=\frac{y_0}{2}$。故 $x_0=2x-2, y_0=2y$。代入椭圆：$\frac{(2x-2)^2}{4}+(2y)^2=1 \Rightarrow (x-1)^2+4y^2=1$，轨迹为中心在 $(1,0)$ 的椭圆。

> [!question]- 10. 过抛物线 $y^2=2px$ 上一定点 $M(x_0,y_0)$ 作两条互相垂直的弦 $MA, MB$，求证直线 $AB$ 恒过定点，并求该定点坐标。
>> [!success]- 解答
>> 用参数式，设 $M(2pt_0^2, 2pt_0)$，$A(2pa^2,2pa), B(2pb^2,2pb)$。$MA\perp MB \Rightarrow (a+t_0)(b+t_0)=-1$。直线 $AB$ 方程为 $x-(a+b)y+2pab=0$。利用上式消去 $ab$ 并整理，可得 $AB$ 过定点 $(2pt_0^2+2p, -2pt_0)$，即 $(x_0+2p, -y_0)$。

> [!question]- 11. 椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\ (a>b>0)$ 的右顶点 $A$，上顶点 $B$，直线 $y=kx\ (k>0)$ 交椭圆于 $P$，交 $AB$ 于 $M$。求四边形 $OAPB$ 面积的最大值及此时 $k$ 的值。
>> [!success]- 解答
>> 设 $P(a\cos\theta, b\sin\theta)$，则四边形面积 $S=S_{\triangle OAP}+S_{\triangle OBP}= \frac12 a\cdot b\sin\theta + \frac12 b\cdot a\cos\theta = \frac12 ab(\sin\theta+\cos\theta) = \frac{\sqrt{2}}{2}ab\sin(\theta+\frac{\pi}{4}) \le \frac{\sqrt{2}}{2}ab$。当 $\theta=\frac{\pi}{4}$ 时取最大值，此时 $k = \frac{b\sin\theta}{a\cos\theta} = \frac{b}{a}$。

> [!question]- 12. (竞赛) 双曲线 $C:\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$ 的右焦点 $F$，右准线 $l$。过 $F$ 垂直于 $x$ 轴的直线交 $C$ 于 $A,B$，以 $AB$ 为直径的圆与 $l$ 交于另一点 $P$，且 $\angle PAF=30^\circ$。求双曲线的离心率 $e$。
>> [!success]- 解答
>> $F(c,0)$，$x=c$ 代入得 $A(c,\frac{b^2}{a}), B(c,-\frac{b^2}{a})$，圆半径 $R=\frac{b^2}{a}$。准线 $x=\frac{a^2}{c}$。联立圆方程 $(x-c)^2+y^2=\frac{b^4}{a^2}$ 与 $x=\frac{a^2}{c}$，求得 $P(\frac{a^2}{c}, \frac{b^3}{ac})$ (取上方点)。$\angle PAF$ 中 $AF\perp x$ 轴，$\tan\angle PAF = \frac{|x_P-x_A|}{|y_P-y_A|} = \frac{\frac{b^2}{c}}{\frac{b^2}{a}(1-\frac{b}{c})} = \frac{a}{c-b}$。由 $\angle PAF=30^\circ$ 得 $\frac{a}{c-b} = \frac{1}{\sqrt{3}} \Rightarrow c-b = \sqrt{3}a$。又 $c^2=a^2+b^2$，代入解得 $c = \frac{2}{\sqrt{3}}a$，故 $e = \frac{2\sqrt{3}}{3}$。
