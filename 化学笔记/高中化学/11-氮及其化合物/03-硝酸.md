# 硝酸

> [!abstract] 概览
> 硝酸（$\ce{HNO3}$）是氮的 +5 价含氧酸，**具有酸的通性**，但最突出的是**强氧化性**（由 +5 价 $\ce{N}$ 体现）。浓硝酸、稀硝酸与 $\ce{Cu}$ 反应产物不同，常温下使 $\ce{Fe}$、$\ce{Al}$ **钝化**，受热或光照**分解**。硝酸的强氧化性与不稳定性是高考的重难点。

## 核心概念

- **物理性质**：无色、易挥发、有刺激性气味的液体；浓硝酸因溶有 $\ce{NO2}$ 常呈**黄色**（久置）；"发烟硝酸"是浓度很高的硝酸（挥发出的 $\ce{HNO3}$ 与空气中水蒸气形成白雾）。
- 保存：**棕色试剂瓶**，密封，避光、阴凉处（防止光照分解）。
- 工业制取：氨催化氧化法（$\ce{NH3 ->[O2] NO ->[O2] NO2 ->[H2O] HNO3}$）。

## 化学性质

### 1. 酸的通性

$$\ce{HNO3 -> H+ + NO3-}$$

- 与碱、碱性氧化物、盐反应（生成硝酸盐）。
- 注意：**硝酸与金属反应一般不放出 $\ce{H2}$**（因硝酸有强氧化性，即使稀硝酸也是如此）。

### 2. 强氧化性（核心）

> 硝酸中 +5 价 $\ce{N}$ 是强氧化剂，本身被还原为 $\ce{NO2}$（浓）或 $\ce{NO}$（稀）。

#### （1）与铜反应（浓稀产物不同）

$$\ce{Cu + 4HNO3(浓) -> Cu(NO3)2 + 2NO2 ^ + 2H2O}$$

$$\ce{3Cu + 8HNO3(稀) -> 3Cu(NO3)2 + 2NO ^ + 4H2O}$$

| 浓度 | 还原产物 | 现象 |
| --- | --- | --- |
| 浓硝酸 | $\ce{NO2}$（红棕色） | 剧烈反应，产生红棕色气体，溶液变蓝 |
| 稀硝酸 | $\ce{NO}$（无色） | 反应较缓，产生无色气体（遇空气变红棕色），溶液变蓝 |

> [!important] 规律
> **浓硝酸的氧化性强于稀硝酸，但其还原产物中氮的价态更高（$\ce{NO2}$ 中 +4 价）**；稀硝酸氧化性较弱，氮被还原到更低价（$\ce{NO}$ 中 +2 价）。即：**"浓硝酸还原产物价态高，稀硝酸还原产物价态低"**。

#### （2）常温钝化

- 常温下，**浓硝酸**与浓硫酸一样能使 $\ce{Fe}$、$\ce{Al}$ 表面形成致密氧化膜而**钝化**。
- 应用：常温下可用铝罐、铁罐盛装浓硝酸。
- 注意：加热时 $\ce{Fe}$、$\ce{Al}$ 仍能与浓硝酸剧烈反应；稀硝酸不能使 $\ce{Fe}$、$\ce{Al}$ 钝化。

#### （3）与非金属反应

$$\ce{C + 4HNO3(浓) ->[Δ] CO2 ^ + 4NO2 ^ + 2H2O}$$

$$\ce{S + 6HNO3(浓) ->[Δ] H2SO4 + 6NO2 ^ + 2H2O}$$

（浓硝酸将非金属氧化到最高价。）

#### （4）与还原性化合物反应

- 与 $\ce{Fe^{2+}}$：$\ce{3Fe^{2+} + NO3^- + 4H+ -> 3Fe^{3+} + NO ^ + 2H2O}$（$\ce{Fe^{2+}}$ 被氧化为 $\ce{Fe^{3+}}$）
- 与 $\ce{SO3^{2-}}$、$\ce{S^{2-}}$、$\ce{I^-}$ 等均能发生氧化还原反应（这也是检验 $\ce{SO4^{2-}}$ 时慎用硝酸的原因，见 [[10-硫及其化合物/04-硫酸根离子的检验|硫酸根离子的检验]]）。

### 3. 不稳定性

$$\ce{4HNO3 ->[光照或加热] 2H2O + 4NO2 ^ + O2 ^}$$

- 浓硝酸久置变黄，是因为分解生成的 $\ce{NO2}$ 溶于硝酸中。
- 保存于**棕色瓶**、避光、密封。

### 4. 硝酸盐的受热分解规律

硝酸盐受热都分解，产物因金属活动性不同而不同：

- **$\ce{K}$、$\ce{Ca}$、$\ce{Na}$ 的硝酸盐**（活泼金属）：分解生成**亚硝酸盐 + $\ce{O2}$**
$$\ce{2NaNO3 ->[Δ] 2NaNO2 + O2 ^}$$
- **$\ce{Mg}$ 至 $\ce{Cu}$ 的硝酸盐**：分解生成**金属氧化物 + $\ce{NO2}$ + $\ce{O2}$**
$$\ce{2Cu(NO3)2 ->[Δ] 2CuO + 4NO2 ^ + O2 ^}$$
- **$\ce{Cu}$ 以后的硝酸盐**（不活泼金属）：分解生成**金属单质 + $\ce{NO2}$ + $\ce{O2}$**
$$\ce{2AgNO3 ->[Δ] 2Ag + 2NO2 ^ + O2 ^}$$

> [!note] 硝酸盐与检验
> 硝酸盐（如 $\ce{KNO3}$）在**酸性环境**中即表现出强氧化性（$\ce{NO3^- + H+}$ 组合相当于稀硝酸），可使还原性离子（$\ce{Fe^{2+}}$、$\ce{SO3^{2-}}$、$\ce{I^-}$ 等）被氧化。这是高考常考陷阱。

### 5. 王水

- 组成：**浓盐酸 : 浓硝酸 = 3:1**（体积比）。
- 性质：氧化能力极强，能溶解**金、铂**（单独的盐酸或硝酸都不能）。

## 典型例题

### 例题 1

**题目**：向 $100\ \mathrm{mL}$ 的 $0.1\ \mathrm{mol/L}$ $\ce{CuSO4}$ 溶液中加入足量稀硝酸与适量铁粉，充分反应后铁有剩余。下列说法正确的是（　）
A. 最终溶液呈蓝色
B. 铁与稀硝酸反应生成 $\ce{Fe^{2+}}$
C. 溶液中无 $\ce{Fe^{3+}}$
D. 产生的气体为 $\ce{NO2}$

**分析**：铁过量时，$\ce{Fe + 4HNO3(稀) -> Fe(NO3)3 + NO ^ + 2H2O}$ 生成的 $\ce{Fe^{3+}}$ 又会与过量 $\ce{Fe}$ 反应：$\ce{2Fe^{3+} + Fe -> 3Fe^{2+}}$，故最终溶液中铁以 $\ce{Fe^{2+}}$ 存在，无 $\ce{Fe^{3+}}$。同时 $\ce{Fe}$ 会置换出 $\ce{Cu}$（$\ce{Fe + Cu^{2+} -> Fe^{2+} + Cu}$），蓝色 $\ce{Cu^{2+}}$ 消失。稀硝酸还原产物是 $\ce{NO}$，不是 $\ce{NO2}$。

**解答**：选 **C**（铁过量时最终溶液中无 $\ce{Fe^{3+}}$；且溶液不呈蓝色，气体为 $\ce{NO}$）。

**点评**：本题考查铁与稀硝酸反应的"过量问题"——铁过量时生成 $\ce{Fe^{2+}}$ 而非 $\ce{Fe^{3+}}$，这是高考高频陷阱。同时要牢记稀硝酸的还原产物是 $\ce{NO}$。

### 例题 2

**题目**：下列关于硝酸的叙述正确的是（　）
A. 浓硝酸与 $\ce{Cu}$ 反应生成 $\ce{NO}$，稀硝酸与 $\ce{Cu}$ 反应生成 $\ce{NO2}$
B. 常温下浓硝酸能使 $\ce{Fe}$、$\ce{Al}$ 钝化，故可用铁罐盛装
C. 浓硝酸久置变黄是因为生成了 $\ce{Fe^{3+}}$
D. 硝酸见光分解只生成 $\ce{NO2}$

**分析**：A 错误：浓硝酸还原产物是 $\ce{NO2}$，稀硝酸还原产物是 $\ce{NO}$。B 正确：常温浓硝酸使 $\ce{Fe}$、$\ce{Al}$ 钝化，可用铁罐、铝罐盛装。C 错误：浓硝酸久置变黄是**分解生成的 $\ce{NO2}$ 溶于硝酸**所致。D 错误：$\ce{4HNO3 ->[光照] 2H2O + 4NO2 ^ + O2 ^}$，还生成 $\ce{O2}$。

**解答**：选 **B**。

**点评**：浓稀硝酸与 $\ce{Cu}$ 反应的产物区分、钝化、见光分解产物、久置变黄原因都是常考易错点，需逐一记牢。

## 易错提醒

> [!warning]
> - **浓稀硝酸与 $\ce{Cu}$ 反应的还原产物不同**：浓 → $\ce{NO2}$，稀 → $\ce{NO}$；但浓硝酸氧化性更强。
> - **硝酸与金属反应不放 $\ce{H2}$**，因为 $\ce{NO3^-}$ 的氧化性强于 $\ce{H+}$。
> - **常温钝化**：浓硝酸、浓硫酸都能使 $\ce{Fe}$、$\ce{Al}$ 钝化（化学变化）；稀硝酸不能。
> - 硝酸**见光/受热分解**：$\ce{4HNO3 ->[光照] 2H2O + 4NO2 + O2}$，久置变黄是因 $\ce{NO2}$ 溶解。
> - **硝酸盐 + 酸性条件 = 稀硝酸**：$\ce{NO3^-}$ 在 $\ce{H+}$ 存在时具有强氧化性，可氧化 $\ce{Fe^{2+}}$、$\ce{SO3^{2-}}$、$\ce{I^-}$ 等（检验硫酸根时用稀盐酸酸化即为了避开此干扰）。
> - 铁与稀硝酸：铁过量生成 $\ce{Fe^{2+}}$，铁不足生成 $\ce{Fe^{3+}}$。
> - 硝酸的酸酐是 $\ce{N2O5}$，不是 $\ce{NO2}$。
