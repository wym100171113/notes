# 数学基础

## 1. 卷积运算

**离散二维卷积**：
$$
S(i, j) = (I * K)(i, j) = \sum_m \sum_n I(m, n) \cdot K(i-m, j-n)
$$

其中 $I$ 是输入图像矩阵，$K$ 是卷积核。

**示例**：一个 3×3 卷积核在 5×5 输入上的运算：

```
输入 (5×5):          卷积核 (3×3):
1  2  3  0  1       1  0  1
0  1  2  3  0       0  1  0
3  0  1  2  1       1  0  1
2  1  0  3  2
1  0  2  1  0

输出 (3×3):
// 卷积核在输入上滑动，每个位置做逐元素乘法再求和
```

## 2. 梯度下降

**目标**：最小化损失函数 $J(\theta)$

**参数更新公式**：
$$
\theta := \theta - \alpha \cdot \nabla_\theta J(\theta)
$$

其中 $\alpha$ 是学习率（learning rate），$\nabla_\theta J(\theta)$ 是梯度。

**学习率选择**：
- 太大：震荡，不收敛
- 太小：收敛慢
- 常用策略：初始 0.001，配合 ReduceLROnPlateau 动态调整

## 3. 反向传播（Backpropagation）

**核心思想**：利用链式法则，从输出层向输入层逐层计算梯度。

**步骤**：
1. 前向传播：计算预测值 $\hat{y}$
2. 计算损失 $L(\hat{y}, y)$
3. 反向传播：计算 $\frac{\partial L}{\partial w}$ 对所有参数 $w$
4. 更新参数：$w := w - \alpha \cdot \frac{\partial L}{\partial w}$

## 4. 交叉熵损失函数

**多分类交叉熵**：
$$
L = -\sum_{i=1}^{C} y_i \cdot \log(\hat{y}_i)
$$
其中 $C$ 是类别数，$y_i$ 是真实标签（one-hot），$\hat{y}_i$ 是预测概率。

**直觉**：预测概率越接近真实标签，损失越小；预测错误时损失急剧增大。

**PyTorch 实现**：
```python
criterion = nn.CrossEntropyLoss()
```

## 5. 评估指标

### 混淆矩阵
|            | 预测为正 | 预测为负 |
|------------|---------|---------|
| 实际为正 | TP      | FN      |
| 实际为负 | FP      | TN      |

### 精确率（Precision）
$$
P = \frac{TP}{TP + FP}
$$

### 召回率（Recall）
$$
R = \frac{TP}{TP + FN}
$$

### F1-Score
$$
F1 = 2 \cdot \frac{P \cdot R}{P + R}
$$

### 准确率（Accuracy）
$$
Acc = \frac{TP + TN}{TP + TN + FP + FN}
$$
