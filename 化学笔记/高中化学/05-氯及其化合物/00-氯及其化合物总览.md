# 氯及其化合物总览

> [!abstract] 概览
> 氯是**卤族元素**（第 VIIA 族）的代表，位于第三周期，最外层 7 个电子，**得电子能力强**，是典型的活泼非金属。氯及其化合物在生产、生活和消毒防疫中应用极广，是高考元素化学的另一主干。本章围绕"**氯气单质 → 氯的化合物（次氯酸、次氯酸盐、漂白粉）→ 实验室制法与离子检验**"展开：
>
> - **氯气**：黄绿色、有毒、密度大于空气、易液化；强氧化性，与金属、非金属、水、碱的反应；氯水的成分与漂白性；
> - **氯的化合物**：次氯酸 $\ce{HClO}$（弱酸、强氧化、不稳定）、次氯酸盐与漂白粉（有效成分 $\ce{Ca(ClO)2}$）、含氯消毒剂的原理；
> - **实验室制法与氯离子检验**：$\ce{MnO2}$ 与浓盐酸加热制氯气，装置、除杂、收集、尾气处理；$\ce{AgNO3}$ 与稀硝酸检验 $\ce{Cl^-}$。
>
> 氯的性质体现了"**结构决定性质**"：最外层 7 个电子 → 强氧化性 → 单质活泼、化合物多样。

## 核心概念

| 物质 | 颜色/状态 | 关键性质 | 核心反应 |
| --- | --- | --- | --- |
| $\ce{Cl2}$ | 黄绿色有毒气体 | 强氧化性，可液化 | $\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$ |
| $\ce{HClO}$ | 弱酸（存在于氯水） | 弱酸性、强氧化性、漂白、不稳定 | $\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$ |
| $\ce{NaClO}$ | 漂白液/84 消毒液主要成分 | 强氧化性、漂白 | $\ce{2NaClO + CO2 + H2O -> Na2CO3 + 2HClO}$ |
| $\ce{Ca(ClO)2}$ | 漂白粉有效成分 | 强氧化性、漂白 | $\ce{Ca(ClO)2 + CO2 + H2O -> CaCO3 v + 2HClO}$ |
| $\ce{HCl}$ | 无色有刺激性气味 | 强酸，浓盐酸有还原性 | $\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$ |

## 核心方程式汇总

**氯气与金属/非金属**：
$$\ce{2Fe + 3Cl2 \xrightarrow{\Delta} 2FeCl3}\qquad\ce{Cu + Cl2 \xrightarrow{\Delta} CuCl2}$$
$$\ce{H2 + Cl2 \xrightarrow{点燃} 2HCl}$$

**氯气与水/碱**：
$$\ce{Cl2 + H2O <=> HCl + HClO}$$
$$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$$
$$\ce{2Cl2 + 2Ca(OH)2 -> Ca(ClO)2 + CaCl2 + 2H2O}$$

**次氯酸与漂白粉**：
$$\ce{2HClO \xrightarrow{光} 2HCl + O2 ^}$$
$$\ce{Ca(ClO)2 + CO2 + H2O -> CaCO3 v + 2HClO}$$

**实验室制氯气与氯离子检验**：
$$\ce{MnO2 + 4HCl(浓) \xrightarrow{\Delta} MnCl2 + Cl2 ^ + 2H2O}$$
$$\ce{Ag+ + Cl^- -> AgCl v}$$

## 高考考点与易错点

> [!warning] 高频易错
> 1. **漂白的是 $\ce{HClO}$ 不是 $\ce{Cl2}$**：干燥氯气无漂白性，氯气使湿润有色布条褪色是因为生成 $\ce{HClO}$。
> 2. **液氯是纯净物**（液态 $\ce{Cl2}$），氯水是混合物；液氯无漂白性。
> 3. **氯气与变价金属生成高价氯化物**：$\ce{Fe + Cl2 -> FeCl3}$、$\ce{Cu + Cl2 -> CuCl2}$，与盐酸产物不同。
> 4. **氯水"三分子三离子"**：分子是 $\ce{Cl2}$、$\ce{H2O}$、$\ce{HClO}$；离子是 $\ce{H+}$、$\ce{Cl^-}$、$\ce{ClO^-}$。
> 5. **新制氯水有漂白性，久置氯水无漂白性**：久置后 $\ce{HClO}$ 全部分解。
> 6. **漂白粉是混合物**，有效成分是 $\ce{Ca(ClO)2}$；失效要写两步（生成 $\ce{HClO}$，$\ce{HClO}$ 再分解）。
> 7. **84 消毒液不能与洁厕灵（盐酸）混用**：会生成有毒氯气。
> 8. **制氯气必须用浓盐酸**：$\ce{MnO2}$ 与稀盐酸不反应，盐酸变稀后反应停止。

## 学习建议与考查方式

- **命题角度**：氯常以"实验题（制备、净化、收集、尾气）""氯水成分分析""漂白粉失效""氯离子检验"等形式出现，选择题、实验题、计算题均有涉及；
- **方程式要求**：熟练书写氯气与金属/非金属/水/碱的反应、次氯酸分解、漂白粉起效与失效、实验室制氯气等方程式（含离子方程式）；
- **定量计算**：氯气与碱反应的比例关系（$\ce{Cl2}$ 一半到 $\ce{Cl^-}$ 一半到 $\ce{ClO^-}$）、$\ce{MnO2}$ 与浓盐酸反应的"盐酸不能完全反应"陷阱，需结合 [[06-物质的量/00-物质的量总览|物质的量]]；
- **实验素养**：实验室制氯气的装置连接顺序（发生→除杂→干燥→收集→尾气）、验满方法（湿润淀粉碘化钾试纸）、尾气吸收（$\ce{NaOH}$）；
- **建议顺序**：先学 [[01-氯气]] 掌握单质性质，再学 [[02-氯的化合物与含氯消毒剂]] 理解消毒/漂白主线，最后学 [[03-氯气的实验室制法与氯离子检验]] 训练实验与检验，配合 [[常见离子的检验方法]] 对照记忆。

## 与其他知识关联

- 氯气的强氧化性、氯水成分涉及"氧化还原反应"与"离子反应"；
- 氯的化合价变化（$-1$、$0$、$+1$、$+3$、$+5$、$+7$）是"氧化还原"的典型素材；
- 漂白性对比：$\ce{Cl2}$/$\ce{NaClO}$/$\ce{Na2O2}$ 为氧化性漂白（不可逆），$\ce{SO2}$ 为化合性漂白（可逆）；
- 氯离子检验属于 [[常见离子的检验方法]] 的一部分；
- 氯气在"海水中提溴、提碘"及"含氯消毒剂"中应用，与元素周期律（卤素递变性）相关；
- 气体摩尔体积、物质的量计算见 [[06-物质的量/00-物质的量总览|物质的量]]。
