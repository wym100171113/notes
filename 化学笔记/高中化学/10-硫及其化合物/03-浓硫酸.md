# 浓硫酸

> [!abstract] 概览
> 硫酸是硫的最高价含氧酸（$\ce{S}$ 为 +6 价）。学习时要把**稀硫酸**（酸的通性，由 $\ce{H+}$ 体现）与**浓硫酸**（吸水性、脱水性、强氧化性三大特性）严格区分。浓硫酸的**强氧化性**（与 $\ce{Cu}$、$\ce{C}$ 反应，常温钝化 $\ce{Fe}$、$\ce{Al}$）是高考的必考内容。

## 核心概念

- 稀硫酸：$\ce{H2SO4 -> 2H+ + SO4^{2-}}$，完全电离，体现酸的通性，**没有**浓硫酸的特性。
- 浓硫酸：约 $98.3\%$，溶质主要以 $\ce{H2SO4}$ 分子形式存在，**几乎不电离**，因此其"酸性"（$\ce{H+}$）弱，但表现出特殊的**吸水性、脱水性、强氧化性**。

## 一、稀硫酸的三重性质（酸的通性）

1. **与金属反应**（排在氢前）：$\ce{Fe + H2SO4(稀) -> FeSO4 + H2 ^}$
2. **与碱反应**：$\ce{H2SO4 + 2NaOH -> Na2SO4 + 2H2O}$
3. **与碱性氧化物反应**：$\ce{CuO + H2SO4 -> CuSO4 + H2O}$
4. **与某些盐反应**：$\ce{BaCl2 + H2SO4 -> BaSO4 v + 2HCl}$；$\ce{Na2CO3 + H2SO4 -> Na2SO4 + CO2 ^ + H2O}$

> 稀硫酸体现这些性质的是 **$\ce{H+}$**（酸的通性）。检验 $\ce{SO4^{2-}}$ 时加入的稀硫酸起"提供 $\ce{SO4^{2-}}$"的作用，与检验对象有关。

## 二、浓硫酸的三大特性

### 1. 吸水性

- **含义**：吸收气体中或物质中的**游离水**，如吸收 $\ce{CuSO4·5H2O}$ 中的结晶水。
- 应用：实验室常用作**干燥剂**（干燥 $\ce{O2}$、$\ce{Cl2}$、$\ce{SO2}$、$\ce{CO2}$ 等），**不能干燥碱性气体**（$\ce{NH3}$）和**还原性气体**（$\ce{H2S}$、$\ce{HBr}$、$\ce{HI}$）。
- 现象：$\ce{CuSO4·5H2O}$（蓝色）$\ce{->[浓H2SO4]}$ $\ce{CuSO4}$（白色）。
- 记忆：**吸水吸的是"水里游离的水"，物质化学组成不变**。

### 2. 脱水性

- **含义**：将有机物中 $\ce{H}$、$\ce{O}$ 按 $2:1$（水分子组成）脱去，**有机物发生炭化**。
- 实验：浓硫酸使蔗糖变黑（炭化），并有刺激性气味气体产生：
$$\ce{C12H22O11 ->[浓H2SO4] 12C + 11H2O}$$
$$\ce{C + 2H2SO4(浓) ->[Δ] CO2 ^ + 2SO2 ^ + 2H2O}$$
（黑色固体体积膨胀，因生成 $\ce{CO2}$、$\ce{SO2}$ 气体所致。）
- 记忆：**"脱水脱的是有机物中的'氢氧水'，发生了化学变化（炭化）。"**

### 3. 强氧化性

> 由 $\ce{+6}$ 价硫体现，浓硫酸是强氧化剂，本身被还原为 $\ce{SO2}$。

**(1) 与金属反应（加热）**

$$\ce{Cu + 2H2SO4(浓) ->[Δ] CuSO4 + SO2 ^ + 2H2O}$$

- 现象：铜片溶解、有刺激性气味气体、溶液变蓝（$\ce{Cu^{2+}}$）。
- 注意：随着反应进行，硫酸变稀，**稀硫酸不能氧化 $\ce{Cu}$**，故反应到一定程度停止。
- 氧化产物：$\ce{CuSO4}$；还原产物：$\ce{SO2}$。**浓硫酸既作氧化剂又表现酸性**（生成 $\ce{CuSO4}$ 的部分）。

**(2) 常温钝化**

- 冷的浓硫酸使 $\ce{Fe}$、$\ce{Al}$ 表面生成**致密氧化膜**，阻止反应继续进行，称为"钝化"。
- 应用：常温下可用**铁罐、铝罐**盛装浓硫酸（注意：加热时 $\ce{Fe}$、$\ce{Al}$ 会与浓硫酸反应）。
- 钝化是**化学变化**，不是不反应。

**(3) 与非金属反应（加热）**

$$\ce{C + 2H2SO4(浓) ->[Δ] CO2 ^ + 2SO2 ^ + 2H2O}$$

$$\ce{S + 2H2SO4(浓) ->[Δ] 3SO2 ^ + 2H2O}$$

**(4) 与还原性化合物反应**

$$\ce{H2S + H2SO4(浓) -> S v + SO2 ^ + 2H2O}$$

$$\ce{2HBr + H2SO4(浓) -> Br2 + SO2 ^ + 2H2O}$$

## 三、浓硫酸的稀释

- **操作**：将浓硫酸**沿器壁缓慢倒入水中**，不断搅拌，使热量及时散失。
- **切不可**将水倒入浓硫酸中（水浮于硫酸表面，放出大量热导致暴沸飞溅）。

## 四、浓硫酸与稀硫酸性质对比

| 项目 | 稀硫酸 | 浓硫酸 |
| --- | --- | --- |
| 电离情况 | 完全电离，以 $\ce{H+}$、$\ce{SO4^{2-}}$ 存在 | 主要以 $\ce{H2SO4}$ 分子存在 |
| 酸的通性 | **显著**（与活泼金属、碱、碱性氧化物反应） | 弱（几乎不电离） |
| 吸水性 | 无 | **有**（干燥剂） |
| 脱水性 | 无 | **有**（使有机物炭化） |
| 氧化性 | 仅 $\ce{H+}$ 的氧化性（与活泼金属放 $\ce{H2}$） | **$\ce{S}$ 的强氧化性**（钝化、氧化 $\ce{Cu}$/$\ce{C}$） |
| 与 $\ce{Cu}$ | 不反应 | 加热生成 $\ce{CuSO4}$、$\ce{SO2}$ |

## 典型例题

### 例题 1

**题目**：某同学将浓硫酸与 $\ce{Cu}$ 片共热，收集到标准状况下 $\ce{SO2}$ 气体 $2.24\ \mathrm{L}$。求被氧化的 $\ce{Cu}$ 的物质的量。

**分析**：由方程式 $\ce{Cu + 2H2SO4(浓) ->[Δ] CuSO4 + SO2 ^ + 2H2O}$ 可知，生成 $\ce{SO2}$ 的物质的量等于被氧化 $\ce{Cu}$ 的物质的量。$n(\ce{SO2}) = \dfrac{2.24\ \mathrm{L}}{22.4\ \mathrm{L\cdot mol^{-1}}} = 0.1\ \mathrm{mol}$。

**解答**：$n(\ce{Cu}) = n(\ce{SO2}) = 0.1\ \mathrm{mol}$。被氧化的 $\ce{Cu}$ 为 $0.1\ \mathrm{mol}$。

**点评**：这是"氧化还原 + 物质的量"的基础计算。关键是把化学方程式与物质的量建立对应关系，注意 $\ce{Cu}$ 与 $\ce{SO2}$ 的化学计量比为 $1:1$。

### 例题 2

**题目**：下列有关浓硫酸的说法错误的是（　）
A. 浓硫酸具有吸水性，可作干燥剂
B. 浓硫酸使蔗糖变黑，体现其脱水性
C. 常温下浓硫酸与 $\ce{Fe}$ 反应放出 $\ce{SO2}$
D. 稀释浓硫酸时应将浓硫酸沿器壁缓缓倒入水中并搅拌

**分析**：A 正确；B 正确（炭化是脱水性）；C **错误**——常温下浓硫酸使 $\ce{Fe}$ 钝化（生成致密氧化膜），加热时才放出 $\ce{SO2}$；D 正确（稀释操作规范）。

**解答**：选 **C**。

**点评**：本题考查"钝化"这一易错概念。常温钝化是化学变化但不放出气体；只有加热时才发生剧烈氧化反应。

## 易错提醒

> [!warning]
> - **稀硫酸与浓硫酸性质不同**：稀硫酸体现酸的通性（$\ce{H+}$），浓硫酸体现吸水性、脱水性、强氧化性。不能用"稀硫酸"的性质去推断"浓硫酸"。
> - **钝化 ≠ 不反应**：常温浓硫酸使 $\ce{Fe}$、$\ce{Al}$ 钝化是化学变化；加热时仍会反应。
> - **脱水性 ≠ 吸水性**：吸水是吸收游离水（物质不变），脱水是夺取有机物中氢氧元素（发生炭化等化学变化）。
> - **浓硫酸氧化 $\ce{Cu}$ 时被还原为 $\ce{SO2}$**（$\ce{+6 -> +4}$），不是 $\ce{H2}$，也不是 $\ce{S}$。
> - 浓硫酸作干燥剂不能干燥 $\ce{NH3}$（碱性气体）和 $\ce{H2S}$、$\ce{HBr}$、$\ce{HI}$（还原性气体）。
> - 稀释浓硫酸**只能"酸入水"**，不能"水入酸"。
