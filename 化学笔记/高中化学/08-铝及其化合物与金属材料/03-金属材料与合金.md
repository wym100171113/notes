# 金属材料与合金

> [!abstract] 概览
> 本笔记介绍金属材料的基本概念——**合金**的定义、性质与常见种类，以及**金属的冶炼方法**（电解法、热还原法、热分解法）。合金是高考的常考概念，重点把握"合金硬度比纯金属大、熔点比纯金属低"的性质特点；金属冶炼方法则与金属活动性顺序对应，是推断题与工艺题的基础。

## 核心概念

### 合金

- **定义**：由一种金属与另一种（或几种）金属（或非金属）**熔合**而形成的具有金属特性的物质。
- 注意：合金是**混合物**，不是纯净物；形成过程是熔合（物理过程），但合金内部存在金属键。

### 合金的性质

| 性质 | 与纯金属比较 |
| --- | --- |
| 硬度 | **更大**（合金的硬度一般大于各成分金属） |
| 熔点 | **更低**（合金的熔点一般低于各成分金属） |
| 导电性、导热性 | 比纯金属**差** |
| 抗腐蚀能力 | 一般**更强**（如不锈钢） |

> [!tip] 记忆口诀
> 合金"硬度大、熔点低、导电导热差、抗腐蚀强"。为什么熔点低？因为不同原子半径不同，破坏了金属晶体的整齐排列，使金属键变弱，熔点下降。

## 重点知识：常见合金

### 1. 铁合金（黑色金属材料）

- **生铁**：含碳量 $2\% \sim 4.3\%$，硬而脆，可铸不可锻。
- **钢**：含碳量 $0.03\% \sim 2\%$，韧性好，可锻可铸。
- **碳素钢**：按含碳量分为低碳钢（含碳 $\le 0.3\%$）、中碳钢、高碳钢（含碳 $> 0.6\%$）。
- **合金钢**：在碳素钢中加入 $\ce{Cr}$、$\ce{Mn}$、$\ce{Ni}$、$\ce{W}$ 等合金元素，如**不锈钢**（含 $\ce{Cr}$ 约 $12\%$、$\ce{Ni}$），抗腐蚀。

### 2. 铝合金

- 密度小、强度大、抗腐蚀，广泛用于飞机、汽车、门窗等。
- **硬铝**：含 $\ce{Cu}$、$\ce{Mg}$、$\ce{Mn}$、$\ce{Si}$ 等，强度接近钢材而密度小，用于飞机结构材料。

### 3. 铜合金

- **青铜**：铜锡合金（我国商周时期已使用），耐磨、耐腐蚀。
- **黄铜**：铜锌合金，用于制造仪器零件。
- **白铜**：铜镍合金。

### 4. 新型合金

- 储氢合金（如 $\ce{LaNi5}$）：用于氢能源的储存与运输。
- 钛合金：强度高、耐高温、耐腐蚀、"亲生物"金属，用于航天与人体植入材料。
- 形状记忆合金：镍钛合金等。

## 重点知识：金属的冶炼方法

金属冶炼的本质：把金属阳离子**还原**为金属单质，即 $\ce{M^{n+} + ne^- -> M}$。方法由金属的**活动性强弱**决定：

### 1. 电解法（冶炼活泼金属：$\ce{K}$、$\ce{Ca}$、$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）

- 电解熔融 $\ce{NaCl}$：$2\ce{NaCl} \xrightarrow{电解} 2\ce{Na} + \ce{Cl2 ^}$
- 电解熔融 $\ce{MgCl2}$：$\ce{MgCl2} \xrightarrow{电解} \ce{Mg} + \ce{Cl2 ^}$
- 电解熔融 $\ce{Al2O3}$（加冰晶石助熔）：$2\ce{Al2O3} \xrightarrow[冰晶石]{电解} 4\ce{Al} + 3\ce{O2 ^}$

### 2. 热还原法（冶炼中等活泼金属：$\ce{Zn}$、$\ce{Fe}$、$\ce{Sn}$、$\ce{Pb}$、$\ce{Cu}$）

用 $\ce{C}$、$\ce{CO}$、$\ce{H2}$、$\ce{Al}$ 等作还原剂：

- $\ce{Fe2O3 + 3CO \xrightarrow{高温} 2Fe + 3CO2}$（高炉炼铁）
- $\ce{2CuO + C \xrightarrow{高温} 2Cu + CO2 ^}$
- $\ce{ZnO + CO \xrightarrow{高温} Zn + CO2}$
- 铝热反应：$\ce{2Al + Fe2O3 \xrightarrow{高温} Al2O3 + 2Fe}$（冶炼难熔金属 $\ce{V}$、$\ce{Cr}$、$\ce{Mn}$ 等）

### 3. 热分解法（冶炼不活泼金属：$\ce{Hg}$、$\ce{Ag}$）

- $2\ce{HgO} \xrightarrow{\Delta} 2\ce{Hg} + \ce{O2 ^}$
- $2\ce{Ag2O} \xrightarrow{\Delta} 4\ce{Ag} + \ce{O2 ^}$

### 4. 金属活动性与冶炼方法对照

| 金属活动性 | 示例 | 冶炼方法 |
| --- | --- | --- |
| $\ce{K Ca Na Mg Al}$ | 活泼金属 | **电解熔融**法 |
| $\ce{Zn Fe Sn Pb Cu}$ | 中等活泼 | **热还原**法（$\ce{C}$、$\ce{CO}$、$\ce{H2}$、$\ce{Al}$） |
| $\ce{Hg Ag}$ | 不活泼 | **热分解**法 |
| $\ce{Pt Au}$ | 极不活泼 | 以**游离态**存在于自然界 |

> [!warning] 冶炼方法与活动性的对应
> "越活泼越难还原"，所以活泼金属（$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）必须用电解熔融法，中等活泼金属（$\ce{Fe}$、$\ce{Cu}$）用热还原法，不活泼金属（$\ce{Hg}$、$\ce{Ag}$）加热分解即可。$\ce{Pt}$、$\ce{Au}$ 以单质形式存在，无需冶炼。

## 典型例题

### 例题 1：合金的性质

**题目**：下列有关合金的说法正确的是（ ）
A. 合金的熔点一般比成分金属的熔点高
B. 合金的硬度一般比成分金属的硬度小
C. 合金是混合物，具有金属特性
D. 合金中只含金属元素，不含非金属元素

**分析**：合金的熔点比成分金属**低**（A 错）；硬度比成分金属**大**（B 错）；合金是混合物且具有金属特性（C 对）；合金可含非金属元素，如钢含碳（D 错）。

**解答**：答案：**C**。

**点评**：合金概念的两个核心性质是"硬度大、熔点低"，与纯金属比较记忆。合金是混合物但具有金属特性，这是判断合金身份的标准。

### 例题 2：金属冶炼方法判断

**题目**：下列金属的冶炼方法错误的是（ ）
A. $\ce{Al}$——电解熔融 $\ce{Al2O3}$
B. $\ce{Fe}$——$\ce{CO}$ 还原 $\ce{Fe2O3}$
C. $\ce{Hg}$——加热分解 $\ce{HgO}$
D. $\ce{Na}$——热还原 $\ce{NaCl}$

**分析**：$\ce{Na}$ 是活泼金属，必须用**电解熔融 $\ce{NaCl}$** 冶炼，不能用热还原法（$\ce{Na}$ 太活泼，还原剂无法还原）。A 铝电解熔融 $\ce{Al2O3}$ 正确；B 铁用 $\ce{CO}$ 还原正确；C 汞加热分解 $\ce{HgO}$ 正确。

**解答**：答案：**D**。

**点评**：金属冶炼方法与活动性严格对应。看到活泼金属（$\ce{K}$、$\ce{Ca}$、$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）直接选"电解熔融"，中等活泼金属选"热还原"，不活泼金属选"热分解"。

## 易错提醒

> [!warning] 易错点清单
> 1. 合金是**混合物**，不是纯净物。
> 2. 合金的熔点**低于**成分金属，硬度**大于**成分金属——方向不要记反。
> 3. 钢是铁碳合金（含碳 $0.03\%\sim2\%$），不是纯铁。
> 4. 活泼金属（$\ce{Na}$、$\ce{Mg}$、$\ce{Al}$）冶炼必须用电解熔融法，不能用热还原法。
> 5. 电解冶炼 $\ce{Al}$ 用 $\ce{Al2O3}$（加冰晶石），不用 $\ce{AlCl3}$。
> 6. 金属腐蚀（如钢铁生锈）是金属与环境物质发生氧化还原反应，与金属活动性密切相关。
