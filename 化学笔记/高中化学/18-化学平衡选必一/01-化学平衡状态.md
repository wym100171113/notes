# 化学平衡状态

> [!abstract] 概览
> 本笔记回答"什么是化学平衡、平衡有哪些特征、怎样判断反应是否达平衡"。核心是理解**动态平衡**的本质（$v_\text{正} = v_\text{逆} \neq 0$）与**平衡标志**的判断方法——尤其是"哪些量不变才能作为平衡标志"这一高频考点。

## 核心概念

### 1. 可逆反应

**定义**：在同一条件下，既能向正反应方向进行，又能向逆反应方向进行的化学反应。

**特点**：
- 用符号 $\rightleftharpoons$ 表示；
- 反应物不能完全转化为生成物，反应有限度；
- 正、逆反应同时进行、互为前提。

**示例**：$\ce{N2 + 3H2 <=> 2NH3}$、$\ce{SO2 + O2 <=> 2SO3}$、$\ce{Cl2 + H2O <=> HCl + HClO}$。

> [!note] 典型可逆反应
> 高中常考：$\ce{N2 + 3H2 <=> 2NH3}$、$\ce{2SO2 + O2 <=> 2SO3}$、$\ce{H2 + I2 <=> 2HI}$（$\Delta n = 0$）、$\ce{2NO2 <=> N2O4}$、$\ce{Cl2 + H2O}$、$\ce{NH3 + H2O}$ 等。注意 $\ce{NaHCO3}$ 受热分解、$\ce{NH4Cl}$ 等并非严格意义上的"同一条件"可逆。

### 2. 化学平衡状态

**定义**：在一定条件下的可逆反应中，**正反应速率与逆反应速率相等**，反应混合物中**各物质的浓度不再改变**，此时反应达到了化学平衡状态。

**化学平衡的五大特征（"逆等动定变"）**：

| 特征 | 含义 |
| --- | --- |
| **逆** | 只有可逆反应才有化学平衡 |
| **等** | $v_\text{正} = v_\text{逆} \neq 0$（同一物质表示） |
| **动** | 动态平衡，反应仍在进行，速率不为零 |
| **定** | 平衡时各组分浓度、百分含量不再改变 |
| **变** | 条件改变，平衡状态可能被破坏并建立新平衡 |

> [!warning] "等"的含义
> $v_\text{正} = v_\text{逆}$ 是指**同一物质**表示的正逆速率相等。若用不同物质表示，需满足 $v_\text{正}(\ce{A}) : v_\text{逆}(\ce{B}) = a : b$（化学计量数比），否则即使数值相等也不一定是平衡。

## 重点知识

### 1. 化学平衡的建立过程

以 $\ce{N2 + 3H2 <=> 2NH3}$ 为例：

- 反应开始时：$v_\text{正}$ 最大，$v_\text{逆} = 0$；
- 反应进行中：$v_\text{正}$ 逐渐减小，$v_\text{逆}$ 逐渐增大；
- 达到平衡：$v_\text{正} = v_\text{逆} \neq 0$，浓度不再变化。

**注意**：平衡建立后，正逆反应"仍在进行"，只是速率相等，各物质浓度不变。这就是"动态平衡"。

### 2. 平衡状态的判断标志

判断一个可逆反应是否达平衡，可以从**本质标志**和**宏观标志**两方面入手。

#### (1) 本质标志（直接依据）

- 同一种物质的正反应速率等于逆反应速率：$v_\text{正}(\ce{A}) = v_\text{逆}(\ce{A})$；
- 不同物质：$v_\text{正}(\ce{A}) : v_\text{逆}(\ce{B}) = a : b$（计量数比）。

#### (2) 宏观标志（间接依据）

| 标志 | 说明 |
| --- | --- |
| 各组分的**浓度/物质的量/物质的量分数**不再改变 | 平衡时必成立 |
| 反应物的**转化率**不再改变 | 平衡时必成立 |
| 体系的**颜色**不再改变 | 适用于有颜色物质，如 $\ce{2NO2 <=> N2O4}$（红棕色 $\ce{NO2}$） |
| 体系的**总压强**不再改变 | **仅当 $\Delta n(\text{g}) \neq 0$ 时**才是平衡标志 |
| 体系的**平均摩尔质量**不再改变 | 当 $\Delta n(\text{g}) \neq 0$ 且组分不同时可用 |
| 体系的**密度**不再改变 | 恒容且有气体计量数变化时可用 |
| 混合气体中某组分的**体积分数**不再改变 | 平衡时必成立 |

> [!warning] 压强/密度作为标志的局限性
> - 对于 $\ce{H2(g) + I2(g) <=> 2HI(g)}$（$\Delta n = 0$），恒容时总压强**始终不变**，不能作为平衡标志；
> - 对于全为气体且恒容、$\Delta n = 0$ 的反应，密度始终不变，不能作为标志；
> - 判断原则：**只有"随反应进行会发生变化的量"在某时刻后不再变化，才能作为平衡标志**；若该量一直不变，则不能判断。

### 3. 平衡标志判断的一般步骤

1. 分析反应特点：是否可逆？是否有气体计量数变化？是否有有色物质？
2. 列出随反应进行可能变化的量；
3. 若某个量在反应过程中**本来就恒定**，则它不能作为标志；若**本来变化、平衡时不再变**，则能作为标志。

## 典型例题

### 例题 1（平衡标志判断）

**题目**：恒温恒容下，对可逆反应 $\ce{N2(g) + 3H2(g) <=> 2NH3(g)}$，下列说法中能作为反应达平衡标志的是？
A. $\ce{N2}$、$\ce{H2}$、$\ce{NH3}$ 的分子数之比为 $1:3:2$
B. 混合气体的密度保持不变
C. $v_\text{正}(\ce{N2}) : v_\text{逆}(\ce{NH3}) = 1:2$
D. 混合气体的总压强保持不变

**分析**：
- A：分子数之比等于计量数比，只能说明投料比例，不能说明平衡；
- B：恒容且全为气体，气体总质量不变、体积不变，密度**始终不变**，不能作标志；
- C：$v_\text{正}(\ce{N2}) : v_\text{逆}(\ce{NH3}) = 1:2$，换算成同一物质：$v_\text{正}(\ce{N2}) \times 2 = v_\text{逆}(\ce{NH3}) \times \frac{1}{2} \times 2$... 实际用计量数校验：平衡时 $v_\text{正}(\ce{N2}) : v_\text{逆}(\ce{NH3}) = 1:2$ 恰好符合计量数比，说明正逆速率相等，能作标志；
- D：$\Delta n(\text{g}) = 1+3-2 = 2 \neq 0$，总压强随反应进行而变化，平衡时不变，能作标志。

**解答**：C、D。

**点评**：B 是典型陷阱——恒容全气体反应，密度不是"变量"。C 需把不同物质的正逆速率按计量数换算后判断。

### 例题 2（平衡建立的图像理解）

**题目**：反应 $\ce{2SO2(g) + O2(g) <=> 2SO3(g)}$，起始时只充入 $\ce{SO2}$ 和 $\ce{O2}$。描述 $v_\text{正}$、$v_\text{逆}$ 随时间的变化趋势，并指出平衡建立时刻的特征。

**分析**：起始 $v_\text{正}$ 最大、$v_\text{逆} = 0$；随反应进行 $v_\text{正}$ 减小、$v_\text{逆}$ 增大；某时刻二者相等即平衡。

**解答**：平衡建立时 $v_\text{正} = v_\text{逆} \neq 0$，此后各物质浓度不再改变，但反应仍在双向进行。图像上 $v_\text{正}$ 与 $v_\text{逆}$ 曲线在平衡时刻相交且保持重合。

**点评**：这是"动"字特征的核心——平衡不是反应停止，而是正逆速率相等的动态过程。

### 例题 3（$\Delta n = 0$ 反应的标志辨析）

**题目**：恒温恒容下，反应 $\ce{H2(g) + I2(g) <=> 2HI(g)}$ 达平衡的标志是？
A. 容器内压强保持不变
B. 气体颜色不再变化
C. $\ce{H2}$ 的浓度保持不变
D. 气体平均摩尔质量保持不变

**分析**：$\Delta n(\text{g}) = 0$，恒容下总压强、气体总物质的量、平均摩尔质量**始终不变**，不能作标志；$\ce{I2(g)}$ 有颜色，颜色不变可作标志；$\ce{H2}$ 浓度不变可作标志。

**解答**：B、C。

**点评**：对 $\Delta n = 0$ 的反应，压强、密度、平均摩尔质量往往恒定，**不能**作为平衡标志；颜色、浓度、转化率等仍可用。

## 易错提醒

> [!warning]
> 1. **"浓度不变"才代表平衡**：不是"浓度相等"或"浓度之比等于计量数比"。比例恒定可能是投料所致，不一定是平衡。
> 2. **$v_\text{正} = v_\text{逆}$ 必须针对同一物质**：不同物质需按计量数换算后再比较。
> 3. **恒容全气体且 $\Delta n = 0$，压强不能作标志**：压强一直不变。
> 4. **"动态平衡"不是反应停止**：$v_\text{正} = v_\text{逆} \neq 0$，反应仍在进行。
> 5. **有颜色反应的颜色标志**：只有涉及有色物质的体系，颜色不变才能作为标志（如 $\ce{NO2}$ 红棕色）。
