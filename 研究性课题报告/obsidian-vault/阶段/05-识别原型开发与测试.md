# 第五阶段：识别原型开发与测试

> [!info] 阶段概览
> **时间**：2027.05.01 ~ 2027.06.30（2 个月）
> **方法**：应用开发、用户测试、反馈收集
> **产出**：可运行的垃圾分类识别原型 + 用户测试报告

## 任务清单

### 任务 1：模型导出与部署准备

- [ ] 将最优 PyTorch 模型导出为 TorchScript 或 ONNX 格式
- [ ] 测试模型推理速度（单张图片推理时间）
- [ ] 优化推理管道（预处理 → 推理 → 后处理）
- [ ] 编写模型推理的 Python 接口

### 任务 2：开发识别原型

**方案 A：网页端（推荐）**

- [ ] 使用 Gradio 或 Streamlit 搭建 Web 界面
- [ ] 界面功能：上传图片 → 显示分类结果 + 置信度
- [ ] 支持拖拽上传和拍照上传
- [ ] 美观的 UI 设计

**方案 B：本地桌面应用**

- [ ] 使用 Tkinter 或 PyQt 搭建 GUI
- [ ] 界面功能：选择图片 → 显示分类结果

**方案 C：命令行工具**

- [ ] 简单的命令行脚本，输入图片路径，输出分类结果
- [ ] 方便批量测试

- [ ] 选择一种方案实现（推荐方案 A）
- [ ] 编写原型代码
- [ ] 自测：各种垃圾图片输入 → 检查输出是否正确

### 任务 3：用户测试

- [ ] 邀请 10-20 名同学试用原型
- [ ] 收集分类准确率反馈
- [ ] 记录易混淆的类别（如：玻璃瓶 vs 塑料瓶）
- [ ] 收集界面易用性反馈
- [ ] 汇总测试数据

### 任务 4：最终优化迭代

- [ ] 根据用户反馈调整模型
- [ ] 优化界面交互
- [ ] 修复 bug
- [ ] 最终版本冻结

> [!question] 部署方案选择
> - **Gradio**：最快上手，5 行代码即可生成 Web 界面，支持 HuggingFace Spaces 免费部署
> - **Streamlit**：功能更丰富，界面更美观，适合复杂交互
> - **Tkinter**：无需网络，纯本地运行，但界面较简陋

## 阶段产出

- [ ] 可运行的垃圾分类识别原型
- [ ] 用户测试报告（含准确率统计）
- [ ] 优化后的最终模型
