# 离子共存与离子检验

> [!abstract] 概览
> 判断溶液中离子能否**大量共存**，本质是判断"离子之间能否发生反应使浓度显著减小"。能反应则不共存。
> 离子共存是高考选择题的高频考点，需要同时考虑：**复分解（生成沉淀、气体、水、弱电解质）、氧化还原、络合、双水解**以及**隐含条件**（颜色、酸碱性、环境要求）。
> 离子检验则强调"特征现象 + 排除干扰"。完整的检验方法见根目录 [[常见离子的检验方法]]。

## 核心概念

### 1. 离子共存的本质

"离子能大量共存" = 离子之间**不发生任何反应**。任一离子对满足以下情况之一，则**不能共存**：

1. 生成**沉淀**：$\ce{Ag+ + Cl- -> AgCl v}$，$\ce{Ba^2+ + SO4^2- -> BaSO4 v}$，$\ce{Ca^2+ + CO3^2- -> CaCO3 v}$；
2. 生成**气体**：$\ce{H+ + CO3^2- -> CO2 ^ + H2O}$，$\ce{NH4+ + OH- ->[△] NH3 ^ + H2O}$；
3. 生成**弱电解质/水**：$\ce{H+ + OH- -> H2O}$，$\ce{H+ + CH3COO- -> CH3COOH}$；
4. 发生**氧化还原**：$\ce{Fe^3+ + I- -> Fe^2+ + 1/2 I2}$，$\ce{MnO4- + Fe^2+}$，$\ce{NO3-（酸性）+ Fe^2+}$；
5. 发生**络合**：$\ce{Fe^3+ + 3SCN- <=> Fe(SCN)3}$（血红色）；
6. 发生**双水解**：$\ce{Al^3+}$ 与 $\ce{HCO3-}$、$\ce{CO3^2-}$、$\ce{AlO2-}$、$\ce{S^2-}$ 等相互促进水解。

### 2. 常见不能共存的离子对速查

| 类型 | 不能共存的离子对 |
| --- | --- |
| 生成沉淀 | $\ce{Ag+}$ 与 $\ce{Cl-}$、$\ce{Ba^2+}$ 与 $\ce{SO4^2-}$、$\ce{Ca^2+}$ 与 $\ce{CO3^2-}$、$\ce{Ba^2+}$ 与 $\ce{CO3^2-}$、$\ce{Ag+}$ 与 $\ce{CO3^2-}$、$\ce{Mg^2+}$ 与 $\ce{OH-}$、$\ce{Cu^2+}$ 与 $\ce{OH-}$、$\ce{Fe^3+}$ 与 $\ce{OH-}$ |
| 生成气体 | $\ce{H+}$ 与 $\ce{CO3^2-}$/$\ce{HCO3-}$/$\ce{SO3^2-}$/$\ce{S^2-}$；$\ce{NH4+}$ 与 $\ce{OH-}$（加热） |
| 生成水/弱电解质 | $\ce{H+}$ 与 $\ce{OH-}$、$\ce{CH3COO-}$、$\ce{ClO-}$、$\ce{F-}$ |
| 氧化还原 | $\ce{Fe^3+}$ 与 $\ce{I-}$/$\ce{S^2-}$；$\ce{MnO4-}$ 与 $\ce{Fe^2+}$/$\ce{I-}$/$\ce{SO3^2-}$/$\ce{Cl-}$（酸性）；$\ce{ClO-}$ 与 $\ce{I-}$/$\ce{S^2-}$；酸性 $\ce{NO3-}$ 与 $\ce{Fe^2+}$/$\ce{I-}$/$\ce{SO3^2-}$ |
| 络合 | $\ce{Fe^3+}$ 与 $\ce{SCN-}$ |
| 双水解 | $\ce{Al^3+}$ 与 $\ce{HCO3-}$、$\ce{CO3^2-}$、$\ce{AlO2-}$、$\ce{S^2-}$；$\ce{Fe^3+}$ 与 $\ce{CO3^2-}$、$\ce{HCO3-}$ |

> [!warning] $\ce{NO3-}$ 的"酸性才氧化"
> $\ce{NO3-}$ 在中性、碱性溶液中氧化性很弱，可与 $\ce{Fe^2+}$、$\ce{I-}$ 等共存；但**在酸性条件下**（相当于硝酸），$\ce{NO3-}$ 具有强氧化性，不能与 $\ce{Fe^2+}$、$\ce{I-}$、$\ce{SO3^2-}$、$\ce{S^2-}$ 等还原性离子共存。

## 重点知识

### 1. 隐含条件（审题陷阱）

离子共存题常附加"隐含条件"，必须先转化为离子环境：

| 隐含条件 | 含义 | 注意 |
| --- | --- | --- |
| 无色溶液 | 排除有色离子 | $\ce{Cu^2+}$（蓝）、$\ce{Fe^3+}$（棕黄）、$\ce{Fe^2+}$（浅绿）、$\ce{MnO4-}$（紫红）、$\ce{Cr2O7^2-}$（橙红） |
| pH < 7 / 酸性溶液 / 加甲基橙变红 | 溶液含大量 $\ce{H+}$ | 排除与 $\ce{H+}$ 反应的离子（$\ce{OH-}$、$\ce{CO3^2-}$、$\ce{HCO3-}$、$\ce{AlO2-}$、$\ce{SO3^2-}$ 等） |
| pH > 7 / 碱性溶液 / 加酚酞变红 | 溶液含大量 $\ce{OH-}$ | 排除与 $\ce{OH-}$ 反应的离子（$\ce{H+}$、$\ce{NH4+}$、$\ce{Mg^2+}$、$\ce{Al^3+}$、$\ce{Fe^3+}$、$\ce{Cu^2+}$、$\ce{HCO3-}$ 等） |
| 能与 $\ce{Al}$ 反应放出 $\ce{H2}$ | 溶液为**强酸或强碱** | 分两种情况讨论；酸性时 $\ce{NO3-}$ 不行（与 $\ce{Al}$ 生成 $\ce{NO}$ 不放 $\ce{H2}$） |
| 由水电离的 $c(\ce{H+})=1\times 10^{-13}\ \text{mol/L}$ | 水的电离被抑制，溶液可能**强酸或强碱** | 分两种情况讨论 |
| "澄清透明" | 不产生浑浊即可 | 允许有色离子（不是"无色"） |

> [!tip] "澄清透明"≠"无色"
> 题干写"澄清透明"时，溶液可以有色（如 $\ce{CuSO4}$ 溶液是蓝色且澄清透明）；题干写"无色"时才排除有色离子。这是高频文字陷阱。

### 2. 离子共存判断的解题程序

1. **先看颜色**：无色溶液排除有色离子；
2. **再看酸碱环境**：把隐含条件转化为 $\ce{H+}$ 或 $\ce{OH-}$ 环境；
3. **逐对排查**：将每个选项中的离子与环境的 $\ce{H+}$/$\ce{OH-}$ 及彼此之间逐一检查是否能发生复分解、氧化还原、络合、双水解；
4. **注意附加信息**：如"$\ce{Al}$ 能放出 $\ce{H2}$""由水电离的 $\ce{H+}$ 浓度"需分酸、碱两种情形。

### 3. 常见离子的检验（要点）

| 离子 | 检验方法 | 现象 | 离子方程式 |
| --- | --- | --- | --- |
| $\ce{Cl-}$ | 加稀 $\ce{HNO3}$ 酸化，再加 $\ce{AgNO3}$ | 白色沉淀 | $\ce{Ag+ + Cl- -> AgCl v}$ |
| $\ce{SO4^2-}$ | 加稀 $\ce{HCl}$ 酸化（无沉淀），再加 $\ce{BaCl2}$ | 白色沉淀 | $\ce{Ba^2+ + SO4^2- -> BaSO4 v}$ |
| $\ce{CO3^2-}$ | 加稀盐酸，气体通入澄清石灰水 | 石灰水变浑浊 | $\ce{CO3^2- + 2H+ -> CO2 ^ + H2O}$ |
| $\ce{NH4+}$ | 加浓 $\ce{NaOH}$ 加热，湿润红色石蕊试纸检验 | 试纸变蓝 | $\ce{NH4+ + OH- ->[△] NH3 ^ + H2O}$ |
| $\ce{Fe^3+}$ | 加 $\ce{KSCN}$ 溶液 | 溶液变血红色 | $\ce{Fe^3+ + 3SCN- <=> Fe(SCN)3}$ |
| $\ce{Fe^2+}$ | 加 $\ce{KSCN}$ 无现象，再滴氯水变红；或加 $\ce{NaOH}$ 白色→灰绿→红褐 | 先无后红 | $\ce{2Fe^2+ + Cl2 -> 2Fe^3+ + 2Cl-}$ |
| $\ce{Al^3+}$ | 加 $\ce{NaOH}$ 至过量，先沉淀后溶解 | 白色沉淀溶解 | $\ce{Al^3+ + 3OH- -> Al(OH)3 v}$；$\ce{Al(OH)3 + OH- -> [Al(OH)4]-}$ |
| $\ce{Na+}$/$\ce{K+}$ | 焰色反应 | 黄 / 紫色（钴玻璃） | — |

> [!note] 检验干扰排除
> 检验 $\ce{Cl-}$ 时先加稀 $\ce{HNO3}$ 排除 $\ce{CO3^2-}$、$\ce{SO3^2-}$ 等干扰；检验 $\ce{SO4^2-}$ 时先加稀 $\ce{HCl}$ 排除 $\ce{Ag+}$、$\ce{CO3^2-}$、$\ce{SO3^2-}$、$\ce{PO4^3-}$ 干扰（若无沉淀再滴加 $\ce{BaCl2}$）。完整内容见 [[常见离子的检验方法]]。

## 典型例题

### 例题 1（离子共存判断）

**题目**：在**无色、强酸性**溶液中，能大量共存的离子组是（　）
A. $\ce{K+}$、$\ce{Cu^2+}$、$\ce{Cl-}$、$\ce{NO3-}$
B. $\ce{Na+}$、$\ce{Fe^3+}$、$\ce{SO4^2-}$、$\ce{I-}$
C. $\ce{NH4+}$、$\ce{Mg^2+}$、$\ce{SO4^2-}$、$\ce{Cl-}$
D. $\ce{K+}$、$\ce{HCO3-}$、$\ce{Cl-}$、$\ce{NO3-}$

**分析**：A 错——$\ce{Cu^2+}$ 呈蓝色，不符合"无色"；B 错——$\ce{Fe^3+}$ 呈棕黄色且与 $\ce{I-}$ 发生氧化还原（$\ce{2Fe^3+ + 2I- -> 2Fe^2+ + I2}$），且酸性下 $\ce{NO3-}$ 也能氧化 $\ce{I-}$；C 对——四种离子相互不反应，均无色，且不消耗 $\ce{H+}$；D 错——强酸性溶液中 $\ce{HCO3-}$ 不能存在：$\ce{HCO3- + H+ -> CO2 ^ + H2O}$。

**解答**：选 **C**。

**点评**：先排除"颜色"，再检查"酸环境"，最后排查离子间反应。本题同时考查有色离子（$\ce{Cu^2+}$、$\ce{Fe^3+}$）、氧化还原（$\ce{Fe^3+}$ 与 $\ce{I-}$）、与 $\ce{H+}$ 反应（$\ce{HCO3-}$）三个层次。

### 例题 2（隐含条件 + 定量计算）

**题目**：某无色溶液只含 $\ce{Na+}$、$\ce{Mg^2+}$、$\ce{Cl-}$、$\ce{SO4^2-}$ 四种离子。测得 $n(\ce{Na+})=0.2\ \text{mol}$、$n(\ce{Mg^2+})=0.1\ \text{mol}$、$n(\ce{Cl-})=0.2\ \text{mol}$，求 $n(\ce{SO4^2-})$。

**分析**：溶液呈电中性，遵循**电荷守恒**：阳离子所带正电荷总数 = 阴离子所带负电荷总数。列出电荷守恒方程求解。

**解答**：
由电荷守恒：
$$n(\ce{Na+}) + 2n(\ce{Mg^2+}) = n(\ce{Cl-}) + 2n(\ce{SO4^2-})$$
$$0.2 + 2\times 0.1 = 0.2 + 2n(\ce{SO4^2-})$$
$$0.4 = 0.2 + 2n(\ce{SO4^2-})\ \Rightarrow\ n(\ce{SO4^2-})=0.1\ \text{mol}$$

答：$n(\ce{SO4^2-})$ 为 **0.1 mol**。

**点评**：电荷守恒是离子浓度（物质的量）计算的通法，也是离子方程式配平检验的关键工具。注意 $\ce{Mg^2+}$ 带 2 个正电荷，系数为 2。

## 易错提醒

> [!warning] 易错提醒
> - **"无色"与"澄清透明"不同**：无色才排除有色离子；澄清透明允许有色。
> - **酸性条件下 $\ce{NO3-}$ 是强氧化剂**：不能与 $\ce{Fe^2+}$、$\ce{I-}$、$\ce{SO3^2-}$、$\ce{S^2-}$ 共存；碱性或中性时则可共存。
> - **$\ce{HCO3-}$ 的两性**：既不能与 $\ce{H+}$ 大量共存，也不能与 $\ce{OH-}$ 大量共存（生成 $\ce{CO3^2-}$ + $\ce{H2O}$）。
> - **$\ce{Al^3+}$ 与 $\ce{AlO2-}$（或 $\ce{[Al(OH)4]-}$）、$\ce{HCO3-}$、$\ce{CO3^2-}$、$\ce{S^2-}$ 因双水解不能共存**。
> - **能与 $\ce{Al}$ 反应放 $\ce{H2}$ 的溶液**：可能强酸或强碱；若为强酸，还要求无 $\ce{NO3-}$。
> - **检验 $\ce{SO4^2-}$ 必须"先加酸、后加 $\ce{BaCl2}$"**：若先加 $\ce{BaCl2}$，$\ce{Ag+}$、$\ce{CO3^2-}$、$\ce{SO3^2-}$ 会产生干扰沉淀。
