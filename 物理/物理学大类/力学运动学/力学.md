# 力学

> [!abstract] 概览
> 力学是研究物体机械运动规律及其应用的物理学分支，是整个物理学的基础。它涵盖运动学、动力学、静力学、万有引力、振动与波等内容，从牛顿运动定律出发，建立起描述宏观物体运动的完整理论体系。本文件作为力学学科的总览索引，并指向同目录下的具体专题笔记。

## 学科框架

- **运动学**：描述运动的几何性质，不涉及原因
- **动力学**：牛顿运动定律，力与运动的关系
- **静力学**：平衡条件、力矩、刚体平衡
- **万有引力**：开普勒定律、轨道运动、壳层定理
- **功与能**：动能定理、机械能守恒
- **动量与碰撞**：动量守恒、冲量、碰撞
- **振动**：简谐运动、阻尼振动、受迫振动
- **波动**：机械波的传播与叠加

## 核心概念

- **牛顿运动定律**：惯性、$F = ma$、作用与反作用
- **守恒律**：能量、动量、角动量守恒
- **万有引力**：$F = G m_1 m_2 / r^2$，天体运动的根源
- **简谐运动**：$\ddot{x} + \omega^2 x = 0$，最基础的周期运动
- **功能原理**：功是能量转化的量度

## 与高中物理的衔接
