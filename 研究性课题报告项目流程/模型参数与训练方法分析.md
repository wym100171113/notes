# CNN垃圾分类识别模型参数与训练方法分析

## 1. 模型架构概述

本项目采用 **MobileNetV2** 作为骨干网络，通过迁移学习实现25类细粒度垃圾分类识别。MobileNetV2是一种轻量级卷积神经网络，具有以下特点：

- **倒残差结构（Inverted Residuals）**：先扩展通道数，再进行深度可分离卷积，最后压缩
- **线性瓶颈（Linear Bottlenecks）**：在低维空间使用线性激活，避免信息丢失
- **深度可分离卷积（Depthwise Separable Convolutions）**：大幅减少参数量和计算量

### 1.1 模型结构

```
输入层：224×224×3 RGB图像
↓
Rescaling层：像素值归一化到[0,1]
↓
MobileNetV2骨干网络（ImageNet预训练，冻结/部分解冻）
↓
全局平均池化层：将特征图压缩为向量
↓
Dropout层（0.3）：防止过拟合
↓
全连接层：256个神经元，ReLU激活
↓
Dropout层（0.3）：防止过拟合
↓
输出层：25个神经元，Softmax激活
```

## 2. 模型参数详情

### 2.1 核心参数

| 参数类别      | 参数名称     | 参数值       | 说明               |
| --------- | -------- | --------- | ---------------- |
| **输入参数**  | 输入尺寸     | 224×224×3 | 标准ImageNet输入尺寸   |
|           | 通道数      | 3         | RGB三通道           |
| **骨干网络**  | 预训练权重    | ImageNet  | 在ImageNet数据集上预训练 |
|           | 包含顶部     | False     | 移除原始分类层          |
|           | 总层数      | 约154层     | MobileNetV2标准结构  |
| **分类头参数** | 全局平均池化   | -         | 将特征图转换为特征向量      |
|           | Dropout率 | 0.3       | 30%的神经元随机失活      |
|           | 隐藏层神经元数  | 256       | 全连接层宽度           |
|           | 输出神经元数   | 25        | 对应25个垃圾类别        |
| **总参数量**  | 可训练参数    | ~259万     | 包含分类头和部分骨干网络参数   |

### 2.2 参数量分布

- **MobileNetV2骨干网络**：约230万参数（部分冻结/解冻）
- **分类头**：约29万参数
  - 全局平均池化：0参数
  - Dropout：0参数
  - 全连接层：256×(512+1) ≈ 13.1万参数（假设输入维度为512）
  - 输出层：25×(256+1) ≈ 6.4万参数

## 3. 训练方法

### 3.1 两阶段迁移学习策略

#### **阶段一：分类头训练（冻结骨干网络）**
- **目标**：训练自定义分类头，适应垃圾分类任务
- **策略**：冻结MobileNetV2所有层，仅训练新增的分类层
- **训练轮数**：10个epoch
- **优化器**：Adam，初始学习率=0.001
- **输出**：`phase1_checkpoint.h5`

#### **阶段二：全模型微调（解冻部分骨干）**
- **目标**：微调骨干网络后半部分，提升特征提取能力
- **策略**：解冻MobileNetV2第100层之后的所有层（约54层）
- **训练轮数**：15个epoch
- **优化器**：Adam，初始学习率=0.0001（比阶段一小10倍）
- **输出**：`garbage_classification.h5`

### 3.2 微调策略详解

```
MobileNetV2层级结构：
├── 第0-99层：冻结（保留ImageNet通用特征）
├── 第100-154层：解冻（适配垃圾分类特定特征）
└── 分类头：始终可训练
```

**解冻层数计算**：
- MobileNetV2总层数：约154层
- 冻结层数：100层
- 解冻层数：54层
- 可训练层比例：约35%

## 5. 优化器与学习率调度

### 5.1 优化器配置

| 阶段 | 优化器 | 初始学习率 | 权重衰减 |
|------|--------|-----------|----------|
| 阶段一 | Adam | 0.001 | 默认 |
| 阶段二 | Adam | 0.0001 | 默认 |

### 5.2 学习率调度

**ReduceLROnPlateau回调**：
- **监控指标**：验证损失（val_loss）
- **衰减因子**：0.5（学习率减半）
- **耐心值**：3个epoch
- **最小学习率**：
  - 阶段一：1e-6
  - 阶段二：1e-7

**学习率变化示例**：
```
阶段一：0.001 → 0.0005 → 0.00025 → 0.000125 → ...
阶段二：0.0001 → 0.00005 → 0.000025 → 0.0000125 → ...
```

### 5.3 早停策略

**EarlyStopping回调**：
- **监控指标**：验证准确率（val_accuracy）
- **耐心值**：
  - 阶段一：5个epoch
  - 阶段二：7个epoch
- **恢复最佳权重**：True

## 6. 正则化技术

### 6.1 Dropout正则化

- **位置**：分类头中两个全连接层之间
- **丢弃率**：30%（0.3）
- **作用**：防止过拟合，增强泛化能力

### 6.2 数据增强正则化

- **强度**：中等（旋转25°，平移20%）
- **目的**：增加训练数据多样性，减少过拟合风险

### 6.3 早停正则化

- **监控**：验证集性能
- **效果**：在验证集性能不再提升时停止训练
