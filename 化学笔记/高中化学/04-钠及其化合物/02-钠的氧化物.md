# 钠的氧化物

> [!abstract] 概览
> 钠有两种氧化物：**氧化钠 $\ce{Na2O}$**（白色，碱性氧化物）与**过氧化钠 $\ce{Na2O2}$**（淡黄色，过氧化物）。二者的阴离子不同（$\ce{O^{2-}}$ 与 $\ce{O2^{2-}}$），决定了它们性质的巨大差异。本笔记重点对比 $\ce{Na2O}$ 与 $\ce{Na2O2}$ 的组成、与水/$\ce{CO2}$ 的反应、$\ce{Na2O2}$ 的强氧化性与漂白性，以及"$\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$"这一高考高频反应的定量计算。

## 核心概念

- **$\ce{Na2O}$**：白色固体，属于碱性氧化物，氧元素为 $-2$ 价；与水、酸性氧化物反应生成碱和盐，但**无强氧化性、无漂白性**。
- **$\ce{Na2O2}$**：淡黄色固体，氧元素为 $-1$ 价（过氧根 $\ce{O2^{2-}}$，两氧原子间有一个共价键）；既显氧化性又显还原性，且有漂白性。
- **供氧反应**：$\ce{Na2O2}$ 与 $\ce{CO2}$、$\ce{H2O}$ 反应都能放出 $\ce{O2}$，因此用作呼吸面具和潜水艇的**供氧剂**。

## 重点知识

### 1. 组成与性质对比

| 对比项 | $\ce{Na2O}$ | $\ce{Na2O2}$ |
| --- | --- | --- |
| 颜色状态 | 白色固体 | 淡黄色固体 |
| 氧元素化合价 | $-2$ | $-1$ |
| 类别 | 碱性氧化物 | 过氧化物（非碱性氧化物） |
| 与水反应 | $\ce{Na2O + H2O -> 2NaOH}$（化合） | $\ce{2Na2O2 + 2H2O -> 4NaOH + O2 ^}$（有氧气放出） |
| 与 $\ce{CO2}$ 反应 | $\ce{Na2O + CO2 -> Na2CO3}$ | $\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$（有氧气放出） |
| 强氧化性 | 无 | 有（如使品红褪色、与还原剂反应） |
| 漂白性 | 无 | 有（靠强氧化性漂白） |
| 稳定性 | 较稳定，加热不分解 | 较稳定，但遇水、酸剧烈反应 |

> [!warning] 注意
> $\ce{Na2O2}$ 中氧元素的化合价为 $-1$ 价，既不是 $-2$ 价也不是 0 价；它与水、$\ce{CO2}$ 反应时，$\ce{Na2O2}$ **既作氧化剂又作还原剂**（歧化反应）。

### 2. 过氧化钠与水、二氧化碳反应（高频考点）

$$\ce{2Na2O2 + 2H2O -> 4NaOH + O2 ^}$$
$$\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$$

> [!tip] "固体增重"规律
> - 与 $\ce{CO2}$ 反应：每吸收 $2\ \mathrm{mol}$ 的 $\ce{CO2}$，放出 $1\ \mathrm{mol}$ 的 $\ce{O2}$，固体增重等于 $\ce{CO}$ 的质量（即 $2\ \mathrm{mol}\ \ce{CO2}$ 的质量减去 $1\ \mathrm{mol}\ \ce{O2}$ 的质量 = $2 \times 44 - 32 = 56\ \mathrm{g} = 2\ \mathrm{mol}\ \ce{CO}$ 的质量）。
> - 与 $\ce{H2O}$ 反应：每吸收 $2\ \mathrm{mol}$ 的 $\ce{H2O}$，放出 $1\ \mathrm{mol}$ 的 $\ce{O2}$，固体增重等于 $\ce{H2}$ 的质量（$2 \times 18 - 32 = 4\ \mathrm{g} = 2\ \mathrm{mol}\ \ce{H2}$ 的质量）。
> - 综合结论：**$\ce{CO2}$、$\ce{H2O}$ 的混合气通过足量 $\ce{Na2O2}$ 后，气体体积减半，固体增重等于相应组成"$\ce{CO}$ + $\ce{H2}$"的质量**。这是差量法计算的核心。

### 3. 过氧化钠的强氧化性与漂白性

- **漂白**：$\ce{Na2O2}$ 溶于水产生的 $\ce{H2O2}$ 或本身有强氧化性，能使品红溶液褪色、使有色布条褪色，属**氧化性漂白**（不可逆），区别于 $\ce{SO2}$ 的化合性漂白（可逆）。
- **强氧化性实例**：能把 $\ce{SO2}$ 氧化为 $\ce{Na2SO4}$：
  $$\ce{Na2O2 + SO2 -> Na2SO4}$$
  能把 $\ce{Fe^{2+}}$ 氧化为 $\ce{Fe^{3+}}$ 等。

> [!note] 电子式
> $\ce{Na2O}$ 电子式：$\ce{Na^+ [:\overset{..}{O}:]^{2-} Na^+}$；
> $\ce{Na2O2}$ 电子式：$\ce{Na^+ [:\overset{..}{O}:\overset{..}{O}:]^{2-} Na^+}$（含 $\ce{O—O}$ 非极性共价键）。

### 4. 用途

- $\ce{Na2O2}$：呼吸面具、潜水艇**供氧剂**；作漂白剂、氧化剂。
- $\ce{Na2O}$：性质与 $\ce{CaO}$ 类似，主要用于制 $\ce{NaOH}$。

### 5. 关于 $\ce{Na2O2}$ 与水反应的实验现象

将 $\ce{Na2O2}$ 放入水中：剧烈反应、放出大量热、产生能使带火星木条复燃的气体（$\ce{O2}$）；反应后溶液滴加酚酞变红（碱性），但红色会**逐渐褪去**（因 $\ce{H2O2}$ 的漂白/氧化作用）。这一"先红后褪"现象是高考常考点。

### 6. 常见漂白剂对比（漂白原理）

| 漂白剂 | 原理 | 是否可逆 |
| --- | --- | --- |
| $\ce{Na2O2}$、$\ce{H2O2}$ | 氧化性漂白（强氧化性） | 不可逆 |
| 氯水（$\ce{HClO}$）、$\ce{NaClO}$、漂白粉 | 氧化性漂白（$\ce{HClO}$ 强氧化性） | 不可逆 |
| $\ce{SO2}$ | 化合性漂白（与有色物质结合成不稳定无色物质） | 可逆（加热复原） |
| 活性炭 | 吸附性漂白（物理吸附） | 可逆（物理过程） |

> [!note] 联系
> $\ce{Na2O2}$ 漂白与氯水、$\ce{NaClO}$ 同属氧化性漂白，均可对比见 [[05-氯及其化合物/02-氯的化合物与含氯消毒剂|含氯消毒剂]]。

### 7. 过氧化钠的制备

- 钠在空气中**点燃**直接生成 $\ce{Na2O2}$：
  $$\ce{2Na + O2 \xrightarrow{\Delta} Na2O2}$$
- $\ce{Na2O}$ 在空气中继续加热也可转化为 $\ce{Na2O2}$（不完全氧化时产物中可能混有 $\ce{Na2O}$）。

## 典型例题

### 例题 1（供氧反应的气体体积计算）

**题目**：将 $78\ \mathrm{g}$ 的 $\ce{Na2O2}$ 与足量 $\ce{CO2}$ 反应，求生成 $\ce{O2}$ 在标准状况下的体积。

**分析**：$\ce{Na2O2}$ 摩尔质量为 $78\ \mathrm{g/mol}$。由方程式 $\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$ 可知 $\ce{O2}$ 与 $\ce{Na2O2}$ 的物质的量之比为 $1:2$。

**解答**：
$$n(\ce{Na2O2}) = \dfrac{78\ \mathrm{g}}{78\ \mathrm{g/mol}} = 1\ \mathrm{mol}$$
$$n(\ce{O2}) = \dfrac{1}{2} n(\ce{Na2O2}) = 0.5\ \mathrm{mol}$$
$$V(\ce{O2}) = 0.5\ \mathrm{mol} \times 22.4\ \mathrm{L/mol} = 11.2\ \mathrm{L}$$

**点评**：抓住"每 2 mol $\ce{Na2O2}$ 生成 1 mol $\ce{O2}$"，系数比是计算的关键。注意 $\ce{Na2O2}$ 的摩尔质量恰为 $78\ \mathrm{g/mol}$（$\ce{Na2O2}$ 式量），常被直接设为计算陷阱。

### 例题 2（固体增重/差量法）

**题目**：将 $2.24\ \mathrm{L}$（标准状况）$\ce{CO2}$ 与足量 $\ce{Na2O2}$ 反应，求固体质量的增加量。

**分析**：$\ce{2Na2O2 + 2CO2 -> 2Na2CO3 + O2}$。气体体积 $V=2.24\ \mathrm{L}$，物质的量 $n = V/V_m$。反应的"固体增重 = $\ce{CO}$ 的质量"，也可按差量法直接计算。

**解答**：
$$n(\ce{CO2}) = \dfrac{2.24\ \mathrm{L}}{22.4\ \mathrm{L/mol}} = 0.1\ \mathrm{mol}$$

由方程式，$0.1\ \mathrm{mol}$ 的 $\ce{CO2}$ 参与反应生成 $0.05\ \mathrm{mol}$ 的 $\ce{O2}$。固体增重为吸收的 $\ce{CO2}$ 质量减去放出的 $\ce{O2}$ 质量：
$$\Delta m = 0.1 \times 44 - 0.05 \times 32 = 4.4 - 1.6 = 2.8\ \mathrm{g}$$

（也可用"增重 = $n(\ce{CO2}) \times 28 = 0.1 \times 28 = 2.8\ \mathrm{g}$"，即 $\ce{CO2}$ 中"$\ce{CO}$ 部分"的质量。）

**点评**：差量法（增重/减重）是过氧化钠计算的灵魂。理解"每 2 mol $\ce{CO2}$ 吸收、1 mol $\ce{O2}$ 放出，净增重等于 2 mol $\ce{CO}$"这一规律，可快速口算。

## 易错提醒

> [!warning] 易错点
> 1. **$\ce{Na2O2}$ 中氧为 $-1$ 价**：不是 $-2$ 价，故既有氧化性又有还原性，与水/$\ce{CO2}$ 反应为歧化反应。
> 2. **$\ce{Na2O2}$ 不是碱性氧化物**：它与酸反应除生成盐和水外还放出氧气，不符合碱性氧化物的定义。
> 3. **颜色记忆**：$\ce{Na2O}$ 白色，$\ce{Na2O2}$ 淡黄色，常考颜色区分。
> 4. **漂白不可逆**：$\ce{Na2O2}$（及新制氯水、$\ce{H2O2}$、$\ce{NaClO}$）的漂白是氧化性漂白，不可逆；$\ce{SO2}$ 漂白可逆（加热复原）。
> 5. **"先红后褪"**：$\ce{Na2O2}$ 与水反应后的溶液加酚酞先变红后褪色，若答"变红"不够完整。
> 6. **供氧剂适用**：$\ce{Na2O2}$ 可与呼出的 $\ce{CO2}$ 和水蒸气反应供氧，但注意它有强氧化性和腐蚀性，不能直接接触皮肤。
