# 物质的量浓度与溶液配制

> [!abstract] 概览
> **物质的量浓度**是表示溶液组成的一种常用浓度：单位体积溶液中所含溶质的物质的量，$c = \dfrac{n}{V}$，单位 $\mathrm{mol/L}$。配制一定物质的量浓度的溶液是高中化学最重要的实验操作之一，涉及**容量瓶**的使用与系统的**误差分析**。本笔记整理物质的量浓度的概念与换算、稀释定律、配制步骤、容量瓶使用及误差分析，重点掌握"操作错误导致浓度偏高/偏低"的判断方法。

## 核心概念

- **物质的量浓度**：$c = \dfrac{n}{V}$，$V$ 是**溶液体积**（不是溶剂体积）。
- **稀释定律**：稀释前后溶质的物质的量不变，$c_1 V_1 = c_2 V_2$。
- **与质量分数的换算**：$c = \dfrac{1000 \rho w}{M}$（$c$ 单位 $\mathrm{mol/L}$，$\rho$ 单位 $\mathrm{g/mL}$，$w$ 为质量分数）。
- **配制步骤**：计算 → 称量（量取）→ 溶解（稀释）→ 冷却 → 转移 → 洗涤 → 定容 → 摇匀 → 装瓶。
- **容量瓶**：一种细颈、梨形的精确计量容器，只能用于配制溶液，不能久置、不能加热、不能作反应容器。

## 重点知识

### 1. 物质的量浓度

$$c = \dfrac{n}{V},\qquad n = c \times V$$

> [!warning] 体积是溶液体积
> 公式中的 $V$ 是**溶液的总体积**，不是水的体积。例如把 $0.1\ \mathrm{mol}\ \ce{NaCl}$ 溶于水配成 $1\ \mathrm{L}$ **溶液**，浓度才是 $0.1\ \mathrm{mol/L}$；若加 $1\ \mathrm{L}$ 水，体积大于 $1\ \mathrm{L}$，浓度小于 $0.1\ \mathrm{mol/L}$。

**粒子浓度**：
- $\ce{Na2SO4}$ 溶液中，$c(\ce{Na+}) = 2c(\ce{Na2SO4})$，$c(\ce{SO4^{2-}}) = c(\ce{Na2SO4})$。
- 例：$0.5\ \mathrm{mol/L}$ 的 $\ce{BaCl2}$ 溶液中，$c(\ce{Ba^{2+}}) = 0.5\ \mathrm{mol/L}$，$c(\ce{Cl^-}) = 1.0\ \mathrm{mol/L}$。

### 2. 稀释定律与混合

- **稀释**：溶质物质的量不变，$c_1 V_1 = c_2 V_2$。
- **混合**（体积可加时近似）：$c_{\text{混}} = \dfrac{n_1 + n_2}{V_1 + V_2}$。

### 3. 物质的量浓度与质量分数的换算

$$c = \dfrac{1000 \rho w}{M}$$

- $c$：$\mathrm{mol/L}$；$\rho$：$\mathrm{g/mL}$；$w$：质量分数（无量纲）；$M$：摩尔质量（$\mathrm{g/mol}$）。
- 推导：$c = \dfrac{n}{V} = \dfrac{m_{\text{溶质}}/M}{V_{\text{溶液}}} = \dfrac{1000 \rho V w / M}{V} = \dfrac{1000 \rho w}{M}$。

### 4. 配制一定物质的量浓度溶液（以 $\ce{NaCl}$ 固体为例）

**仪器**：托盘天平（或分析天平）、药匙、烧杯、量筒、玻璃棒、**容量瓶**（如 100 mL）、胶头滴管、试剂瓶。

**步骤**：
1. **计算**：$m = n \times M = c \times V \times M$。
2. **称量**：用托盘天平称取所需 $\ce{NaCl}$ 质量（精确到 0.1 g）。
3. **溶解**：在烧杯中加适量蒸馏水溶解，用玻璃棒搅拌。
4. **冷却**：冷却至室温（**必须冷却**，否则热胀导致误差）。
5. **转移**：沿玻璃棒将溶液转入容量瓶。
6. **洗涤**：用少量蒸馏水洗涤烧杯和玻璃棒 2–3 次，洗涤液一并转入容量瓶。
7. **定容**：加水至刻度线下 1–2 cm，改用胶头滴管逐滴加水至**凹液面最低点与刻度线相切**。
8. **摇匀**：盖好瓶塞，上下颠倒摇匀。
9. **装瓶**：转入试剂瓶并贴标签。

> [!warning] 容量瓶使用要点
> - 容量瓶不能加热、不能盛装过冷过热液体、不能作反应容器、不能长期存放溶液；
> - 容量瓶上标有**温度**（20℃）、**容积**（如 100 mL）和**刻度线**；
> - 定容时视线要与刻度线平齐，**俯视**读数会使浓度偏高，**仰视**会使浓度偏低；
> - 配制前要**检漏**。

### 5. 误差分析（高频考点）

以配制一定物质的量浓度的溶液为例，$c = \dfrac{n}{V}$：

| 操作 | $n$（或 $V$）变化 | 对 $c$ 的影响 |
| --- | --- | --- |
| 称量时药品与砝码放反（未用游码） | $m$ 不变 | 无影响 |
| 称量时药品与砝码放反（用了游码） | $m$ 减小 | 偏低 |
| 溶解后未冷却就转移、定容 | $V$ 偏小（热胀） | **偏高** |
| 转移时溶液溅出 | $n$ 减小 | 偏低 |
| 未洗涤烧杯和玻璃棒 | $n$ 减小 | 偏低 |
| 定容时俯视刻度线 | $V$ 偏小 | **偏高** |
| 定容时仰视刻度线 | $V$ 偏大 | **偏低** |
| 定容摇匀后发现液面低于刻度线 | — | **无影响**（液面下降是正常的，不能再加水） |
| 定容时加水超过刻度线 | $V$ 偏大 | 偏低（需重新配制） |

> [!tip] 误差记忆
> 凡是使溶质损失的（未洗涤、溅出、砝码放反）→ 浓度**偏低**；凡是使体积偏小的（未冷却、俯视）→ 浓度**偏高**；凡是使体积偏大的（仰视、加水过量）→ 浓度**偏低**。"摇匀后液面下降"是正常现象，不影响浓度。

## 典型例题

### 例题 1（配制一定浓度溶液的称量计算）

**题目**：配制 $100\ \mathrm{mL}$ 浓度为 $0.1\ \mathrm{mol/L}$ 的 $\ce{NaCl}$ 溶液，需要称取 $\ce{NaCl}$ 多少克？

**分析**：$n(\ce{NaCl}) = c \times V$，$m = n \times M$。注意 $V$ 用升（$100\ \mathrm{mL} = 0.1\ \mathrm{L}$），$\ce{NaCl}$ 摩尔质量为 $58.5\ \mathrm{g/mol}$。

**解答**：
$$n(\ce{NaCl}) = 0.1\ \mathrm{mol/L} \times 0.1\ \mathrm{L} = 0.01\ \mathrm{mol}$$
$$m(\ce{NaCl}) = 0.01\ \mathrm{mol} \times 58.5\ \mathrm{g/mol} = 0.585\ \mathrm{g}$$

**点评**：计算时务必把 $\mathrm{mL}$ 换算为 $\mathrm{L}$。托盘天平只能精确到 0.1 g，实际称量约 0.6 g；若用分析天平可精确称 0.585 g。

### 例题 2（稀释定律）

**题目**：将 $100\ \mathrm{mL}$ 浓度为 $2\ \mathrm{mol/L}$ 的 $\ce{H2SO4}$ 溶液稀释至 $500\ \mathrm{mL}$，求稀释后溶液的物质的量浓度。

**分析**：稀释前后溶质的物质的量不变，用 $c_1 V_1 = c_2 V_2$。

**解答**：
$$c_2 = \dfrac{c_1 V_1}{V_2} = \dfrac{2 \times 0.1}{0.5} = 0.4\ \mathrm{mol/L}$$

**点评**：稀释定律 $c_1 V_1 = c_2 V_2$ 的本质是"溶质的物质的量不变"。注意体积单位要一致（都用 L 或都用 mL）。

### 例题 3（质量分数与物质的量浓度换算）

**题目**：某浓盐酸的密度为 $1.19\ \mathrm{g/mL}$，质量分数为 37%，求其物质的量浓度（$\ce{HCl}$ 摩尔质量取 $36.5\ \mathrm{g/mol}$）。

**分析**：用公式 $c = \dfrac{1000 \rho w}{M}$ 直接计算。

**解答**：
$$c = \dfrac{1000 \times 1.19 \times 0.37}{36.5} \approx \dfrac{440.3}{36.5} \approx 12.1\ \mathrm{mol/L}$$

**点评**：质量分数与物质的量浓度的换算用 $c = \dfrac{1000\rho w}{M}$，注意 $\rho$ 用 $\mathrm{g/mL}$ 代入时，1000 是为了把 mL 换算成 L。

## 易错提醒

> [!warning] 易错点
> 1. **$V$ 是溶液体积**，不是溶剂体积：把 1 mol 溶质加到 1 L 水中，浓度不是 1 mol/L。
> 2. **容量瓶的使用限制**：不能加热、不能久置溶液、不能作反应容器、不能溶解固体。
> 3. **未冷却就转移**会使浓度**偏高**；定容时**俯视偏高、仰视偏低**，方向勿记反。
> 4. **摇匀后液面低于刻度线**是正常现象，**不能再加水**。
> 5. **定容时加水超过刻度线**：只能重新配制，不能倒出部分溶液。
> 6. **托盘天平的精度**：只能精确到 0.1 g；称量时左物右码。
> 7. **质量分数无单位、物质的量浓度有单位**（$\mathrm{mol/L}$），换算公式中的系数 1000 不能漏。

## 与其他知识关联

- 物质的量浓度公式 $c = n/V$ 与 [[01-物质的量与摩尔质量]] 的 $n = m/M$ 联用，可进行"质量 → 物质的量 → 浓度"的换算；
- 离子浓度计算（如 $\ce{BaCl2}$ 溶液中 $c(\ce{Cl^-})$）是"离子反应"与"电解质电离"的基础；
- 配溶液实验是化学实验基本操作的重点，与后续滴定实验（用容量瓶/滴定管）相关；
- 元素化学中的定量实验（如检验、除杂）也常结合溶液配制与浓度计算，见 [[04-钠及其化合物/00-钠及其化合物总览|钠及其化合物]]、[[05-氯及其化合物/00-氯及其化合物总览|氯及其化合物]]。
